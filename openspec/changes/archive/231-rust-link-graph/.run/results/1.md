## Changed

- Added `crates/core/src/graph.rs` with `NodeId`, `Location`, `Node`,
  `EdgeKind`, `Edge`, `Graph`, `Rule`, `Finding`, `run_rules` and `tag_id`,
  following rust-core "Link graph", "Tag ids" and "Link rules".
- Declared `pub mod graph;` in `crates/core/src/lib.rs` and re-exported the
  ten items from the crate root.
- Added `crates/core/tests/graph.rs`, proving node id display and order, edge
  kind names, location and finding display, graph queries and dangling edges,
  tag id cases, and rule order with the `dangling` and `quiet` rules.

## Deviated

- Added a second `graph-queries` test, `graph_queries_dangling_from`. The
  scenario's graph has no edge whose `from` names no node, so without it a
  mutant that drops the `from` half of `Graph::dangling` would survive.
- Kept the graph types in one `graph.rs` rather than splitting into
  `graph/*.rs`; the file is well under the function budget and one file keeps
  the module's `Implements` lines together.

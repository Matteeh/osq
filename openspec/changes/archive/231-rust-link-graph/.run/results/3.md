## Changed

- Copied `openspec/changes/231-rust-link-graph/fixtures/link-graph/` to
  `crates/kernel/linter/tests/fixtures/link-graph/` byte for byte with
  `cp -R`, then confirmed the trees are identical with `diff -r`.
- Added `osq-kernel-specs.workspace = true` to the linter crate, which adds
  `osq-kernel-specs` to the linter's `Cargo.lock` dependency list.
- Added `crates/kernel/linter/src/graph/`: `mod.rs` holds `GraphError` and
  `build_link_graph`'s re-export, `build.rs` orchestrates the build,
  `adr.rs` adds ADR nodes and ADR edges, `specs.rs` adds capabilities,
  requirements, scenarios and groups, and `files.rs` walks workspace
  members, adds file/item/test nodes, tag edges and ownership edges.
- Made `read_text`, `collect_rust_files`, `relative_slash_path` and
  `parse_members` in `workspace.rs` `pub(crate)`, leaving their behaviour
  unchanged, and reused them from the builder.
- Exported `GraphError` and `build_link_graph` from the crate root.
- Added `tests/link_graph.rs`, proving the fixture's nodes, edges, dangling
  edges, rebuild equality and error cases, and `tests/link_graph_corpus.rs`,
  proving every live tag line becomes an edge and the ADR and capability
  nodes match `read_decisions` and the living specs.
- Ran cargo-mutants over each new source file; every mutant is caught or
  unviable.

## Deviated

- Added the extra test `adr_numbers_need_digits` to `link_graph.rs`.
  cargo-mutants found two survivors in the ADR-number digit guard, and the
  fixture's all-digit targets cannot distinguish them. The test builds an
  ADR numbered `000` and tags with empty and `abc` targets, which pins the
  rule that a number stays as written unless both sides are ASCII digits.
- Kept `same_number` as a digit guard plus leading-zero comparison rather
  than parsing integers, so arbitrarily long numbers keep the spec's value
  comparison without overflow.

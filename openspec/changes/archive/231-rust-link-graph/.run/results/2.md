## Changed

- Copied the tag fixture byte for byte to
  `crates/kernel/linter/tests/fixtures/code-tags/lib.rs` with `cp`.
- Added `crates/kernel/linter/src/tags.rs` with `TagKind`, `Tag`,
  `CodeItem`, `CodeTags` and `code_tags`, following rust-linter "Code
  tags".
- Added `src/tags/collect.rs` (items, module/trait/impl qualification and
  visibility), `src/tags/doc_tags.rs` (doc attributes and tag lines) and
  `src/tags/item_macros.rs` (functions in item-level macros).
- Declared `pub mod tags;` in `src/lib.rs` and re-exported
  `CodeItem`, `CodeTags`, `Tag`, `TagKind` and `code_tags`.
- Added `tests/code_tags.rs`, proving "Items of the tags fixture" on the
  copied fixture and "Unparsable tag source".
- Added `tests/code_tags_edges.rs` with fast cases for source shapes the
  fixture cannot reach: unions, trait constants, impl constants, macro
  functions with modifiers, a macro function whose attribute is the first
  token, and bracket groups that are not attributes.

## Deviated

- Added `tests/code_tags_edges.rs`, as the task allows, because
  cargo-mutants found nine survivors the fixture cannot reach (union,
  trait constant, impl constant, `macro_rules!` guard, macro test
  detection, and the macro attribute walk). With those tests, all 76
  mutants over the four new source files are caught or unviable.
- Split the reader across `src/tags/*.rs` to stay under the 80-line
  function budget.

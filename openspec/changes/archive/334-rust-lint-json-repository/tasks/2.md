## Details

- Reuse `find::find_change`, `text::not_found`, `spec_line` and `merge_line` from `src/lint/`; the repository line is `repository: ` followed by what `spec_line` writes after the folder.
- The repository count line and header are TypeScript's `formatRepositoryCount` and `REPOSITORY_HEADER` in `src/core/spec/lint-output.ts`; copy their text, never import or read that file.
- Gather each other active change's `validate_change` findings once per run, then build each checked change's repository findings from them, so a run with many ids validates each change once.
- Keep the findings of each change as data, not only as lines, so task 3 can write the same findings as JSON; task 3 extends the files in `src/` after this task.
- Copy the fixture with the helpers in `tests/copy/mod.rs`, which no test changes.

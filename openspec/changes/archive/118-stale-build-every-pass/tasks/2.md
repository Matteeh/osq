## Acceptance

- [ ] `VcsFastForwardResult` gains an optional `changed`. `fastForward` in `src/core/vcs/git-vcs-land.ts` returns `done` with `changed` set to the sorted paths it already collects with `changedPaths`, and a `blocked` result has no `changed` field. In `tests/vcs-land-ops.test.ts`, only the `done` deep-equal changes, to `{ status: 'done', blocked: [], changed: ['b.txt'] }`, which covers the version-control delta's "Fast-forward reports changed paths". Every other line stays the same.
- [ ] `LandResult` gains `changed`, the absolute paths from the version-control delta's "Land reports changed paths": `landChange` joins each path of the `done` result to `(await vcs.root()) ?? projectRoot`, and every return without a land commit gives an empty list. `src/core/vcs/land.ts` stays within 250 lines.
- [ ] `landCommand` in `src/cli/land.ts` takes optional `allowStale` and `packageRoot`. Inside its `try`, before `loadConfig`, it calls `findStaleBuild` from `src/watcher/build.ts` with `allowStale` and `packageRoot`. When that returns a line, it writes only that line and a newline to `stderr` and calls `exit(1)`. After a land with code 0, it writes `osq's own source changed; run the build and restart the watcher` to `stdout` after the land's lines when a path in `changed` lies under the real path of `packageRoot ?? osqPackageRoot()` joined with `src`. Compare against the real path of each changed file's directory, climbing to the nearest directory that exists, since a land can delete files. `registerLandCommand` adds `--allow-stale` with the description `allow landing when dist/ is older than src/` and passes it through. No file under `src/cli/` calls `process.exit`.

## Changed

- `src/core/vcs/vcs.ts`: `VcsFastForwardResult` gains an optional `changed`.
- `src/core/vcs/git-vcs-land.ts`: `fastForward` collects the changed paths once, uses them for the blocked check, and returns them sorted as `changed` on `done`; a `blocked` result still carries no `changed`.
- `src/core/vcs/land.ts`: `LandResult` gains `changed`; `landCommit` returns the `fastForward` changed list; `landChange` joins each entry to `(await vcs.root()) ?? projectRoot`; every return without a land commit, including both cleanup outcomes, returns `changed: []`.
- `src/cli/land.ts`: `landCommand` takes injectable `allowStale` and `packageRoot`; inside `try` and before `loadConfig` it calls `findStaleBuild` and, on the stale line, writes only that line to stderr and exits one. After a zero-code land it prints `REBUILD_MESSAGE` when a changed path lies under `<packageRoot>/src`, resolving the package root and each changed file's nearest existing directory through real paths. `registerLandCommand` adds `--allow-stale` and passes it through.
- `tests/vcs-land-ops.test.ts`: the single `done` deep-equal now expects `changed: ['b.txt']`.
- `tests/vcs-land-stale.test.ts`: new coverage for stale land, allow-stale, land into osq itself, a linked package root, a consumer project, the `--allow-stale` help flag, and `landChange`'s changed paths for a land and for an already-landed cleanup.

## Deviated

Exported `REBUILD_MESSAGE` from `src/cli/land.ts` so the new test asserts the exact line instead of duplicating the string. No behavior change.

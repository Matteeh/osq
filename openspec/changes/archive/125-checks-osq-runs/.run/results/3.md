## Changed

- `src/core/status/dispatch-items.ts`: `DispatchKind` is now
  `'approval' | 'halt' | 'land'`; `KIND_RANK` dropped `verify`. Deleted
  `verifyItems` and the `path`, `changeTrees`, and `StatusOverview` imports it
  used. `readDispatchItems` no longer reads the overview's pending
  verifications.
- `src/core/status/dispatch-cards.ts`: deleted `VerifyCard` and `verifyCard`
  (and the `readVerification` import). `LandCard` gained `check` from
  `readCheckCommand` and `afterLanding` from `parseHumanSteps`, both read from
  the proposal the card already parses.
- `src/core/status/dispatch-text.ts`: deleted `verifyLines` and its case.
  `landLines` prints the check and after-landing steps after the squash message
  with the existing `scalar` and `block` helpers.
- `src/core/status/dispatch-keys.ts`: `MAPPED_VERBS` dropped `check` and
  `verified`, and their key cases left; those commands now fall through to
  `manual`.
- `src/core/status/inbox-projection.ts`: deleted `projectPendingVerifications`
  and `changeId`; `readInbox` applies blocked items to the projected needs-you
  group only.
- `src/core/status/inbox.ts`: `NeedsYouKind` dropped `verification-pending` and
  `verification-failed`.
- `src/core/status/inbox-text.ts`: dropped the two verification text lines.
- `src/core/report/report-inbox-wait.ts`: added a local
  `DispatchKind | 'verify'` type for the `Inbox waiting` kinds so old wait logs
  keep their `verify` bucket; the file stays within budget.
- `packages/ui/src/home/labels.ts`: dropped the two verification labels.
- `tests/dispatch-items.test.ts`, `tests/dispatch-cards.test.ts`,
  `tests/dispatch-keys.test.ts`, `tests/dispatch-order.test.ts`,
  `tests/inbox-next-step.test.ts`: stopped expecting verify items, verify
  cards, verification keys/labels/items. The order test's idle case now uses a
  heavy `land` item, and the card test asserts the land card's check and
  after-landing fields.
- `tests/dispatch-no-verify.test.ts` (new): covers "Each kind", "Verify keys",
  "Archived change with after-landing steps", and "Verify card" (a worktree
  land card whose check and steps print after the squash message).

`pnpm verify` passes (typechecks, build, suite, lint).

## Deviated

- Removed the obsolete verify-card and verify-key tests instead of rewriting
  them, because the new `dispatch-no-verify.test.ts` now owns the "Verify card"
  and "Verify keys" scenarios and the removed `kind`/verbs no longer exist to
  assert against. The land-card check/steps coverage from the old verify-card
  test moved into `dispatch-cards.test.ts` and the new file.
- `tests/inbox-next-step.test.ts` dropped its `createArchived` helper with the
  verification block it served; leaving it unused fails the lint.

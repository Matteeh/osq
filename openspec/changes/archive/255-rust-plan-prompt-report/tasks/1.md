## Details

Port the timing loop of `deriveMeasuredTask` in `src/core/report/report.ts`.
The accumulator in `outcomes.rs` needs each line's timestamp, so the caller
in `events.rs` passes it in. Read the timestamp with the crate's
`timestamp_ms`.

cargo-mutants runs on every line this task touches, so each branch must
change a value that a row checks. That covers the overwrite of a pending
start, the dropped pair with a later start, an `end` with no start, and the
rejected-snapshot filter.

Before exiting, run `cargo fmt --all`, then
`OSQ_CHANGE=openspec/changes/255-rust-plan-prompt-report sh scripts/verify-rust.sh`
so the link-gate corpus test sees this change's requirements.

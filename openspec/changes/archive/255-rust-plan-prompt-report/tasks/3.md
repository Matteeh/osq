## Details

Port `formatRecentDisclosures` from `src/core/report/recent-disclosures.ts`
and `formatManualEditsSection` from
`src/core/report/manual-edits-section.ts`. Read the disclosures from each
snapshot's `disclosures`, the archive time from `archive_time`, a change's
capabilities from its `deltas`, and the records from `read_manual_edits`.
Count and cut lengths in UTF-16 code units, as task 2 does for the history
cap.

`src/next/report.rs` belongs to task 2. Extend its reading function with
`read_manual_edits` and its section builder with the two new sections, and
change nothing else in it.

The corpus test links each file of every archived folder numbered 001 to
251 into its scratch root with `std::fs::hard_link`, and falls back to
`std::fs::copy` when linking fails. It does the same for each
`openspec/manual/*.md` whose `kept_at` is before
`2026-10-21T16:00:00.000Z`. It writes the queue
`## [next] Next\n\nDepends on: nothing\n\nNext.\n` and runs
`PlanFeature::at(1792584000000)`. When it fails, print the first line that
differs.

cargo-mutants runs on every line this task adds, but not on corpus tests,
so each branch must change a value that a fast row checks. That covers each
section kind, the empty-section skip, the three-change window, the cut and
its 11-unit floor, the trailing-newline trim, and the archive-time
comparison both as timestamps and as text.

Before exiting, run `cargo fmt --all`, then
`OSQ_CHANGE=openspec/changes/255-rust-plan-prompt-report sh scripts/verify-rust.sh`.

## Changed

- Added `src/next/report.rs`: one function reads `read_history` and the living ownership, and a pure builder turns storage values into the text after `## Brief`; an unreadable archive fails with `Cannot read the archive: <error>` before any folder is written.
- Added `src/next/report/record.rs` for the `## This repository's record` body: the 20-snapshot window, measured tasks, largest first-attempt pass, median duration and first ten dead outcomes.
- Added `src/next/report/hints.rs` for the `## What history says` body: the 30-row minimum, the 100-row newest window, the counted lines and the 1500 UTF-16 code unit cap.
- `src/next.rs` now reads the sections before `write_folder`, appends the pure builder's text after `prompt::build`, and builds the first sections in `prompt_text` instead of the former `write_prompt`.
- `tests/fixtures/plan-created/005-beta/plan-prompt.md` now equals `openspec/changes/255-rust-plan-prompt-report/golden/005-beta-plan-prompt.md` byte for byte.
- `tests/prompt_sections.rs` appends `<record>` to every expected prompt.
- Added `tests/prompt_record.rs` for every "Repository record bodies" row and "Archive that cannot be read", plus median and numeric-order edge cases.
- Added `tests/prompt_history.rs` for every "History hint bodies" row, plus window-ordering and character-cap cases.

## Deviated

- The character cap and window-order checks use a test-only `include!` of `hints.rs` so the private `fit_lines` and `newest_first` can be reached with fabricated rows; the file is the real source, and the module carries `#[allow(dead_code)]` for the functions those cases do not call. Without it the cap is unreachable from typed archive data, whose dead reasons are a fixed short enum. The scenario rows themselves still run `plan --next` on roots under `CARGO_TARGET_TMPDIR`.
- `report.rs` doc comments sit on the `mod hints;` declaration and `hints.rs` begins with a plain comment, so the same file can be included in that test.

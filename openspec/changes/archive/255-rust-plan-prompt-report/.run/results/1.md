## Changed

- Added `start_scope_resolver` and `measured_ms` to `TaskOutcomeFacts`, filled from the task stream's `measures` events using each line's `timestamp_ms`.
- Taught the outcome accumulator to overwrite a pending start, drop a pair whose end precedes its start, ignore an end without a start, and sum every valid start-to-end pair.
- Renamed the private `TaskOutcomeRow` to the public `TaskOutcome` with public table-column fields.
- Added the public `task_outcomes(snapshots, ownerships)` query, filtered to archived snapshots, and exported it with `TaskOutcome` from the crate root.
- Routed `insert_task_outcomes` through the query so the read model stores exactly the values the query returns.
- Added `tests/reading_measured.rs` covering every row of the measured-facts table and a task without a stream.
- Added `tests/task_outcome_query.rs` comparing the query rows field by field with `task_outcomes.json` and proving rejected snapshots yield no row.

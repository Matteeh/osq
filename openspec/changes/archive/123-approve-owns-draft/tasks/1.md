## Details

A worktree holds its change only when its changes directory holds
`<folder>/.run/approved`, as "Change locations" says, so write that file in
the worktree's copy. The stacked approval directory is
`<vcs.worktreeRoot>/<repo>/.stacked/<folder>`; `stackedPath` in
`src/core/vcs/worktree.ts` builds it. Point `vcs.worktreeRoot` at a
temporary directory.

`loadConfig` loads the project's `.env` into `process.env`, which is why
`createNewSpec` takes the config from its caller instead of loading it.

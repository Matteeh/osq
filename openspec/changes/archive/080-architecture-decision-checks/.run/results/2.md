- `src/core/spec/digest-decisions.ts`: `DigestDecisionTask` projection (number,
  `testsModify`, resolved scope paths) and a `checkFlags` rule that raises one
  `adr_check_modified` flag per task with `tests.modify: true` and per accepted
  ADR check file in its resolved scope, in task-number, ADR number, and check
  file order. `collectDigestDecisions` takes the projections and returns the
  departure flags followed by the check flags.

  `buildApprovalDigest` builds the task projections from resolved task entries
  and passes them to `collectDigestDecisions`.

  after `adr_departure`.

  recorded by `approveSpec`, and counted in `osq report`; without
  `tests.modify` no flag fires and `runTask` with an adapter that edits the
  check file dies with `undeclared_test_change`.
- `tests/report-approval-flags.test.ts`, `tests/report-json.test.ts`, and
  `fixture/report/expected.json`: the new key with zero counts.

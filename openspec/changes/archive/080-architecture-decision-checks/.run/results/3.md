## Changed

- Added `src/watcher/dependencies.ts`:
  - `readScopedDependencies(projectRoot, scope)` resolves scope and maps each
    scoped `package.json` (by file name) to its sorted distinct names from
    `dependencies`, `devDependencies`, `peerDependencies`, and
    `optionalDependencies`; missing/unreadable files map to `[]` and unscoped
    files are never read.
  - `checkDependencies(options, fail)` reads the latest `measures` start
    event's `dependencies`, compares it with each manifest's current names,
    appends one `dependencies_added` event with the sorted new `{ file, name }`
    pairs, and fails `denied_dependency` when an accepted ADR denies an added
    name (proposed/superseded denied names are ignored). Marker body starts
    `The task added packages an accepted ADR denies:` with
    `- <name> in <file>: ADR <number>: <rule>` lines.
- `src/watcher/measures.ts`: `gatherStartMeasures` adds the new module's
  `readScopedDependencies` call and emits `dependencies` only when non-empty.
- `src/harness/types.ts`: added `dependencies_added` to `HarnessEventType`,
  `DependenciesAddedEventData` to the event map, and the optional
  `dependencies` field on `MeasuresEventData`.
- `src/watcher/failure-reason.ts`: added `denied_dependency`.
- `src/watcher/auto-retry.ts`: added `denied_dependency` after
  `verify_path_missing` in `ELIGIBLE_AUTO_RETRY_REASONS`.
- `src/watcher/task-verify.ts`: `checkBlockedFirst` now takes
  `TaskVerifyOptions` and runs `checkDependencies` between the blocked check
  and `checkMissingVerifyPaths`.
- `src/watcher/runner.ts`: call is now `checkBlockedFirst(verifyCtx, fail)` on
  one line; file stays 199 lines.
- Added `tests/denied-dependency.test.ts` covering the baseline (scoped and
  outside scope), allowed addition, denied dependency (event data, marker
  lines, no post-spawn verify), superseded denial, and the automatic retry's
  `priorFailureOutput`.

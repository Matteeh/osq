## Changed

- `src/core/report/stream-reads.ts`: `withStreamReads` now takes an optional
  `StreamIndex`; the ambient scope holds the parser cache plus that index.
  `readEventStream` for a covered path stats the file, returns re-frozen
  indexed events on a path/size/mtime hit, and on a miss reads and parses the
  file and stores the events JSON. Non-covered paths and `readParsedFile` read
  exactly as before.
- `src/core/report/report.ts`: added `MetricsReportOptions extends
  InboxWaitOptions` with `index?: boolean` (default false). `getMetricsReport`
  with `index: true` opens `openStreamIndex` for the change tree's archive
  folder before the scope and closes it in a `finally`, falling back to the
  file-only scope when the index cannot be opened. `buildMetricsReport` is
  unchanged.
- `src/cli/report.ts`: `reportCommand` passes `index: true`.
- `decisions/008-sqlite-read-index.md` (new): accepted ADR for the derived
  SQLite read index, `applies_to: [metrics-and-reporting]`, the rule under
  `## Rule`, `checks: [tests/report-index.test.ts]`, and Status, Context,
  Decision, Consequences and Rejected sections drawn from the proposal's
  Background.
- `decisions/README.md`: added the ADR 008 index line.
- `tests/report-index.test.ts` (new): copies the `fixture/report` archive
  fixture into a temp project under `openspec/changes/archive` and covers the
  cold/warm-index deep equality, a warm run reading no archived event stream,
  and the deleted, corrupt, locked, appended-line and removed-archive scenarios,
  each deep-equaling the report without an index.

## Deviated

- The warm-run read check counts archived event streams (`.run/events/*.jsonl`)
  rather than every archived `.jsonl`. `plan.jsonl` is also an archived
  `.jsonl` but is a non-goal to index and stays read from files, so counting it
  would contradict the delta scenario "reads no archived event stream from
  disk". The index covers only the event streams the report reads through
  `readEventStream`.

  `<tmp>/openspec/changes/archive` so the change tree's archive folder is the
  one the index covers; the fixture's files are unchanged.

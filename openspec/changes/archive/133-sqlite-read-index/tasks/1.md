## Acceptance

- [ ] `src/core/report/stream-index.ts` exports the port below. It loads `node:sqlite` with a dynamic `import` and uses `DatabaseSync`; when the import fails, `openStreamIndex` resolves to null.
- [ ] `openStreamIndex` creates `<projectRoot>/.osq/` when missing, writes `.osq/.gitignore` holding `*` when that file is missing, and opens `.osq/index.sqlite` in WAL mode with a zero busy timeout.
- [ ] The database holds a `meta` table with a schema version and a `streams` table of path, size, modification time and events JSON. An index with another schema version is emptied and rebuilt. A file that is not a SQLite database is deleted with its `-wal` and `-shm` files and created again; if that fails too, `openStreamIndex` resolves to null.
- [ ] `lookup` returns the stored events JSON only when path, size and modification time all match, and null otherwise. `store` replaces the row for a path.
- [ ] `close` deletes every row whose path `lookup` was not called with in this session and whose file no longer exists, then closes the database.
- [ ] No method throws. While another connection holds a write lock (`BEGIN IMMEDIATE`), `store` and `close` give up silently and `lookup` still works or returns null.
- [ ] `tests/report-index-store.test.ts` covers each line above in a temporary project, except a missing `node:sqlite`.

## Port

```ts
export interface StreamIndex {
  /** True when the path lies under the archive folder this index covers. */
  covers(filePath: string): boolean;
  lookup(filePath: string, size: number, mtimeMs: number): string | null;
  store(filePath: string, size: number, mtimeMs: number, eventsJson: string): void;
  close(): void;
}

export function openStreamIndex(
  projectRoot: string,
  archiveDir: string,
): Promise<StreamIndex | null>;
```

## Details

Paths are absolute, resolved with `path.resolve`. `covers` is true for a path
inside `archiveDir`. The schema version and file names are constants in the
module. The module reads and writes nothing outside `<projectRoot>/.osq/`.
No other file changes in this task; task 2 connects the index to the report.

## Acceptance

- [ ] `withStreamReads` takes an optional `StreamIndex`. Inside a scope with an index, `readEventStream` for a path the index `covers` stats the file, returns the indexed events on a hit, and on a miss reads and parses the file as today and stores the result. Everything else reads as today, and the events callers get are the same frozen, log-free events in both cases.
- [ ] `getMetricsReport` takes a new `MetricsReportOptions`, which extends `InboxWaitOptions` with `index?: boolean`, default false. With `index: true` it opens the index for the change tree's archive folder before the scope and closes it after, even when the report throws. `reportCommand` in `src/cli/report.ts` passes `index: true`; no other caller changes.
- [ ] `decisions/008-sqlite-read-index.md` is an accepted ADR in the format of `decisions/007-role-environments.md`, with `applies_to: [metrics-and-reporting]`, the rule below, `checks: [tests/report-index.test.ts]`, and sections Status, Context, Decision, Consequences and Rejected drawn from the proposal's Background. `decisions/README.md` gains its index line.
- [ ] `tests/report-index.test.ts` copies `fixture/report` into a temporary project laid out under `openspec/changes/archive`, and checks that `getMetricsReport` with `index: true` deep-equals it without, on a cold and a warm index, and that the warm run reads no archived `.jsonl` with `fs.readFile`.
- [ ] The same test covers the delta's scenarios: a deleted index, a corrupt index file, a lock held through a second `DatabaseSync` with `BEGIN IMMEDIATE`, a line appended to an archived `change.jsonl`, and a removed archive folder. Each report deep-equals the one without an index.
- [ ] Every existing test passes unchanged.

## ADR rule

```
SQLite is only a derived read index of osq's files; deleting it changes nothing but speed, and no state lives only in it.
```

## Details

`getMetricsReport` already finds the archive folder through `changeTrees`; use
the same tree for the index. Keep the wrapper small: `buildMetricsReport` is
grandfathered by the function budget and must not change. `src/cli/report.ts`
and `report.ts` are on the line-budget allow list; `stream-reads.ts` must stay
under 250 lines.

The ADR's Rejected section names the two alternatives the Background measured:
`~/.osq/index/`, which tests filled in the real home, and using the index in
`osq serve`, which the web-inspection spec forbids.

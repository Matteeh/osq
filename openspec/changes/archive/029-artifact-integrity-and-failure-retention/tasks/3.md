## Acceptance
- [ ] src/cli/index.ts and src/cli/done.ts register osq done <id> <n> with required --manual <reason> option
- [ ] src/core/done.ts writes .run/done/<n> with YAML frontmatter manual: true and reason, ticking the task checkbox in tasks.md
- [ ] src/core/done.ts and src/harness/types.ts append a typed done_manual event to .run/events/<n>.jsonl
- [ ] src/core/doctor.ts inspects done markers and reports any marker lacking valid automated or manual frontmatter
- [ ] src/core/report.ts counts manual task completions separately from verified ones in TaskMetrics, formatted tables, and JSON
- [ ] tests/done-manual.test.ts verifies osq done writes marker, appends event, and ticks checkbox
- [ ] tests/done-manual.test.ts and tests/doctor.test.ts verify doctor detection of hand-placed markers and separate report counting

## Details

1. In `src/harness/types.ts`:
   - Add `'done_manual'` to `HarnessEventType`.
   - Define `DoneManualEventData`:
     ```typescript
     export interface DoneManualEventData {
       readonly task: string;
       readonly reason: string;
     }
     ```
   - Add `done_manual: DoneManualEventData` to `OsqEventData`.

2. In `src/core/done.ts`:
   - Implement `markTaskDoneManual(projectRoot: string, specIdOrPrefix: string, taskNumber: string, reason: string, config: OsqConfig)`:
     - Find spec folder using `findSpecFolder`.
     - Verify task exists in `tasks/${taskNumber}.md` or `tasks.md`.
     - Write `.run/done/${taskNumber}` with content:
       ```
       ---
       manual: true
       reason: ${JSON.stringify(reason)}
       ---
       ${new Date().toISOString()}
       ```
     - Append `done_manual` event to `.run/events/${taskNumber}.jsonl`.
     - Tick task checkbox in `tasks.md` if present.

3. In `src/cli/done.ts` & `src/cli/index.ts`:
   - Create `doneCommand(id: string, taskNumber: string, options: { manual?: string })`.
   - Register in `src/cli/index.ts`:
     ```typescript
     program
       .command('done <id> <task>')
       .description('mark a task done manually with required justification')
       .requiredOption('--manual <reason>', 'reason for manual completion')
       .action(async (id: string, task: string, options: { manual: string }) => {
         await doneCommand(id, task, options);
       });
     ```

4. In `src/core/doctor.ts`:
   - Add `checkDoneMarkers(projectRoot: string, config: OsqConfig)` check:
     - For active changes under `openspec/changes/`:
       - Inspect all files in `.run/done/`.
       - Parse frontmatter with `parseFrontmatter`.
       - Valid if:
         - has `scope_hash` (automated)
         - OR has `manual === true` and `typeof reason === 'string'` (manual)
       - If invalid or missing frontmatter, flag as failure:
         `unverified done marker placed by hand: ${relPath}`.
     - Add to `runDoctorChecks`.

5. In `src/core/report.ts`:
   - Add `verified: number` and `manual: number` to `TaskMetrics`.
   - In active specs: read `.run/done/<n>` frontmatter. If `manual === true`, increment `manualDone`; else increment `verifiedDone`.
   - In archived specs: check terminal events for `done_manual` or `manual: true` in marker.
   - Format human-readable output to show verified and manual counts.

6. In `tests/done-manual.test.ts` and `tests/doctor.test.ts`:
   - Assert all acceptance criteria.

7. Verify:
   `node --import tsx --test tests/done-manual.test.ts tests/doctor.test.ts`

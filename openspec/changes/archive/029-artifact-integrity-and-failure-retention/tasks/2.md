## Acceptance
- [ ] approveSpec inspects .run/dead/ and renames any active dead/<n>.md to dead/<n>.<attempt>.md based on existing attempts
- [ ] Attempt number is derived from existing files: 1 if no dead/<n>.*.md exists, or max(existing attempts) + 1
- [ ] src/watcher/runner.ts eliminates the deletion of dead/<n>.md upon successful task completion
- [ ] Re-approving a spec with a prior dead task allows the task to run while preserving dead/<n>.<attempt>.md diagnostics
- [ ] tests/dead-marker-retention.test.ts asserts that re-approval renames dead/1.md to dead/1.1.md and subsequent re-approval to dead/1.2.md
- [ ] tests/dead-marker-retention.test.ts asserts that both dead/1.1.md and done/1 exist after task rerun succeeds

## Details

1. In `src/core/approve.ts`:
   - Before writing `.run/approved`, inspect `path.join(runDir, 'dead')`.
   - If directory exists, read entries.
   - For each file matching `^(\d+)\.md$`:
     - Extract `taskNumber = match[1]`.
     - Find all existing attempt files for this task: matching `new RegExp(`^${taskNumber}\\.(\\d+)\\.md$`)`.
     - Compute `nextAttempt`: if no matches, `1`; otherwise `Math.max(...matchedNumbers) + 1`.
     - Rename `dead/${taskNumber}.md` to `dead/${taskNumber}.${nextAttempt}.md`.

2. In `src/watcher/runner.ts`:
   - Locate line where `fs.unlink(path.join(runDir, 'dead', `${taskNumber}.md`))` is called.
   - Delete this `fs.unlink` call. Nothing under `.run/` should be deleted by the runner.

3. In `tests/dead-marker-retention.test.ts`:
   - Test that `approveSpec` on a change with `dead/1.md` renames it to `dead/1.1.md`.
   - Test that a second failure (`dead/1.md`) and re-approval renames it to `dead/1.2.md`.
   - Test that when runner executes and completes task 1, `dead/1.1.md` is retained alongside `done/1`.

4. Verify:
   `node --import tsx --test tests/dead-marker-retention.test.ts`

  directly after `maxConcurrency: 1,`. No other key changed.
- Rewrote `tests/no-skipped-in-src.test.ts`: it now calls `loadConfig(REPO_ROOT)`
  and, for every `bannedWords` entry, resolves `entry.paths` through
  `resolveScope`, reads every matched file, and fails naming the offenders when
  any file contains `entry.word` ignoring case. A `findBannedWordFiles` helper
  asserts at least one entry exists and that each entry's paths match a file, so
  the check still fails when no entry is configured or an entry matches nothing.
  The repository check no longer hard-codes the word or `src/`; the synthetic
  cases use `legacy` under `lib/**`.
- Added `tests/own-banned-words.test.ts`: one plain `node:test` block asserting
  `loadConfig(REPO_ROOT).bannedWords` deep-equals
  `[{ word: 'skipped', paths: ['src/**'] }]`.

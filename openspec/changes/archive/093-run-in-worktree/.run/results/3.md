## Changed

- `src/core/vcs/vcs.ts`: the `Vcs` port gains the `show(ref, path)` read and the `worktreePrune()` write.
- `src/core/vcs/git-vcs.ts`: implements `show` (`git show <ref>:<path>`, null on a non-zero exit) and `worktreePrune` (`git worktree prune`, throwing git's combined output on failure) directly, leaving `git-vcs-write.ts` untouched.
- `src/core/vcs/no-vcs.ts`: `show` returns null and `worktreePrune` rejects naming the reason git is off.
- `src/core/spec/approve-worktree.ts`: the existing `runPrepare` step is now exported so recreation runs the same prepare as approval.
- `src/core/vcs/worktree-recreate.ts` (new): `recreateWorktrees(projectRoot, config)` finds every `osq/` branch whose worktree is missing (none listed, or listed with a gone directory), prunes stale records once, and for each branch whose tip still holds `<changes>/<folder>/.run/approved` adds the worktree at the "Worktree location" path, runs prepare, and returns a `recreated worktree <path> for <folder>` line; a per-branch failure becomes an error line and the rest continue; it returns nothing under `NoVcs` or with `vcs.enabled` off.
- `src/cli/watch.ts`: `watchCommand` runs `recreateWorktrees` before `startWatcher` and logs each returned line through its logger.
- `tests/vcs-write.test.ts`: added only `show` and `worktreePrune` to `PORT_MEMBERS`.
- `tests/vcs-worktree-recreate.test.ts` (new): covers `show` at a branch, `worktreePrune`, the deleted-directory and removed-worktree recreations (including the next task running in the recreated worktree), the archived-change and flag-off non-recreations, and the `NoVcs` no-op.

## Deviated

- Kept the prepare helper's name `runPrepare` and only exported it, rather than renaming it.
- Added a direct `recreateWorktrees` unit case for the `NoVcs` no-op, beyond the four named recreation scenarios, because the requirement names `NoVcs` alongside the flag-off case.
- The archived-change test builds a branch whose tip holds the change only under `changes/archive/` by committing through a short-lived temp worktree, then removes that worktree so the branch has no worktree when `osq watch` starts.

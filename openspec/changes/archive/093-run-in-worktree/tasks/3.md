## Details

Run `watchCommand` in tests with `{ once: true, allowStale: true }` after
`process.chdir` into a temporary repository whose `osq.config.ts` exports
`harness: 'mock'` and a `vcs` block with `worktreeRoot` inside the temporary
directory; restore the directory afterwards. Approve with `approveSpec` as
`tests/approve-worktree.test.ts` does. The branch tip's path to
`.run/approved` is the changes directory from `changesDirLabel`, the folder,
and `.run/approved`, with forward slashes. A deleted worktree shows in
`worktreeList` with its old path, so compare each listed path with the file
system. Get the `Vcs` through `selectVcs`; never import `GitVcs`.

Commit `verify.cjs` in the temporary repository before approving: a worktree
holds only committed files, and `tests/approve-worktree.test.ts` writes it
after its seed commit.

## Details

Put the new loop behaviour in new `src/watcher/worktree-*.ts` modules that
`runWatcherCycle` calls only when `change.tree.worktreeFolder` is set; keep
`loop.ts` to the calls. Get the `Vcs` with `selectVcs` on the tree root; never
import `GitVcs`. Commit paths are relative to `vcs.root()`. Match status paths
to a task's scope with `scopeCoversPath`. Halt with `writeRegressedMarker` and
`recordRegressedEvent` from `outcome.ts`, target `change`. Build outcome lines
with `formatTaskOutcomeLine`, symbols off. Read the proposal's title before the
archiver moves the folder. A failed `commit` throws an error whose message
holds git's output.

In tests, approve into a worktree with `approveSpec` as
`tests/approve-worktree.test.ts` does, run `runWatcherCycle` from the checkout,
and copy `ActingAdapter` from `tests/vcs-guard.test.ts` to edit files under the
adapter's `projectRoot`. Hooks live in the main repository's `.git/hooks`. A
reaped lock is `.run/running/<n>.pid` naming a process that does not exist, as
`reapStaleLocks` in `src/core/run/lock.ts` reads it. Set `gates.autoRetries` to
0 where a retry would hide the state a scenario checks.

Commit `verify.cjs` in the temporary repository before approving: a worktree
holds only committed files, and `tests/approve-worktree.test.ts` writes it
after its seed commit.

## Details

commit the change folder on that branch before writing `.run/approved` from
`hashChangeFolder`, or approve with `approveSpec` as
`tests/approve-worktree.test.ts` does. Pass the worktree path as
`projectRoot`. Reuse `ActingAdapter`, `prepareChange`, and the git helpers of
`tests/vcs-guard.test.ts` by copying them into the new test. Take the
`vcs_violation` marker body from `formatVcsViolationWarning`. Get the `Vcs`
through `selectVcs`; never import `GitVcs`.

Commit `verify.cjs` in the temporary repository before approving: a worktree
holds only committed files, and `tests/approve-worktree.test.ts` writes it
after its seed commit.

## Details

TypeScript's `\s` is Rust's `char::is_whitespace` without U+0085 and with
U+FEFF. Never read anything under `src/` from Rust; `src/` is in `entry` only
so you can port it. `golden/print-prompts.mjs.txt` in the change folder is the
script that printed the goldens from TypeScript's built `dist`; do not run it.

## Changed

- Added the `osq-feature-manual` crate for rust-manual, with `ManualFeature` and its `manual` command, argument checks, and the config, vcs and path refusals in TypeScript's order.
- Registered `ManualFeature::new()` after `RetryFeature` and added the crate to the workspace and CLI.
- Copied the manual fixture and goldens into the crate, then added `tests/feature.rs` and `tests/manual_refusals.rs`; the latter drives the nine refusal cases through the `cases.json` runner in `tests/support/mod.rs`.
- Added path-rule and tracked-change tests beyond the goldens so cargo-mutants finds no missed mutant, as the task details ask.

## Deviated

- `ManualFeature::new()` still leaves the clock open, and the placeholder `keep` ignores it. Resolving the system clock cannot change any task 1 result while nothing writes a record, so task 2 must resolve it when it writes the keep time. `ManualFeature::at(now_ms)` exists and keeps `now_ms`.

## Next

Task 2's "Manual keep equals TypeScript's" replaces the placeholder keep and should resolve `ManualFeature::new()`'s system clock at that point.

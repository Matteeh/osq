## Details

Port the refusal half of `keepManualEdits`: `refusedNamedPath`, `namesEntry`
and `selectEntries`, with `path.posix.normalize` written as a small pure
function. Ask `project_git_root` whether git is on: `Err` is refusal 2,
`Ok(None)` refusal 3, and `Ok(Some(_))` gives the root for `GitVcs::new`
with `with_timeouts(&config.timeouts)`. Read `status()` through the `Vcs`
trait.

The case runner reads `cases.json` with `serde_json`, copies the fixture,
writes `osq.toml`, and runs git and every step with `std::process::Command`
as the script does. Give each case its own fresh folder under
`std::env::temp_dir()`, named `osq-manual-<case>` with this process's id,
because `CARGO_TARGET_TMPDIR` sits inside this repository and the `no-git`
case needs a folder in no repository. Canonicalize the scratch folder before
writing `<root>` and `<top>`, as `nested.txt` shows. Remove the folder when
the case ends. The runner compares the whole dump with the golden file. For
`block`, the golden's `osq.config.ts` is replaced with `osq.toml` before
comparing.

When the mutation check reports a missed mutant, add a case to the test
rather than keeping a branch no test reaches. Take the expected value from
the TypeScript source. Run the proposal's verify as the watcher does, with
`OSQ_CHANGE=openspec/changes/338-rust-manual-command`, so the link gates see
the new capability and its ownership. `Cargo.lock` follows the root
`Cargo.toml`; it needs no scope line.

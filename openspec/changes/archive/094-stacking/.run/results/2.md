## Changed

- `src/core/status/change-locations.ts`:
  - `ChangeTree` gains optional `stackedFolder`.
  - `treeAt` now takes a `{ worktreeFolder?, stackedFolder? }` refs object and emits whichever is set.
  - New `stackedRoot(vcs, repoRoot)` derives the `.stacked` directory as the parent of `stackedPath(vcs, repoRoot, <folder>)`, so no path is named by hand.
  - `changeTrees` records worktree-named folders, then appends one tree per directory directly under the stacked root, rooted at that directory and carrying `stackedFolder`, skipping a folder a worktree tree already names. A missing stacked root adds nothing (`readdir` catch).
  - `listChanges` collects worktree and stacked folder names together, has a stacked tree contribute only the folder it names, and drops the project root's active folder when any such tree names it.
- `tests/change-locations-stacked.test.ts` (new): covers "Stacked change", "Stacked folder with a worktree", and "Stacked directory with the flag off".

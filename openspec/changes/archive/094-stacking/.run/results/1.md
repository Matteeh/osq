## Changed

- `src/core/vcs/vcs.ts`: added the read `pathExists(ref, path): Promise<boolean>` to the `Vcs` interface, after `show`.
- `src/core/vcs/git-vcs.ts`: implemented `pathExists` with `git cat-file -e <ref>:<path>` through the same bounded read runner `show` uses, returning `true` only on exit code 0.
- `src/core/vcs/no-vcs.ts`: implemented `pathExists` to return `false`.
- `src/core/vcs/worktree.ts`: added `stackedPath(config, repoRoot, folderName, home?)`, returning `<vcs.worktreeRoot>/<repo>/.stacked/<folder>` with the leading `~` expanded as `worktreePath` does.
- `tests/vcs-write.test.ts`: added `pathExists` to `PORT_MEMBERS`; no other change.
- `tests/vcs-path-exists.test.ts` (new): covers the "Path at a branch" scenario (directory, file, missing path, absent path on the default branch, unknown ref, and `NoVcs`) and the "Stacked approval path" scenario (configured root, `~/` expansion, and the default root).

Touched: src/core/vcs/vcs.ts, src/core/vcs/git-vcs.ts, src/core/vcs/no-vcs.ts, src/core/vcs/worktree.ts, tests/vcs-write.test.ts, tests/vcs-path-exists.test.ts

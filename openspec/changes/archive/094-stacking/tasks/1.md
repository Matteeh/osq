## Details

In `GitVcs`, run `git cat-file -e <ref>:<path>` through the bounded read
runner that `show` uses, and return true only for exit code 0. A missing ref
exits non-zero, so it reads as false. Build the test repository the way
`tests/vcs-write.test.ts` does, with its clean git environment.

## Acceptance

- [ ] New `src/core/spec/stack-cut.ts` exports the decision for one stacked change, which is wait, halt with a reason and detail, or cut with a base. It also exports the cut itself, which returns the worktree path. Both follow the watcher-and-harness delta's "Stacked cut".
- [ ] New `src/watcher/stack-run.ts` visits stacked changes, cuts or halts them as "Stacked cut" and "Stacked halt" say, and logs each cut. `runWatcherCycle` calls it once, before it lists changes.
- [ ] `WorktreeHaltReason` in `src/watcher/worktree-run.ts` adds `dependency_changed`, `dependency_diverged`, and `stack_cut_failed`, and `haltWorktreeChange` writes stacked halts.
- [ ] With `vcs.enabled` off, a cycle does exactly what it did before.
- [ ] New `tests/stack-run.test.ts` covers every scenario of "Stacked cut" and "Stacked halt".

## Details

Read dependency states and `.run/stacked-on` only through
`src/core/spec/stack-dependencies.ts`. Get the `Vcs` with `selectVcs` on the
project root, run the prepare step with `runPrepare`, and find the worktree
path with `worktreePath` and the stacked directory with `stackedPath`. Pass a
branch name as `createBranch`'s base. Read `.run/base` from the new
worktree's `head()`. Take `<changes>` and `<archive>` from the first
`changeTrees` tree, relative to its root. `src/core` may not import
`src/watcher`, so the halt stays in `stack-run.ts`. `runWatcherCycle` is
grandfathered, so add only the call there.

Build tests as `tests/worktree-run.test.ts` does. Approve with `approveSpec`,
copy its adapter stub that edits one file in the adapter's `projectRoot`, and
drive `runWatcherOnce` or `runWatcherCycle` from the checkout. Commit
`verify.cjs` before approving. To land by hand, run
`git merge --squash osq/<folder>` and `git commit` in the checkout. For a
rejected dependency, commit a `git mv` of its folder into the rejected
directory inside its worktree. For a changed hash, edit the recorded hash in
`.run/stacked-on`. Clear a halt with `retrySpec(<root>, <id>, 'change', ...)`,
as `tests/worktree-run.test.ts` does.

## Acceptance

- [ ] `ChangeTree` gains the optional `stackedFolder`, and `changeTrees` appends one stacked tree per directory under `stackedPath`'s parent, as the status-inspection delta's modified "Change locations" says. A missing directory adds none.
- [ ] `listChanges` treats a stacked tree like a worktree tree: it contributes only the folder it names, and the project root drops an active folder that a stacked tree names.
- [ ] No stacked tree carries `worktreeFolder`, so the watcher's worktree checks and commits never run for it.
- [ ] New `tests/change-locations-stacked.test.ts` covers "Stacked change", "Stacked folder with a worktree", and "Stacked directory with the flag off".

## Details

Get the stacked root as the parent directory of `stackedPath(vcs config,
repo root, any folder name)`, where the repository root comes from
`vcs.root()`. Name no path by hand. Build a stacked directory in a test by
creating `<stacked root>/<folder>/openspec/changes/<folder>/` with a
`proposal.md` and `.run/approved`. Set `vcs.worktreeRoot` inside the test's
temporary folder, as `tests/change-locations-worktrees.test.ts` does.

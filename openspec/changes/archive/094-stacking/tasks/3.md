## Acceptance

- [ ] New `src/core/spec/stack-dependencies.ts` exports the dependency state read that the spec-lint-and-approve delta's "Stack dependency state" defines. It also exports a function that returns the awaited `{ folder, hash }` entries of a change folder's `depends_on`, and the format and parse of `.run/stacked-on` lines.
- [ ] `approveIntoWorktree` drops `refuseUnlandedDependencies` and records a stacked approval when any entry is awaited, as "Stacked approval" says. Otherwise it approves into a worktree as before and then deletes any stacked approval of the folder.
- [ ] `approveSpec` approves the checkout's folder when `findChange` returns the change from a stacked tree, as "Stacked approval" says.
- [ ] `ApproveResult` gains the optional `stackedPath` and `waitingFor`, and `osq approve` prints `  Waiting for: <folders>` and `  Stacked: <path>` in place of the `Worktree:` and `Branch:` lines.
- [ ] In `tests/approve-worktree.test.ts`, only "refuses an approved dependency that has not landed" changes, into the modified "Unlanded dependency" scenario.
- [ ] New `tests/approve-stacked.test.ts` covers every scenario of "Stack dependency state" and "Stacked approval".

## Details

Take `<changes>` and `<archive>` as the first `changeTrees` tree's
`changesDir` and `archiveDir` relative to its root. Never call
`getChangesDir` or `getArchiveDir`; `tests/change-locations-readers.test.ts`
forbids it here. Use `vcs.pathExists`, `vcs.show`, and `vcs.listBranches`
for the git reads, and `stackedPath` for a stacked approval's directory.
Write the stacked copy with the same steps that write the worktree's copy:
`appendObservedSessions`, `writeApprovalSeal`, and the approver line of
`writeProvenance`. Pass the stacked root as `writeApprovalSeal`'s project
root. `.run/base` is written at the cut, not here. `approve-worktree.ts` has
241 lines and must stay at or under 250, so put new helpers in
`stack-dependencies.ts`.

Build projects as `tests/approve-worktree.test.ts` does, with
`vcs.worktreeRoot` inside the test's temporary folder. For "archived" and
"rejected on its branch", commit the move by hand with git inside the
dependency's worktree: `git mv` the folder into the archive or rejected
directory, then commit. For "landed", commit an archive folder on `main`.

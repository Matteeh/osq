## Acceptance

- [ ] MetricsReport exposes required `now`, `history`, and `coverage` blocks while retaining the existing unrelated report metrics and removing the replaced top-level task, failure, and cost fields.
- [ ] `now` derives all eight task counts only from current markers, includes regressed tasks, and always serializes and prints verified and manual even when zero.
- [ ] `history` derives attempts, repeated attempts, unexplained re-runs, dead reasons, verify exit codes, and missing verify exit codes only from each task's append-only event file.
- [ ] Historical cost retains finite event-value totals and per-change sums, identifies harness-reported provenance, and reports how many total attempts carried at least one cost value.

## Details

Reuse `getMetricsReport`, `formatMetricsReport`, `reportCommand`, `serializeSortedJson`, `deriveSpecState`, `doneMarkerIsManual`, `formatCost`, and the existing token, duration, and file-change aggregation. Keep task discovery shared so the marker and event views cannot disagree about the set of tasks, but do not use terminal events or archived-folder assumptions to derive `now`. Marker precedence remains the precedence implemented by state derivation, and a non-manual done marker is a verified completion.

Use stable task identities formatted as `<change>/<task>` in history maps. The report shape is:

- `now`: `total`, `done`, `verified`, `manual`, `dead`, `regressed`, `running`, and `pending`.
- `history.attempts`: `total`, `byTask`, and `multipleAttempts`, with every discovered task present in `byTask`, including zero-attempt tasks.
- `history.deadByReason`: one count per `dead` event reason, using `unknown` only when the event has no non-empty reason.
- `history.unexplainedReruns`: `total` and `byTask`; count each `started` after a prior `started` when no `dead` or `regressed` event occurred between them.
- `history.verifyRuns`: `total`, `missingExitCode`, and `byTask`, where each task maps to its ordered array of numeric exit codes or `null` for a missing code.
- `history.cost`: `total`, `perSpec`, `formattedTotal`, `provenance: "harness-reported"`, and `coverage` containing `reportedAttempts` and `totalAttempts`.
- `coverage`: `withEvents`, `withoutEvents`, and `byChange`; each change maps to sorted `withEvents` and `withoutEvents` task-number arrays.

An attempt is one `started` event. Associate later finite cost-bearing events with the most recent attempt in that task stream until the next `started`; sum all finite cost values as today, but count an attempt at most once for cost coverage. Ignore `.run/events/change.jsonl` for task attempts and coverage. An existing `.run/events/<n>.jsonl` counts as covered even when empty or containing no valid events. Parse malformed event lines defensively as the current report does.

Move the current failure breakdown and cost information into `history`; remove the top-level `tasks`, `failureBreakdown`, and `cost` projection from JSON. Preserve the exact existing shapes of `specs`, `completionRate`, `durations`, `tokens`, and `fileChanges`, with completion rate calculated from `now.done / now.total`. Render the historical cost line even at zero as `Harness-reported cost: <amount> (n of m attempts reported cost)`.

Extend `fixture/report` with one archived three-task change: one task has a done marker and no event file, one has two `started` events with no intervening `dead` or `regressed` event, and one has a `dead` event. Give current-state fixture tasks explicit markers so event history cannot determine `now`. Check in the complete sorted CLI JSON as `fixture/report/expected.json`. Update existing report assertions for the intentional structure and fixture-total changes; tests outside `tests/report*.test.ts` are frozen, including `tests/golden-events.test.ts`.

The report test suite must exercise text formatting, raw JSON through `reportCommand`, marker/event disagreement, regressed state, zero-valued verified and manual fields, zero attempts, event-file presence, unexplained re-runs, dead reasons, verify exit-code absence, and attempt-level cost coverage. Run the task verify and the change-level verify before exit.

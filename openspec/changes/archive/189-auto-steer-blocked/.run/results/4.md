- A `ready` item keeps its `blocked` field. The new requirement takes precedence over "Steering inbox items" and the command/text rows only; "Blocked inbox items" still requires `blocked` on a task-dead item, so the JSON keeps it even though the ready row does not print the need.
- `readNextStep`'s archived path was left unchanged. Acceptance line 4 scopes the `ready` next step to an active change, and the details note archived changes never get a record.

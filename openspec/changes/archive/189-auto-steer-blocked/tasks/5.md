## Details

The watcher may not import `src/cli/` (`tests/import-graph.test.ts`), so the CLI hands the builder to `startWatcher` through the `steeringPrompt` option task 3 adds, as `osq serve` hands web actions to core. Measured on 2026-10-13 in a scratch tree with a rough version of tasks 2 to 5: `osq watch --once` twice recorded one `auto_steer_ran` event with outcome `unchanged`, and the mock's result file under `.run/results/` was put back. Without `brief.md` the builder throws `ENOENT`, which task 3's run records as `failed`.

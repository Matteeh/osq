## Acceptance

- [ ] New `src/roles/mod.rs` and files beside it hold `Harness` with `as_str`, `ExecutorConfig`, `PlannerConfig` and `ValidatorConfig` per rust-config "Role settings", the default models and the planner agent `osq-planner` as named constants, and pure readers for the three tables that use the `pub(crate)` readers in `src/blocks/`.
- [ ] `src/config.rs`'s `Config` gains `executor: ExecutorConfig`, `planner: PlannerConfig` and `validator: Option<ValidatorConfig>`, and `parse_config` reads `executor`, `planner` and `validator` after `vcs`, in that order, the planner following the executor when its table is missing. Nothing else in `src/config.rs` changes.
- [ ] `src/lib.rs` declares `mod roles;` and also re-exports `Harness`, `ExecutorConfig`, `PlannerConfig` and `ValidatorConfig`; nothing else in it changes.
- [ ] New `tests/roles.rs` proves "Role defaults", "Executor model by harness", "Every role key set", "Role tables with defaults" and "Role errors", one test row per table row with the literal values of the scenario.
- [ ] Every new public function's doc ends with `Implements: rust-config/role-settings`, and each test's one-line doc names `Covers: rust-config/<scenario>` in kebab-case, such as `Covers: rust-config/role-errors`.

## Details

TypeScript's rules are `resolvePlannerSelection` and the harness catalog in
`src/core/foundation/harness-catalog.ts`, `validatePlannerConfig` in
`src/core/foundation/config-codex.ts` and `validateValidatorConfig` in
`src/core/foundation/config-validator.ts`. Read them only to check a rule;
the delta is the contract. The runners kernel's `RoleSettings` shows what
the roles will feed later; do not depend on `osq-kernel-runners` or change
it.

`Cargo.toml`, `Cargo.lock` and the files under `src/blocks/` and `src/error.rs`
do not change. If a reader you need is missing from `src/blocks/`, write a
small one in `src/roles/`.

cargo-mutants runs on every line this task adds. Each harness name, each
default model, the agent rule per harness and each required-key rule must
change a value a table row checks; add a row with values worked out from
the delta's rules if a mutant survives. Before exiting, run
`cargo fmt --all`, then
`cargo mutants -p osq-kernel-config -f <file> -o "$(mktemp -d)"` on each
new or changed source file, then `sh scripts/verify-rust.sh` with
`OSQ_CHANGE` set to `openspec/changes/252-rust-config-kernel`.

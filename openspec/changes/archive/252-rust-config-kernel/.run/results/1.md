## Changed

- Added the `osq-kernel-config` workspace member and dependency, and the `toml`
  workspace dependency with `parse`, `std` and `serde` and no default features.
- Added `crates/kernel/config/Cargo.toml` with the runners kernel's package and
  lint sections and `toml.workspace = true` as its only dependency.
- Added `src/error.rs` with `ConfigError`, its five variants and the display
  texts of "Config errors".
- Added `src/blocks/value.rs` with the shared `pub(crate)` readers:
  `check_keys`, `table`, `positive_integer`, `boolean` and `non_empty_string`,
  each taking a dotted key for its errors.
- Added `src/blocks/timeouts.rs` with `Timeouts`, the named TypeScript default
  constants and `read_timeouts`.
- Added `src/blocks/vcs.rs` with `VcsConfig`, `ManualEdits`, the named
  defaults, the hand-written author check and `read_vcs`.
- Added `src/config.rs` with `Config`, its `Default`, the pure `parse_config`
  and `load_config`, which treats `NotFound` as the defaults and every other
  read failure as `ConfigError::Read`.
- Added `src/lib.rs` re-exporting the config types and the two readers.
- Added `tests/config_file.rs`, `tests/config_timeouts.rs` and
  `tests/config_vcs.rs`, one row per scenario table row plus a row for an
  author with an interior `>` and a test that `manualEdits = "keep"` stays
  `Keep`, both worked out from the delta's rules for mutation coverage.
- `Cargo.lock` gained only the new crate and the packages `toml` brings, added
  with `cargo build --offline -p osq-kernel-config`.

## Deviated

- The top-level unknown-key check in task 1 already lists `executor`,
  `planner` and `validator` as known, because task 2 says nothing else in
  `src/config.rs` changes. Task 1 does not read those tables; task 2 adds their
  reads and fields.
- The crate doc names ADR 025 as the acceptance line says, although the
  proposal's decisions call the new decision ADR 029.

## Missing context

- The acceptance says the crate doc names ADR 025 while the proposal says ADR
  029 governs config; I followed the acceptance line literally.

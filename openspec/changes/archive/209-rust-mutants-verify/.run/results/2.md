## Changed

- `scripts/verify-rust.sh`: after `cargo test --workspace`, when `OSQ_DIFF` is set and not empty it runs `sh scripts/mutants-rust.sh "$OSQ_DIFF"` and exits with that command's status; otherwise it prints `mutation check not run: OSQ_DIFF is not set` and exits 0. Reads the variable as `${OSQ_DIFF:-}` under POSIX `sh` and `set -eu`, and its header comment states the mutation step.
- `AGENTS.md`: added, after the last bullet of the hand-written `## Rust crates` section, the guide bullet naming `OSQ_DIFF`, the missed mutant the verify fails on, and `cargo mutants -p <package> -f <file>`. No managed block changed.
- `tests/rust-verify-script.test.ts` (new): proves rust-core "Verify script steps", one case per table row, and "Verify script names the missing diff". Each case builds its own child environment (osq's `OSQ_DIFF` removed) and prepends a temporary folder holding a recording `sh` `cargo` stub to `PATH`, so no real cargo runs. It asserts the three cargo steps run in order, that the diff rows add one `cargo mutants` call holding `--in-diff <the absolute diff path the row passed>`, and that the no-diff rows add none.
- `tests/rust-agent-guide.test.ts`: `TERMS` gains `OSQ_DIFF`, `missed mutant`, and `cargo mutants -p <package> -f <file>`.

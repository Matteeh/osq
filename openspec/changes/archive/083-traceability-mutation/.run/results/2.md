## Changed

- New `src/core/trace/function-ranges.ts`:
  - `findTopLevelFunctions(file, text)` finds every column-0 `function`,
    `async function`, and `const … = (arrow|async arrow|function expression
    |async function expression)` declaration, exported or not, with its start
    and end line and whether its `(`, `[`, and `{` balance outside strings,
    template literals (their `${}` parts included), and comments.
  - `mutationRanges(file, text, name)` returns the function's own range plus
    the ranges of every non-exported top-level helper it reaches through such
    helpers, sorted by start line as `<file>:<start>-<end>`, or `null` when the
    function or any range is unknown.
  - `hashFunctionRange(file, text, name)` returns the `sha256:` of the
    function's own range text, or `null`.
  - `readScopedFunctionHashes(projectRoot, scope)` is the "Function baseline"
    reader: `<file>#<name>` to the hash of each scoped exported function with a
    `@scenario` tag, or `null` for an unknown range.
- `src/harness/types.ts`: `MeasuresEventData` gains optional `functionHashes`;
  `HarnessEventType` and `OsqEventData` gain `mutation_ran`, backed by new
  `MutationRanEventData` (all fields of "Mutation check after a pass", with an
  optional `reason` and `output`) and `MutationSurvivor`.
- `src/watcher/measures.ts`: `gatherStartMeasures` awaits
  `readScopedFunctionHashes` beside `readScopedDependencies` and spreads
  `functionHashes` only when it isn't empty. The file is 229 lines, within
  budget.
- New `tests/trace-function-ranges.test.ts`: 17 tests covering both "Function
  ranges" scenarios and the "Function baseline" scenario, every declaration
  form, an expression-bodied arrow, a braced return type, a comment holding
  `}`, a nested helper chain, a helper shared by two exported functions, an
  unknown unbalanced range, and `gatherStartMeasures` on temporary scopes with
  and without a tagged function.

## Details

`src/core/run/focused-tests.ts` from change 082 is the model for building the
scenario index once and running a command through `runVerificationCommand`.
Treat every value in the report as untrusted, and check each type before use.
The report written in the trial looked like this:

```
{ "files": { "src/pricing/quote.ts": { "mutants": [
  { "status": "Survived", "mutatorName": "ConditionalExpression", "replacement": "false",
    "location": { "start": { "line": 36, "column": 19 }, "end": { "line": 36, "column": 37 } } } ] } } }
```

The watcher sets `OSQ_CHANGE` for osq's own verify runs, so pass the change
folder explicitly and assert on the value you passed. New functions stay
within 80 lines and new files within 250.

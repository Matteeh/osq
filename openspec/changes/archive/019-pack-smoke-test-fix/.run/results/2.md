# Task 2 result: any test that spawns the package manager uses npm

## Changed

- `tests/bin-execution.test.ts`: `before` hook now runs
  `execFileAsync('npm', ['run', 'build'], { cwd: repoRoot })` instead of
  `execFileAsync('pnpm', ['build'], { cwd: repoRoot })`.
- `tests/package-install-smoke.test.ts`:
  - `run('pnpm', ['build'], repoRoot)` -> `run('npm', ['run', 'build'], repoRoot)`.
  - `run('pnpm', ['add', tarballPath, '--offline'], consumerDir)` ->
    `run('npm', ['install', tarballPath, '--prefer-offline'], consumerDir)`.
  - Inline comment updated from "local pnpm store" to "package manager cache".
    The file header comment (task 1 requirement, mentions pnpm) was left
    untouched; it is prose, not a spawn.
- `tests/package-hygiene.test.ts`: added a `package manager independence`
  suite with a single test that recursively reads every `.ts`/`.js` file under
  `tests/` and fails if any process-execution call
  (`execFile`, `execFileAsync`, `execFileSync`, `execSync`, `spawn`,
  `spawnSync`, `exec`, or the `run` test helper) passes the string literal
  `'pnpm'`/`"pnpm"` as its command. The pattern is assembled from a command
  list via `new RegExp` so the test does not flag its own source.

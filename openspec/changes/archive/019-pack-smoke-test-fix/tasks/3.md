## Acceptance
- [ ] before hook in tests/package-install-smoke.test.ts is removed and setup logic executes inside the first it block
- [ ] Suite-scoped variables hold temporary paths and subsequent it blocks fail cleanly if setup did not complete
- [ ] Process runner helper in tests/package-install-smoke.test.ts wraps spawn errors to report the command, arguments, and working directory
- [ ] tests/smoke-error-reporting.test.ts verifies simulated install failure produces not ok with command details and zero cancelledByParent

## Details

1. In `tests/package-install-smoke.test.ts`:
   - Remove the `before` hook entirely.
   - Retain the `after` cleanup hook to remove `workDir` if created.
   - Move temporary workspace creation, build, pack, init, and tarball install into the first `it` block:
     `it('packs and installs the local tarball into an isolated temporary project', async () => { ... })`.
   - Store `workDir`, `consumerDir`, and `tarballPath` in suite-scoped variables.
   - In subsequent `it` blocks (`npx osq init` and `npx osq new smoke`):
     - Check that `consumerDir` is set and setup succeeded; if not, fail with an explicit assertion:
       `assert.ok(consumerDir, 'Smoke test setup did not complete');`
   - In `run(command, args, cwd)`:
     - Wrap process execution so any thrown error formats a descriptive message including the command, its arguments, and working directory:
       `Command failed: ${command} ${args.join(' ')} (cwd: ${cwd})\n${error?.stderr || error?.message || error}`
2. In `tests/smoke-error-reporting.test.ts`:
   - Create a test that runs a copy or variation of the smoke test where the tarball path points to a nonexistent file.
   - Execute the test runner and inspect TAP or JSON runner output.
   - Assert the output contains `not ok` mentioning the failed command, arguments, and cwd.
   - Assert `cancelledByParent` is 0 and no sibling subtests are reported as cancelled.
3. Verification:
   - Run `node --import tsx --test tests/package-install-smoke.test.ts`.
   - Run `node --import tsx --test tests/smoke-error-reporting.test.ts`.

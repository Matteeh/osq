- [ ] config.log.heartbeatSeconds defaults to 60 seconds
- [ ] runner starts periodic heartbeat timer unreferenced via unref() during task execution
- [ ] heartbeat logs elapsed seconds, event count, and total accumulated tokens to stderr
- [ ] heartbeat timer is reliably cleared in runner finally block upon task completion

## Details

1. The runner reads interval from config.log?.heartbeatSeconds ?? 60 and converts to milliseconds (heartbeatSeconds * 1000).
2. Before spawning the task adapter, create a setInterval timer:
   `	s
   const timer = setInterval(async () => {
     const stats = await computeTaskHeartbeatStats(specFolderPath, taskNumber, startTime);
     logger?.info(
       	ask  heartbeat (elapsed: s, events: , tokens: ),
     );
   }, intervalMs);
   timer.unref();
   `
3. computeTaskHeartbeatStats:
   - Calculates elapsedSeconds = Number(((Date.now() - startTime) / 1000).toFixed(1)).
   - Reads .run/events/.jsonl (if exists), counting total lines (eventCount).
   - Sums event.data.totalTokens across all lines where event.type === 'tokens'.
4. In the inally block of unTask, call clearInterval(timer) so the process never hangs.

# Task 2 result — shared stderr logger and verbosity flags

## Changed

- `src/core/logger.ts` (new)
  - `LogLevel = 'quiet' | 'normal' | 'verbose'`, `Logger` interface, and `createLogger(level, prefix?)`.
  - Writes only via `process.stderr.write`; never `process.stdout`/`console.log`.
  - Optional prefix renders each line as `[<prefix>] <line>`; multi-line messages are prefixed per line.
  - Rank-based filtering: quiet writes warn/error, normal writes info/warn/error, verbose writes all.
- `src/cli/watch.ts`
  - Added exported `WatchCommandOptions { once?, verbose?, quiet? }`.
  - Added `resolveLogLevel(options)` (quiet wins over verbose, else normal).
  - `watchCommand` builds `createLogger(resolveLogLevel(options), 'osq')` and forwards `{ ...options, logger }` to `startWatcher`.
- `src/cli/index.ts`
  - `watch` now registers `--verbose` and `-q, --quiet`; action forwards them to `watchCommand`.
- `tests/logger.test.ts` (new)
  - Intercepts `process.stderr.write`/`process.stdout.write` and asserts filtering, prefixing, and stdout silence for each level.
  - Asserts `watch` registers `--verbose` and `-q/--quiet` and parses them (via `parseOptions`, so the watch action is never invoked).

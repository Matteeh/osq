## Acceptance

- [ ] `src/watcher/build.ts` exports `staleBuildMessage(packageRoot)` returning `osq build is stale: src/ is newer than dist/ in <packageRoot>. Run 'npm run build' there or pass --allow-stale.`, and no longer exports `STALE_BUILD_MESSAGE`.
- [ ] `findStaleBuild` returns `staleBuildMessage` for the package root it resolved, so a relative `packageRoot` appears as an absolute path.
- [ ] `StaleBuildError` takes the line as its constructor argument and uses it as its message. `assertNotStale` and `startStaleCheck` in `src/watcher/stale-pass.ts` pass the line their check returned.
- [ ] New `tests/stale-build-root.test.ts` covers, over a temporary package root with `src/` newer than `dist/`: `findStaleBuild` called with a relative root returns the line with the absolute root; `startWatcher` in `once` mode with that `packageRoot` and an injected `exit` prints exactly that line to `console.error` and exits 1; `runWatcherCycle` with a check returning a line for another root rejects with a `StaleBuildError` whose message is that line.
- [ ] `tests/vcs-land-command-error.test.ts`, `tests/vcs-land-stale.test.ts`, and `tests/watcher-stale-every-pass.test.ts` compare against `staleBuildMessage(<the package root the test built>)` where they used `STALE_BUILD_MESSAGE`, and assert nothing else differently.

## Details

`tests/watcher-stale-preflight.test.ts` stays unchanged and must still pass:
it matches `osq build is stale`, `src/ is newer than dist/`, and
`--allow-stale` in the printed line. `src/cli/land.ts` and
`src/watcher/loop.ts` already pass the line or the error through and need no
edit. Reuse the temporary package root helpers in
`tests/watcher-stale-every-pass.test.ts` as a pattern for setting `src/` and
`dist/` mtimes with `fs.utimes`.

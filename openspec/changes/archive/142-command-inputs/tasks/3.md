## Acceptance

- [ ] `ReportCommandOptions`, `QueryCommandOptions` and `DigestCommandOptions` extend `CommandInputs` instead of declaring `cwd`, `config` and `stdout` themselves, and the three commands resolve them through `resolveInputs`, loading config at the same point as before.
- [ ] Each writes its output to `stdout` as one write of the text plus `\n`, where it called `options.stdout(text)` or `console.log(text)` before. `digest --out` still writes the file and prints nothing. Return values are unchanged.
- [ ] Through `runCli`, `osq report`, `osq report --json`, `osq query <select>`, `osq query`, `osq digest` and `osq digest --json` print the same stdout and stderr as before and exit with the same code.
- [ ] New `tests/command-inputs-history.test.ts` runs those commands once through `runCliCaptured` and once directly with `cwd`, `config`, `stdout` and `stderr` writers that append to strings, in the same project, and asserts the same stdout and stderr text both ways.
- [ ] `tests/report.test.ts` and `tests/report-json.test.ts` expect the trailing newline their `stdout` writer now receives, and assert the same report text otherwise.

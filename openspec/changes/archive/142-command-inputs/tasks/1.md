## Acceptance

- [ ] New `src/cli/command-inputs.ts` exports `Writer`, `CommandInputs`, `processStdout`, `processStderr`, `resolveInputs` and `commandLogger` as the delta "Command inputs" describes. It is the only file under `src/cli/` that calls `process.stdout.write` or `process.stderr.write`. No command uses it yet.
- [ ] `resolveInputs({})` gives `process.cwd()`, the process writers, and a `config()` that loads the config of `cwd`; a passed `cwd`, `config`, `stdout` or `stderr` is used as given, and `config()` then never calls `loadConfig`.
- [ ] `commandLogger({})` is `createLogger(level, 'osq')`; `commandLogger({ stderr })` is a non-interactive `osq` logger whose every line reaches `stderr` as exact text, newline included.
- [ ] `runCliCaptured` in `tests/cli-capture.ts` records each write to `process.stdout` and `process.stderr` instead of each console call, console calls included, as one `CliLine` without one trailing newline, and adds `stdout` and `stderr`: the exact text written to each stream. It restores both writes even when `runCli` rejects.
- [ ] `captureLogs` in `tests/planning-observed-helpers.ts` records each write to either process stream the same way, instead of `console.log` and `console.error` calls.
- [ ] `tests/lint-command-error.test.ts` and `tests/sync-graph-migrate-command-error.test.ts` read the CLI output from the capture instead of wrapping `runCliCaptured` in their own write hooks, and assert the same text.
- [ ] New `tests/command-inputs.test.ts` covers the first three lines and the new `stdout` and `stderr` fields of `runCliCaptured`. Every other test that imports `tests/cli-capture.ts` or `captureLogs` passes unchanged.

## Details

Build the stderr logger by passing `createLogger` a `node:stream` `Writable`
that forwards each chunk to the writer, with `isTTY: false`. A console call
reaches `process.stdout.write` as one chunk ending in a newline, so the
recorded lines match what the console hooks recorded before. Measured on
this tree, the two wrapped tests are the only ones the capture change breaks.

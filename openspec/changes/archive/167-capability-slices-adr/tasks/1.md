## Acceptance

- [ ] New `tests/capability-slices.test.ts` holds a `describe('ADR 016: capability slices', ...)` with a test-local classifier. For each file path, sorted, it gets the owners from `ownerCapabilities` in `src/core/spec/capability-impact.ts` and reports `unowned` with no owner, `shared` with more than one, and `misplaced` when the one owner differs from the file's slice folder. The slice folder is the top-level folder under `src/`, or for a file under `src/kernel/<x>/`, `<x>`. A file directly under `src/`, such as `src/index.ts`, is judged only on its owners (unowned or shared, never misplaced). A file directly under `src/kernel/` has no slice folder, so one owner makes it misplaced. A finding carries `file`, `kind` and `owners`.
- [ ] One test proves the contract's "Classifying a fixed set of files" table. It uses ownerships `report` (`src/report/**`, `src/cli/report.ts`), `web` (`src/web/**`), `config` (`src/index.ts`, `src/kernel/config/**`, `src/kernel/loose.ts`) and `shadow` (`src/web/both.ts`), with files `src/report/a.ts`, `src/cli/report.ts`, `src/core/x.ts`, `src/web/both.ts`, `src/index.ts`, `src/kernel/config/load.ts` and `src/kernel/loose.ts`. It deep-equals exactly `src/cli/report.ts` misplaced `['report']`, `src/core/x.ts` unowned `[]`, `src/kernel/loose.ts` misplaced `['config']`, and `src/web/both.ts` shared `['shadow', 'web']`, in that order.
- [ ] The file declares a list of moved capabilities, empty, with a comment naming ADR 016 decision 7. One test checks that every name in it is in `readLivingCapabilityNames` from `src/core/spec/digest-capability.ts`.
- [ ] One test reads osq's real ownerships with `readCapabilityOwnership(repoRoot, DEFAULT_CONFIG.paths.openspecRoot)` and classifies every file under `src/`, as repository-relative POSIX paths. It fails, listing them, on findings whose owners include a moved capability, or on all findings once every living capability is in the moved list. Otherwise it passes, and prints with the test context's `diagnostic` one line per unowned or shared file and one line per capability with misplaced files, giving the count and the capability's name.
- [ ] Each diagnostic line starts with `ADR 016: `. On today's tree the test passes.
- [ ] No other file changes. Every existing test passes unchanged, `tests/ownership-reader.test.ts` included; the test calls `ownerCapabilities`, not `parseCodeOwnership`.

# Task 3 result

## Changed

- `src/watcher/dev.ts` (new): dev-mode supervisor.
  - `buildWorkerInvocation(options, packageRoot?)` builds
    `process.execPath ['--import','tsx', <root>/src/cli/bin.ts, 'watch', ...flags]` and sets
    `env.OSQ_DEV_WORKER='1'`; `--dev` is intentionally not forwarded.
  - `runDevSupervisor(options, overrides?)` verifies `src/` exists (one error line + exit 1
    otherwise), spawns the worker with `stdio: 'inherit'`, and `chokidar.watch`es `<root>/src`
    with `ignoreInitial: true`.
  - Source change sets `restartPending` and sends `SIGINT` to the worker; the worker's own SIGINT
    handler finishes the running task and exits, after which the supervisor spawns a fresh worker.
    Repeated changes coalesce into one pending restart. A user SIGINT sets `shuttingDown`, kills the
    worker, and exits `130` without restarting. An unsolicited worker exit finalizes with its code.
  - Dependencies (`spawnWorker`, `watchSource`, `onSignal`, `exit`, `logError`, `packageRoot`) are
    injectable for tests; defaults are the real `spawn`/`chokidar`/`process` implementations.
- `src/cli/watch.ts`: `WatchCommandOptions` gains `dev?: boolean`; added
  `shouldRunDevSupervisor(options, env?)`; `watchCommand` dynamically imports and delegates to
  `runDevSupervisor` when `dev` is set and `OSQ_DEV_WORKER !== '1'`.
- `src/cli/index.ts`: `watch` registers `--dev` and the action type/forwarding includes `dev`.
- `tests/watcher-dev.test.ts` (new): 7 tests — worker invocation shape (tsx + `src/cli/bin.ts` +
  `OSQ_DEV_WORKER`), delegation guard, chokidar source dir + spawn, graceful finish-then-restart,
  restart coalescing, SIGINT shutdown with exit 130, and missing-`src/` exit 1.
- `tests/watcher.test.ts`: existing CLI registration test now also asserts the `--dev` option.

## Deviated

- Acceptance 3 says "watches src/ using chokidar". The default watcher is the real
  `chokidar.watch`; tests assert the watched directory and change wiring through an injected
  `watchSource`, not by observing chokidar directly. This keeps the state-machine tests fast and
  deterministic.
- Acceptance 6 is tested by injecting the signal registrar and invoking the handler rather than
  sending a real OS signal to the test process. The handler path being asserted is exactly the one
  installed as the real `process.on('SIGINT')` listener.
- `runDevSupervisor` takes an optional second `overrides` param (the spec only mandated the options
  param) purely as a test seam; production callers use the single-argument form.

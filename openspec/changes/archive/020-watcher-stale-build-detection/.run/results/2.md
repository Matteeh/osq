# Task 2 result

## Changed

- `src/watcher/build.ts`: added `checkStaleBuild(options?: { allowStale?; packageRoot? })` plus a
  `newestMtimeMs(dir)` recursive walker. It returns early on `allowStale`, on a missing `src/`
  (installed package), and compares the newest file mtime under `src/` against the newest under
  `dist/` (`0` when `dist/` is absent). When `src/` is newer it prints exactly one line to stderr
  (`osq build is stale: src/ is newer than dist/. Run 'npm run build' or pass --allow-stale.`) and
  calls `process.exit(1)`. Also added a `RUNNING_FROM_SOURCE` constant derived from
  `import.meta.url`.
- `src/watcher/loop.ts`: `StartWatcherOptions` gains `allowStale?: boolean` and `dev?: boolean`;
  `startWatcher` calls `checkStaleBuild({ allowStale })` before preflight/cycles unless
  `options.allowStale` or `options.dev` is set.
- `src/cli/index.ts`: `watch` registers `--allow-stale` and its action forwards the parsed option.
- `src/cli/watch.ts`: `WatchCommandOptions` gains `allowStale?: boolean`; the existing
  `{ ...options, logger }` spread forwards it into `startWatcher`.
- `tests/watcher.test.ts`: asserts the `watch` command registers `--allow-stale`.
- `tests/watcher-stale-preflight.test.ts` (new): five subprocess tests against mocked temp package
  layouts — stale exit (code 1, one stderr line), checkout with no `dist/`, `allowStale` bypass,
  installed-package bypass (no `src/`), and fresh `dist/`.

## Deviated

- `checkStaleBuild` returns early when no explicit `packageRoot` is given and the running module is
  TypeScript source (`RUNNING_FROM_SOURCE`) rather than compiled output. This keeps the numerous
  existing in-process `startWatcher(..., { once: true })` tests green: they execute via `tsx` from
  the checkout, where the running code *is* the latest source and no compiled build can be stale.
  The preflight still fires for the real case (compiled `dist/` executed from a checkout) and always
  fires when a `packageRoot` is supplied, which is what the subprocess tests exercise. Without this,
  an absent/gitignored `dist/` would make `pnpm test` exit 1 on the first `startWatcher` call.
- Added `dev?: boolean` to `StartWatcherOptions` here (task 3 owns the dev supervisor) because the
  task-2 acceptance line requires the stale check to be skipped when `dev` is set.
- The subprocess tests call `checkStaleBuild` directly rather than `startWatcher`, because
  `startWatcher` has no way to inject a mocked package root; the spec explicitly allows either.

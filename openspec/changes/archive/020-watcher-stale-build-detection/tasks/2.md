## Acceptance
- [ ] checkStaleBuild in src/watcher/build.ts detects checkout by existence of src/ directory under package root
- [ ] checkStaleBuild compares the newest mtime under src/ with the newest mtime under dist/
- [ ] When src/ is newer than dist/ without allowStale, checkStaleBuild prints one error line to stderr and exits with code 1
- [ ] When allowStale is true or src/ does not exist, checkStaleBuild allows execution to proceed without exiting
- [ ] CLI registers --allow-stale option on watch command in src/cli/index.ts and forwards it to startWatcher options
- [ ] startWatcher in src/watcher/loop.ts invokes checkStaleBuild before running cycles unless allowStale or dev is set
- [ ] tests/watcher-stale-preflight.test.ts tests stale exit, allow-stale bypass, and installed package bypass via subprocess execution

## Details

1. In `src/watcher/build.ts`:
   - Implement `checkStaleBuild(options?: { allowStale?: boolean; packageRoot?: string }): Promise<void>`:
     - Locate package root (e.g. `path.resolve(path.dirname(fileURLToPath(import.meta.url)), '../..')`).
     - Check if `path.join(packageRoot, 'src')` exists and is a directory. If not, return (installed package).
     - If `options?.allowStale` is `true`, return.
     - Recursively walk all files under `src/` to find the newest `mtimeMs`.
     - Check if `path.join(packageRoot, 'dist')` exists. If not, set `distNewest = 0`. Otherwise recursively walk all files under `dist/` to find the newest `mtimeMs`.
     - If `srcNewest > distNewest`:
       - `console.error("osq build is stale: src/ is newer than dist/. Run 'npm run build' or pass --allow-stale.");`
       - `process.exit(1);`
2. In `src/cli/index.ts`:
   - Add `.option('--allow-stale', 'allow running when dist/ is older than src/')` to `watch` command.
3. In `src/cli/watch.ts`:
   - Add `allowStale?: boolean` to `WatchCommandOptions`.
   - Pass `allowStale` into `startWatcher` options.
4. In `src/watcher/loop.ts`:
   - Add `allowStale?: boolean` to `StartWatcherOptions`.
   - In `startWatcher`:
     - If `!options.allowStale && !options.dev`:
       - `await checkStaleBuild({ allowStale: options.allowStale });`
5. In `tests/watcher.test.ts`:
   - Add assertion verifying `--allow-stale` option is present on the `watch` command.
6. In `tests/watcher-stale-preflight.test.ts`:
   - Spawn a subprocess running a test script that invokes `checkStaleBuild` (or `startWatcher`) with a mocked temporary package layout where `src/` file mtime is greater than `dist/` file mtime.
   - Assert exit code is 1 and stderr output consists of exactly one line naming stale build.
   - Spawn a subprocess with `allowStale: true` and assert exit code is 0.
   - Spawn a subprocess without `src/` directory and assert exit code is 0.
7. Verification:
   - Run `node --import tsx --test tests/watcher-stale-preflight.test.ts`.
   - Run `node --import tsx --test tests/watcher.test.ts`.

## Acceptance
- [ ] CLI registers --dev option on watch command in src/cli/index.ts and forwards it to WatchCommandOptions
- [ ] In --dev mode, supervisor in src/watcher/dev.ts runs the watcher worker process via tsx pointing at src/cli/bin.ts
- [ ] Supervisor watches src/ directory for file changes using chokidar
- [ ] When a file under src/ changes, supervisor signals the worker to finish the current task first before exiting
- [ ] Upon graceful worker exit following a source change, supervisor restarts the worker process with fresh code
- [ ] User SIGINT cleanly terminates supervisor and worker without restarting
- [ ] tests/watcher-dev.test.ts asserts tsx execution from src/ and graceful loop restart upon file change

## Details

1. In `src/cli/index.ts`:
   - Add `.option('--dev', 'run through tsx from src/ and restart the loop when files change')` to `watch` command.
2. In `src/cli/watch.ts`:
   - Add `dev?: boolean` to `WatchCommandOptions`.
   - If `options.dev` is `true` and `process.env.OSQ_DEV_WORKER !== '1'`:
     - Delegate to `runDevSupervisor(options)` from `src/watcher/dev.ts`.
3. In `src/watcher/dev.ts`:
   - Create `runDevSupervisor(options: WatchCommandOptions): Promise<void>`:
     - Locate package root containing `src/` and `package.json`.
     - If `src/` does not exist, log error and exit non-zero.
     - Set up `chokidar.watch` on `path.join(packageRoot, 'src')` with `ignoreInitial: true`.
     - Maintain state: `let currentWorker: ChildProcess | null = null; let restartPending = false; let shuttingDown = false;`.
     - Define worker spawn function:
       - Spawn `process.execPath` with args `['--import', 'tsx', path.join(packageRoot, 'src/cli/bin.ts'), 'watch', ...forwardedArgs]`.
       - Pass `env: { ...process.env, OSQ_DEV_WORKER: '1' }`.
       - Pipe or inherit stdio appropriately.
     - On file change event from `chokidar`:
       - If `restartPending` is already true, return.
       - `restartPending = true`.
       - Send `SIGINT` to `currentWorker`. The watcher worker's built-in `SIGINT` handler will finish any running task cycle before exiting.
     - On worker exit:
       - If `shuttingDown`, exit process.
       - If `restartPending`:
         - `restartPending = false`.
         - Spawn fresh worker process.
     - On supervisor SIGINT:
       - `shuttingDown = true`.
       - Forward SIGINT to worker and exit on worker termination with exit code 130.
4. In `tests/watcher.test.ts`:
   - Add assertion verifying `--dev` option is present on the `watch` command.
5. In `tests/watcher-dev.test.ts`:
   - Test that `--dev` command supervisor spawns `node --import tsx ...`.
   - Test simulated file change under `src/`: verify active task completes before restart occurs.
6. Verification:
   - Run `node --import tsx --test tests/watcher-dev.test.ts`.
   - Run `node --import tsx --test tests/watcher.test.ts`.

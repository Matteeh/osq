## Acceptance

- [ ] Each non-print planCommand invocation appends a correlated plan_started record before spawn and plan_exited after termination to `<change>/.run/plan.jsonl`, for both new and resumed changes.
- [ ] plan_started records sessionId, harness, model, optional agent, osqVersion, and the `sha256:<hex>` digest of the exact brief bytes; plan_exited records the same sessionId, exitCode, non-negative wallSeconds, and five explicitly nullable usage fields.
- [ ] Spawn errors and non-zero exits still produce plan_exited and preserve existing non-zero propagation, while usage-reader absence, failure, malformed data, or ambiguity produces null values without changing the process outcome.
- [ ] `-print` retains its exact stdout-only behavior and appends no planning event, and `.run/plan.jsonl` remains outside the approved change hash.
- [ ] The optional adapter usage port has the exact interfaces in Details; OpenCode selects one session database row by cwd and interval and returns stored input, output, reasoning, cache-read plus cache-write, and cost values without reading messages.
- [ ] Codex selects one new rollout by session_meta cwd and interval and returns the last thread_token_usage counters with cost null; AGY returns all-null usage while retaining exact lifecycle timing, and no adapter estimates or chooses among multiple candidates.
- [ ] A fake planner executable with a known delay and sanitized OpenCode/Codex artifact fixtures prove event order, pairing, wall time, all three harness identities, exact usage mapping, AGY null usage, resume behavior, and unchanged print mode through planCommand.

## Details

Add the shared append-only record types, JSONL parsing/correlation helpers,
all-null usage value, brief hashing, and osq package-version resolution to
`src/core/planning.ts`. Keep malformed-line handling defensive so manifest,
show, and report consumers in later tasks can reuse the same parser. Do not
store harness session identifiers, transcript text, prompts, titles, tool calls,
or file contents.

Extend the adapter port exactly as follows:

```ts
export interface InteractiveUsage {
  readonly inputTokens: number | null;
  readonly outputTokens: number | null;
  readonly cachedTokens: number | null;
  readonly reasoningTokens: number | null;
  readonly cost: number | null;
}

export interface ReadInteractiveUsageOptions {
  readonly cwd: string;
  readonly startedAt: string;
  readonly endedAt: string;
}

readInteractiveUsage?(
  options: ReadInteractiveUsageOptions,
): Promise<InteractiveUsage>;
```

Reuse `planCommand`, `resolvePlannerSelection`, `getHarnessAdapter`,
`spawnInteractive`, `resolveOpencodeBinary`, `resolveCodexBinary`, and the
existing AGY binary resolver and literal-argv child-process style. Keep
`spawnInteractive` and its inherited stdio contract unchanged. The planning
command owns lifecycle timing:
generate one `crypto.randomUUID()` before append, capture ISO endpoints from the
same wall-clock interval, and call the optional reader only after the child has
closed. A reader exception is telemetry loss, not a planning failure.

For OpenCode 1.18.31, use the resolved harness CLI's read-only `db --format
json` interface to select only session metadata/usage columns from the `session`
table. Match `directory` plus `time_created` within the observed interval and
require exactly one row. Sum only the stored cache-read and cache-write values;
do not derive cache from totals. Quote query values safely and reject non-finite
or negative counters as unavailable.

For Codex 0.155.1, resolve the native data home (`CODEX_HOME` when configured,
otherwise the platform home `.codex`) and inspect rollout JSONL candidates
created during the observed interval. Match exactly one file whose
`session_meta.payload.cwd` resolves to the planning cwd, then use the last
`token_usage_record.payload.thread_token_usage`. Map input_tokens,
output_tokens, cached_input_tokens, and reasoning_output_tokens independently;
never fall back to per-request `usage` or add subset counters to another total.

Implement AGY's reader as an explicit all-null result. Do not scan unrelated
home-directory files or infer AGY usage from terminal output. The executable
under `tests/fixtures/planning/fake-planner.mjs` must be deterministic, tolerate
all three adapters' literal arguments, and delay long enough for a non-zero
measured wall time without making the test timing-fragile. Other new fixtures
contain metadata and usage only. Existing planner and adapter tests are frozen
regressions. Run the task verify and `pnpm verify` before exit.

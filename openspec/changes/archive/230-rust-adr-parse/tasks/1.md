## Details

TypeScript's reader is `readDecisions` in `src/core/foundation/decisions.ts`,
with the groups in `readCapabilityGroups` and `resolveGoverns` in
`decisions-groups.ts`. Read them only to check a rule. The delta's
requirements are the contract, and the tables were printed by TypeScript on
the same fixture. Rust code never imports or calls anything under `src/`.

Rules that are easy to miss:

- ADRs sort by the numeric value of their number, then by path, so
  `decisions/002-superseded.md` comes before `decisions/2-short.md`.
- `applies_to` is `all` only for exactly that string. Its list entries are
  trimmed, but repeats stay; `governs` drops them.
- A check path turns `\` into `/` and drops one leading `./`.
- `superseded_by: 1`, an integer, reads as `1`.
- `status: 5` reads as `5`. A `status` key with no value reads as empty
  text and still makes the file an ADR.
- Living sidecars count only when the folder also holds `spec.md`. A
  change folder's sidecar needs no `spec.md`, and a living group is never
  replaced.

Never edit the copied fixtures or the golden. If the golden test fails,
the parse is wrong. Say in `## Deviated` which rule you found and how you
matched it.

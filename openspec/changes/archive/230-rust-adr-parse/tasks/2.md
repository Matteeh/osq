## Details

TypeScript's validator is `validateDecisions` in
`src/core/foundation/decisions-validate.ts`. Read it only to check a rule;
the delta is the contract. Rust code never imports or calls anything under
`src/`.

- The superseded check compares numbers by numeric value, as
  `sameAdrNumber` does: `1` names `001`. Two values that are not numbers
  compare as text.
- The rule length counts UTF-16 code units, as JavaScript's `length` does.
- An ADR whose status is invalid gets no further findings, warnings
  included.
- Living groups are the groups in `records.groups` whose capability is in
  `living`.
- `max_rule_length` comes from the caller, so no limit is written in
  `src/`.

Task 1 owns `src/lib.rs`, `src/decisions/mod.rs` and `tests/public_api.rs`.
Add to them and leave task 1's lines as they are. Leave the fixtures, the
golden and `reading_decisions.rs` unchanged.

cargo-mutants runs on every line this task adds. The fixture scenario covers
each check, and the code table covers each `as_str` and `fix` arm. Before
exiting, run `cargo mutants -p osq-kernel-specs -f crates/kernel/specs/src/decisions/validate.rs -o "$(mktemp -d)"`.

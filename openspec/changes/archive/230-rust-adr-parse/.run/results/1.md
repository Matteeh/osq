## Changed

- Added the private `decisions` module with `Adr`, `AppliesTo`, `DecisionRecords` and `read_decisions`, plus pure parsing leaves in `decisions/parse.rs`.
- `read_decisions` reads `decisions/*.md`, ignores non-ADR Markdown, resolves living and active-change sidecar groups, and computes `governs` from `group:<name>` entries.
- Added `sha2.workspace = true` to the specs crate; `Cargo.lock` gained only `sha2` in the `osq-kernel-specs` dependency list.
- Re-exported the four new items from `src/lib.rs` and added the `decisions` row to `tests/public_api.rs`.
- Added `tests/reading_decisions.rs` for the seven scenarios. The frozen golden test compares JSON values and names the first differing ADR path and field on a mismatch.
- Added `tests/reading_decisions_edges.rs` for date, membership, list-field, numeric-sort and group edges, including the exact-end date and short `Date:` lines the task asks for.
- Copied the change folder's fixtures and golden byte for byte into the crate's `tests/fixtures/decisions/`, `tests/fixtures/repo_decisions/` and `tests/golden/decisions.json`.

## Deviated

- `AppliesTo` derives `Serialize` through `#[serde(into = "serde_json::Value")]` so its `all` variant serializes as the string `all`; a direct derive cannot produce that shape for a unit variant.
- Folder and sidecar reading lives in private helpers of `decisions/mod.rs`, all called only by `read_decisions`; the parsing leaves themselves are pure functions on text and YAML values.
- Added `reading_decisions_edges.rs` beyond the named test file to cover branches cargo-mutants found, including date separators, empty `applies_to`, blank `superseded_by` and blank `enforced_by`.

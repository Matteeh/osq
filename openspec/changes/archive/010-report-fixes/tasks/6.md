- [ ] FileChangeMetrics derives unique files modified from tool events with tool edit or write
- [ ] File paths are extracted from event data summary, path, or file and normalized
- [ ] Total file change count reflects total edit and write tool events
- [ ] Unique files modified reflects deduplicated paths across all specs
- [ ] fixture/report/ includes tool events for edit and write with duplicate paths
- [ ] tests/report-file-changes.test.ts verifies change events count and unique modified file count

## Details

1. In `src/core/report.ts`, count file modifications using `tool` events:
   - When scanning events, check if `event.type === 'tool'`.
   - If `event.data && typeof event.data.tool === 'string'`:
     Check if `['edit', 'write'].includes(event.data.tool.toLowerCase())`.
     If so, increment `totalFileChanges`.
     Extract the file path from `event.data.summary` (which `extractToolEventSummary` populates with the target file path for edit/write tools), `event.data.path`, `event.data.filePath`, or `event.data.file`.
     Clean and normalize the path (trimming whitespace and stripping leading `./`), then add to a `Set<string>`.
   - Retain support for legacy `file_changed` event types as a fallback.
   - Populate `FileChangeMetrics`:
     `totalChanges: totalFileChanges`, `totalEvents: totalFileChanges`, `uniqueCount: uniqueFiles.size`, and `uniqueFiles: Array.from(uniqueFiles).sort()`.
2. In `fixture/report/`:
   - Add representative tool events to `fixture/report/specs/archive/009-watcher-observability/.run/events/5.jsonl`:
     - `{ "type": "tool", "timestamp": "2026-09-17T21:56:47.000Z", "data": { "tool": "edit", "summary": "src/harness/opencode.ts" } }`
     - `{ "type": "tool", "timestamp": "2026-09-17T21:56:55.000Z", "data": { "tool": "write", "summary": "tests/opencode-tool-events.test.ts" } }`
     - `{ "type": "tool", "timestamp": "2026-09-17T21:57:00.000Z", "data": { "tool": "edit", "summary": "src/harness/opencode.ts" } }`
     - `{ "type": "tool", "timestamp": "2026-09-17T21:57:05.000Z", "data": { "tool": "read", "summary": "src/harness/types.ts" } }` (read tool, ignored for file changes)
3. In `tests/report-file-changes.test.ts`:
   - Call `getMetricsReport` against `fixture/report/`.
   - Assert `fileChanges.totalChanges === 3` (two edit events, one write event; read event excluded).
   - Assert `fileChanges.uniqueCount === 2` (`src/harness/opencode.ts` and `tests/opencode-tool-events.test.ts`).
   - Assert `fileChanges.uniqueFiles` contains exactly those 2 sorted paths.

## Acceptance
- [ ] getMetricsReport counts every dead event across events.jsonl in history grouped by reason
- [ ] Tasks later retried and completed retain their dead events in failureBreakdown
- [ ] Fallback to .run/dead/*.md markers occurs only when a spec has no dead events in events.jsonl
- [ ] Running getMetricsReport against fixture/report/ reports exactly 1 crashed failure in failureBreakdown
- [ ] formatMetricsReport prints failure counts per reason and prints (no failures) when empty
- [ ] tests/report-failure-breakdown.test.ts verifies historical retry failure counts against fixture/report/

## Signatures

In `src/core/report.ts`:

```ts
export interface MetricsReport {
  // ...

  readonly deadBreakdown: Record<string, number>;
}
```

## Details

1. In `src/core/report.ts`, change failure aggregation from inspecting current `.run/dead/` markers to scanning the append-only event stream:
   - For all spec folders, read `.run/events/*.jsonl`.
   - For each event with `event.type === 'dead'`, extract `reason`:
     `const reason = typeof event.data?.reason === 'string' && event.data.reason.trim() ? event.data.reason.trim() : 'unknown';`
     Increment `failureBreakdown[reason] = (failureBreakdown[reason] || 0) + 1`.
   - Maintain `deadBreakdown` as an alias referencing `failureBreakdown`.
2. For legacy specs whose `.run/events/` directory contains no `dead` events at all:
   - Fall back to reading `.run/dead/*.md` files, parsing YAML frontmatter `reason`, and tallying them into `failureBreakdown`.
3. In `formatMetricsReport(report)`:
   - Format the "Failure Breakdown:" section:
     If `Object.keys(report.failureBreakdown).length === 0`, print `  (no failures)`.
     Otherwise, print each sorted reason and its count: `  <reason>: <count>`.
4. In `tests/report-failure-breakdown.test.ts`:
   - Call `getMetricsReport` against `fixture/report/`.
   - Assert `report.tasks.dead === 0` (current dead tasks is zero) while `report.failureBreakdown.crashed === 1` (retaining the retry history of 009 task 1).
   - Assert formatted report contains `Failure Breakdown:\n  crashed: 1`.

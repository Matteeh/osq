## Changed

- `src/watcher/spawn-guard.ts`: new module exporting `spawnOrCrash(adapter,
  options)`, which awaits `adapter.spawn(options)` and returns its result, or
  `{ exitCode: -1, error: <message> }` when the spawn throws or rejects. One-line
  doc comment on the export.
- `src/watcher/spawn.ts`: `spawnTaskAgent` now calls `spawnOrCrash(adapter, …)`
  where it awaited `adapter.spawn`; added the one import. No other change, so
  the module is 198 lines and the function did not grow.
- `tests/spawn-throw.test.ts`: new test file. Direct `spawnOrCrash` coverage for
  a resolving spawn, a synchronous throw, and an async rejection; plus the delta
  "Spawn E2BIG" scenario through `runTask` with a `MockAdapter` subclass whose
  `spawn` throws, asserting a failed result with reason `crashed` and
  `.run/dead/1.md` holding `reason: crashed` and `spawn E2BIG`.

## Acceptance

- [ ] Every `with_program("osq-missing-git")` in the six scoped test files becomes `with_program("/nonexistent/osq-missing-git")`, and every expected command text that starts `osq-missing-git -c` starts `/nonexistent/osq-missing-git -c`, matching the rust-vcs tables in the change's delta.
- [ ] Each test still asserts `VcsError::Spawn`, the source kind `NotFound` and the exact command text; no other assertion, test name or doc comment changes.
- [ ] No file under `crates/` names `"osq-missing-git` without the `/nonexistent/` prefix, and `sh scripts/verify-rust.sh` passes.

## Details

This is a text change in tests only. Run `cargo fmt --all` after it,
since longer string literals may rewrap. `crates/kernel/vcs/tests/tree_record.rs`
uses the program in "Tree record without git", whose spec names no
program, so its spec is unchanged.

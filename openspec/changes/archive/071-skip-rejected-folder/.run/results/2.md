## Changed

- `listChangeFolders` in `src/cli/lint.ts` now filters `readdir` directory
  entries through `isActiveChangeFolderName` imported from
  `src/core/status/layout.ts`, replacing the inline `archive`/leading-`_` check.
  Directories are still joined and sorted with plain `sort`; `findSpecFolder`
  for explicit ids is untouched.
- Added `tests/lint-skip-rejected.test.ts`: scaffolds a project with
  `installFakeValidator` and `scaffoldProject`, plants
  `openspec/changes/rejected/009-nope/proposal.md`, creates one active change
  with `createNewSpec`, replaces its planning-sentinel verify with
  `useLocalVerifier` and writes a valid task with `writeTask1` (mirroring
  `tests/watcher-loop-logging.test.ts`), then calls `lintCommand([], ...)` with
  `cwd`, `DEFAULT_CONFIG`, a capturing logger, and an injected `exit`. It asserts
  `result.valid` is true, `exit` was never called with 1, exactly the one active
  entry was linted, and no logged error or warning names `rejected`.

## Deviated

- Added `config: DEFAULT_CONFIG` to the `lintCommand` options in the test. The
  task named only `cwd` and `logger`, but passing the default config keeps the
  test independent of any consumer `osq.config.ts` discovery, as the sibling
  `tests/scope-lint.test.ts` does.

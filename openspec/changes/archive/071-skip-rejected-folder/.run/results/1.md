## Changed

- Added pure `isActiveChangeFolderName(name)` to `src/core/status/layout.ts`,
  built from the existing `ARCHIVE_DIR` and `REJECTED_DIR` constants. It returns
  false for leading `_`/`.` names and the archive and rejected folders, true
  otherwise. No import from `state.ts` was added.
- Changed `runWatcherCycle` in `src/watcher/loop.ts` to import and filter
  `readdir` entries through `isActiveChangeFolderName`, keeping the
  `compareNumericPrefix` sort. The per-folder `try`/`catch` is untouched, so a
  real change folder with no proposal still logs a watcher error.
- Added `tests/watcher-skip-rejected.test.ts`: a predicate test and a watcher
  cycle test that scaffolds `archive/` and `rejected/009-nope/proposal.md`,
  creates and approves one change (numbered `010` because `createNewSpec` scans
  `rejected/`), runs one `runWatcherCycle`, and asserts `summary.tasksRun === 1`
  with no logged `watcher error`.

## Deviated

- `runWatcherCycle` kept the filter/sort on one line rather than the task's
  implied multi-line shape; Biome's formatter collapses it, and the line-budget
  and function-budget allow lists are unchanged.

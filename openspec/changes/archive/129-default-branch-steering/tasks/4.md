- [ ] Under a `requirement_changed` trigger, the `## Steering` section adds one `#### <capability>: <requirement> on <default branch>` heading per requirement `changedRequirements` reports, with that requirement's text on the default branch in a fenced block or `Removed on <default branch>.`, as the cli-foundation delta's "Planning a change that needs steering" says.

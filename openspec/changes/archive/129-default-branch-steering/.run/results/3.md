## Changed

- Added `src/core/status/steering-change.ts` with `findSteeringChange` and
  `listArchivedSteering`, plus the `SteeringChange` type (`{ change, state }`).
  Both read archived changes through `listChanges(projectRoot, config,
  ['archived'])`, keep those whose `tree.worktreeFolder` is set, and derive the
  state in the change's own tree with `readChangeFolder(change.tree.root,
  change.folderPath)`. `findSteeringChange` returns the active change the id
  matches first, then the archived steered one, else null. Nothing is written.
- `src/core/status/next-step.ts`: `readArchivedNextStep` now derives the
  archived state and returns `{ state: 'dead', command: 'osq plan <id>',
  detail: 'needs steering' }` when the state has `steering`; every other
  archived change stays `landed`.
- `src/core/status/inbox-projection.ts`: `readInbox` adds one
  `change-regressed` needs-you item per `listArchivedSteering` entry, with no
  task, command `osq plan <id>`, and `steering` from its first trigger. The
  combined needs-you list is sorted by numeric change id. `inbox.ts` and
  `inbox-text.ts` are untouched.
- `src/core/status/dispatch-items.ts`: extracted `steeringHaltItem` from
  `haltItems`; `readDispatchItems` now lists `listArchivedSteering`, emits the
  one no-task `halt` item (`osq plan <id>`, `osq show <id>`, first trigger as
  `steering`) for each, and `landItems` skips those folders, so no `land` item
  is emitted for them.
- Added `tests/steering-archived.test.ts`, copied from task 2's
  temporary-repository setup, covering "Archived change found for steering",
  "Inbox row for an archived change", "Change next step", and "Dispatch items".

## Deviated

- The task does not spell out the return shape of `findSteeringChange` /
  `listArchivedSteering`. I returned `SteeringChange` = `{ change:
  LocatedChange, state: SpecState }` because the status-inspection delta says
  both derive state and later tasks (plan/lint/approve) need both the located
  folder and the derived state; this keeps callers from re-deriving.

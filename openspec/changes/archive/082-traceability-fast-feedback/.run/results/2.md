## Changed

- `src/core/run/focused-tests.ts` (new): exports `collectFocusedTests(projectRoot,
  config, scope)`, `runFocusedTests(collection, projectRoot, changeFolder, config)`,
  and the types `FocusedOutcome`, `FocusedCollection`, `FocusedRunResult`.
  Collection checks `traceability.focusedTests`, resolves the scope with
  `resolveScope`, builds one `buildImportGraph` (skipping `config.paths.openspecRoot`)
  and one `buildScenarioIndex`, then reads only `scenarioTestFiles`,
  `scenariosInFile`, and `testsNaming`. It returns the opted-in scenario pairs of
  scoped scenario test files and every repository scenario test file naming one of
  them, sorted and distinct. The run single-quotes each file into the command,
  spawns through `runVerificationCommand` with the change folder and
  `config.timeouts.verifyTimeoutSeconds`, and classifies the TAP output as
  `failed` / `problem` / `passed` in that precedence.
- `tests/focused-tests.test.ts` (new): covers the collection's two scenarios
  (two-scenarios-one-outside-file, capability not opted in), an unset command, a
  path with a space and a quote, and the run's scenarios (failing scenario even on
  exit 0, non-scenario failure on nonzero exit) plus an indented `not ok`, an
  escaped `\#` title, a `# TODO` directive, a timed-out run, and an OSQ_CHANGE
  run. Each project is temporary and its focused command is a small `node` script
  printing the TAP lines, so no real test runner is needed.

Task verify (`node --import tsx --test tests/focused-tests.test.ts`) and the
proposal verify (`pnpm verify`) both pass.

## Deviated

- `runFocusedTests` returns `null` when `traceability.focusedTests` is unset or the
  collection has no files. The delta only says "there is nothing to run", so this
  gives task 3 a single guard; `collectFocusedTests` additionally returns an empty
  collection in those cases. Task 3 can check either `collection.files.length` or a
  null result.
- The "path with a space and a quote" case uses a double quote. The spec asks for
  each file to be single-quoted for the shell, which cannot represent a single
  quote, so a single-quoted path with a single quote would be malformed. A double
  quote exercises quoting safely.

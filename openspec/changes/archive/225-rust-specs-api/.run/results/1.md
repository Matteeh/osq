## Changed

- `crates/kernel/specs/src/lib.rs`: the six top-level modules are now plain `mod`; the root `pub use` blocks are unchanged.
- `crates/kernel/specs/src/document/mod.rs`, `markdown/mod.rs`, `owners/mod.rs`, `validate/mod.rs`: every `pub mod` is now `pub(crate) mod`; their `pub use` lists are unchanged.
- `crates/kernel/specs/src/validate/finding.rs`: `FindingCode::as_str` and `FindingCode::fix` doc comments now end with `Implements: rust-specs/validation-findings`.
- `crates/kernel/specs/src/merge/error.rs`: `MergeError::capability` and `MergeError::requirement` doc comments now end with `Implements: rust-specs/merge-refusals`.
- `crates/kernel/specs/tests/public_api.rs`: new tests pinning the root-only export table and requiring an `Implements: rust-specs/` tag on every `pub fn`, with the four methods checked against their exact rows.

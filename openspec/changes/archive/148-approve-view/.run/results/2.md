## Changed

- `packages/ui/src/contracts.ts`: re-exported, as types only, `WebReview`, `WebDeltaCapability` and `WebDeltaRequirement` from `src/core/web/web-data.ts` and `ApprovalFlag` from `src/core/spec/digest.ts`.
- New `packages/ui/src/change/ReviewPanel.tsx`: the six proposal sections (`Goal`, `Non-goals`, `Surface`, `Decisions`, `Human steps`, `Contract`), each an `h3` over a `<pre className="review-text">` or `None`, followed by `DeltaReview`.
- New `packages/ui/src/change/DeltaReview.tsx`: the `Deltas` section with an `h4` per capability and, per requirement, its operation and name plus a `delta-pair` of `Living` and `Proposed` columns. Added reads `New requirement`; removed reads `Removed`; renamed reads `Renamed from <from>` with the living text; a missing living block reads `No living requirement matched.`.
- New `packages/ui/src/change/DigestPanel.tsx`: the `Approval digest` section with `digestText` and, when passed, the flags.
- New `packages/ui/src/change/ApprovalFlags.tsx`: a list of `<strong>label</strong> — excerpt` items, or nothing when empty.
- `packages/ui/src/change/ChangeActions.tsx` and `ChangeActionsPanel.tsx`: optional `flags` prop; `ChangeActions` shows `ApprovalFlags` inside the Approve button's `action-item`, or before the buttons when there is no approve action.
- `packages/ui/src/change/ChangeView.tsx`: a `review` renders header, error, brief, `ReviewPanel`, `TaskTable`, `DigestPanel` (flags only without an action client), then `ChangeActionsPanel` with the digest flags. A null or missing `review` keeps the original markup and order.
- New `packages/ui/src/change/review.css`: `.review-text` with `white-space: pre-wrap` and `overflow-wrap: anywhere`, `.delta-pair` as an auto-fit grid that stacks at phone width.
- `packages/ui/src/change/index.ts` and `packages/ui/src/main.tsx`: exported the new components and imported `review.css` next to `actions.css`.
- New `tests/ui-review.test.tsx`: heading order, `None` sections, flags in the digest without a client, flag wording, the missing-vs-null unchanged markup, the phone-width CSS rules, and a real core document from `createProject`/`createChange`/`getWebChange` rendering the living and proposed text and the `removed_requirement` flag.

Touched: packages/ui/src/contracts.ts, packages/ui/src/change/ReviewPanel.tsx, packages/ui/src/change/DeltaReview.tsx, packages/ui/src/change/DigestPanel.tsx, packages/ui/src/change/ApprovalFlags.tsx, packages/ui/src/change/ChangeActions.tsx, packages/ui/src/change/ChangeActionsPanel.tsx, packages/ui/src/change/ChangeView.tsx, packages/ui/src/change/index.ts, packages/ui/src/change/review.css, packages/ui/src/main.tsx, tests/ui-review.test.tsx

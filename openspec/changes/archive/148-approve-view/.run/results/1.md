## Changed

- `src/core/web/web-data-types.ts`: added `WebDeltaOperation`, `WebDeltaRequirement`, `WebDeltaCapability` and `WebReview`, imported `ApprovalDigest` as a type, and added the optional `review` field to `WebChange`.
- New `src/core/web/web-data-review.ts`: `readWebReview(projectRoot, details, config)` returns null unless the change is active with no approved hash and a digest, else builds the proposal sections (HTML comments stripped), the per-capability deltas from `parseDelta` beside the living requirements from `parseCapabilitySpec`, the digest and `formatApprovalDigest` text.
- `src/core/web/web-data-change.ts`: `getWebChange` now computes `review` from `readWebReview` and returns it, so the HTTP route and static export carry it.
- `src/core/web/web-data.ts`: re-exports `WebReview`, `WebDeltaCapability`, `WebDeltaRequirement` and `WebDeltaOperation` as types.
- New `tests/web-data-review.test.ts`: covers all four delta operations with their living blocks checked against `lookupRequirement`, the proposal sections, the digest against `buildApprovalDigest`, `digestText` against `formatApprovalDigest`, the `removed_requirement` flag, a missing living match, an approved change, and the archived, rejected and approved active fixture changes.

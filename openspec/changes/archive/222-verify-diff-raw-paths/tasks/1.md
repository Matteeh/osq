## Details

`patch` also feeds the dead attempt's `.patch` (`src/core/run/dead-commit.ts`)
and the validator's diff; `git apply` reads raw paths, so those callers need no
change. With `core.quotepath` true, git without the override writes the path as
`"a/a-\360\237\230\200.md"`, which is what the `\360` check catches. Run git in
the test without `-c core.quotepath=false` of its own, so the test sees what
`patch` alone produces.

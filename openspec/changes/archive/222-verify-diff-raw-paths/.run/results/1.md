## Changed

- `patch` in `src/core/vcs/git-vcs-write.ts` now passes `-c core.quotepath=false` before `diff` in the same git call, so paths are raw UTF-8 whatever the repository's setting. Hoisted the argument list into a local to keep biome from wrapping the call.
- Added the `@scenario version-control: Patch with a non-ASCII path` line to `patch`'s doc comment.
- Added `tests/vcs-patch-raw-paths.test.ts`, which builds a temporary repository with `core.quotepath` true, commits one file, writes the untracked `a-😀.md`, calls `GitVcs.patch()`, and checks the exact `diff --git a/a-😀.md b/a-😀.md` line, the absence of `\360`, and that `git apply` in a clean clone creates the file with the same content.

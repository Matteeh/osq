## Details

Port `formatJson` from `src/core/report/query-run.ts`. Read the values with
`rusqlite::types::ValueRef` as `read_rows` in `src/query.rs` does, and
reuse its root and home texts and `rewrite_paths` of `src/query/text.rs`, made
`pub(super)`,
for text values, without the `\n` rewrite the text cells apply. Do not use
`serde_json` in `src/`; it is only a dev-dependency, and `Cargo.toml` and
`Cargo.lock` must not change.

For a real, `format!("{:e}", value)` gives the shortest digits and the
exponent, such as `3.0000000000000004e-1` or `1e21`; build ECMAScript's
plain or exponent text from those, as "Query JSON reals" says. A non-finite
real is `null`, and `-0.0` is `0`. The `reals` golden case holds one value
for each branch. Write the DEL character in the test as `\u{7f}`.

For the keys, an array index is a column name of ASCII digits with no
leading zero unless it is `0` alone, whose value is at most 4294967294.
Collect each distinct name once, at the place of its first column, with the
value of its last column, then put the array indexes first in ascending
numeric order, as "Query JSON keys" says.

`tests/support/mod.rs` is compiled into every test file that declares
`mod support;`, and clippy's `dead_code` fails when a file leaves a helper
unused, so `tests/query_json.rs` does not declare it: give it its own
scratch copy of a fixture under `CARGO_TARGET_TMPDIR`, a new folder per
case named `query-json-<case>`, dot folders included, and its own reader of
`tests/fixtures/queries-json.json` with `serde_json`. Run every case through
`ReportFeature.run` with an `Invocation` whose arguments hold `--json`. Take
the paths case's expectations from the existing paths tests in
`tests/query_run.rs`, which handle an empty `HOME`.

When the mutation check reports a missed mutant, add a case for that line
in `tests/query_json.rs` rather than keeping a branch no test reaches, and
take its expected value from running the same select through TypeScript's
rules in the spec, never from the Rust code. Run the proposal's verify as
the watcher does, with `OSQ_CHANGE=openspec/changes/286-rust-query-json`, so
the link gates see this change's new requirements.

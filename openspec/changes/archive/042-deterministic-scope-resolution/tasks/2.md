second numeric literal or parse done frontmatter separately in each caller.
Extend `DoneMarkerMetadata`, `buildDoneMetadata`, and `writeDoneMarker` so the
ordinary verified-task path emits the version. Keep snake_case only in marker
frontmatter and existing camelCase conventions inside TypeScript.

has an empty differing-path and attribution list but must retain an explicit
recorded/current resolver indication in its human marker and typed event data;
its lifecycle reason remains `scope_regression` so change 041's report, show,
and retry contracts continue to work. Check the active regression marker before
running verification so the new migration path inherits restart idempotency.

dead or archive-regression transitions. Its successful done-frontmatter rebuild
must preserve unknown keys and body bytes, then set resolver 2 alongside the
fresh `scope_hash` and `scope_files`. A failed detection or human verify does
not bypass the established human decision or spawn an agent inside retry.

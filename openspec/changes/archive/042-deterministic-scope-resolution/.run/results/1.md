# Task 1 — Deterministic scope resolver

Status: complete. All nine acceptance lines are implemented and the task verify
command passes (90 tests, 0 failures). `pnpm tsc --noEmit` and `pnpm lint`
(biome) are clean.

## Changed

- `src/core/scope.ts` (new): the single scope resolver. Exports
  `SCOPE_RESOLVER_VERSION = 2` and `resolveScope(projectRoot, scope)` returning
  `{ relativePath, absolutePath: string | null }[]`. Moved the established
  `globToRegExp` matcher semantics here (`*`, `**`, `?`, trailing-directory).
  Exact declarations resolve through `lstat` (regular file only, else null);
  pattern declarations walk only the static directory prefix and match
  project-relative POSIX paths. Results are deduplicated and lexically sorted;
  patterns and exact entries that would escape the project root contribute no
  readable path (outside exact declarations are retained with null and never
  read). Filesystem-only; imports only `node:fs`, `node:fs/promises`,
  `node:path`.
- `src/core/scope-hash.ts`: `computeTaskScopeHash` now consumes only
  `resolveScope` and folds sorted `path:hash` pairs into the unchanged
  `sha256:<hex>` aggregate. Re-exports `SCOPE_RESOLVER_VERSION`. `DoneMarkerInfo`
  gained `scopeResolver: number | null`; `readDoneMarker` surfaces a finite
  `scope_resolver` or null without changing audit behavior. `ScopeHashResult`,
  `relativePosix`, `findDifferingPaths`, and `attributeScopePaths` are
  preserved.
- `src/core/linter.ts`: the `tests.modify` compliance check resolves each task's
  scope once through `resolveScope`, keeps existing non-null paths in a local
  `resolvedTaskScopes` collection for task 3, and filters to the same `tests/`
  set. Deleted `globToRegExp`, `listExistingTestFiles`, and `touchedTestFiles`.
  The declared-pattern `maxScopeFiles` limit still counts `task.scope.length`.
- `tests/scope-resolver.test.ts` (new): exact paths, missing exact null,
  segment `*`, `?`, nested `**`, trailing-directory, exact/glob dedupe, unmatched
  glob, empty scope, `./` and separator normalization, declaration-order
  independence, outside-project attempts, resolver-projection hashing,
  `SCOPE_RESOLVER_VERSION === 2`, and a source-level cut-over check.
- `tests/runner-scope-hashes.test.ts`: extended only the hash cases with a
  temporary `src/core/queue-report*.ts` fixture that adds, modifies, and deletes
  matches and asserts the sorted `(deleted)`, `(added)`, `(modified)` displays
  from `findDifferingPaths`.

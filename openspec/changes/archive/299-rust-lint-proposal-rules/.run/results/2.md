## Changed

- `lint` now loads the config before checking a change, then reports proposal rule findings, banned word warnings, spec findings and link gate findings in that order. Warnings print above `<folder>: valid`; any error still fails with the finding count and every line.
- Added `lint/proposal.rs` for the `## Assumptions` and `## Decisions` rules and the `AGENTS.md` project rules errors, `lint/banned.rs` for the banned word scan, and `lint/finding.rs` for the shared severity and finding shape.
- Extended `lint/text.rs` with the rule finding line and warning output, and wired the new checks through `lint.rs`.
- Added `osq-kernel-config` to the lint crate; the root `Cargo.lock` followed it.
- Added `tests/copy/mod.rs` to copy the lint fixture into a scratch root per row, plus `lint_proposal_rules.rs`, `lint_banned_words.rs` and `lint_config_error.rs` proving the new requirements. Extra bounded cases cover task ordering, adjacent code spans and quotes, comments, section boundaries and the word-character ADR boundary.
- `cargo fmt --all`, the task verify, the proposal's `sh scripts/verify-rust.sh`, and `cargo mutants` over every changed lint source file pass with no missed mutant.

Touched: crates/features/lint/Cargo.toml, Cargo.lock, crates/features/lint/src/lint.rs, crates/features/lint/src/lint/text.rs, crates/features/lint/src/lint/finding.rs, crates/features/lint/src/lint/proposal.rs, crates/features/lint/src/lint/banned.rs, crates/features/lint/tests/copy/mod.rs, crates/features/lint/tests/lint_proposal_rules.rs, crates/features/lint/tests/lint_banned_words.rs, crates/features/lint/tests/lint_config_error.rs

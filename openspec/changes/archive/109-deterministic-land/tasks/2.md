## Details

Build repositories the way `tests/vcs-merge.test.ts` does, with the `GIT_*`
variables removed from the environment and `user.name` and `user.email` set in
the repository's config, because `commit-tree` takes the committer from there.

For the signing scenario, set `commit.gpgSign` to true and `gpg.program` to an
executable script in the temporary folder. git 2.34 accepts this one: it
records the call in a file, reads stdin, prints
`\n[GNUPG:] SIG_CREATED D 1 8 00 0 X\n` to stderr, and prints a block from
`-----BEGIN PGP SIGNATURE-----` to `-----END PGP SIGNATURE-----` to stdout.
`git cat-file -p <commit>` then shows a `gpgsig` line.

`git merge --ff-only` leaves unrelated modified and staged files alone. The
blocked check compares the status entries with
`git diff --name-only -z HEAD <commit>`, so osq never parses git's refusal
text, which depends on the locale.

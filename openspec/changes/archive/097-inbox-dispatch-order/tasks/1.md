## Details

Build on `getStatusOverview`: its `specs`, `nextSteps`, and
`pendingVerifications` give every kind except land, as `projectNeedsYou` in
`inbox.ts` shows. A task's dead or regressed state comes from its
`TaskState`, and a change regression from `changeRegressed`. For land items
with `vcs.enabled`, list archived changes with `listChanges` and keep those
whose tree has a `worktreeFolder`. Ask `readDependencyState` about each one.
With the flag off, take the archive directory from the first `changeTrees`
tree, never from `getArchiveDir`. Call `selectVcs` on the project root, and
match `status` paths under that directory. An untracked folder is listed
with a trailing `/`.

Build dead and regressed states the way `tests/inbox.test.ts` writes its
markers. For the worktree land case, run a change to its archive commit as
`tests/stack-run.test.ts` does, with its `makeProject` and `ActingAdapter`
copied in, then land it with `git merge --squash osq/<folder>` and a commit.

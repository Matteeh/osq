## Changed

- Added `src/core/status/dispatch-cards.ts`. It exports `readDispatchCard`,
  the `ApprovalCard`, `HaltCard` (`HaltTaskCard`/`HaltChangeCard`), `LandCard`,
  and `VerifyCard` types, and the `DispatchCard` union. Each kind gathers only
  its own evidence: the approval digest; a task's reason, `started` count,
  trailing marker body, and project-relative dead patch path; a change-level
  regression's reason and body; a land card's goal, per-task outcome lines, and
  the squash message (only with `vcs.enabled`, holding `buildSquashMessage`'s
  refusal message when it throws); and a verify card's check command,
  after-landing steps, and outcome. Marker bodies are truncated to
  `limits.cardOutputLines`, and no absolute path enters a card.
- `src/core/run/squash-message.ts` now imports `matchesFolder` from
  `change-locations.ts` instead of keeping a private copy, and exports
  `outcomeLine` for the land card.
- `src/core/foundation/config.ts` adds `cardOutputLines` to `OsqLimits`,
  defaulting to 20 in `DEFAULT_CONFIG`. The halt card reads it from the config.
- Added `tests/dispatch-cards.test.ts`, exercising every "Dispatch cards"
  scenario through `readDispatchItems` and `readDispatchCard`, including a real
  worktree land case built as `tests/squash-message.test.ts` does.

`tests/squash-message.test.ts` was not modified and still passes.

Touched: src/core/status/dispatch-cards.ts, src/core/run/squash-message.ts, src/core/foundation/config.ts, tests/dispatch-cards.test.ts

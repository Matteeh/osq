## Details

This task's `scope` is authoritative over any injected code-ownership rules.

The task status defaults to `pending` where the report maps each task's marker
state. Tell archived from active changes by the location the report already
uses for `specs.active` and `specs.archived`. Replace `formatCost(total)` at
the three cost call sites with a helper that also takes the reported count.

already exist. The queue computation lives outside this scope and exposes no
reported-session count. For the queue's planning cost, treat it as reported
when it has sessions and `costCoverageComplete` is true, or when its sum is
above zero. Keep `formatCost` exported for its other callers.

the real case. After this task, `osq report` in this repository shows

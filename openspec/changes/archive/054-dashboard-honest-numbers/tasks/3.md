## Acceptance

- [ ] New `packages/ui/src/format.ts` exports the one `formatCost(value, coverage?)`. It returns `not reported` for `null`, a non-finite value, or a coverage whose `reported` is 0. Otherwise it returns today's dollar text. `report/format.ts`, `graph/format.ts`, and `change/format.ts` re-export it instead of defining their own.
- [ ] Every cost the dashboard renders goes through it with its coverage when one is at hand. No view shows `$0.0000` or `unavailable` for a cost.
- [ ] `BriefPanel` renders the heading `Brief` alone. When the change has no brief, a paragraph under the heading reads `No brief was recorded; the proposal goal follows.`, followed by the goal. The `brief-absent` class stays on that paragraph.
- [ ] `RepositoryTotals` adds `· unmarked <n>` to the current-state line when `now.unmarked` is above 0, and adds nothing when it is 0.
- [ ] `tests/ui-change.test.tsx` and `tests/ui-report.test.tsx` expect `not reported` and the new brief text where they pinned `unavailable` for a cost or `brief absent`. They add cases for a zero-coverage cost and for the unmarked line. Nothing else in them changes.
- [ ] The task's verify command passes.

## Details

This task's `scope` is authoritative over any injected code-ownership rules.
Task 1 adds `unmarked` to the report's `now` type, which the UI imports from
`src/core/report/report.ts`. Task 2 makes unreported web costs `null`, so the
formatter mostly sees `null`. The coverage check covers documents built before
that task.

Keep `formatCount` and the other non-cost formatters as they are; `unavailable`
stays correct for a malformed count. The costs rendered in the report view come
preformatted from the server as `formattedTotal`, which task 1 already fixes.

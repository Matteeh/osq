# Task 1 result

## Changed

- `src/core/report/report.ts`
  - `NowMetrics` gains `unmarked`. Task discovery records whether each change
    sits under the archive root; a marker state of `pending` in an archived
    change counts as `unmarked`, while active changes keep counting it as
    `pending`. `total` is unchanged and all six state counts sum to it.
  - New `formatReportedCost(total, reportedCount)` shared by the history cost,
    the global planning cost, and the queue planning cost. It returns
    `not reported` only when the sum is zero and no counted attempt or session
    reported a cost; a non-zero sum or a counted reporter keeps a dollar amount.
    `formatCost` stays exported for its other callers.
  - `formatMetricsReport` prints `Unmarked: <n>` directly after the `Pending:`
    line and routes the queue planning cost through the shared helper.
- `tests/report-unreported.test.ts` (new): archived markerless tasks beside an
  active pending task, planning/attempts with no reported cost, and one reported
  attempt among several, in JSON and text.
- `tests/report-now.test.ts`, `tests/report-json.test.ts`,
  `tests/report-planning.test.ts`, `tests/report-task-states.test.ts`,
  `tests/report-cost.test.ts`: expect `unmarked` where the whole `now` object is
  pinned, expect `unmarked` where archived markerless tasks were asserted
  `pending`, and expect `not reported` where `$0.0000` was pinned for an
  unreported cost. No other assertions changed.
- `fixture/report/expected.json`: `now` gains `"unmarked": 0`.

## Changed

- `packages/ui/src/format.ts` (new): the one `formatCost(value, coverage?)`.
  It returns `not reported` for a null, non-finite, or negative value, or a
  coverage whose `reported` is 0; otherwise the established dollar text.
- `packages/ui/src/change/format.ts`, `packages/ui/src/graph/format.ts`,
  `packages/ui/src/report/format.ts`: drop their own `formatCost` and re-export
  the shared one. Every internal call now passes the coverage at hand:
  `costWithCoverage` (change and report), `compactCost`, and `fillDescription`.
- `packages/ui/src/change/BriefPanel.tsx`: the heading is `Brief` alone. A
  missing brief renders `<p class="brief-absent">No brief was recorded; the
  proposal goal follows.</p>` before the goal. The `brief-absent-note` class
  and its old sentence are gone.
- `packages/ui/src/report/RepositoryTotals.tsx`: the task-state line appends
  `· unmarked <n>` only when `now.unmarked > 0`.
- `tests/ui-change.test.tsx`: cost pins now expect `not reported` (`null`,
  `NaN`, `Infinity`, `-1`, zero-coverage `costWithCoverage`); the missing-brief
  and malformed tests expect the new heading and note text; added a
  zero-coverage `formatCost(0, { reported: 0, total: 1 })` case and a
  zero-coverage `costWithCoverage` case.
- `tests/ui-report.test.tsx`: the 0-of-0 planning cost pin expects
  `not reported`; added a zero-coverage cost view case and an unmarked-line
  case (3 shown, 0 absent).
- Ran `pnpm verify` (task and proposal): typechecks, build, all tests, and lint
  pass.

## Deviated

- Acceptance line 1 lists three `not reported` conditions. I also return
  `not reported` for a negative finite value. This preserves `change/format.ts`'s
  prior `value < 0` guard, and acceptance line 5 asks the tests to expect
  `not reported` where they pinned `unavailable` for a cost, which includes the
  existing `formatCost(-1)` pin.
- The `CostChart` y-axis ticks call `formatCost(tick)` with no coverage and are
  outside this task's scope, so a zero axis tick still reads the dollar text.
  They are scale labels with no recorded denominator, not a change's cost.
- `BriefPanel` drops the `brief-absent-note` class because no stylesheet
  defines it and acceptance keeps `brief-absent` on the paragraph.

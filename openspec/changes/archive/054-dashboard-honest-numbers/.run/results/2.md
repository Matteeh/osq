## Changed

- `src/core/web/web-data-observations.ts`
  - `observeTaskFile`: a task's `cost` is now null when
    `stream.costReportedAttempts === 0` instead of only when there are no
    attempts. Coverage stays `{ reported: costReportedAttempts, total: attempts }`.
  - `observeExecution`: a change's `cost` is now null when the accumulated
    `reported` attempt count is 0 instead of only when there are no attempts.
  - `observePlanning`: planning `cost` is now null when no session reported any
    usage (`reported === 0`) instead of summing to zero. Coverage stays
    `{ reported, total: sessions.length }`.
- `tests/web-data-unreported.test.ts` (new): builds an active change whose one
  attempt and one planning session report no cost, plus a change whose first
  attempt reports `0.5` and whose second reports nothing. Through `getWebGraph`
  and `getWebChange` it asserts the unreported change's execution and planning
  costs are null with `{ reported: 0, total: 1 }` coverage while a partially
  reported cost keeps its sum and exact `n of m` coverage.

## Changed

- `src/watcher/sync-run.ts`: new `checkSync(projectRoot, change, config,
  logger)`. It returns null when `vcs.enabled` is off or `NoVcs` is selected,
  when `awaitedDependencies` lists any entry for the change, when the sync had
  nothing to merge, or after a clean merge; it runs `syncWithDefaultBranch`
  with a progress callback that logs through `logger.info`, and maps a thrown
  `SyncStop` to `{ reason, detail }` and any other error to a `sync_failed`
  `WorktreeHalt`.
- `src/watcher/worktree-run.ts`: `WorktreeHaltReason` gains `sync_conflict`
  and `sync_failed`.
- `src/watcher/loop.ts`: imports `checkSync` and calls it at the two points.
  The pre-task call runs in the pending branch after the `checkWorktree` block
  and before the scope audit, only for a worktree change with no done marker,
  re-derives the change state after it, and halts through
  `haltWorktreeChange` before spawning. The pre-archive call runs in
  `archiveCompletedSpec` after `checkWorktree` and before
  `checkAndArchiveSpec`, and halts there before archiving.
- `tests/worktree-sync.test.ts`: new tests over real temporary repositories,
  covering "Sync before the first task" and the proposal's "Main moved while a
  change waited", "No sync between tasks", "Conflict halts the change",
  "Stacked dependent waits for its dependency", and "Dependency lands during
  the dependent's run". They use `runWatcherOnce`/`runWatcherCycle` with a
  local `node verify.cjs`, an adapter that edits in scope, and, for the last
  two, a stacked setup built as `tests/stack-run.test.ts` does, calling
  `landChange` for the dependency mid-run and asserting its code is zero.

## Deviated

The pre-archive call is guarded by a fresh `deriveSpecState`: it syncs only
when the change is actually `done`. `archiveCompletedSpec` runs after every
verified task, so an unconditional call would sync between task 1 and task 2,
which the "No sync between tasks" scenario forbids. The guard is inside
`archiveCompletedSpec` after its `checkWorktree`, as the task requires.

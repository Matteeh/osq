## Changed

- Added `src/docs/adr-page.ts`: `buildAdrPages(projectRoot, config)` builds one
  `AdrPage` per ADR `readDecisions` reads, in number order, carrying its
  frontmatter fields, its `capabilities` (every living capability name for
  `appliesTo: all`, the listed names otherwise, empty when `appliesTo` is
  null), and its `body` — the file text after the frontmatter with the first
  `# ` heading line removed and the result trimmed. Each ADR file is read once
  for its body and stripped with `parseFrontmatter`.
- Added `src/docs/docs-site.ts`: `buildDocsSite(projectRoot, config)` returns
  `{ version: 1, groups, capabilities, adrs }` from `buildCapabilityPages` and
  `buildAdrPages`, with `groups` ordered by group name and the ungrouped
  capabilities last under `ungrouped`.
- Added `tests/docs-site.test.ts`, proving every row of "ADR pages of the docs
  fixture" and "Groups of the docs fixture" on `docsProject()`, including the
  two-build `serializeWebJson` equality.

Touched: src/docs/adr-page.ts, src/docs/docs-site.ts, tests/docs-site.test.ts

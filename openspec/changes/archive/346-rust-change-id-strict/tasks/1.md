## Details

Compare the number forms as text after stripping leading zeros, never by
parsing to an integer, so a long run of digits cannot overflow. An
all-zero run strips to the empty text on both sides.

Later tasks call `parse_change_id(query, false)` and `ChangeId::names`;
keep those signatures exactly as the requirement writes them.

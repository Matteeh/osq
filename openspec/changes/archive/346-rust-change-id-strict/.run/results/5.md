## Changed

- `crates/features/archive/src/lookup.rs`: `archive` now parses its argument with `osq_core::parse_change_id(argument, false)` and matches folders through `ChangeId::names`, in both the git-off and git-on paths. A refused argument returns the `ChangeIdError` display before the lookup. Removed `names` and `leading_digits`.
- `crates/features/retry/src/retry/find.rs`: `matches` now reads the query with `parse_change_id(query, false)` and asks the id whether it names the folder. Removed `matches_prefix`, `padded` and `starts_with_dash`.
- `crates/features/retry/src/retry/text.rs`: `not_found` returns the `ChangeIdError` display when core refuses the id, and the existing `Spec "<id>" not found in <changes>` text otherwise.
- `crates/features/plan/src/steer/lookup.rs`: `matches` now reads the query with `parse_change_id(query, false)` and asks the id whether it names the folder. Removed `matches_prefix`, `padded` and `starts_with_dash`.
- `crates/features/plan/src/steer.rs`: `nothing` returns the `ChangeIdError` display when core refuses the id, and the existing "No active change matching" text otherwise. `plan <name> --brief` keeps treating a refused name as matching no change because `lookup::matches` is false for it.
- Added `crates/features/archive/tests/archive_change_ids.rs`, proving "Change ids archive reads" on fresh `tests/fixtures/project` copies, one case per row, including the trimmed `  007  ` argument.
- Added `crates/features/retry/tests/retry_change_ids.rs`, proving "Retry refuses an id that is not a change id" on fresh `retry-project` copies, one case per row, with every file unchanged.
- Added `crates/features/plan/tests/plan_change_ids.rs`, proving "Steering refuses an id that is not a change id" on fresh `steer-project` copies, one case per row, with every file unchanged.

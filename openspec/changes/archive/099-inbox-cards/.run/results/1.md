## Changed

Extracted the inbox watch loop into a new `src/core/status/dispatch-watch.ts`
exporting `watchDispatch`, `WatchDispatchOptions`, `EveryFn`, `TreesFn`,
`OnItems`, and `DispatchWatch`. It owns the invalidation hub, the poll timer,
the tree-path refresh, and the one-derivation-at-a-time queue, calling
`onItems(items, at)` after each derivation and reporting a thrown derivation
through `options.stderr` as `osq inbox: <message>`. `close()` cancels the poll,
unsubscribes, closes the hub, and waits for the started run.

Rebuilt `src/core/status/dispatch-follow.ts` on `watchDispatch`: it keeps only
the first `readDispatch` print, the `+`/`-` delta, and the sound, and still
exports `followDispatch`, `FollowDispatchOptions`, and a re-exported `EveryFn`
so its importers are unchanged.

Added `tests/dispatch-watch.test.ts` covering batch derivation, poll
derivation, close (watcher closed, poll cancelled, no further derivations),
derivation errors reported while watching continues, hub replacement when the
watched tree paths change, the queued one-more-derivation rule, the start-time
clock passed to `onItems`, and a `followDispatch` smoke test. It uses a fake
watcher, an immediate microtask scheduler, and a manual `every` timer.

Touched: src/core/status/dispatch-watch.ts, src/core/status/dispatch-follow.ts, tests/dispatch-watch.test.ts

## Details

Port approve's folder matching from `src/approve/find.rs` into the lint
crate; do not depend on `osq-feature-approve`. Use rust-storage
`list_changes` for the entries. Run the fixture tests with the root
`Path::new(env!("CARGO_MANIFEST_DIR")).join("tests/fixtures/lint-project")`.

Make the specs kernel's finding paths relative with `Path::strip_prefix`
of the root, and keep the path as given when it does not start with the
root. Pass `change_link_gates` the relative change path
`openspec/changes/<folder>`, so its finding locations stay relative.

`osq-cli` already registers `LintFeature`; dispatch needs no change there.

When the mutation check reports a missed mutant in the lookup, add a test
case for that line rather than keeping a branch no test reaches.

Run the proposal's verify as the watcher does, with
`OSQ_CHANGE=openspec/changes/275-rust-lint-command`, so the link gates see
this change's new requirements.

## Scenarios

- rust-lint: Lint feature commands
- rust-lint: Lint argument errors
- rust-lint: Lint finds no change
- rust-lint: Lint fixture changes
- rust-lint: Lint check errors

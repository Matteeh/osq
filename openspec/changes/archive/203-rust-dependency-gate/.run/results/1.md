## Changed

- `src/kernel/languages/adapter.ts`: exported the `ManifestRead` union and added
  `manifestDependencies` to `LanguageAdapter`; Rust sets it to
  `cargoManifestDependencies`, every other language to null. Added the
  `@scenario languages: No manifest reader for other languages` tag to
  `languageAdapter`.
- `src/kernel/languages/cargo-manifest.ts` (new): `cargoManifestDependencies`,
  osq's own single-pass scanner for `Cargo.toml`. It reads headers, dotted and
  quoted keys, strings, multi-line strings, arrays, inline tables and bare
  scalars; finds crates in `dependencies`, `dev-dependencies`,
  `build-dependencies`, `dev_dependencies`, `build_dependencies`, alone, after
  `workspace`, or after `target.<platform>`; follows `package = "..."` renames
  in both the inline-table and sub-table forms; and returns `line <n>: ...` when
  it cannot read the text. Tagged `@scenario languages: Crates a manifest
  declares` and `@adr 017`. 240 lines, every function under 80.
- `tests/languages-cargo-manifest.test.ts` (new): proves "Crates a manifest
  declares" through the scenario helper with `each` over the spec table's rows
  (every one of the 15 rows), proves "No manifest reader for other languages",
  and checks the adapter wiring directly.

## Deviated

- To stay inside the 250-line budget that `tests/line-budget.test.ts` enforces
  (and that the task's acceptance repeats), the new module drops blank lines
  between declarations and most per-function doc comments. Biome's formatter
  expands the one-line `{ s.failure = line; return null; }` blocks, so the
  compact style is deliberate. `pnpm lint` and both budget tests pass.

## Details

The full key path of a value is the current table header's keys, then the line's dotted keys, then the keys of any inline table around it. A path whose first segments are a dependency table names a crate with its next segment; a string at `<that path>.package` replaces the name. Track strings and brackets across lines in every table, not only dependency tables, so a `[` inside a multi-line string or array is never read as a header.

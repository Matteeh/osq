## Changed
- Moved the scope glob matcher to `crates/core/src/scope/glob.rs` as `scope_covers_path`, with a private JavaScript-compatible trim, and exported it from `osq-core`'s root through `scope.rs` and `lib.rs`.
- Reduced `crates/kernel/specs/src/owners/glob.rs` to a documented one-line call to core's matcher, keeping `Implements: rust-specs/scope-globs`.
- Added `crates/core/src/scope/audit.rs` with `ScopeAudit`, `ChangedPath`, `PathChange`, `LockRule`, `Disallowed`, `DisallowReason` and `audit_scope`, covering the outside-scope, lock-following and frozen-test rules with the required ordering.
- Added `crates/core/tests/scope_audit.rs` covering "Scope coverage cases", "Scope audit cases" and "Lock file at the root follows any covered manifest", including every rust-specs "Scope glob cases" row.
- Verified the task command, the proposal's `sh scripts/verify-rust.sh`, and cargo-mutants over all touched Rust source files.

## Deviated
- Added extra glob edge-case assertions and a same-folder lock-file assertion beyond the scenario tables. They keep the moved matcher's `**/` false cases and the lock rule's at-or-below equality branch covered, so cargo-mutants leaves no missed mutant in the touched lines.

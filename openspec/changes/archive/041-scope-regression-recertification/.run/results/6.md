## Changed

- `src/core/report.ts`
  - New `ScopeRegressionHistory` interface with `detected`,
    `verificationPassedAtDetection`, `verificationFailedAtDetection`,
    `recertifiedByHuman`, and `requeuedForAgent`, added to `HistoryMetrics`.
  - The numbered-task-stream history loop now classifies:
    - `regressed` with `reason === 'scope_regression'` → `detected`; a finite
      `exitCode` of zero → passed-at-detection, a finite non-zero exit →
      failed-at-detection, missing/malformed exit → neither.
    - `recertification` with exact `outcome: 'passed'` → human counter,
      exact `outcome: 'requeued'` → agent counter, anything else ignored.
    - `recertification` is not treated as an execution terminal, so it never
      closes an unexplained-rerun gap; existing `regressed` gap handling is
      unchanged. The new branches add no attempts, dead reasons, or cost.
  - `getMetricsReport` always returns the block, zeros included.
  - `formatMetricsReport` renders one `Scope regressions:` history block with
    all five labels.
- `src/cli/report.ts` — `toStableMetrics` projects `history.scopeRegressions`
  so deterministic JSON carries the block; key ordering stays alphabetical via
  the existing deep sort.
- `tests/report-json.test.ts` — history key assertion adds `scopeRegressions`
  with its five sorted counters; the two synthetic `formatMetricsReport`
  reports include the new field and assert the text block; the zero test
  asserts all five `0` labels.
- `fixture/report/expected.json` — inserted the new zero-valued
  `scopeRegressions` block in sorted position. Byte-for-byte fixture test
  passes.
- `tests/report-scope-regressions.test.ts` (new) — disposable focused fixtures:
  zero-counter shape, finite/missing/malformed detection exits, exact and
  malformed recertification outcomes, active+archive aggregation with active
  markers, retained marker history, results, and a rejected folder excluded,
  attempt/unexplained/dead/cost neutrality after requeue, marker-only
  current-state regression, and text+JSON output.

## Acceptance

- [ ] `RegressedEventData` in `src/harness/types.ts` gains optional `missingPaths?: string[]`, documented as the paths a verify named that did not exist.
- [ ] `verifyArchiveStep` in `archive-verify.ts` records the missing paths in `missingPaths` on the `verify_path_missing` regressed event and no longer sets `differingPaths` there. The marker text and every other regressed event stay unchanged.
- [ ] New `tests/regressed-missing-paths.test.ts` drives the archive step on a done change whose task verify names a deleted file. It asserts that the regressed event's `missingPaths` equals that path and that the event has no `differingPaths` key.
- [ ] `tests/archive-verify-path-missing.test.ts` changes only its `differingPaths` assertion, which becomes the same assertion on `missingPaths`.

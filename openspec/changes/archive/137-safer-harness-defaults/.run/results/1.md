## Changed

- `DEFAULT_CONFIG.agy.dangerouslySkipPermissions` is now `false` (`src/core/foundation/config.ts`).
- `buildAgyArgs` passes `--dangerously-skip-permissions` only when
  `config.agy.dangerouslySkipPermissions === true`; absent, unset, or `false`
  omits it.
- `AgyAdapter.spawnInteractive` follows the same rule.
- `AgyAdapter` gained `preflight(projectRoot, config)`: it rejects when
  `config.agy?.dangerouslySkipPermissions` is not `true`, naming
  `agy.dangerouslySkipPermissions: true` and choosing another harness, and
  resolves when it is `true`. It spawns no process.
- Added `tests/agy-permissions.test.ts` covering the default, `buildAgyArgs`,
  `preflight`, and `spawnInteractive` (fake agy via `AGY_PATH`).
- `tests/config.test.ts` now expects the new default.
- `tests/harness-interactive.test.ts`'s agy case writes
  `agy: { dangerouslySkipPermissions: true }` into its config so the flag is
  still asserted.

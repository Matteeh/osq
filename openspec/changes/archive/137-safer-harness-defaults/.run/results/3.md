## Changed

- `src/core/foundation/init.ts`: `osq.config.ts` scaffolds
  `harness: process.env.OSQ_HARNESS || 'codex'`; `.env.example` starts with
  `OSQ_HARNESS=codex`. The Codex guidance block is unchanged, and a new
  commented line says agy needs `agy: { dangerouslySkipPermissions: true }` in
  `osq.config.ts` to run headless.
- `.env.example` and `templates/.env.example`: rewritten to the scaffolded
  content, byte for byte.
- `README.md`: added `### Antigravity (agy)` with `#### agy permissions` under
  `## Harnesses`; updated the `harness-containment` bullet under
  `## Diagnostics & Health` to say doctor reports it for every harness, fails
  for agy without the bypass, and warns for agy with it or an opencode agent
  other than `osq-coder`; added an `Unreleased:` list above `To 0.2.2:` under
  `## Upgrading`.
- `CHANGELOG.md`: one `## [Unreleased]` entry for the scaffold, the agy default
  change, and the containment line, ending `(137).`.
- `tests/harness-defaults-docs.test.ts` (new): checks the scaffolded config and
  environment example, that both repository `.env.example` files mirror the
  scaffold byte for byte, the README agy section, the `harness-containment`
  bullet, the `Unreleased:` ordering, and the changelog entry.
- `tests/codex-guidance.test.ts`: now expects `OSQ_HARNESS=codex` as the active
  scaffolded default and rejects `OSQ_HARNESS=agy`.

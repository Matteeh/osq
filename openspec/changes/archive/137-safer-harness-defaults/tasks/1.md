## Acceptance

- [ ] `DEFAULT_CONFIG.agy.dangerouslySkipPermissions` is `false`.
- [ ] `buildAgyArgs` adds `--dangerously-skip-permissions` only when `config.agy.dangerouslySkipPermissions` is `true`; unset, `false`, or no config at all leaves it out.
- [ ] `AgyAdapter.spawnInteractive` adds `--dangerously-skip-permissions` under the same rule.
- [ ] `AgyAdapter` gains `preflight(projectRoot, config)`. It rejects when `config.agy?.dangerouslySkipPermissions` is not `true`, with an error saying that headless agy denies every tool call it cannot prompt for and naming `agy.dangerouslySkipPermissions: true` and choosing another harness as the two ways on. It resolves when the setting is `true`. It spawns no process.
- [ ] `tests/agy-permissions.test.ts` covers each line above through `buildAgyArgs`, `AgyAdapter.preflight`, and `AgyAdapter.spawnInteractive` with a fake agy binary through `AGY_PATH`, the way `tests/harness-interactive.test.ts` does it.
- [ ] `tests/config.test.ts` expects the new default, and `tests/harness-interactive.test.ts`'s agy case sets `agy: { dangerouslySkipPermissions: true }` in its config so it still checks the flag is passed.

## Details

The watcher already calls an adapter's optional `preflight` port before the
first cycle for any harness with an external executable; see
`ClaudeAdapter.preflight` for the shape. Don't touch `src/watcher/loop.ts`.

Only flip the value in `config.ts`; the file is at 249 lines against a
250-line budget. Leave `DEFAULT_CONFIG.harness` as `agy`.

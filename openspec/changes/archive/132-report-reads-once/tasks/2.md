don't change that module. The glob `src/core/report/report*.ts` covers
`report.ts`, `report-dependencies.ts` and `report-mutation.ts`; leave the

own loop. Replace that loop with `readEventStream`; it keeps returning the
first valid `archived` timestamp.

Keep every file under 250 lines. `report-mutation.ts` is at 244, so remove the
imports the change leaves unused rather than adding lines.

## Changed

- `land-checks.ts` now exports `assertLandableWorktree(worktree, change, status)`: it refuses an archived change whose own worktree's `.run/regressed/change.md` has reason `commit_failed` with `<folder>'s archive commit failed; fix the cause, then run osq retry <id> change`, and only otherwise runs `assertWorktreeClean`.
- `land.ts` calls `assertLandableWorktree` in place of the bare `assertWorktreeClean` at the same spot, so the archive-commit refusal comes before the clean check and `land.ts` stays at 249 lines.
- New `tests/vcs-land-archive-commit.test.ts` proves version-control "Land on a failed archive commit" with `scenario()`, scaffolding a temp repository like `tests/steering-archived.test.ts`, moving change 002 into the worktree's archive without committing the move, and writing the `commit_failed` marker by hand. It asserts exit 1, the exact refusal, no uncommitted-path list, and both the default branch and the worktree unchanged.

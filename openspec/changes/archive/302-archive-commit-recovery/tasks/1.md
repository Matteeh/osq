## Details

Put the catch-up in the new `src/watcher/archive-catch-up.ts`, reusing
`commitFailedCount`'s rule from `commit-catch-up.ts` and `commitArchive`
from `src/core/run/task-commit.ts`; export what you need from
`commit-catch-up.ts` only through the new module's own copy if exporting
would widen that file's surface. Call it once per cycle from `loop.ts`
before the next task is picked; `loop.ts` is on the line and function
budget allow lists, so add a single call and keep the logic in the new
module. In `retry-archived.ts`, branch on the marker's reason before
`commitArchivedRetry` commits, and keep the land-stop path as it is.

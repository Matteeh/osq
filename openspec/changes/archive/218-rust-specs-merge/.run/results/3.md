# Task 3 result

## Changed

- Added `crates/kernel/specs/tests/replay_corpus.rs`: the corpus test that
  proves rust-specs "Living specs replay" over this repository.
  - `repository_root()` is `env!("CARGO_MANIFEST_DIR")` up three folders.
  - `archived_folders()` orders archived folders by landing: those whose
    `.run/events/change.jsonl` has no `archived` event with a string
    `timestamp` first, by name bytes; then the rest by the last such
    timestamp, then by name. Event lines that do not parse as JSON objects
    are ignored (`serde_json::Value`).
  - `applying_folders()` adds each folder directly under
    `openspec/changes/` other than `archive` that holds
    `.run/archive-specs.json`, by name bytes.
  - The test starts from an empty scratch specs folder under
    `env!("CARGO_TARGET_TMPDIR")`, merges each folder with `merge_change`,
    and writes each merged text or removes the capability folder before the
    next. A merge error panics naming the change folder and the error.
  - For every capability with a living folder or a delta in a replayed
    change it checks: no replay and no living `spec.md`; otherwise the
    living text with its first `## Purpose\n\n` read as `## Purpose\n` for
    the six named capabilities, and the living text unchanged for all
    others. It also fails a named capability that matches without the
    Purpose transform, and collects every failure (each with its first
    differing line) before asserting.

The replay matched byte for byte on the first run; no line in `src/merge/`
needed a fix, so nothing under the task's `src/merge/` scope changed. The
test is a corpus test with the required `#[ignore = "corpus test: reads the
live archive and living specs"]`, under 250 lines, each function under 80.
`cargo test -p osq-kernel-specs --test replay_corpus -- --include-ignored`
passes, `cargo fmt --all` and clippy report nothing, and
`sh scripts/verify-rust.sh` passes (its mutation step prints
`mutation check not run: OSQ_DIFF is not set`).

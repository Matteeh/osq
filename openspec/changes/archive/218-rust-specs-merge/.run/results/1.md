## Deviated

- `apply.rs` passed 250 lines after the doc comments, so the name/scenario
  helpers moved to `apply_names.rs` (allowed by the `apply*.rs` scope).
- The task file says to keep `delta.ts`'s quirks. Three branches there are
  observationally dead and each produced a surviving mutant, so I simplified
  them without changing any output:
  - `extractRequirementsSection`'s no-header `before` and header `before`
    ternaries append a newline that `recompose` trims away; `after`'s
    `rawAfter.startsWith('\n')` is never true because the slice starts at a
    `##` line. I write the trimmed-equivalent values directly.
  - `parseBlocks`'s `isTopLevelHeader` stop never fires: `bodyLines` already
    ends at the first `##` heading outside fences, so the body holds none.
  - The cursor loops (`cursor += 1`) turned into cargo-mutants timeouts under
    `*=`/`-=` mutants; they are now `find`/`filter`/slicing without a cursor.
- The tests are split across `merging_deltas.rs` (the tables) and
  `merging_deltas_edges.rs` to keep each file under 250 lines and each
  function under 80.

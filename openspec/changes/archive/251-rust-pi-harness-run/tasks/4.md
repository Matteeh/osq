## Details

Copying the fake and then running it races with other test threads: a
process forked while the copy was open for writing keeps it open, and Linux
refuses to run it with `Text file busy (os error 26)`. A trial run of the
binary 40 times failed 5 times this way, which failed cargo-mutants'
baseline at archive. Running the committed file, which nothing writes,
removes the race. Do not add retries or sleeps.

`run.sh` keeps its mode and its text; it is task 2's file and outside this
task's scope.

Before exiting, run `cargo fmt --all`, then `sh scripts/verify-rust.sh`
with `OSQ_CHANGE` set to `openspec/changes/251-rust-pi-harness-run`.

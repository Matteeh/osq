## Details

TypeScript's `eventLine` in `src/core/vcs/sync-recertify.ts` writes the
recertification without `output`; ADR 025 says Rust reads today's files as
they are, so the field becomes optional rather than TypeScript changing.
Read it only to check the shape; Rust code never imports anything under
`src/`.

The line at `openspec/changes/251-rust-pi-harness-run/.run/events/2.jsonl`
line 89 is the real case; the schedule corpus test failed on it. No code
outside core reads `RecertificationData.output`.

Before exiting, run `cargo fmt --all`, then `sh scripts/verify-rust.sh`
with `OSQ_CHANGE` set to `openspec/changes/251-rust-pi-harness-run`.

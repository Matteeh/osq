## Details

Add the stop to the runner's existing state machine in `src/process/state.rs`:
a stop deadline beside the timeout, kill and stdout deadlines, set once on
the first `true` from `on_line`, that sends `SIGTERM` through the existing
`signal` and then arms the kill deadline as the timeout does, without
marking the run timed out. Change `RunState::apply` and the receive loop to
take the `bool`-returning callback.

Put `PiHarness` in `src/pi/harness.rs`, declared from `src/pi.rs`, and port
the run part of `PiAdapter.spawn` from `src/harness/pi/pi.ts`: build the
arguments with `pi_args`, feed each line to `pi_line_events` with a fresh
`PiStreamState`, and read `PiStreamState::settled` after each line. The
agent names come from `HARNESS_AGENT_ENV.pi` in
`src/core/foundation/config-confinement.ts`. The real-pi test builds its
environment with `osq_kernel_runners::role_env` for `EnvRole::Agent` from
`std::env::vars()`.

Keep each condition observable for cargo-mutants: add a row-named test for
any branch the scenario tables leave unchecked rather than a branch no test
reaches. cargo-mutants does not run ignored tests, so `tests/real_pi_run.rs`
proves nothing a fake test does not also prove.

Before exiting, run `cargo fmt --all`, then
`OSQ_CHANGE=openspec/changes/251-rust-pi-harness-run sh scripts/verify-rust.sh`
so the link-gate corpus test sees this change's requirements.

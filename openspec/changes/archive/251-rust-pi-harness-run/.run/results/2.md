## Changed

- Added `run_process_until` to the process runner, with a stop deadline that sends `SIGTERM` one `kill_grace` after the first accepted line and `SIGKILL` one `kill_grace` after that, without marking the run timed out. `run_process` now delegates to it with an `on_line` that returns `false`.
- Added `PiHarness` in `crates/kernel/harnesses/src/pi/harness.rs`, implementing `osq_kernel_runners::Harness`: group agent names, `pi_args` from the start request and settings, stdout translated through `pi_line_events`, stop after `agent_settled`, TypeScript's missing-key hint, and `last_error`.
- Added the `osq-kernel-harnesses` dependency on `osq-kernel-runners` and updated `Cargo.lock` through cargo.
- Added the fake pi run fixture and tests for stop-after-line, fake pi runs, start arguments and defaults, cannot-start, agent names, and the ignored real-pi run.
- Ran `cargo fmt --all`, the task's `cargo test` command, and `OSQ_CHANGE=openspec/changes/251-rust-pi-harness-run sh scripts/verify-rust.sh`. All passed. Manual `cargo mutants` on `harness.rs`, `process/state.rs` and `process/runner.rs` found no missed mutants after the extra branch test below.

## Deviated

- Added a `settled-with-stderr` mode to the fake pi and a small `settled_start_hides_stderr` test beside the scenario rows. It makes the settled-start suppression of stderr observable, which removed the only missed mutant in `PiHarness::failure`; the scenario rows themselves are unchanged.

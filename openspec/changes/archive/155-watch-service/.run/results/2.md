## Changed

- `src/watcher/service-build.ts` (new): exports exactly the Ports — `EXIT_NEW_BUILD` (75), `BuildChangedError` and `BuildWaitError`, both extending `StaleBuildError`, `ServiceBuildCheckOptions`, and `createServiceBuildCheck`. The build key (the package root's `version` plus the newest `dist/` mtime, read via `newestDistMtimeMs`) is read once at creation; each call of the returned `StaleCheck` follows the "Service worker build checks" table: a changed key whose newest `dist/` is at least `settleSeconds` old throws `BuildChangedError`; a changed key with a younger `dist/` waits `a new osq build is being written`; an unchanged key with `src/` newer than `dist/` waits the stale line from `findStaleBuild({ packageRoot, distMtimeMs: keyMtime })`; an unchanged key with `src/` no newer passes with null. Every wait calls `onWaiting` with the reason and throws `BuildWaitError`; the first pass after a wait calls `onWaiting(null)`; each reason is logged through `logger.info` only when it differs from the last one logged.
- `src/watcher/stale-pass.ts`: `handleStaleBuild` now handles both new subclasses — a `BuildWaitError` is swallowed so the caller's loop lives on, a `BuildChangedError` clears the status and exits with `EXIT_NEW_BUILD` without printing, and a plain `StaleBuildError` prints its line and exits 1 as before.
- `src/watcher/loop.ts`: `StartWatcherOptions` gains `buildCheck?: StaleCheck`. When set, `startWatcher` uses it in place of `startStaleCheck` (the start check never runs), runs it at the top of every continuous cycle in `cycleHandler`, and keeps passing it to `runWatcherCycle` as the `staleCheck` argument, so the existing pass points (before picking up a pending task, at the top of the archive step) use it unchanged. A `BuildWaitError` ends the cycle without stopping the loop or logging a `watcher error`; a `BuildChangedError` stops the loop and `handleStaleBuild` calls `options.exit(EXIT_NEW_BUILD)` without printing. A watcher without `buildCheck` behaves exactly as before.
- `tests/watch-service-build.test.ts` (new): direct calls of the returned check for each row of the table with `now` injected (settled key change, younger key change, unchanged-with-stale-line, unchanged-pass), plus the `onWaiting`/logging contract (reason on every wait, null on the first pass after, reason logged once).

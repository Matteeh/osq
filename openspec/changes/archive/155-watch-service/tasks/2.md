## Acceptance

- [ ] New `src/watcher/service-build.ts` exports exactly the Ports below and implements watcher-and-harness "Service worker build checks": the build key is read once by `createServiceBuildCheck`, and each call of the returned check follows the requirement's table. Reuse `findStaleBuild` with `distMtimeMs` set to the key's mtime for the stale line, and `newestDistMtimeMs` for the key.
- [ ] The check calls `onWaiting` with the reason on every wait and with null on the first pass after a wait, and logs the reason through `logger.info` only when it differs from the last one logged.
- [ ] `StartWatcherOptions` in `loop.ts` gains `buildCheck?: StaleCheck`. When set, `startWatcher` uses it in place of `startStaleCheck`, runs it at the top of every continuous cycle and keeps using it at the existing pass check points; a `BuildWaitError` ends that cycle without stopping the loop or logging a `watcher error`; a `BuildChangedError` stops the loop and calls `options.exit(EXIT_NEW_BUILD)` without printing. `handleStaleBuild` in `stale-pass.ts` handles both subclasses. A watcher without `buildCheck` behaves exactly as before.
- [ ] New `tests/watch-service-build.test.ts` covers every scenario of "Service worker build checks" through `startWatcher` with the mock adapter, an injected `exit`, and a temporary package root holding `package.json`, `src/` and `dist/` with mtimes set by `fs.utimes`, built the way `tests/watcher-stale-every-pass.test.ts` builds one. It also calls the check directly for each row of the table, with `now` injected.
- [ ] Every touched source file stays at or under 250 lines except `loop.ts`, which is on the line-budget allow list, and no file in `src/` holds the word "skipped". // src/watcher/service-build.ts
```ts
import type { Logger } from '../core/foundation/logger.js';
import { StaleBuildError } from './build.js';
import type { StaleCheck } from './stale-pass.js';

/** Exit code of a service worker that found a new osq build. */
export const EXIT_NEW_BUILD = 75;

export class BuildChangedError extends StaleBuildError {}
/** Its message is the reason the worker waits. */
export class BuildWaitError extends StaleBuildError {}

export interface ServiceBuildCheckOptions {
  /** osq's package root; defaults to the running one. */
  readonly packageRoot?: string;
  /** `config.watch.buildSettleSeconds`. */
  readonly settleSeconds: number;
  readonly logger?: Logger;
  readonly onWaiting?: (reason: string | null) => void | Promise<void>;
  readonly now?: () => number;
}

export async function createServiceBuildCheck(options: ServiceBuildCheckOptions): Promise<StaleCheck>;
```

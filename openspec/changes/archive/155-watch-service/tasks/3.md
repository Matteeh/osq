## Acceptance

- [ ] New `src/watcher/service.ts` exports exactly the Ports below and implements watcher-and-harness "Watch service supervisor". Its shape follows `runDevSupervisor` in `dev.ts`: injectable seams, one `exit` path, and a promise that settles when the supervisor is done.
- [ ] The default `spawnWorker` opens `spec.logPath` for appending and spawns `spec.command` with `spec.args`, `spec.env` and `spec.cwd`, its stdin ignored and its stdout and stderr on that file. The worker env is the supervisor's env with `OSQ_WATCH_ROLE=worker`. Its args are `execArgv`, then `entry`, `watch`, and `forwardArgs`.
- [ ] Log rotation runs before every spawn. The supervisor's own lines are appended to the log path from `readWatchState`, each starting with an ISO timestamp. Delays and sizes come only from `config.watch`, and `EXIT_NEW_BUILD` is imported from `service-build.ts`. `service.json` is removed with `removeWatchRecord` and the supervisor's own pid.
- [ ] New `tests/watch-supervisor.test.ts` covers every scenario of "Watch service supervisor" with injected seams: fake children (`EventEmitter`s with a `kill` that records the signal), a fake timer and clock, and a temporary home and project. The backoff table is checked delay by delay.
- [ ] Every touched source file stays at or under 250 lines and no file in `src/` holds the word "skipped". Every existing test passes unchanged.

```ts
// src/watcher/service.ts
import type { ChildProcess } from 'node:child_process';
import type { OsqConfig } from '../core/foundation/config.js';

export const WATCH_ROLE_ENV = 'OSQ_WATCH_ROLE';

export interface ServiceWorkerSpec {
  readonly command: string;
  readonly args: string[];
  readonly env: NodeJS.ProcessEnv;
  readonly cwd: string;
  /** Absolute path of watch.log. */
  readonly logPath: string;
}

export interface ServiceSupervisorOptions {
  readonly projectRoot: string;
  readonly config: OsqConfig;
  /** The `osq` entry path the supervisor was started with (`process.argv[1]`). */
  readonly entry: string;
  readonly execArgv: readonly string[];
  /** `--verbose` or `--quiet`, when given. */
  readonly forwardArgs: readonly string[];
  readonly home?: string;
}

export interface ServiceSupervisorOverrides {
  readonly spawnWorker?: (spec: ServiceWorkerSpec) => ChildProcess;
  readonly setTimer?: (callback: () => void, delayMs: number) => { cancel(): void };
  readonly now?: () => number;
  /** Subscribes to SIGTERM and SIGINT; returns the unsubscribe. */
  readonly onSignal?: (handler: () => void) => () => void;
  readonly exit?: (code: number) => void;
}

export async function runServiceSupervisor(
  options: ServiceSupervisorOptions,
  overrides?: ServiceSupervisorOverrides,
): Promise<void>;
```

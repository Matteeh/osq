## Deviated

- No `Implements:` tag sits in the doc of the public `Gates.commit_retries`
  or `Config.gates` field. The linter's corpus test counts every `Implements:`
  text line in a file but only builds edges for struct, field-less and
  function doc tags, so a field tag makes `live_tags_become_edges` fail. The
  struct and reader carry the tag instead.

## Acceptance

- [ ] For a change in an osq worktree, `refusals::check` runs rust-run "Worktree checks" after its git check and before its marker refusals, and a failed verified or dead commit writes the "Worktree halt" record before `run` fails with its existing text.
- [ ] New `tests/run_worktree_halts.rs` proves every row of "Worktree halts before the start", "Worktree check allows the change's records", "Pending verified commit" and "Failed commits halt the change".
- [ ] `tests/worktree_support/mod.rs`'s `build` writes `fake-pi-mode` and a newline to the checkout's `.git/info/exclude` after `git init`. In `tests/run_worktree.rs`, `an_untracked_test_file_is_committed` narrows the scope to `src/a.txt` and `src/tests/new.rs`, runs the fake pi's `added-test` mode and writes no file before the run; every other run test passes unchanged.
- [ ] Every public item ends its doc with `Implements: rust-run/<requirement>`, and each new test's doc names `Covers: rust-run/<scenario>`. `cargo fmt --all`, then the proposal's verify, pass with no missed mutant.

## Details

Put the halt record and the checks in their own files in the run crate.
Append the `regressed` event with `events::append` and core's
`RegressedData`, and cut the detail with `output::tail_verify_output`. The
pending verified commit reads task `<n>`'s file with `read_task_file` and
reuses `commit::verified`; status entries and the "outside the change"
test can reuse `pause::outside_change` and `scope::relative`. The commit
failures in `commit.rs` and `dead::kill` call the halt writer; with git off
or for a change at the root nothing here runs.

Build test repositories with `tests/worktree_support/mod.rs` and its
`refuse_commits`. When the mutation check reports a missed mutant, add a
test case for that line. Run the proposal's verify with
`OSQ_CHANGE=openspec/changes/312-rust-run-worktree-checks`.

## Scenarios

- rust-run: Worktree halts before the start
- rust-run: Worktree check allows the change's records
- rust-run: Pending verified commit
- rust-run: Failed commits halt the change
- rust-run: Verified task commit
- rust-run: Verified task commit fails
- rust-run: Dead task commit
- rust-run: Dead task commit fails
- rust-run: Run refusal texts

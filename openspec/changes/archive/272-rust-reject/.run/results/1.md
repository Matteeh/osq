## Changed

Added `reject` to the approve feature. `ApproveFeature` now lists `approve` then `reject`, and dispatches `reject` to a new `src/reject.rs` with submodules for arguments, markers, eligibility, the record, texts and the UTC time.

The reject path parses `--reason` and one id before reading files, reuses the widened approve lookup, and refuses in order: no match, an existing rejected destination, any running pid, and an approved but healthy change. Eligibility reads `.run/` markers directly, including task files for dead and regressed markers. A successful rejection renames the folder into `openspec/changes/rejected/`, writes `.run/rejected.md`, appends the `rejected` event line with `serde_json` strings, and prints the three rejection lines.

The timestamp conversion lives in `src/reject/time.rs` and is a pure epoch-millisecond formatter. `tests/reject_time.rs` includes that source with `#[path = "../src/reject/time.rs"]` so it can prove the private pure conversion over every month, leap year, era and time-of-day field, alongside the integration "Rejection files" test that parses the clock back.

New tests prove every reject scenario: argument errors, every outcome row and refusal order, no match, marker eligibility, the marker/event/output bytes, and the time conversion. `tests/approve_feature.rs` only changed `approve_feature_commands` to expect both commands.

`cargo test -p osq-feature-approve` and `OSQ_CHANGE=openspec/changes/272-rust-reject sh scripts/verify-rust.sh` pass. `cargo mutants -p osq-feature-approve` caught all 211 viable mutants with none missed. Cargo updated `Cargo.lock` with the new `serde_json` dependency entry.

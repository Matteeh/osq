## Details

Never read anything under `src/` from Rust; the TypeScript files are in
`entry` only so you can port them. Do not use `read_change`: it folds event
streams, while reject reads the marker files directly, as TypeScript's
`assertRejectable` does. "Rejection files" parses `<t>` back to epoch
milliseconds in the test and checks it lies between the two clock
readings, so every field of the time conversion is checked.

Run the proposal's verify as the watcher does, with
`OSQ_CHANGE=openspec/changes/272-rust-reject`, so the link gates see this
change's new requirements.

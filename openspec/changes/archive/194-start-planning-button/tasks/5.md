## Details

Measured on 2026-10-14 with `plan` added to `WebActionVerb`: the CLI typecheck failed only in `tests/serve-actions.test.ts`, at its two command tables; the UI typecheck failed in `useChangeActions.ts`; and `web-write.ts` went to 251 lines with the new body branch, which is why `parseActionRequest` moves.

The glob `src/core/web/web-action*.ts` covers `web-actions.ts` and the new `web-action-body.ts`. To let a test swap `planCommand`, give `createServerCommands` and the default table an injectable plan command the way `createServerCommands` already takes `land`.

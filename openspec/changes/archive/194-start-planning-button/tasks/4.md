## Details

The scratch tree is `path.join(path.dirname(worktreePath(config.vcs, projectRoot, folderName)), '.planning', folderName)`. `vcs.worktreeAdd(path, sha)` with HEAD's commit gives a detached checkout, so no port method is added. A scratch folder holds untracked files, so remove it with `fs.rm(..., { recursive: true, force: true })` and then `vcs.worktreePrune()`, never `worktreeRemove`.

Take two snapshots of plan files in the scratch flow: the change folder before the copy (what to copy back), and the scratch folder after `planCommand` wrote `plan-prompt.md` (what the planner changed). Without the second, a planner that does nothing would count the regenerated `plan-prompt.md` as its edit.

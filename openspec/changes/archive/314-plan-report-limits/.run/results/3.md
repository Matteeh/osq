## Changed

- `report::sections` now loads `osq.toml` with `load_config(root)` (mapping a config error to `FeatureError::failed("plan", ...)`, as `next/number.rs` does) and passes `config.planning` to `build`; a small `to_size` helper converts each `u64` size to `usize`.
- `record::body` takes `minimum_tasks`, `recent_changes` and `dead_outcomes` as `usize` arguments, formats the too-small sentence with the configured minimum, truncates its window and dead rows by the configured sizes, and keeps no size constant.
- `hints::body` takes `minimum_tasks`, `recent_tasks` and `max_characters` as `usize` arguments; `fit_lines` and `newest_first` keep their names and signatures, and the file still uses only `super::leading_number`.
- `disclosures::body` takes `recent_changes` and `max_characters` as `usize` arguments; `recent_archived` truncates to the configured count and the budget uses the configured cap.
- Added `crates/features/plan/tests/prompt_config.rs`, which writes `osq.toml` into each scratch root and proves every row of "Configured record sizes", "Configured history sizes" and "Configured disclosure sizes".

## Deviated

- Renamed the record's private dead-row helper to `dead_lines`, since its old name collided with the new `dead_outcomes` size argument. Behaviour is unchanged.
- The new test file also builds its own archive fixtures, because the task scoped it but no existing test fixture covered every configured row.

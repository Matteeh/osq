## Acceptance

- [ ] New `decisions/015-mcp-transport.md` implements cli-foundation "MCP transport decision". Its frontmatter is `status: accepted`, `applies_to: [cli-foundation]`, the rule exactly as the requirement quotes it, and `checks` listing `tests/mcp-protocol.test.ts`, `tests/mcp-files.test.ts`, `tests/mcp-tools.test.ts` and `tests/mcp-cli.test.ts` in that order. Its body follows ADR 014's sections: `# 015. MCP transport`, `Date: 2026-10-09`, then Status, Context, Decision, Consequences and Rejected.
- [ ] Context says that ADR 014 decision 7 gives MCP clients `osq mcp`, and that the protocol has two live eras: the `initialize` handshake (2024-11-05 to 2025-11-25) and the stateless 2026-07-28 revision with per-request `_meta` and `server/discover`. It also says that on 2026-10-09 the official SDK's `LATEST_PROTOCOL_VERSION` was `2025-11-25` in both v1 (`@modelcontextprotocol/sdk` 1.32.1, 17 runtime dependencies including express, hono, jose and zod) and v2 (`@modelcontextprotocol/server` 2.3.1, adding `@modelcontextprotocol/core` and `zod`).
- [ ] Decision has these numbered points:
  1. osq speaks newline-delimited JSON-RPC over stdio itself, in both eras, and answers only `initialize`, `ping`, `tools/list`, `tools/call` and `server/discover`.
  2. The tools are only `plan`, `list_files`, `read_file`, `write_file`, `edit_file`, `delete_file`, `spec`, `query` and `lint`. The file tools stay inside one unapproved change folder, or its working copy against a server.
  3. Command tools return exactly the CLI's text through 162's forwarded runner or client.
  4. `tools/call` runs one at a time in arrival order.
- [ ] Rejected names the MCP SDK and says to revisit it when osq takes `zod` as a dependency for another reason, or when the SDK serves the 2026-07-28 era. Then only `src/cli/mcp-protocol.ts` would change. Rejected also names MCP over HTTP (ADR 014 rejects OAuth for now) and approve, land, reject and retry as tools (ADR 014 decision 7).
- [ ] `decisions/README.md`'s index gains `- [015. MCP transport](015-mcp-transport.md)` after the ADR 014 line. Nothing else in it changes.

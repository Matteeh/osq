## Changed

- Updated `src/harness/opencode.ts`:
  - Defined `OpencodeTokensData` interface representing prompt, candidate, total, and cached token counts along with execution cost.
  - Implemented `extractOpencodeTokens` to extract `promptTokens` (from `tokens.input`), `candidateTokens` (from `tokens.output`), `totalTokens` (from `tokens.total` or derived sum), `cachedTokens` (supporting numeric values and `{ read, write }` objects), and `cost` from OpenCode event payloads.
  - Implemented `processOpencodeStdoutLine` to parse JSON lines, append `tokens` events to `.run/events/<n>.jsonl`, log unknown event types (e.g. `step_start`, `text`) at debug level via `console.debug`, and silently ignore malformed/unparseable non-JSON lines without throwing.
  - Implemented `OpencodeEventStreamParser` to buffer incoming stream chunks across arbitrary byte and newline splits and sequentially await pending event append operations.
  - Updated `OpencodeAdapter.spawn` to feed stdout chunks to `OpencodeEventStreamParser` and flush pending events before writing the final `exited` marker event.
- Created `tests/opencode-events.test.ts`:
  - Added test validating line-by-line parsing and chunked stream parsing matching `fixture/opencode-events.jsonl`.
  - Added test validating token extraction from `step_finish` events for input, output, total, and cache tokens with cost.
  - Added test validating that `tokens` events are appended to `.run/events/<n>.jsonl` both directly and end-to-end via `OpencodeAdapter.spawn`.
  - Added test validating that unknown events like `step_start` and `text` are logged at debug level without throwing.
  - Added test validating that malformed or non-JSON stdout lines do not crash the adapter process or disrupt stream processing.

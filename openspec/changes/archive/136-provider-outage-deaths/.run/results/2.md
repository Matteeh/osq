## Changed

- `src/watcher/provider-retry.ts` (new): holds the provider retry decision. `decideProviderRetry` returns whether a `provider_unavailable` death may be retried, checking its own `gates.providerRetries` budget by counting automatic retry events whose reason is `provider_unavailable` since the cutoff, and requiring `gates.providerRetryDelaySeconds` to have passed since the task's latest `dead` event. The clock is injected as `now`. It also exports the stream helpers (`readStream`, `laterOf`, `lastManualRetryAt`, `automaticRetriesSince`) and the `PROVIDER_REASON` / `PROVIDER_DEFAULTS` constants.
- `src/watcher/auto-retry.ts`: `provider_unavailable` joined `ELIGIBLE_AUTO_RETRY_REASONS`; `automaticRetriesSince` now skips provider retries so they never spend `gates.autoRetries`; a provider death skips the stuck check entirely and routes through `decideProviderRetry`, while every other reason keeps the existing stuck and budget logic. `runAutomaticRetries` and `decideDeadTask` accept an injected `now` (defaulting to `Date.now()`). The stream helpers moved to `provider-retry.ts` so this file stays at 201 lines and `decideDeadTask` at 53.
- `tests/provider-retry.test.ts` (new): builds an approved temporary change folder, writes dead markers and event streams, and drives `runAutomaticRetries` with an injected clock. Covers the wait before the delay and the retry after it, the separate provider budget under `gates.autoRetries: 1` (two same-fingerprint provider deaths never stuck, then a `verify_red` death that still retries), budget exhaustion, `gates.autoRetries: 0` disabling provider retries, and that a repeated non-provider death is still stuck. Also unit-tests `decideProviderRetry` directly.
- `README.md`: `provider_unavailable` added to the Automatic retry reasons, its wait and its own `gates.providerRetries` budget, the never-stuck rule added to the Stuck tasks bullet, a new Provider outages bullet explaining `gates.providerStallSeconds` and the early SIGTERM stop, and `provider_unavailable` added to the dead reasons list.

## Deviated

The task said to reuse the stream helpers already in `auto-retry.ts`. That file was at 256 lines after the provider branch, over the 250-line budget, so I moved `readStream`, `laterOf`, `lastManualRetryAt`, and `automaticRetriesSince` into `src/watcher/provider-retry.ts` and import them back. `auto-retry.ts` is now 201 lines.

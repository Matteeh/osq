## Changed

- `src/core/foundation/config-gates.ts`: added `gates.providerStallSeconds` (300), `gates.providerRetries` (3) and `gates.providerRetryDelaySeconds` (300) to `GatesConfig`/`DEFAULT_GATES_CONFIG`, and validated all three through one non-negative-integer helper that keeps each missing key's default and names the key on rejection.
- `src/watcher/failure-reason.ts`: added `provider_unavailable` to `RunTaskFailureReason`.
- `src/watcher/provider-outage.ts` (new): `findOpenProviderRetry`/`readOpenProviderRetry` classify an attempt's open provider retry (events after the last `started`, a `harness_retry` start with no later `success: true` end; first open start time, latest open error), `formatAgentFailureMarker` renders the `crashed`, `timeout` and `provider_unavailable` marker bodies, `describeAgentFailure` combines both, and `startProviderStallWatch` runs the unref'd `setTimeout` chain that SIGTERMs a stalled agent.
- `src/watcher/spawn-guard.ts`: `spawnOrCrash` wraps `onSpawn` to capture the pid and starts/stops the provider stall watch around `adapter.spawn`.
- `src/watcher/spawn.ts`: the failure branch now delegates classification and marker text to `describeAgentFailure`; `spawn.ts` is 197 lines (under the 200-line budget).
- `tests/provider-outage.test.ts` (new): covers the gate keys, the classifier, the marker text, the classification of timeout/crash with and without an open retry, and the SIGTERM early stop (including `providerStallSeconds: 0` starting no timer and the timer stopping after exit).

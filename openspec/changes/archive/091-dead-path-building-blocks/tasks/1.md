## Details

No argument list in `src/core/vcs/` may contain `reset`, `--force`, or the
other forbidden arguments `tests/vcs-write.test.ts` lists. `git restore
--source=HEAD --staged --worktree -- <paths>` restores both, and `git rm
--cached -q -- <paths>` unstages a file HEAD lacks before `clean -fd`; `git ls-tree
-r --name-only HEAD -- <paths>` tells which paths HEAD has. `git commit
--only -- <paths>` commits only them; leave both out when there are no paths. Prove "runs no git command" by
counting calls through a context whose `run` records them, or by a
non-worktree tree where any git call would throw. `git-vcs-write.ts` has 214
lines; keep it within 250 and every function within 80.

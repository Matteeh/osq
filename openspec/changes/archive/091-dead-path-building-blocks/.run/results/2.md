## Changed

- Added `src/core/run/commit-message.ts`:
  - `readCommitTrailers(changeFolder, taskNumber)` always returns the
    `Osq-Change` (change folder base name) and `Osq-Task` trailers, and adds
    `Osq-Model`/`Osq-Version` from the last valid `started` event in
    `.run/events/<n>.jsonl`, found via `getEventsPath`. Malformed jsonl lines
    and events whose `data` lacks string `harness`, `model`, or `osqVersion`
    are ignored; a missing events file yields only the two base trailers.
  - `formatCommitMessage({ subject, title, outcomeLine, trailers })` assembles
    the subject, a blank line, the title and outcome line, a blank line, the
    trailers, and one trailing newline. Pure, with no watcher import.
- Added `tests/commit-message.test.ts` covering "Trailers parse" (second
  `started` event wins, parsed with `git interpret-trailers --parse`), "No
  started event", malformed-line tolerance, and an invalid `started` event
  counting as absent.

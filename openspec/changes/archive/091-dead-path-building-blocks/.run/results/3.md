## Changed

- Added `src/core/run/dead-commit.ts` exporting `commitDeadTask(vcs, config,
  changeFolder, taskNumber, reason, title, outcomeLine)`. It fails first when
  `config.vcs.author` is unset; resolves the worktree root through `vcs.root()`
  and the change folder to a worktree-relative POSIX path; writes `vcs.patch()`
  to `.run/dead/<n>.patch`; discards every `vcs.status()` path outside the
  change folder (both `path` and a rename's `from`); then commits whichever of
  `.run/dead/<n>.md`, `.run/dead/<n>.patch`, and `.run/events/<n>.jsonl` exist.
  The subject is `osq: <numeric prefix> task <n> dead, reason <reason>`, the
  message comes from `readCommitTrailers` + `formatCommitMessage`, and the
  author is `config.vcs.author`. Returns the new commit.
- Added `tests/dead-commit.test.ts` with a temporary repo and a linked worktree
  on `osq/091-dead`, getting the `Vcs` through `selectVcs`. Covers "Agent edits
  put back" (one commit holding only the three `.run/` files, empty status
  outside `.run/`, subject with the folder prefix, and `git apply` restoring the
  modified tracked file and the new untracked file), "Patch before discard" (a
  proxy `Vcs` whose `discard` throws, patch already on disk), "Spec conflict"
  (`tasks/1.md` edit stays uncommitted while only `.run/` is committed), and
  "Missing `vcs.author` fails before writing anything" (no `.run/dead/<n>.patch`).

## Deviated

- In the "Agent edits put back" test the committed patch also contains the
  `.run/dead/<n>.md` and `.run/events/<n>.jsonl` new-file diffs, which already
  exist after the dead commit, so `git apply` runs with
  `--exclude=openspec/changes/091-dead-path-building-blocks/.run/*` to apply the
  agent's two edits without the already-present `.run/` records. The apply still
  runs from the worktree root as the task asked.

## Changed

- `src/core/vcs/git-vcs-write.ts`:
  - `discard` returns immediately when given no paths, before any git call
    including the linked-worktree and `osq/` branch assertions.
  - `discard` now restores the given paths to HEAD in both the index and the
    working tree (`git ls-tree` for HEAD's files, `git restore --source=HEAD
    --staged --worktree --`), unstages files HEAD lacks with `git rm --cached`
    before `git clean -fd`, so a staged new file is removed from the index and
    the tree. Ignored files are still left alone.
  - `commit` stages exactly the given paths and commits only them with `git
    commit --only -- <paths>`, leaving any other staged change staged; with no
    paths it commits the index as before. `commitMessage` now takes the paths.
- Added `tests/vcs-discard-commit.test.ts`: a temporary repository with a
  linked worktree on `osq/001-a` covering "Discard with no paths" (recording
  context proves zero git calls and the untracked file remains), "Discard a
  staged new file" (staged new file gone from index and tree, staged tracked
  file matches HEAD, status empty), "Commit leaves other staged paths", and
  commit with no paths committing the index.

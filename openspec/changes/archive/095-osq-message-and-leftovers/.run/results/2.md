## Changed

- Added `src/core/run/squash-message.ts`: `buildSquashMessage` selects the
  `Vcs`, finds the matching change across `listChanges` worktree trees (active
  matching folder refuses with `<folder> has not archived on osq/<folder>`, no
  archived match refuses with `No archived change "<id>" in an osq worktree`),
  applies the `awaitedDependencies` stacked refusal, and assembles the message
  exactly as "Squash commit message" says. It writes nothing. `formatSquashMessage`
  builds the subject from the folder prefix and words, the trimmed proposal
  `## Goal`, one `[verified]`/`[manual] task <n>: <title>` line per `tasks.md`
  entry (manual from the `.run/done/<n>` frontmatter), then the trailers
  `Osq-Change`, `Osq-Base`, `Osq-Head` (worktree head from `worktreeList`),
  `Osq-Approved`, `Osq-Approved-By`, and distinct `Osq-Model` then distinct
  `Osq-Version` values in task order via `readCommitTrailers`, ending with one
  newline. Missing/empty file trailers are left out.
- Added `src/cli/message.ts`: `messageCommand` takes `stdout`, `stderr`, and an
  injectable `exit` (defaulting to `process.exitCode`), prints the message to
  stdout and `Branch:`/`Land:` to stderr on success, and prints only the
  refusal to stderr and exits one otherwise. `registerMessageCommand` registers
  `osq message <id>`.
- Changed `src/cli/index.ts`: imports and calls `registerMessageCommand`
  alongside `registerApproveCommand` (244 lines, under the 250 budget).
- Added `tests/squash-message.test.ts`: temporary git repositories built like
  `tests/worktree-run.test.ts`. Covers Message after archive incl. a real
  `git merge --squash` + `git commit -F -` and `git interpret-trailers --parse`,
  two models, a manual task, not-archived and no-archived refusals, the stacked
  dependency refusal, branch/land on stderr, and the flag-off refusal.

## Changed

- Added `src/core/trace/lookup-root.ts`: the openspec root search moved out of
  `scenario-lookup.ts`, plus the linked-worktree read from the traceability
  delta. It reads `<folder>/.git`, resolves the `gitdir:` line against the
  folder, reads that directory's `HEAD`, accepts only `ref: refs/heads/osq/<folder>`
  where `<folder>` is a single segment directly under `<openspecRoot>/changes`,
  and caches the result per openspec root. `clearLookupRootCache` drops it.
  Imports only `node:fs` and `node:path`; no `node:child_process`.
- Changed `src/core/trace/scenario-lookup.ts`: imports `findOpenspecRoot`,
  `worktreeChangeFolder`, `clearLookupRootCache`, and `SpecLocation` from the new
  module; `resolveLocation` uses the worktree's change folder when `OSQ_CHANGE`
  is unset; `clearScenarioLookupCache` also clears the worktree cache. Now 239
  lines.
- Added `tests/trace-worktree-change.test.ts`: five tests through
  `lookupScenario` in temporary trees with hand-written `.git` and `HEAD` files,
  covering the delta's "Change from the worktree branch", "Worktree change
  already archived", "Checkout or other branch" (both a `.git` directory and a
  non-`osq/` branch), and "Branch read once". No git runs.

## Deviated

- Added a guard that rejects a worktree folder containing `/` or `\` and an
  empty folder name. The delta's "a change folder that is not under `changes/`,
  such as one already archived" needs it so a branch like
  `osq/archive/002-b` cannot resolve to `<changes>/archive/002-b`.

Touched: src/core/trace/lookup-root.ts, src/core/trace/scenario-lookup.ts, tests/trace-worktree-change.test.ts

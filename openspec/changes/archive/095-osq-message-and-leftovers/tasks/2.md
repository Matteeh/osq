## Details

Find the change with `listChanges` and match ids the way `findChange` does.
The archived folder is the one in a tree whose `worktreeFolder` names it.
Get the `Vcs` with `selectVcs` on the project root, and take `Osq-Head` from
its `worktreeList` entry for that tree's root. Reuse `readCommitTrailers` for
each task's `Osq-Model` and `Osq-Version`, `parseSpecMdFromFolder` for the
goal, `parseTaskList` for the task titles, `parseFrontmatter` for the done
marker, and `awaitedDependencies` for the stacked refusal. `src/core` may not
import `src/watcher`. Let the command take `stdout` and `stderr` callbacks,
as `statusCommand` takes `stdout`, so tests can capture both.

Build the repository as `tests/worktree-run.test.ts` does. Commit
`verify.cjs` before approving, approve with `approveSpec`, and run a change
to its archive commit with `runWatcherCycle` and that file's acting adapter.
To land by hand, run `git merge --squash osq/<folder>` in the checkout, then
`git commit -F <file>` with the captured stdout, and parse the checkout's
HEAD message with `git interpret-trailers --parse`. For the two-model and
manual cases, rewrite the archived events or done marker inside the
worktree after the archive commit. For the stacked case, approve a
dependency without running it, then add its id to the archived dependent's
`depends_on` in the worktree.

It builds each tree in a temporary directory with hand-written `.git` and `HEAD` files and runs no git.

## Details

A linked worktree's `.git` file holds one line, `gitdir: <path>`. The
directory it names holds a `HEAD` file such as
`ref: refs/heads/osq/002-b`. Build the temporary trees the way
`tests/trace-scenario-lookup.test.ts` builds its openspec roots, and call
`clearScenarioLookupCache` between tests. Keep `resolveLocation` returning a
change folder, so the effective places path handles a found worktree change
exactly as it handles `OSQ_CHANGE`.

## Changed

- Added `crates/kernel/storage/src/model/requirement_rows.rs`: the
  `requirements` row struct and the mapping from each snapshot delta's added,
  then modified, then removed requirement names, then its renames keyed on the
  new name.
- Added `crates/kernel/storage/src/model/task_outcome_rows.rs`: the
  `task_outcomes` row struct and the mapping for every column, with
  `owner_capabilities` for the dominant capability, the hand-written
  JavaScript-whitespace split, the one-each quote strip, the `.test.`/`.spec.`
  base-name check, and the last dead reason from `EventFacts`.
- Added `crates/kernel/storage/src/model/insert_specs.rs`:
  `insert_requirements` and the public `write_task_outcomes`, which fills the
  table for archived snapshots in order in its own transaction.
- `crates/kernel/storage/src/model/mod.rs`: `CREATE_TABLES` now names
  `requirements` and `task_outcomes` (16 tables), `insert_snapshot` inserts the
  requirement rows, and `build_read_model` reads today's ownership from
  `<project_root>/openspec/specs` and fills `task_outcomes` last.
- `crates/kernel/storage/src/lib.rs`: re-exports `write_task_outcomes`.
- Added `crates/kernel/storage/tests/read_model_specs.rs`, which builds the
  spec tables fixture through `build_read_model`, asserts 16 tables, and
  compares `requirements` and `task_outcomes` row by row against
  `tests/fixtures/spec-tables-rows/` (6 and 6 rows).
- Added `crates/kernel/storage/tests/read_model_specs_cases.rs` and the
  `tests/fixtures/spec-tables-cases/` project: snapshots read by `read_archive`,
  `write_read_model` + `write_task_outcomes` with an ownership list built in
  the test, asserting all `task_outcomes` columns and the extra verify kinds.
- `cargo fmt --all`, `cargo clippy --all-targets` and
  `sh scripts/verify-rust.sh` pass; cargo-mutants over the three new source
  files (57 mutants), `mod.rs` and `lib.rs` (9 mutants) reports no missed
  mutant.

## Deviated

- Split the row mapping into `requirement_rows.rs` and
  `task_outcome_rows.rs` rather than one `src/model/spec_rows.rs`, because a
  single file reached 267 lines, over the 250-line cap.
- Beyond the four named extra rules, the cases fixture has two more tasks: one
  with an owned-path set where a later-named capability has strictly more
  paths (to kill the dominant-capability comparison mutants) and one whose
  verify token is `"tests/a.test.ts/"`, because cargo-mutants reported the
  trailing-quote strip as missed without it.

## Missing context

- The task names four extra rules to prove but does not say whether extra
  mutant-killing cases may be added; two were, as recorded under Deviated.

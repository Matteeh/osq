## Deviated

- TypeScript gates the pattern branch on `isPatternEntry` before calling
  `globToRegExp`. Since translating a non-pattern entry yields only literal
  tokens, whose match is exactly string equality, that gate changes no
  result; the matcher just tries `matches` after the equality check. Keeping
  the gate as its own `-> bool` function produced a mutant cargo-mutants
  reported as missed (replacing the body with `true` is unobservable), so it
  is inlined away. Observable behaviour equals TypeScript's on every input.
- TypeScript's `globToRegExp` strips trailing `/` after appending `**` to a
  `/`-terminated pattern. The append already removes the trailing slash, so
  that strip is unreachable; it is not emitted, to avoid a dead statement
  whose removal no test could catch.
- Added `scope_glob_edge_cases`, extra cases beyond the delta table (all
  derived from the "Scope globs" rules, not from running the code), needed to
  kill the `whole_segments` mutants.

## Missing context

  `isPatternEntry` gate, both behaviourally inert, must be kept verbatim.
  Both omissions are recorded under Deviated.

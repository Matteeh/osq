## Deviated

- `read_deltas` does not filter directory entries with `is_dir`; it lists every
  entry name and skips any whose `spec.md` is not a file. A file directly under
  `specs/` can never hold a child `spec.md`, so the result is the same, and
  dropping the extra predicate avoids an unobservable mutant that no test could
  kill. The folder-without-`spec.md` case stays covered by the `is_file` check.
- The extra mutation-oriented tests live in `tests/reading_specs_edges.rs` and
  `tests/reading_specs_outcomes.rs` rather than one file, to keep every `.rs`
  file under 250 lines.

## Missing context

- The task names the three scenario rows for task plans but not whether the
  tests may also drive `read_change` on generated temporary change folders for
  the outcome edges; I did so under `CARGO_TARGET_TMPDIR`, as the existing
  `reading_events.rs` does.

## Changed

- Added `scripts/mutants-rust.sh`: a POSIX `sh` script modelled on
  `scripts/verify-rust.sh` that runs `cargo mutants --workspace --jobs
  "${OSQ_MUTANTS_JOBS:-4}" --output <mktemp -d>` from the repository root,
  removes the temporary folder with an `EXIT` trap, adds `--in-diff <file>`
  for its one optional argument (resolved from the caller's directory before
  the `cd`), and exits with cargo-mutants' status.
- Added `.cargo/mutants.toml` with a comment naming ADR 024 and the rule that
  an `exclude_re` pattern is allowed only for an equivalent mutant, and the
  line `exclude_re = []`.
- Added `crates/core/tests/display.rs`, proving "Read error messages"
  (EventError), "Task id text" (`TaskId`) and "Seal and seal error text"
  (`Seal`, `SealError`), each text taken from the delta spec's tables.
- Added `crates/core/tests/edges.rs`, proving "Task ids with one number sort by
  text", "Done clears an earlier reason", "Task regressions and retries leave
  the change record" and "A change keeps its id and tasks", the last reading
  `id` and `tasks` in the draft, approved and archived states.

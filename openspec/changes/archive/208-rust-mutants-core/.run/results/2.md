## Changed

- `.github/workflows/rust.yml`: kept `push`/`pull_request` on `main` and the
  `cargo` job as they were, added one weekly `schedule` (`cron: '0 6 * * 1'`),
  and added the `mutants` job. It checks out with `fetch-depth: 0`, repeats
  the `cargo` job's toolchain and cache steps, installs with
  `cargo install cargo-mutants --version 27.1.0 --locked`, then runs one step
  gated on `github.event_name != 'schedule'` that writes `git diff` from the
  event base to `HEAD` under `$RUNNER_TEMP` and passes it to
  `sh scripts/mutants-rust.sh`, and one gated on
  `github.event_name == 'schedule'` that runs the script with no argument. The
  base reaches the step through `env` as
  `${{ github.event.pull_request.base.sha || github.event.before }}`, never
  spliced into the script.

  after the "Coverage check" bullet, verbatim from the task's "ADR text".
  Nothing else, frontmatter included, changed.

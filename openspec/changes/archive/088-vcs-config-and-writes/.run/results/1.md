## Changed

- Added `src/core/foundation/config-vcs.ts` with `VcsConfig`,
  `DEFAULT_VCS_CONFIG` (`{ enabled: false }`), `validateVcsConfig`, and
  `DEFAULT_GIT_COMMIT_SECONDS` (120). The validator mirrors
  `validateGatesConfig`: a partial block keeps defaults, a non-boolean
  `enabled`, a malformed author, a missing author while enabled, and blank or
  non-string `worktreeRoot`/`prepare` are rejected. `worktreeRoot` and
  `prepare` are kept trimmed. The two delta error messages are verbatim.
- Added `src/core/foundation/config-agents.ts` and moved `AgyConfig` and
  `OpencodeConfig` there. `config.ts` re-exports both, so `config-user.ts` and
  `src/index.ts` keep resolving them.
- `config.ts`: `OsqTimeouts` gained optional `gitCommitSeconds`; `OsqConfig`
  gained `vcs`; `DEFAULT_CONFIG` carries `vcs: DEFAULT_VCS_CONFIG`; and
  `defineConfig` sets `vcs: validateVcsConfig(config.vcs)`, so every loaded
  config carries a validated block. The file is 244 lines.
- `config-user.ts`: `OsqUserConfig` accepts a partial `vcs` block.
- `src/index.ts`: exports the `VcsConfig` type.
- Added `tests/vcs-config.test.ts`, covering the delta's three scenarios
  through `loadConfig` in temporary projects, plus trimming, a blank `prepare`
  failing, a non-boolean `enabled` failing, the commit-timeout default and
  override, and the moved/public types.

## Deviated

- `OsqConfig.vcs` is optional (`vcs?: VcsConfig`) rather than required. A
  preexisting test, `tests/opencode-config.test.ts`, constructs an `OsqConfig`
  literal without `vcs`; that file is outside this task's `scope` and
  `tests.modify` is not set, so a required field would fail `pnpm verify`.
  Defined and loaded configs still always carry `vcs`; only the interface
  stays optional, like the other harness blocks.
- `gitCommitSeconds` is not written into `DEFAULT_CONFIG.timeouts`. It stays an
  optional field, and task 2 applies `DEFAULT_GIT_COMMIT_SECONDS` at the commit
  call, matching the existing `timeouts.gitSeconds` / `DEFAULT_GIT_SECONDS`
  pattern.

## Missing context

- The cli-foundation delta fixes the wording only for the two author errors. It
  does not name the error for a blank or non-string `worktreeRoot`/`prepare`; I
  used `vcs.<field> must be a non-empty string if provided`, the wording
  `config-codex.ts` uses for its trimmed fields.

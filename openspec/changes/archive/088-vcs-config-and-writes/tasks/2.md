## Details

```ts

// added to Vcs:
configValue(key: string): Promise<string | null>;

```

Failures throw an `Error` whose message holds git's stdout and stderr. Read
hooks from the directory `git rev-parse --git-path hooks` names, which follows
`core.hooksPath`. A hook is active when it is an executable file whose name
does not end in `.sample`. A tree is a linked worktree when
`git rev-parse --git-dir` and `--git-common-dir` differ. For the patch, copy
the index `git rev-parse --git-path index` names to a temporary file, run
`add -A` and `diff --cached --binary HEAD` against the copy, then delete it.
For the discard, use `checkout HEAD -- <paths>` for tracked paths and
`clean -fd -- <paths>` for untracked ones. Pass the commit message on stdin
or through a temporary file, never as an argument. Bound commits by
`timeouts.gitCommitSeconds`, using `DEFAULT_GIT_COMMIT_SECONDS` from
`config-vcs.ts` when unset. Give each temporary repository `user.name` and
`user.email`. `git-vcs.ts` has 142 lines; keep every file within 250 and every
function within 80.

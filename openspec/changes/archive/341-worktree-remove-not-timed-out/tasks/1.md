script that answers `--version` and `rev-parse --show-toplevel` itself, and
for `worktree remove` runs `sleep 1` then `exec git "$@"`, passed to
`selectVcs` as `gitBinary`. Add a linked worktree with real git first, and
check the removed rows by the directory being gone.

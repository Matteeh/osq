## Details

git writes one trace2 file per process into the `GIT_TRACE2_EVENT` directory.
Each line is a JSON event, and a child process shows up as
`"event":"child_start"` with an `argv` array. Read every file in the directory
and parse each line.

`cleanGitEnv` in `tests/worktree-run.test.ts` shows how a test strips
variables from a copy of `process.env`. Strip `GIT_DIR`, `GIT_INDEX_FILE`, and
`GIT_WORK_TREE` the same way. For the control, also strip every
`GIT_CONFIG_COUNT`, `GIT_CONFIG_KEY_*`, and `GIT_CONFIG_VALUE_*`.

Local git 2.34.1 runs `git maintenance run --auto` in the foreground, so both
trace checks pass locally and on CI, whatever the git version. The test does
not need a git that detaches.

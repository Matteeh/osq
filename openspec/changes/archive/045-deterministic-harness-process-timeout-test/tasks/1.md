## Details

Reuse `spawnWithTimeout` and `DEFAULT_KILL_GRACE_PERIOD_MS` from
`src/harness/process.ts`; do not edit that module. Split the default-value
assertion out of the existing kill-grace case as a compact synchronous test.
In the real child script, install `process.on('SIGTERM', () => {})` before
`process.stdout.write('READY\\n')`, then retain the interval that keeps the
child alive.

Remove the readiness promise, fake-clock ticks, `try`/`finally` reset, and
elapsed-time reasoning from the kill-grace case. Pass the focused timeout and
grace values directly to `spawnWithTimeout`, await its result, and retain only
the timeout and terminating-signal assertions. Remove `mock` from the
`node:test` import once it has no remaining use.

The verifier is intentionally one Node command because task verifies cannot
chain shell commands. Its synchronous child invocations run the process test
three separate times in order and throw immediately on the first failure;
only after all three pass does it run the frozen import-graph and line-budget
tests together.

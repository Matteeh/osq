## Changed

- `src/core/run/verify-log.ts` (new): `writeVerifyLog` writes a run's whole
  output to the next free `.run/logs/<target>-<n>.log`, creates `.run/logs/`
  and its `.gitignore` (`*\n`) when missing, and returns the change-folder
  relative path.
- `src/core/run/verify-excerpt.ts`: added `tailVerifyOutput`, which keeps a
  short text exactly (trailing newline included), the last
  `limits.markerOutputLines` lines of a longer text with each line cut to
  `limits.markerLineChars` by the shared `cutLine`, and `''` for blank text.
- `src/watcher/verify.ts`: `runVerificationGateResult` writes the run's log and
  appends `verify_ran` with `log` plus the tail as `output` only when that tail
  is not blank, and returns `log` (null without a context). The record path
  moved to `src/watcher/record-verify.ts` to keep `verify.ts` under budget; the
  compat `runVerificationGate` keeps its shape and carries `log` when a context
  ran.
- `src/watcher/task-verify.ts`, `change-verify.ts`, `archive-verify.ts`,
  `src/core/run/scope-regression-marker.ts`: every `verify_ran`-based marker
  ends with `Full output: <log>` when the log is known and keeps the old event
  wording otherwise. `archive-verify.ts` builds its marker from
  `runVerificationGateResult` and no longer reads its `verify_ran` line back.
- `src/core/run/scope-hash.ts`: `StaleTaskAudit` gained `log?: string`.
- `src/watcher/regression.ts`: the audit's `log` comes from the gate, the
  `regressed` event's `output` is `tailVerifyOutput(...)`, and `autoRecertify`
  receives a gate result whose `output` is that tail.
- `src/harness/types.ts`: `VerifyRanEventData` gained `log?: string`.
- `src/watcher/fingerprint.ts`: `normalizeFailureBody` now replaces the run
  number of a `.run/logs/<target>-<n>.log` path with `<n>` and keeps the
  target, so two identical deaths that only differ in their per-run log still
  share a fingerprint and the second is marked stuck.
- Tests: new `tests/verify-log.test.ts` (includes the "Verify log run number"
  fingerprint scenario); `tests/dead-marker-excerpt.test.ts`,
  `tests/scope-regression-excerpt.test.ts`, `tests/verify-excerpt.test.ts`
  updated to the log pointer and log-file reads; golden fixtures
  `tests/fixtures/events/verified.jsonl` and `dead.jsonl` regenerated and
  differ only by the new `log` keys and tailed `output`.

The task verify passes (70/70) and the proposal verify `pnpm verify` exits 0:
CLI and UI typecheck, build, the full test suite, and biome. The only deviation
from the previous attempt is the added `src/watcher/fingerprint.ts`

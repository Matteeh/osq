## Changed

- Added the archived-change sync before the land commit: `land/sync.rs` and its submodules check rewritten requirements, merge the default branch, resolve living-spec, archive and `Cargo.lock` conflicts, rebuild specs and lock files, run `vcs.prepare`, append the `synced` event and write the sync commit.
- Added the land stop record for `sync_conflict`, `requirement_changed` and `sync_verify_red`, including aborting the merge, restoring the change stream, and restoring both marker and event when the record commit fails.
- Wired the sync into `run_land` before the moved check, with the land tip read from the worktree again and the land message's `Osq-Head` taken from the sync commit.
- Added `osq-kernel-specs` to `osq-feature-land` and updated `Cargo.lock`.
- Dropped the moved row from `tests/land_commit.rs` and added `tests/land_sync.rs` covering every scenario row, plus supplemental rows for living-spec resolution, delta-only capabilities, deleted living specs and file-removal failures.

## Deviated

- Added four supplemental sync rows beyond the task's listed rows so the new conditionals and error branches are exercised; this also closed the mutation gaps reported by cargo-mutants.
- The `sync::run` call in `run_land` is one call expression split over lines by rustfmt; `run_land` remains under clippy's `too_many_lines`.

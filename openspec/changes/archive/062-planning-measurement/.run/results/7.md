## Deviated

- The two new text sections are printed only when at least one valid planning
  start exists (`report.planning.sessions > 0`). The frozen preexisting
  `tests/report-cost.test.ts` asserts `!formatted.includes('Cost:')` for a
  cost-free project with no planning records, and the mandated comparison line
  is `Cost: planning …, execution …`. Since `tests/report-cost.test.ts` is
  outside this task's scope and frozen, gating the new sections on the presence
  of planning data is the only way to satisfy both. Both JSON fields are always
  present regardless.
- `changedLines` takes each task's last `measures` end event as authoritative:
  a later end without `changedLines` makes that task contribute nothing rather
  than reusing an earlier attempt's value, matching "each task's last end".

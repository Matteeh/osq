## Acceptance

- [ ] `observePlanning` counts a session in `costCoverage.reported` only when its `usage.cost` is not null, keeps `total` as the number of sessions, and returns a null `cost` when no session reported one, even if sessions reported tokens.
- [ ] Token groups and durations are unchanged.
- [ ] New `tests/web-planning-cost.test.ts` builds a change whose one observed session reports tokens with a null cost and asserts a null planning cost and coverage `{ reported: 0, total: 1 }`. A second change with one priced and one unpriced session asserts the priced session's cost and `{ reported: 1, total: 2 }`.
- [ ] Rendering the first change's planning cost through `formatCost` from `packages/ui/src/format.ts` gives `not reported`.

## Details

Today `observePlanning` counts a session as reported when it has any token
count, then sums an empty cost list, so the dashboard shows `$0.0000`. Build the
test data the way `tests/web-data-unreported.test.ts` does. Measured against the
full suite, this fix changes no existing test. Every existing test is frozen.

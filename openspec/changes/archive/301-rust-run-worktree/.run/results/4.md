## Changed

- `dead::kill` now takes a `Death` with the tree's root, the config and whether
  the change lives in a worktree, so every death the run records in an osq
  worktree also runs the dead commit, while the checkout path makes no git
  call.
- Added `commit::dead`, which writes the change's `.run/dead/<task>.patch`,
  discards the status paths outside the change folder, and commits whichever
  dead records exist with TypeScript's subject, title, elapsed outcome line and
  trailers. A failed step becomes
  `task <task> of <folder> died: <reason>; osq could not commit it: <error>`.
- Added `pause::discard_worktree`, run after `.run/paused.md` in a worktree,
  which discards the executor's status paths outside the change folder and
  makes no commit. A git error fails the pause with its display.
- Threaded the death context through `scope::audit`, `verdict::judge` and the
  approval check, and passed the worktree flag and config to `start::run`
  through a new `Start` value.
- Added `tests/run_worktree_dead.rs`, proving "Dead task commit", "Dead task
  commit fails" and "Paused worktree discards outside files", plus the
  root-change case that keeps `outside_change`'s empty-folder branch tested.
- Added `tests/fixtures/worktree-limit-pi/run.sh`, executable, which writes
  `src/a.txt` and then reports the usage limit.
- Extended `tests/worktree_support/mod.rs` with `use_limit_pi` and a shared
  config builder that names any fake pi.

## Deviated

- The shared "outside the change folder" status filter lives in `pause.rs`
  rather than `scope.rs`, because `run_usage_pause` compiles `pause.rs` on its
  own and it cannot name sibling modules. `commit::dead` calls the same
  function, and its empty-change case is covered directly.
- The dead commit's patch is written before git status is read, so status sees
  the untracked patch inside the change folder and excludes it, as TypeScript's
  order does.

## Missing context

- The task did not say how a death before the task file is read, such as a
  changed approval, gets the commit title. The dead commit reads the task file
  itself, which the earlier refusal has already established exists.

## Changed

- Added `crates/kernel/vcs/src/git/patch_and_discard.rs` with `patch` and
  `discard`: `patch` builds the binary diff through a copy of the index in a
  unique temporary folder and removes that folder on every result; `discard`
  checks the linked-worktree and `osq/` branch preconditions, restores HEAD's
  paths, unstages files HEAD lacks, and cleans untracked paths.
- Added `patch` and `discard` to the `Vcs` trait and `GitVcs`, with
  `Implements: rust-vcs/patch-and-discard` docs.
- Added `crates/kernel/vcs/tests/patch_and_discard.rs` covering both patch
  scenarios and every row of both discard scenarios, each row in its own
  scratch repository.
- `cargo test -p osq-kernel-vcs --test patch_and_discard` passes, every
  existing vcs test passes, `cargo fmt --all` and workspace clippy pass, and
  `sh scripts/verify-rust.sh` passes with
  `OSQ_CHANGE=openspec/changes/301-rust-run-worktree`. A manual
  `cargo mutants -p osq-kernel-vcs -f
  crates/kernel/vcs/src/git/patch_and_discard.rs` reported 38 caught and one
  unviable mutant, none missed.

Touched: crates/kernel/vcs/src/git/patch_and_discard.rs, crates/kernel/vcs/src/git.rs, crates/kernel/vcs/src/port.rs, crates/kernel/vcs/tests/patch_and_discard.rs

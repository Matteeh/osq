## Acceptance

- [ ] Every death of a task in an osq worktree is recorded as rust-run "Dead task commit" says, and a usage pause there discards as "Paused worktree discard" says, both reusing task 3's message function and task 2's tree.
- [ ] New `tests/run_worktree_dead.rs` proves "Dead task commit", "Dead task commit fails" and "Paused worktree discards outside files", building its repositories with `tests/worktree_support/mod.rs` from tasks 2 and 3, which it may extend. The pause test uses a new fake under `tests/fixtures/worktree-limit-pi/`, made like `tests/fixtures/limit-pi/run.sh`, that writes `src/a.txt` before it reports the limit.
- [ ] Every existing run test passes unchanged.
- [ ] Every public item ends its doc with `Implements: rust-run/<requirement>`, and each new test's doc names `Covers: rust-run/<scenario>`. `cargo fmt --all`, then the proposal's verify, pass with no missed mutant.

## Details

Hook the commit into `dead.rs`'s `kill`, so every death the run records
in a worktree is committed, and keep the checkout path free of git calls.
Commit the fake with mode `0o755`.

When the mutation check reports a missed mutant, add a test case for that
line rather than keeping a branch no test reaches. Take its expected value
from the TypeScript source. Run the proposal's verify as the watcher does,
with `OSQ_CHANGE=openspec/changes/301-rust-run-worktree`, so the link
gates see this change's requirements.

## Scenarios

- rust-run: Dead task commit
- rust-run: Dead task commit fails
- rust-run: Paused worktree discards outside files

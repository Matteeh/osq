## Details

This task is the first half of the earlier task 2, which timed out twice
while also writing the commit. Leave the commit and its message to task 3.

Build the trees as archive's lookup does in
`crates/features/archive/src/archive.rs`: `GitVcs::new`, `with_timeouts`,
`worktree_list` turned into `TreeCandidate`s, and `change_trees` with no
stacked folders. A feature never calls another, so write that code in a
new module under `src/feature/` in this crate. Pass the tree's root
wherever `run.rs` and its modules take the root today.

In the test, build the repository with `git` through
`std::process::Command`, under a new folder of `CARGO_TARGET_TMPDIR`
named after the test, with the fake pi set up as `tests/support/mod.rs`
sets it up, its mode file in the worktree. A test cannot set environment
variables.

When the mutation check reports a missed mutant, add a test case for that
line rather than keeping a branch no test reaches. Run the proposal's
verify as the watcher does, with
`OSQ_CHANGE=openspec/changes/301-rust-run-worktree`, so the link gates
see this change's requirements.

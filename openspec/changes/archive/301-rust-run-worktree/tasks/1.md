repositories as `tests/branch_and_commit_writes.rs` does. Make the
temporary index folder's name unique, for example from the process id and
a counter, under `std::env::temp_dir()`, and remove it on every path.

When the mutation check reports a missed mutant, add a test case for that
line rather than keeping a branch no test reaches. Take its expected value
from `git-vcs-write.ts`. Run the proposal's verify as the watcher does,
with `OSQ_CHANGE=openspec/changes/301-rust-run-worktree`, so the link
gates see this change's requirements.

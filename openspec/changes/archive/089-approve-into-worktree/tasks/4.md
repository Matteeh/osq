## Acceptance

- [ ] With `vcs.enabled` and `GitVcs` selected, `approveSpec` approves into a worktree as the spec-lint-and-approve delta's "Approval into a worktree" says, in new `src/core/spec/approve-worktree.ts`, and returns the worktree path and branch.
- [ ] It refuses as "Approval refusals under version control" says, word for word, after lint and before the digest, and a refused approval writes nothing anywhere.
- [ ] `ApproveOptions` and `ApproveCommandOptions` gain `baseOk` and `ignoreDirty`. `osq approve` gains `--base-ok` and `--ignore-dirty` and prints the `Worktree:` and `Branch:` lines. Its registration moves out of `createProgram` into a `registerApproveCommand` exported from `src/cli/approve.ts`, keeping `--confirm`.
- [ ] README.md documents both flags next to `osq approve <id> --confirm`.
- [ ] New `tests/approve-worktree.test.ts` covers every scenario of both requirements against temporary repositories, plus one approval with `vcs.enabled` off that writes `.run/approved` in the checkout as before.

## Details

Branch and worktree come from `worktreeBranch` and `worktreePath` in
`src/core/vcs/worktree.ts`, the default branch from the port's `defaultBranch`,
and dirt from `status` checked with `scopeCoversPath` against every task's
`scope`. Commit in the worktree through a second `selectVcs` on the worktree
path, staging only the change folder's path relative to it. Run the prepare
command with `runVerificationCommand` in the worktree, with `changeFolder`
null. Build the manifest with the worktree as the project root. Copy the
folder with `fs.cp` recursively, `.run/` included, after prepare. A missing
`user.name` or `user.email` leaves that part of `.run/approver` empty.

`approveSpec` has 76 of 80 lines; move the seal writes into a helper that
takes the folder to write into, so both paths share it. `src/cli/index.ts` has
249 of 250 lines. Build test projects the way `tests/approve.test.ts` does,
with `scaffoldProject`, `createNewSpec`, a local `verify.cjs`, and a fake
validator under `node_modules`, then `git init -b main`, set
`user.name` and `user.email`, ignore `node_modules/`, and commit. Put
`vcs.worktreeRoot` in the test's temporary folder, outside the repository.

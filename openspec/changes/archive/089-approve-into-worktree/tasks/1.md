## Details

Read origin's default with `symbolic-ref --quiet --short refs/remotes/origin/HEAD`,
which prints `origin/<branch>` and never contacts the remote. A test sets it
with `git symbolic-ref refs/remotes/origin/HEAD refs/remotes/origin/trunk`
after creating that ref with `git update-ref`. `git-vcs.ts` and
`git-vcs-write.ts` have 201 lines each; keep every file within 250 and every
function within 80. Give each temporary repository `user.name` and
`user.email`.

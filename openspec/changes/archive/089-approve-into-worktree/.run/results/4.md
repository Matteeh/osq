## Changed

- `src/core/spec/approve.ts`: `approveSpec` now lints, then dispatches to the
  worktree path when `vcs.enabled` and `GitVcs` are selected, otherwise to a new
  in-place helper. The in-place body moved to `approveInPlace`; the digest +
  review and the seal/manifest writes moved into shared helpers. `ApproveResult`
  gained optional `worktreePath` and `branch`, and `ApproveOptions` gained
  `baseOk` and `ignoreDirty`.
- `src/core/spec/approve-worktree.ts` (new): `approveIntoWorktree` performs the
  four refusals (non-default HEAD, dirty task scope, existing branch, unlanded
  approved dependency) after lint and before the digest, then cuts
  `osq/<folder>` at HEAD, adds the linked worktree, runs `vcs.prepare` there,
  copies the checkout's change folder in, appends observations, writes
  `.run/approved`, `.run/base`, `.run/approver`, and the manifest in the
  worktree, and commits the folder (`osq: <id> approved`, `vcs.author`) through
  a second `selectVcs` on the worktree path. The checkout is never written.
- `src/core/spec/approve-worktree-shared.ts` (new): the seal/manifest writer
  (takes the folder to write into), the digest + review gate, and the
  `ApprovalReview`/`ApprovalDeclinedError` types and time/brief helpers, shared
  by both approval paths.
- `src/cli/approve.ts`: `ApproveCommandOptions` gained `baseOk`/`ignoreDirty`;
  successful approvals print `  Worktree:` and `  Branch:`; the command's
  registration moved here as `registerApproveCommand`, keeping `--confirm` and
  adding `--base-ok` and `--ignore-dirty`.
- `src/cli/index.ts`: calls `registerApproveCommand(program)` instead of
  registering the approve command inline.
- `README.md`: documents `--base-ok` and `--ignore-dirty` next to
  `osq approve <id> --confirm`.
- `tests/approve-worktree.test.ts` (new): covers approval onto the branch and
  worktree, `prepare` in the worktree, failing prepare retaining the branch and
  worktree, all four refusals (and their overriding flags), approval with vcs
  off writing in place, and the CLI flag registration.

## Deviated

- The shared seal/review helpers live in a new `approve-worktree-shared.ts`
  rather than in `approve.ts`. `approve.ts` dispatches to `approve-worktree.ts`,
  which needed those helpers; a separate module keeps the dependency graph
  acyclic while still letting both paths share one seal writer, as the task
  required. The file name matches the task's `src/core/spec/approve-worktree*.ts`
  scope.

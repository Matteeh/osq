## Changed

- `src/core/status/status.ts`: added `ChangeWorktree` (`path`, `checkoutChanged`)
  and the optional `StatusOverview.worktrees` map, keyed by folder name. In
  `getStatusOverview`, each active change whose `tree.worktreeFolder` is set
  records its tree root as the worktree path and whether the first tree's
  changes directory still holds a folder of the same name whose
  `hashChangeFolder` differs from the change's approved hash; a matching or
  missing checkout copy records `false`. `formatStatusOverview` prints
  `  worktree: <path>` directly below the change heading and, when the checkout
  copy changed, the `  warning: the checkout's copy of <folder> ...` line below
  it, before the existing `  next:` line. Changes with no worktree tree are
  unchanged.
- `tests/status-worktree.test.ts` (new): builds a committed temp repo, approves
  one change with `approveSpec` into its worktree (same setup as
  `tests/approve-worktree.test.ts`), and covers: the worktree path printed
  directly below the heading through `statusCommand`; the warning after editing
  the checkout copy; no warning when the checkout copy is untouched; and no
  warning when the checkout copy is missing.

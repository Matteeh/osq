## Details

```ts
export type ChangeLocation = 'active' | 'archived' | 'rejected';
export interface ChangeTree {
  readonly root: string; // absolute project root of the tree
  readonly changesDir: string;
  readonly archiveDir: string;
  readonly rejectedDir: string;
}
export interface LocatedChange {
  readonly folderName: string;
  readonly folderPath: string; // absolute
  readonly location: ChangeLocation;
  readonly tree: ChangeTree;
}
export function changeTrees(projectRoot: string, config: OsqConfig): Promise<ChangeTree[]>;
export function listChanges(
  projectRoot: string,
  config: OsqConfig,
  locations?: readonly ChangeLocation[],
): Promise<LocatedChange[]>;
export function findChange(projectRoot: string, config: OsqConfig, idOrPrefix: string): Promise<LocatedChange>;
export function locateFolder(projectRoot: string, config: OsqConfig, folderPath: string): Promise<LocatedChange | null>;
export function changesDirLabel(config: OsqConfig): string;
```

A missing changes, archive, or rejected directory lists as empty, as every
reader treats it today, and a relative project root resolves against the
current directory. `changeTrees` is async, although it reads nothing today, because stage 1 adds
`git worktree list` behind it. Build the paths with `getChangesDir`,
`getArchiveDir`, and `getRejectedDir`. Sort with `compareNumericPrefix` from
`state.ts`. Copy `findSpecFolder`'s matching rules and its not-found message,
and leave `findSpecFolder` itself unchanged. `resolveSpecFolder` is exactly
80 lines, so keep it at 80 or fewer. New files stay within 250 lines and new
functions within 80.

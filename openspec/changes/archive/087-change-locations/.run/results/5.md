## Changed

- `src/watcher/loop.ts`:
  - `runWatcherCycle` now calls
    `listChanges(projectRoot, config, ['active'])` and iterates the returned
    `LocatedChange`s. Each change's `folderName`, `folderPath`, and
    `change.tree.root` replace the local `readdir`/`isActiveChangeFolderName`/
    `compareNumericPrefix` listing, and every per-change call
    (`writeDeadMarker`, `readChangeFolder`, `runAutomaticRetries`,
    `auditScopeRegressions`, `runTask`, `runMutationCheck`,
    `checkAndArchiveSpec`) receives that tree's root as `projectRoot` instead of
    the cycle argument.
  - `findLatestArchivedSpec` lists archived changes with
    `listChanges(projectRoot, config, ['archived'])` and stats each
    `folderPath`; the `Dirent` import and the local archive `readdir` are gone.
  - The idle status label uses `changesDirLabel(config)` in place of
    `getChangesDir(config.paths.openspecRoot)`.
  - `startWatcher` watches `changeTrees(projectRoot, config).map((tree) =>
    tree.changesDir)` instead of one `getChangesDir` path.
  - The `layout` import is removed; `compareNumericPrefix` stays for the
    scope-regression halt line.
- `src/watcher/baseline.ts`: `changeFolders` is now
  `listChanges(projectRoot, config, ['active', 'archived'])` mapped to
  `folderPath`. The `Dirent` import and the `layout` import are gone.
- `tests/change-locations-readers.test.ts` (new): recursively scans every
  non-declaration `.ts` file under `src/`, and fails naming each file that
  calls `getChangesDir(` or `getArchiveDir(` and is not on the delta's allowed
  list. Modelled on `tests/line-budget.test.ts`, with an import-tolerant call
  regex.

## Deviated

- The `runWatcherCycle` missing-changes-directory early-return branch is gone:
  `listChanges` already swallows a missing directory and returns `[]`, and the
  cycle then falls through to the same idle-status line. Output for a missing
  `openspec/changes` is unchanged because `findLatestArchivedSpec` also yields
  `undefined` when the archive tree is absent.
- The per-change `fs.stat`/`isDirectory` guard in `runWatcherCycle` is removed
  because `listChanges` only returns directories. Same for the archive's
  `_`/`.` filter: `findLatestArchivedSpec` now inherits the resolver's rule
  that archived folders never start with `_` or `.`, which the previous local
  `readdir` did not apply. No real archive tree contains such folders.
- The structural test's allowed set includes
  `src/core/status/change-locations.ts` alongside the delta's seven explicit
  files. The resolver is the module the requirement puts "inside", and it
  necessarily calls `getChangesDir`/`getArchiveDir`; `layout.ts` is both the
  definition site and explicitly listed.

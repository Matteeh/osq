## Changed

- Added `src/core/status/change-locations.ts`: `changeTrees`, `listChanges`,
  `findChange`, `locateFolder`, and `changesDirLabel`, plus the `ChangeLocation`,
  `ChangeTree`, and `LocatedChange` types. `changeTrees` resolves the project
  root absolute and is async so stage 1 can add `git worktree list`. `listChanges`
  lists directories only, active first then archived then rejected, each sorted
  with `compareNumericPrefix`, including only names that pass
  `isActiveChangeFolderName` for active and that do not start with `_` or `.` for
  archived and rejected. `findChange` searches active changes with
  `findSpecFolder`'s exact/padded/prefix matching and its not-found message.
  `locateFolder` resolves the absolute path against every tree and returns null
  outside them.
- Rewrote `resolveSpecFolder` in `src/core/status/show.ts` to discover folders
  through `listChanges` and to classify a path argument through `locateFolder`,
  keeping its empty-query error, its direct-path handling, its active/archived/
  rejected search order, its `matchesFolder` rules (including the
  suffix-slug match), and its `not found in specs or archive` message. Removed
  the now-unused `searchFolder` helper and the layout imports.
- Rewrote `listChangeFolders` in `src/core/web/web-data-folders.ts` on top of
  `listChanges`, keeping the `resolveChangeDoc` filter and its own
  `compareFolders` order. Removed the local `discoverLocation` helper.
- Added `tests/change-locations.test.ts` covering the delta's five scenarios
  (order and filters, lookup by number, lookup miss, locate an archived folder,
  one tree today) plus lookup by padded number and `<number>-` prefix,
  `locateFolder` null outside every tree, relative-root resolution, the optional
  location filter, and `changesDirLabel`.

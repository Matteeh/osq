## Changed

- Removed the land crate's `OUTPUT_TAIL_LINES`, `MARKER_OUTPUT_LINES` and
  `MARKER_LINE_CHARS` constants.
- Threaded the loaded config's `limits` through the land command: the
  after-land failure tail now uses `limits.cardOutputLines`, the sync stop
  tails use `limits.cardOutputLines`, and `verify_ran` excerpts use
  `limits.markerOutputLines` and `limits.markerLineChars`.
- Converted the configured `u64` sizes to `usize` with
  `usize::try_from(..).unwrap_or(usize::MAX)` at the call sites.
- Added `crates/features/land/tests/land_limits.rs`, proving the three new
  scenarios: after-land tail, sync stop tail and sync verify tail.
- Moved the located change's land-facts lookup into a small `land_facts`
  helper so `run_land` stays within the function line limit after the
  extra limits plumbing.

## Deviated

- The after-land and sync tail functions take the already-converted
  `usize` line counts, while the intermediate functions take `&Limits`;
  the task allowed either passing `Limits` or the sizes as `usize`.

## Details

Pass the config's `Limits`, or the sizes taken from it as `usize`, down to
the tail functions instead of reading constants; convert from `u64` with
`usize::try_from(..).unwrap_or(usize::MAX)`, as doctor does. No new
dependency is needed.

When the mutation check reports a missed mutant, add a test case for that
line rather than keeping a branch no test reaches. Run the proposal's
verify as the watcher does, with
`OSQ_CHANGE=openspec/changes/303-rust-land-limits`, so the link gates see
this change's requirements.

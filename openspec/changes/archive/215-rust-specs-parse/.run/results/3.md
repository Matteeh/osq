## Changed

Added the golden parse-parity half of the `osq-kernel-specs` crate, all of it
inside task 3's scope:

- `crates/kernel/specs/tests/golden/`: byte-for-byte copies of the five
  TypeScript-printed goldens, verified with `cmp`: `deltas.json`,
  `tasks.json`, `proposals.json`, `task_lists.json` and `living.json`.
- `crates/kernel/specs/tests/fixtures/living/`: the three frozen living specs
  `rust-core`, `metrics-and-reporting` and `traceability`, each with its
  `spec.md` and `osq.yml`.
- `crates/kernel/specs/tests/golden_support/mod.rs` with three submodules:
  `digest.rs` (the FNV-1a 64 digest over `serde_json::Value`s, strings over 64
  UTF-16 code units hashed, object keys and the `path` and `capability` values
  left as written), `entries.rs` (the builders for all five golden entries,
  including a sidecar as `{group, tags, problems: []}`) and `diff.rs`
  (`Difference` and `first_difference`, naming the RFC 6901 pointer of the
  first difference with both values). `mod.rs` holds `golden_dir`,
  `read_golden` and `assert_no_failures` (count plus the first twenty lines).
- `crates/kernel/specs/tests/golden_cases.rs`: the fast test proving "Living
  fixtures match TypeScript" over the three frozen specs, plus two fast cases
  for the digest length/key rules and the pointer naming.
- `crates/kernel/specs/tests/golden_corpus.rs` with `golden_corpus/`
  (`corpus.rs`, `archive.rs`, `living.rs`, `scan.rs`): two corpus tests, each
  `#[ignore = "corpus test: ..."]`, proving "Archived documents match
  TypeScript" over the 492 delta specs, 729 task files, 212 proposals and 212
  `tasks.md` files of archived folders 001 to 214 (compared by path relative to
  the repository root, with path-set equality in both directions) and "Living
  specs read" over every current `openspec/specs/<capability>/` spec and
  sidecar.

Every parse already equals its golden entry, so no `src/markdown/`,
`src/document/` or `src/read/` line changed and no `tests/golden_cases_*.rs`
or `tests/fixtures/cases/` file was needed.

Verification: the task's `cargo test -p osq-kernel-specs --test golden_cases
--test golden_corpus -- --include-ignored` passes (3 + 2 tests). `cargo fmt
--all --check`, `cargo clippy --workspace --all-targets -- -D warnings` and
`sh scripts/verify-rust.sh` pass. `cargo mutants -p osq-kernel-specs` reports
358 mutants, 323 caught, 35 unviable, 0 missed; the change adds no `src/` line,
and a test-file-only diff gives cargo-mutants "No mutants to filter", so the
verify's diff step sees no new mutant. Both corpus tests carry
`Covers: rust-specs/archived-documents-match-typescript` or
`Covers: rust-specs/living-specs-read`, and the fast tests
`Covers: rust-specs/living-fixtures-match-typescript`.

## Deviated

- The helper module is declared `pub mod golden_support;` in both test files
  rather than `mod golden_support;`: as a private module, each test binary
  flags the entry builders that only the other binary uses as dead code, and
  `-D warnings` turns that into an error. The module, its
  `tests/golden_support/mod.rs` root and `mod golden_support;` inclusion are
  otherwise as the task asks; submodules keep every file under 250 lines and
  every function under 80.

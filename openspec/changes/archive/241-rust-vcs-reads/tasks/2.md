## Acceptance

- [ ] `src/port.rs` gains `DiffStat`, with public `files`, `added` and `removed` of type `u64`, deriving `Debug`, `Clone`, `Copy`, `PartialEq` and `Eq`, and the `Vcs` trait gains the five reads of rust-vcs "History reads", each `&self` and returning `Result<_, VcsError>`, with `exclude: &[&str]` for `diff_stat`.
- [ ] New `src/git/history.rs` holds each history read's git arguments and its pure parser; `src/git.rs` declares `mod history;` and its `impl Vcs for GitVcs` calls them through the same private runner as the state reads.
- [ ] `src/lib.rs` also re-exports `DiffStat`; nothing else in it changes, and `Cargo.toml` and `Cargo.lock` do not change.
- [ ] New `tests/history_reads.rs` declares `mod support;` and builds the history repository with the helpers of `tests/support/mod.rs`, unchanged, using every one of them.
- [ ] It proves "Reads of the history repository" and "History reads with a program that cannot start" with the literal values of their tables, one assertion per row.
- [ ] Each new trait method's doc ends with `Implements: rust-vcs/history-reads`, and each test's one-line doc names `Covers: rust-vcs/<scenario>` in kebab-case, such as `Covers: rust-vcs/reads-of-the-history-repository`.

## Details

Port `mergeBase`, `isAncestor` and `trailerValues` from
`git-vcs-merge.ts`, `diffStat` from `git-vcs-diff.ts` and `countCommits`
from `git-vcs-land.ts`. The state reads of task 1 stay as they are.

Make the commits with `git commit -m <subject> -m <trailers>` so the
trailers form the message's last paragraph, `Osq-Change: 241` and
`Osq-Change: 241b` on two lines of one paragraph. Make `lone` with
`git commit-tree "main^{tree}" -m lone` and `git branch lone <sha>`.

cargo-mutants runs on every line this task adds, so each condition must
change a value a table row checks: the `-` count for the binary row, the
exclude pathspecs, the file count, the record and unit separators, and the
fall-back to 0. Before exiting, run `cargo fmt --all`, then
`cargo mutants -p osq-kernel-vcs -f <file> -o "$(mktemp -d)"` on each new
or changed source file, then `sh scripts/verify-rust.sh` with `OSQ_CHANGE`
set to `openspec/changes/241-rust-vcs-reads`.

## Scenarios

- rust-vcs: Reads of the history repository
- rust-vcs: History reads with a program that cannot start

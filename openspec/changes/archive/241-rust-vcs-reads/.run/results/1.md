## Changed

- Added `VcsError::Spawn` in `src/error.rs`, displaying as `could not run <command>: <source>` and returning the `std::io::Error` from `source()`.
- Added the `Vcs` read trait plus `Head`, `StatusEntry` and `Worktree` in `src/port.rs`.
- Added `GitVcs` in `src/git.rs` with `new`, `with_program`, `with_env`, the `command` builder, one private runner, and the nine state reads delegating to `src/git/state.rs`.
- Ported `root`, `head`, `status`, `config_value`, `default_branch`, `show`, `path_exists`, `list_branches` and `worktree_list` with TypeScript's git arguments and parsing.
- Re-exported the new public types and trait from `src/lib.rs`; `Cargo.toml` and `Cargo.lock` are unchanged.
- Added scratch helpers in `tests/support/mod.rs` with isolated git settings, canonical scratch folders, file writing and a matching `GitVcs`.
- Added `tests/git_command.rs` for the command builder and missing-program errors, and `tests/state_reads.rs` for the three repository-state scenarios.
- Verified with `cargo test -p osq-kernel-vcs --test git_command --test state_reads`, `cargo clippy -p osq-kernel-vcs --all-targets -- -D warnings`, cargo-mutants on each new source file, and `OSQ_CHANGE=openspec/changes/241-rust-vcs-reads sh scripts/verify-rust.sh`.

Touched: crates/kernel/vcs/src/lib.rs, crates/kernel/vcs/src/error.rs, crates/kernel/vcs/src/port.rs, crates/kernel/vcs/src/git.rs, crates/kernel/vcs/src/git/state.rs, crates/kernel/vcs/tests/support/mod.rs, crates/kernel/vcs/tests/git_command.rs, crates/kernel/vcs/tests/state_reads.rs

## Changed

- `crates/kernel/vcs/src/port.rs`: added the public `DiffStat` struct (`files`, `added`, `removed`, all `u64`, deriving `Debug`, `Clone`, `Copy`, `PartialEq`, `Eq`) and the five history reads of the `Vcs` trait: `merge_base`, `is_ancestor`, `count_commits`, `diff_stat` (with `exclude: &[&str]`) and `trailer_values`, each documented with `Implements: rust-vcs/history-reads`.
- `crates/kernel/vcs/src/lib.rs`: re-exported `DiffStat`; no other change.
- `crates/kernel/vcs/src/git.rs`: declared `mod history;` and implemented the five history reads on `GitVcs`, each delegating to `history` through the same private `read` runner as the state reads.
- `crates/kernel/vcs/src/git/history.rs`: new module holding each history read's git arguments and its pure parsers (`parse_diff_stat` with `-` as 0 lines and binary files counted, `parse_trailers` on U+001E/U+001F, `parse_count` falling back to 0).
- `crates/kernel/vcs/tests/history_reads.rs`: new test file declaring `mod support;`, building the history repository with every helper of `tests/support/mod.rs` unchanged, and proving every row of "Reads of the history repository" and "History reads with a program that cannot start".

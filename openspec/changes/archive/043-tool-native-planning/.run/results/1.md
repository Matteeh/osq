# Task 1 result — prompt handoff is the default planning path

Status: complete. Task verify and `pnpm verify` both pass.

## Changed

- `src/cli/plan.ts` — `planCommand` now resolves the planner only when
  `options.session` is set. New `session?: boolean` option. After folder/brief
  resolution and one `buildOpeningPrompt` call it dispatches to exactly one of:
  `--print` (stdout), default (prompt file + one-line handoff), or `--session`
  (existing adapter/lifecycle/usage/exit path). Creation logging is quieted for
  every non-session mode.
- `src/cli/plan-queue.ts` — `formatBriefContent`, `writeBriefAndManifest`, and
  `createQueueChange` accept `string | null` planner attribution, so YAML `null`
  is written unquoted. `createChange`/`createQueueChange` take a `quiet` flag.
  Added `writePromptHandoff`, extended `validatePlanModeOptions` with the
  session/print rejection, and moved `readBriefInput` here to stay under the
  source line budget (`plan.ts` is now 207 lines, `plan-queue.ts` 239).
- `src/cli/index.ts` — registers `--session` on `plan` and forwards it through
  the action options; keeps `--brief`, `-p/--print`, `--next`, `--replan`, and
  the `-print` normalization.
- `tests/plan-handoff.test.ts` (new) — default null-brief/prompt-file/one-line
  handoff, exact `buildOpeningPrompt` bytes stored in the file, print-only
  creates no prompt file/process/record, print bytes equal the file bytes,
  resumed default refresh of the prompt file with unchanged brief and no new
  folder, default+print succeed with an unusable configured planner, `--session`
  registration and session/print rejection before mutation.
- `tests/plan.test.ts`, `tests/plan-telemetry.test.ts`,
  `tests/planning-integration.test.ts`, `tests/queue-plan.test.ts`,
  `tests/codex/plan.test.ts` — converted every implicit interactive invocation
  to explicit `session: true` / `--session`, asserted print mode leaves no
  `plan-prompt.md`, and added the default `plan --next` handoff regression
  (landed dependency archive path, queue item/hash metadata, planner `null`,
  one planned item, no spawn, no planning log).

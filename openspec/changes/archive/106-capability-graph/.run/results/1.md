## Changed

- Added `src/core/trace/test-path.ts` exporting `isTestPath`, the single
  definition for `tests`, paths under `tests/`, and file names holding
  `.test.` or `.spec.`.
- `src/core/spec/traceability-lint.ts` now imports `isTestPath` from
  `../trace/test-path.js` and no longer defines its own.
- `src/core/report/report-traceability.ts` now imports `isTestPath`, exports
  `optedInCapabilities` and the new `ownedFunctions(capability, index,
  ownerships)` (the owned, non-test, non-scenario-file functions before the
  tag check, sorted by file then line), and rebuilds `unclaimedFunctionsFor`
  on top of `ownedFunctions`. Both are exported for the system graph.
- Added `tests/trace-test-path.test.ts` covering both "Test paths" scenarios
  (behavior; and the one-definition check by reading the two sources) plus an
  `ownedFunctions` test that a tagged function survives there while
  `unclaimedFunctionsFor` leaves it out.

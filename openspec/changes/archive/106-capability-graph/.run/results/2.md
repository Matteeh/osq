## Changed

- Added `src/core/web/system-graph-types.ts`: the `SystemGraph` document
  (`version` a literal `1`), one node type per kind (`group`, `capability`,
  `requirement`, `scenario`, `adr`, `change`, `test`, `function`, `file`), the
  `SystemGraphEdge` type with the ten edge kinds and the import-only `pairs`,
  `code`, and `test` fields, plus `SystemGraphPart` and the id-allocator type.
- Added `src/core/web/system-graph-specs.ts`: builds the group, capability,
  requirement, scenario, and ADR nodes and the `contains` and `applies_to`
  edges from `listCapabilityFolders`, `readCapabilitySpec`,
  `readLivingSidecar`, `parseCapabilitySpec`, and `readDecisions`.
- Added `src/core/web/system-graph-code.ts`: builds the unowned `file` nodes
  and the capability-to-capability `imports` edges from `buildImportGraph`
  with the OpenSpec root left out, `readCapabilityOwnership`,
  `ownerCapabilities`, and `isTestPath`, with sorted, deduped `pairs` and the
  `code`/`test` counts.
- Added `src/core/web/system-graph.ts`: `getSystemGraph(projectRoot, config)`
  assembles the spec part, the code part, and the change nodes and
  `reads`/`writes` edges of one `getWebGraph` call, allocates collision-safe
  ids with the `~2`, `~3` rule, dedupes edges by key, and sorts nodes by id and
  edges by key. In this task every capability is `traceability: false` with
  `gaps: null` and every scenario has `gap: null`.
- Added `tests/web-system-graph.test.ts`: covers the three "System graph
  document" scenarios, the four "System graph links" scenarios, and the
  "Unowned file" scenario of "System graph gaps" through `getSystemGraph` on
  temporary copies of `fixture/trace/pricing`.

## Outside scope

`src/core/spec/digest.ts` and `src/core/spec/test-impact.ts` still define their
own narrower `isTestPath` (checking only `tests/`), which task 1 was told to
leave alone. The system graph calls the shared `src/core/trace/test-path.ts`.

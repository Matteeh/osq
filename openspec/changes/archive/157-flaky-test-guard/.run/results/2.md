## Deviated

- `runChangeVerifyGate`'s fourth argument is optional so the three-argument signature keeps working; the runner always supplies it.
- The "agent changed the failing test" row scopes that test with `tests.modify: true`. A changed, unauthorized preexisting test is killed by the pre-spawn test gate before the change verify runs, so the only path that reaches the rerun decision with a changed test is an authorized one; the scope check then also applies, and the row still yields no rerun as the table requires.
- The "imports a scoped file through another file" row scopes `src/scoped.ts`, reached by `tests/importer.test.ts` -> `tests/helper.ts` -> `src/scoped.ts`, because an existing test in scope would itself require `tests.modify`.

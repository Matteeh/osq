## Changed

- `src/core/spec/lint-output.ts`: added `formatRepositoryCount(count)`, which renders `repository: <n> finding(s) about other changes and living specs; osq lint --repository lists them` with the singular noun for one, and `printRepositoryCount(logger, count)`, which logs it at `info` level and prints nothing for zero. `REPOSITORY_HEADER` and `printRepositoryFindings` are unchanged.
- `src/cli/lint.ts`: `LintCommandOptions` gained optional `repository`. In text mode, when `repository` is true it calls `printRepositoryFindings` as before; otherwise it calls `printRepositoryCount` with the deduplicated count. JSON mode and the exit code are unchanged.
- `src/cli/index.ts`: added `--repository` to `lint [ids...]` with description `list every repository finding` and passed the parsed options through to `lintCommand`. The options are spread into the call to keep the file within the 250-line budget after adding the flag.
- `tests/lint-output.test.ts`: only the `lintCommand` call in "prints one repository finding once after two changes and never exits" changed, adding `repository: true`.
- `tests/lint-repository-count.test.ts`: new test covering the two-long-requirements count line, the singular count, the no-findings silence, the JSON document with both findings and no text line, `--repository` appearing in lint help, and `--repository` reaching the command through `createProgram` (chdir into the temp project and a replaced `process.stderr.write`).

Touched: src/core/spec/lint-output.ts, src/cli/lint.ts, src/cli/index.ts, tests/lint-output.test.ts, tests/lint-repository-count.test.ts

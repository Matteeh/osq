## Details

Build the project, the living spec with a long requirement, the change, and
the recording logger the way `tests/lint-output.test.ts` does, with the real
OpenSpec binary from `node_modules/.bin/openspec`. Copy the helpers rather
than importing them from that test file. For "Flag reaches the command",
`lintCommand` then uses `process.cwd()` and a logger that writes to
`process.stderr`, so `process.chdir` into the temporary project and replace
`process.stderr.write` around `parseAsync`, restoring both after.

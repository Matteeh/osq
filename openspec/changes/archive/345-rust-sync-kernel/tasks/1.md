## Details

Write the moved files by copying them (`cp`, then `rm` the originals), never
by retyping, so git sees renames and the mutation check tests only the lines
you change. Keep those changes small: a large rewrite of a moved file makes
it a new file, whose every line must then be covered by the kernel's tests.

The land tests already prove the moved steps through `osq land` and
`osq sync`, but cargo-mutants runs only the mutated crate's tests. The
kernel's tests must therefore catch mutants in what you change: the
outcome, the conflicted paths, the three options and `append_sync_stopped`.
Check them by hand with
`cargo mutants -p osq-kernel-sync -f crates/kernel/sync/src/lib.rs -f crates/kernel/sync/src/time.rs -o "$(mktemp -d)"`,
and for `sync.rs` add `--re` with the names of the functions you changed.

Set `OSQ_CHANGE=openspec/changes/345-rust-sync-kernel` when running the
proposal's verify, so the link gates see the new capability's ownership.

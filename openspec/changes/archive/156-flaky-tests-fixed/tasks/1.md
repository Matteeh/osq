## Details

This failed as `ENOENT ... lstat 'fixture/report/.osq/index.sqlite-shm'` inside `fs.cp` in 147 task 1 and 154 task 2. `fs.cp` calls `filter` before it stats an entry, so a filtered directory is never opened. The test's own `getMetricsReport` calls build a fresh index in the temporary copy, which is what the test measures.

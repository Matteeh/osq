## Acceptance

- [ ] In "reads the inbox through a core helper without advancing the cursor", the test takes `Date.now()` right before and right after `runBin(project, home, ['--json'])`, and projects the inbox with `readInbox` at both instants (`now: new Date(before)` and `now: new Date(after)`), without advancing the cursor.
- [ ] For each running item, the CLI's `pid` and `startedAt` equal the projection's exactly, and the CLI's `elapsedSeconds` is at least the value projected at `before` and at most the value projected at `after`. The `Math.abs(...) <= 2` assertion is gone.
- [ ] The test still asserts that `needsYou` and `landed` are deep-equal, that the running lists have the same length, that the cursor file does not exist before the CLI runs, and that the CLI writes it.
- [ ] No other test in `tests/inbox.test.ts` changes.

## Details

`projectRunning` in `src/core/status/inbox.ts` computes `elapsedSeconds` as `Math.round((nowMs - lock.startedAt) / 1000)`, floored at 0. The value is monotonic in `now`, so the CLI's value must lie between the projections at the two clocks, however long the spawn takes. Under full-suite load the spawn took 3–4 s and broke the old 2-second window (153 task 2, twice).

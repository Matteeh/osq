## Acceptance

- [ ] `scaffoldProject` takes an optional `{ refreshSchema?: boolean }`. When it is true, each of the six bundled OpenSpec template files that exists and differs byte for byte from its template is overwritten and listed in a new `refreshedFiles` array. Files that already match are left untouched and listed in a new `currentFiles` array.
- [ ] With `refreshSchema`, a schema file lands in `createdFiles`, `refreshedFiles`, or `currentFiles`, never in `existingFiles`. `osq.config.ts` and `.env.example` keep today's behavior and stay in `existingFiles` when present.
- [ ] `osq init` accepts `--refresh-schema` and passes it through `initCommand`. It prints `  refreshed <file>` and `  current   <file>` lines after the `created` and `exists` lines.
- [ ] Without the flag, `scaffoldProject` returns the same `InitResult` values as today, and `initCommand` prints the same lines.
- [ ] New `tests/init-refresh-schema.test.ts` covers four cases in a scaffolded temporary project: a stale proposal template that gets refreshed, a fully current schema that gets no rewrite (the file's mtime doesn't change), a deleted schema file that gets created, and a plain rerun that lists the files under `existingFiles`. It also captures `initCommand` output for the refresh case.
- [ ] `README.md` documents `osq init --refresh-schema` in the command list next to `osq init`, and warns that it overwrites local edits to those six files.
- [ ] The task's verify command passes, with `tests/init.test.ts` and the golden event fixtures unchanged.

## Details

This task's `scope` is authoritative over any injected code-ownership rules.

The six files are the `bundledTemplates` list inside `scaffoldProject`. Reuse
that list. Don't write a second copy of it, and don't add `osq.config.ts` or
`.env.example` to the refresh. Compare bytes against the file under
`TEMPLATES_ROOT`, and write only when they differ.

`scaffoldProject` is about 70 lines, and the function budget caps functions at
80. Put the refresh in a helper function rather than growing
`scaffoldProject`.

`initCommand` currently takes `{ cwd?: string }`. Add the flag to that options
object. The `init` command in `src/cli/index.ts` declares the option with
commander's `.option('--refresh-schema', ...)` and passes it on. Keep
`initCommand`'s existing output lines and their order unchanged.

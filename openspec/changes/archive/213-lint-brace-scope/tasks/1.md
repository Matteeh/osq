## Details

A brace group is a `{`, then one or more characters that include at least
one `,` and no `{` or `}`, then a `}`. One check for that shape decides each
entry. Entries are compared as written in the task file, trimmed, as
`parseTaskMd` returns them.

Set up each case's project as `setupProject` in
`tests/lint-cargo-verify.test.ts` does: `installFakeValidator`,
`scaffoldProject`, a root `verify.cjs`, and one unapproved change whose task 1
lists the row's entry in the row's field. Put a plain existing path in the
other field, so only the row's entry can give a brace group error. Assert on
the errors that contain `holds a brace group`, so unrelated findings, such
as a scope that names a file not yet created, do not affect the result.

`linter.ts` is on the line-budget allow list and `lintChangeFolder` on the
function-budget grandfather list, so both may grow by the call. Keep the new
module under 250 lines and each function under 80.

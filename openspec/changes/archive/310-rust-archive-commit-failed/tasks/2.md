## Acceptance

- [ ] A `change` retry whose marker reason is `commit_failed` makes the archive commit as rust-retry "Archived retry" says, putting back and removing every deleted path `HEAD` holds first, and on a failed commit writes the record back and fails with `osq could not commit the archive: <output>`; every other archived retry keeps its `osq: <id> land retry` commit.
- [ ] `tests/fixtures/archive-failed/` holds `before/`, a copy of the archive crate's `tests/fixtures/project/`; `after/`, a copy of its `tests/golden/project/`; `archive-fails-007.txt`, a copy of this change's golden; and `worktree-007.txt`, a copy of the archive crate's `tests/fixtures/worktree-golden/worktree-007.txt`; each byte for byte.
- [ ] New `tests/retry_archive_commit.rs` proves "Failed archive commit retried" and "Failed archive commit retry refused", and checks that the built failed archive's status equals the golden's `status:` lines before it runs `retry`.
- [ ] Every existing retry test passes unchanged.
- [ ] Every public item ends its doc with `Implements: rust-retry/<requirement>`, and each new test's doc names `Covers: rust-retry/<scenario>`. `cargo fmt --all`, then the proposal's verify, pass with no missed mutant.

## Details

Copy the archive feature's path selection and message builder from
`crates/features/archive/src/commit.rs` into this crate; a feature never
calls another. Use the vcs kernel's `status`, `show`, `stage` and `commit`;
the kernel has no `discard` yet. Snapshot the archived folder's
`.run/regressed/` files and `.run/events/change.jsonl` before the retry
record, so a failed commit can write them back.

TypeScript's `commitArchivedRetry` stages back only the old change folder
and fails on this fixture's deleted living spec files; the Rust retry
departs from it there, as the proposal says.

When the mutation check reports a missed mutant, add a test case for that
line rather than keeping a branch no test reaches. Run the proposal's
verify as the watcher does, with
`OSQ_CHANGE=openspec/changes/310-rust-archive-commit-failed`, so the link
gates see this change's requirements.

## Scenarios

- rust-retry: Failed archive commit retried
- rust-retry: Failed archive commit retry refused

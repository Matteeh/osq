## Acceptance

- [ ] A failed worktree archive commit writes the archived folder's `.run/regressed/change.md` and appends the `regressed` event to its `.run/events/change.jsonl`, both uncommitted, as rust-archive "Worktree archive" says, and `archive` still fails with `osq could not commit the archive of <folder>: <error>`.
- [ ] `tests/fixtures/commit-failed-golden/` is a byte-for-byte copy of this change's `golden/` folder.
- [ ] New `tests/archive_commit_failed.rs` proves "Worktree archive commit fails", building its repository as `tests/archive_worktree.rs` builds the `hook-fails` case and printing the golden's `name:`, `tree:`, `tip:`, `commit:` and `status:` sections as the golden's script prints them.
- [ ] `worktree_archive_commit_fails` is removed from `tests/archive_worktree.rs`, since the new file proves its scenario; every other archive test passes unchanged.
- [ ] Every public item ends its doc with `Implements: rust-archive/<requirement>`, and each new test's doc names `Covers: rust-archive/<scenario>`. `cargo fmt --all`, then the proposal's verify, pass with no missed mutant.

## Details

The detail is git's output: match `VcsError::Failed { output, .. }`, and
use the display for the other variants. Cut it with a copy of the retry
feature's `tail_verify_output` in its own file in this crate, with
`config.limits.marker_output_lines` and `marker_line_chars`. Append the
event with rust-core's `Envelope`, `event_line` and `RegressedData`, as
land's stop record does. The tree's event lines are parsed, their
`timestamp` written `<timestamp>`, and written back with sorted keys.

When the mutation check reports a missed mutant, add a test case for that
line rather than keeping a branch no test reaches. Run the proposal's
verify as the watcher does, with
`OSQ_CHANGE=openspec/changes/310-rust-archive-commit-failed`, so the link
gates see this change's requirements.

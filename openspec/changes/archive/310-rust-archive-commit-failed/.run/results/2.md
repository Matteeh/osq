## Changed

- `crates/features/retry/src/retry/archive_commit.rs` (new): the `commit_failed` retry now copies the archive feature's path selection and message, puts every deleted path `HEAD` holds back, stages and removes it again, commits the archive in the change's tree, and on a failed commit restores the archived folder's `.run/regressed/` files and `.run/events/change.jsonl`.
- `crates/features/retry/src/retry/vcs_detail.rs` (new): the detail a failed git step reports (git's output for `VcsError::Failed`, otherwise the error's display), shared by the archive commit's error text.
- `crates/features/retry/src/retry/record.rs`: added `Snapshot` and `snapshot`, read before the retry record so a failed commit can put the record back.
- `crates/features/retry/src/retry.rs`: `finish` now also returns the marker's reason; an archived `change` retry whose reason is `commit_failed` takes the archive commit instead of the `land retry` commit, and every other archived retry keeps its `land retry` commit.
- `crates/features/retry/tests/retry_archive_commit.rs` (new): proves "Failed archive commit retried" and "Failed archive commit retry refused", plus the absent event stream, a record path that cannot be written, unrelated paths staying out of the commit, and the detail helper.
- `crates/features/retry/tests/fixtures/archive-failed/`: byte-for-byte copies of the archive crate's `tests/fixtures/project/` (`before/`) and `tests/golden/project/` (`after/`), this change's `archive-fails-007.txt`, and the archive crate's `worktree-007.txt`.

## Changed

- `crates/features/archive/src/commit.rs`: the archive commit now returns a `Failure` carrying the command error and, for a refused commit, git's output detail cut with the config's marker limits.
- `crates/features/archive/src/archive.rs`: a failed worktree archive commit writes the `commit_failed` record in the archived folder before returning the original error.
- New `crates/features/archive/src/regress.rs`: the detail selector, `.run/regressed/change.md` writer and `regressed` event appender.
- New `crates/features/archive/src/excerpt.rs` and `crates/features/archive/src/time.rs`: the retry feature's output-tail cut and UTC timestamp format, copied for this crate.
- New `crates/features/archive/tests/archive_commit_failed.rs`: proves the failure golden and TypeScript's record, plus the detail, tail and timestamp leaves.
- `crates/features/archive/tests/archive_worktree.rs`: removed `worktree_archive_commit_fails` and its now-unused hook helpers.
- `crates/features/archive/tests/fixtures/commit-failed-golden/`: byte-for-byte copy of this change's `golden/` folder.

## Outside scope

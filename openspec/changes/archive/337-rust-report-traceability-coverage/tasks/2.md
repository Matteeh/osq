## Details

Port `formatValidation` and `collectValidation`'s counting from
`report-validation.ts`, the `Coverage:` lines of `formatMetricsReport` in
`report.ts`, and the `coverage` and `validation` members of
`toStableMetrics` in `src/cli/report.ts`. Never read anything under `src/`
from Rust; it is in `entry` only so you can port it.

Put each section in its own small module, such as `validation.rs` and
`coverage.rs`, and keep `output.rs` and `history_json.rs` small: they only
call the new modules and add their lines and members. Order folder names
and task ids with `order::compare_numeric_prefix`. Write every number with
`js_number`.

The old `report_summary.rs` table gains one row, and its goldens now run
through the end of Coverage. Keep the rest of the file as it is.
`report_history.rs` and `report_sizes.rs` pass unchanged; if one of them
compares a whole report text, it must still pass, so check it before you
start.

When the mutation check reports a missed mutant, add a test case for that
line rather than keeping a branch no test reaches. Take its expected value
from the goldens or the TypeScript source. Run the proposal's verify as the
watcher does, with
`OSQ_CHANGE=openspec/changes/337-rust-report-traceability-coverage`, so the
link gates see this change's new requirements.

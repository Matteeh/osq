## Changed

- Added `crates/kernel/storage/src/read/validation.rs` with `ValidationRun` and `read_latest_validation`, porting TypeScript's `latestForChange`/`readValidation`: loose `change.jsonl` parsing, `timestamp_ms` timestamps, `js_trim` outcomes, validated-only findings arrays, greatest timestamp with later-line tie-breaking, and `None` on a missing or unreadable file.
- Added `crates/kernel/storage/src/read/coverage.rs` with `TaskEventFile`/`read_task_event_files` and `CapabilitySidecars`/`read_capability_sidecars`, porting the task-file event check and `collectCapabilityCoverage` with byte-order output.
- Exported the new types and readers from `read/mod.rs` and `lib.rs`, and added the three new requirement links to the read module docs.
- Widened `task_history/stream.rs` visibility to `pub(crate)` so the validator reader reuses its existing loose event parser.
- Added `tests/reading_validation_coverage.rs` proving every "Latest validator runs" row, "Task event files of a change", and "Sidecars of the living specs", plus directory-named-task and byte-order edge cases.
- Added the committed fixture `tests/fixtures/task-event-files/` with `305-active` task files and event files, and the living specs `alpha`, `beta`, `notes` and `index.txt`.

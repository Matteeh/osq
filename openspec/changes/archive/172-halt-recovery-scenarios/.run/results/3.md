  `.run/running/<n>.pid`, parses a numeric `pid`, and asks `isPidRunning` from

## Deviated

- The child holds one ref'd `setInterval(() => {}, 1000)`. A genuinely running
  watcher awaits a real spawned agent process, which keeps Node's event loop
  alive; the fake never-resolving adapter promise alone does, so Node detected
  an unsettled top-level await and exited 13 within milliseconds of the spawn,
  and the parent's kill/exit handshake then hung waiting for an `exit` event
  that had already fired. The earlier red run and the first, lucky green run are
  both explained by this race. The timer makes the child a real mid-task
  watcher, and `stopChild` attaches its exit listener before SIGKILL and
  returns early if the child is already gone.
- `--import` of `tests/git-test-env.ts` is passed as a `file://` URL so it
  resolves regardless of the child's working directory.

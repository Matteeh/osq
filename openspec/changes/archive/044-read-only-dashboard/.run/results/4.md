## Deviated

- `noUncheckedIndexedAccess` is not enabled. The required erased contract
  imports pull core modules (`report.ts`, `inbox.ts`, `web-data.ts` and their
  transitive graph) into the UI program, and those modules predate indexed-access
  strictness (54 errors). Enabling it would require editing `src/`, which is out
  of scope, so `strict`, `noUnusedLocals`, and `noUnusedParameters` are used.
- The root `tsconfig.json` owns `include: ["tests/**/*"]` and has no `jsx`
  option; a `tests/ui-data.test.tsx` with JSX therefore cannot compile under
  root `tsc`, and `tsconfig*.json` belongs to task 8. CLI typechecking was moved
  to the in-scope `packages/ui/tsconfig.cli.json`, which applies the same root
  options to `src`, `tests/**/*.ts`, and `osq.config.ts` while excluding the UI
  workspace.
- `.tsx` tests must build elements with `createElement` and reach React through
  the runtime tsconfig; the root `tsx` loader does not apply `jsx: react-jsx` to
  files under `tests/`. UI source itself uses JSX and is transformed correctly.
- `.gitignore` entries for the two UI build directories are redundant with the
  existing `dist/` pattern but were added to make the intent explicit.

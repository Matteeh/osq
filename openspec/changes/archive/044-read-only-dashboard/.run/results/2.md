## Deviations

- `OsqConfig.serve` is typed `Partial<ServeConfig>` rather than required. This
  keeps the existing one-line `Omit` union in `config.ts` inside the 250-line
  source budget and avoids breaking `OsqConfig` literals in frozen tests.
  `defineConfig` still returns fully defaulted, validated values.
- `startWebServer` gained an explicit `port` option so the CLI port precedence
  reaches the listener; task 3 can extend the same handle with the SSE watcher.
- Static 404s are `text/plain`; all API failures are JSON as required.

# Task 8 result

## Changed

Distribution and release ownership for the dashboard:

- `scripts/stage-ui.mjs` (new): removes only the package-root `ui/dist`
  directory, recreates it, and copies regular files from `packages/ui/dist`
  using `readdir`/`lstat`-backed directory entries. Symlinks and paths outside
  either root are skipped, so only build output can be published. `--clean`
  removes both `ui/dist` and `packages/ui/dist` and is the supported reset path.
- `package.json`:
  - scripts now separate the authoritative route into `build:cli`
    (`tsc -p tsconfig.build.json`), `build:ui` (`pnpm --filter @osq/ui build`),
    and `stage:ui`; `build` runs UI production build, staging, then CLI build.
    `prepublishOnly` remains `npm run build`; `clean:ui` is the staging script's
    clean path. `verify` now runs both typechecks, the full `build`, the tests,
    then lint, so asset inspection always follows a build.
  - `files` gained `ui` so the staged `ui/dist` ships while `packages/**`
    remains excluded.
  - `engines.node` raised to `>=24.0.0`; root `@types/node` moved to
    `^24.13.6`.
- `.github/workflows/ci.yml`, `.github/workflows/release.yml`: `node-version`
  set to `24`.
- `README.md`: Install now states the Node.js 24 LTS floor; the command list
  gained `osq serve [--port <n>]`; a new `Delivery Dashboard` section documents
  the loopback-only read-only server, default `http://127.0.0.1:4173/`, `--port`
  precedence and `0`/range behavior, `--open`, the `#/report`, `#/graph`, and
  `#/changes/<key>` routes, no writes/no hosting/hash-routing boundaries, and
  SIGINT/SIGTERM shutdown.
- `tests/package-ui-budget.test.ts` (new): fails clearly when the staged
  `ui/dist/index.html` is missing and recursively sums only regular files,
  asserting the 1,000,000-byte ceiling with the measured total and limit in the
  failure message.
- `tests/line-budget.test.ts`: added a UI source budget that scans `.ts`,
  `.tsx`, and `.css` below `packages/ui/src` against the same 250-line ceiling
  with no allow-list entry.
- `tests/package-hygiene.test.ts`: allows only `ui/dist/**` in addition to the
  established assets, requires `ui/dist/index.html` plus a fingerprinted
  `ui/dist/assets/*` file, rejects `packages/` and any unstaged `ui/` path,
  asserts the exact four permitted root runtime dependencies, asserts React,
  React DOM, their declarations, and Vite are private-workspace devDependencies
  absent from root dependencies, and asserts the Node 24 baseline across root
  and UI engines, 24.x Node types, both workflows, and the README.
- `tests/package-install-smoke.test.ts`: added a sequential smoke step that
  spawns the installed compiled executable with literal `serve --port 0`, parses
  its single printed URL under a timeout, fetches the index and its fingerprinted
  asset with Node `fetch`, asserts loopback, port, and content-type headers, then
  sends SIGTERM and requires a clean zero exit. It also asserts none of
  React/React DOM/type declarations/Vite are installed runtime dependencies and
  that the installed package ships `ui/dist/index.html`. The finally block
  SIGKILLs a still-running child; the existing `after` hook removes the temp
  project.
- `pnpm-lock.yaml`: re-resolved for the root `@types/node` 24 line only
  (`pnpm install`); the pinned `packageManager` field is unchanged.

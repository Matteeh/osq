## Changed

- Added `src/core/foundation/rules-block.ts`: `RULES_START_MARKER`,
  `RULES_END_MARKER`, `renderRulesBlock`, `writeRulesBlock`, and
  `checkProjectRules`. The block holds one line per accepted system-wide ADR in
  number order, sits directly before `<!-- OSQ:START -->` with one blank line
  between, is appended at the end when no managed marker exists, and is removed
  together with its following blank line so write-then-remove restores the file
  byte for byte.
- Added `src/core/foundation/doctor-decisions.ts`: `checkDecisions` validates
  the ADRs with `validateDecisions`/`readLivingCapabilityNames`, folds in
  `checkProjectRules`, fails on any error, warns with the ignored-file and
  unknown-capability list, passes with `<n> ADRs valid`, and returns null when
  the project has neither a decision markdown file nor a rules marker.
- `src/core/foundation/doctor.ts`: `runDoctorChecks` inserts the `decisions`
  check right after `managed-blocks`, only when `checkDecisions` returns one.
- `src/core/foundation/init.ts`: `scaffoldProject` takes an optional `config`
  (default `DEFAULT_CONFIG`), writes the rules block right after
  `updateAgentsMd`, and `InitResult` gained `updatedProjectRules`.
- `src/cli/init.ts`: loads the config with `loadConfig`, falls back to
  `DEFAULT_CONFIG` on failure, passes it to `scaffoldProject`, and prints
  `  updated  AGENTS.md (project rules)` when the block changed.
- Added `tests/rules-block.test.ts` (18 tests) on temporary projects covering
  the canonical block, no system-wide ADR, direct placement, idempotency,
  supersession, removal with byte-identical restore, preamble/epilogue
  preservation, append without a managed block, the `limits.maxProjectRules`
  message, stale/missing/unexpected block errors, stale-then-fixed doctor,
  ignored-file warning, validation failure, and the doctor check-list position.

Task verify (`node --import tsx --test tests/rules-block.test.ts`) and the
proposal verify (`pnpm verify`, exit 0) both pass.

Touched: src/core/foundation/rules-block.ts, src/core/foundation/doctor-decisions.ts, src/core/foundation/doctor.ts, src/core/foundation/init.ts, src/cli/init.ts, tests/rules-block.test.ts

## Details

A test function is the item after a `#[test]` line; read the attribute lines
between `#[test]` and its `fn` line, so the order of `#[test]` and
`#[ignore = ...]` does not matter. Read the files as text with `std::fs`;
tests are exempt from rust-core's no-IO rule. The check fails when no
`*_corpus.rs` file exists at all, so an empty walk never passes.

Measured on 2026-10-18 with `event_corpus` ignored: cargo-mutants over
`osq-core` tests 117 mutants in 44 seconds, 90 caught and 27 unviable, none
missed. The fast tests in `crates/core/tests/events.rs` already cover "Event
lines round-trip".

Leave every other test file and `scripts/mutants-rust.sh` alone; cargo-mutants
runs plain `cargo test`, which leaves ignored tests out by itself. Run
`cargo fmt --all` before exiting.

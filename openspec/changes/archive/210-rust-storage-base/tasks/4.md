## Details

The rows in `golden/` were printed by TypeScript's `osq query --json` and are
the expected values. When a row disagrees, the Rust reading is wrong: fix it
in `src/read/` or `src/model/` within this task's scope, keep
tasks 1 and 2's tests passing, add the fast case that pins the rule, and say
in `## Deviated` which rule changed and why. Never edit a golden file, an
existing fixture file or an existing test to make a row pass; a new fixture
folder is fine.

The test never runs `node` or `osq`. It ignores archived changes numbered
above 209 for the golden rows, but replays them with the rest.

`.run/done/<n>` is the marker; a task's folded status is `Done` exactly when
it exists. Every change numbered 038 or higher must hold at least one
`archived` event in `change.jsonl`; it need not be the last event.

Keep the test file under 250 lines and every function under 80. Workspace
lints include `clippy::pedantic` and `-D warnings`. Run `cargo fmt --all`
before exiting.

## Acceptance
- [ ] tests/fixtures/events/verified.jsonl contains checked-in golden event sequence for a successful task
- [ ] tests/fixtures/events/dead.jsonl contains checked-in golden event sequence for a failed task
- [ ] tests/golden-events.test.ts executes runTask with MockAdapter end-to-end for a verified task
- [ ] tests/golden-events.test.ts executes runTask with MockAdapter end-to-end for a dead task
- [ ] Event normalization masks non-deterministic timestamps, pids, versions, and paths to standard tokens
- [ ] UPDATE_GOLDEN=1 regenerates golden fixtures directly from the test runner
- [ ] package.json registers test:golden script to run the golden events suite

## Details

1. In `tests/fixtures/events/verified.jsonl`:
   - Check in expected normalized event sequence for a verified task:
     - `started` (with masked pid, commit, version)
     - `tokens`
     - `result_written`
     - `exited`
     - `verify_ran`
     - `done`
2. In `tests/fixtures/events/dead.jsonl`:
   - Check in expected normalized event sequence for a dead task (`verify_red`):
     - `started`
     - `tokens`
     - `result_written`
     - `exited`
     - `verify_ran`
     - `dead`
3. In `tests/golden-events.test.ts`:
   - Build a helper `normalizeEvents(rawJsonl: string, projectRoot: string): string`:
     - Parse each line as JSON.
     - Replace `timestamp` with `"[TIMESTAMP]"`.
     - Replace `data.pid` with `12345`.
     - Replace `data.commit` with `"[COMMIT]"`.
     - Replace `data.version` and `data.osqVersion` with `"[VERSION]"`.
     - Replace `data.elapsedSeconds` with `0`.
     - Replace any absolute paths containing `projectRoot` with relative equivalents.
     - Return re-serialized deterministic JSONL.
   - Test 1 (Verified):
     - Set up mock environment with `MockAdapter`, approve spec, and invoke `runTask`.
     - Read `.run/events/1.jsonl`, normalize, and assert strict equality with `tests/fixtures/events/verified.jsonl`.
   - Test 2 (Dead):
     - Set up task with failing verification (`node -e "process.exit(1)"`), approve, and invoke `runTask`.
     - Read `.run/events/1.jsonl`, normalize, and assert strict equality with `tests/fixtures/events/dead.jsonl`.
   - Regeneration support:
     - If `process.env.UPDATE_GOLDEN === '1'`, write normalized outputs directly to fixture paths and log notice.
4. In `package.json`:
   - Add `"test:golden": "node --import tsx --test tests/golden-events.test.ts"` under `scripts`.
5. Verification:
   - Run `node --import tsx --test tests/golden-events.test.ts`.

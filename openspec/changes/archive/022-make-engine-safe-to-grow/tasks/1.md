- [ ] src/core/init.ts exports updatePlannerMd to insert or replace the managed block in PLANNER.md

## Details

1. In `src/core/init.ts`:
   - Declare and export `MANAGED_PLANNER_BLOCK`:
     Contains the standardized OSQ planning instructions wrapped between `${OSQ_START_MARKER}` and `${OSQ_END_MARKER}`.
   - Implement and export `updatePlannerMd(targetDir: string): Promise<boolean>`:
     - Resolves `path.join(targetDir, 'PLANNER.md')`.
     - If the file does not exist, write `# Planning a change for osq\n\n${MANAGED_PLANNER_BLOCK}\n`.
     - If the file exists, locate `OSQ_START_MARKER` and `OSQ_END_MARKER`.
     - If both markers are found in valid order, replace the content between them (inclusive) with `MANAGED_PLANNER_BLOCK`.
     - If markers are not present, append `MANAGED_PLANNER_BLOCK` preserving existing preamble/content.
   - In `scaffoldProject`:
     - Call `await updatePlannerMd(targetDir)`.
     - Return `updatedPlannerMd` on `InitResult`.
   - Ensure `src/core/init.ts` stays strictly under 250 lines.
2. In repository root `PLANNER.md`:
   - Wrap the planning instructions with `<!-- OSQ:START -->` and `<!-- OSQ:END -->` so it is recognized as current by managed block checks.
3. In `tests/init-planner.test.ts`:
   - Test creating `PLANNER.md` in an empty directory.
   - Test updating `PLANNER.md` when markers are present, confirming user content before/after markers is preserved.
   - Test updating `PLANNER.md` when markers are absent, confirming block is appended.
4. Verification:
   - Run `node --import tsx --test tests/init-planner.test.ts`.

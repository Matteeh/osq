## Details

Add `osq-kernel-loop`, `osq-kernel-vcs`, `serde_json` and `yaml-rust2`
to the crate's `Cargo.toml` as the other dependencies are written, all
from the workspace; tasks 2 and 3 use the ones this task does not. The
root `Cargo.lock` follows on its own.

Today `rule_findings` in `lint.rs` returns nothing when `proposal_body`
fails. Read `proposal.md` once: a missing file gives the not-found error,
bytes that are not UTF-8 give nothing, a `parse_frontmatter` refusal
gives the YAML error, and a parsed proposal runs every proposal rule.
Take `verify` from rust-specs `parse_proposal`. The Surface rule reuses
`read_section` and `is_blank` in `proposal.rs`.

For the project paths, call rust-vcs `GitVcs::root()` at the root and use
`line_endings` paths only when it gives the root itself, compared after
`fs::canonicalize`, so a scratch copy inside this repository has none.
Copy TypeScript's package manager word lists from `linter.ts`.

When the mutation check reports a missed mutant, add a row-shaped test
case for that line with the expected value from the TypeScript source.
Run the proposal's verify as the watcher does, with
`OSQ_CHANGE=openspec/changes/306-rust-lint-task-rules`, so the link gates
see this change's requirements.

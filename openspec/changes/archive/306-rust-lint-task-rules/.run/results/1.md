## Changed

- Copied every file under the change fixture `fixture/lint-project/openspec/changes/` over the lint fixture, giving each fixture change a clean `proposal.md` with `verify` and `## Surface`, and a `tasks/1.md`.
- Reworked `lint.rs` to read `proposal.md` once: a missing file gives the not-found error, non-UTF-8 bytes give no proposal finding, a `parse_frontmatter` refusal gives the YAML error, and a parsed proposal then runs every proposal rule before the banned words.
- Extended `proposal.rs` with the declared-verify, `## Surface`, and change-verify rules, in TypeScript's order, and added the `Input` struct to keep the function within the argument budget.
- Added `src/lint/verify.rs`: command tokenization, placeholder detection, package-script resolution with TypeScript's package-manager word lists, the Rust `cargo` verify runner, existing-path resolution, chaining, and the three verify messages. It reads the root `package.json` scripts and the project paths that give the languages, calling rust-vcs `root()` and using `line_endings` only when it names the project root itself.
- Updated `tests/lint_proposal_rules.rs` to build every row from the new `<goal>` frontmatter and to expect the new frontmatter YAML error.
- Updated the last row of `tests/lint_banned_words.rs` to the four findings the new proposal rules add.
- Added `tests/lint_proposal_verify.rs` proving "Proposal verify and Surface findings", plus token-rule cases for the verify analysis.
- Added `osq-kernel-loop`, `osq-kernel-vcs`, `serde_json` and `yaml-rust2` to the crate's dependencies from the workspace; the root `Cargo.lock` followed on its own.

## Deviated

- Added extra token-rule test rows, and an `assumptions_at_start` proposal row, beyond the scenario tables. They cover lines the mutation check reported as missed (chaining operators, placeholder guards, token path rules, and a section heading at offset 0).
- Marked the private `same_root` helper `#[cfg_attr(docsrs, mutants::skip)]` with a comment: under lint the link gates refuse a root without `Cargo.toml`, so the tracked-paths branch cannot change the Rust language and every mutant of that helper is equivalent. `docsrs` is never set by the build or tests, so no extra dependency is needed.

## Changed

- Added `src/core/report/record-verification.ts`:
  - `VerificationCounts` (`passed`, `failed`, `pending`).
  - `collectVerificationCounts(archivedFolders)` reads each archived folder
    with task 1's `readVerification`, counts a change once when
    `required` is true (`passed`, `failed`, else `pending`), and returns
    `null` when no archived change requires verification.
  - `formatVerificationCounts(counts)` renders
    `After-landing checks: <passed> passed, <failed> failed, <pending> pending`.
- `src/core/report/report.ts`:
  - `HistoryMetrics` gains optional `verification?: VerificationCounts`.
  - `getMetricsReport` computes `collectVerificationCounts(archivedFolders)`
    and adds `verification` to `history` only when it is non-null.
  - `formatMetricsReport` prints `formatVerificationCounts(...)` after the
    rework and disclosure sections, only when the field is present.
- Added `tests/report-verification.test.ts`, covering both delta scenarios
  through `reportCommand` in text and `json`:
  - "Mixed outcomes": three archived changes requiring verification, one
    `passed`, one `failed`, one with no outcome, yield
    `After-landing checks: 1 passed, 1 failed, 1 pending` and
    `history.verification: { passed: 1, failed: 1, pending: 1 }`.
  - "No verification required": no line and no `verification` key.

## Deviated

- The acceptance requires the JSON form to carry `history.verification`, but
  `src/cli/report.ts` (which owns the stable `toStableMetrics` projection) was
  not in the task's `scope`. No other task owns it either. Without a one-line
  conditional spread there, `reportCommand --json` cannot show the field, so I
  edited it as the minimal necessary change and list it here and in `Touched`.
- The delta fixes no byte format for the text line. I print it without the
  two-space indent the surrounding history lines use, so it matches the spec's
  backticked string exactly.

## Missing context

  `src/cli/report.ts`; the task's scope omitted that file and no task owns it.
  See Deviated.

## Changed

- `crates/kernel/loop/Cargo.toml` adds only `osq-kernel-specs.workspace = true`, and `Cargo.lock` records it.
- New `crates/kernel/loop/src/scope.rs` holds `scope_files(project_root, scope)` and classifies each normalized entry as exact or pattern. `crates/kernel/loop/src/scope/files.rs` walks a pattern's search root for regular files without following symbolic links.
- `crates/kernel/loop/src/lib.rs` keeps its crate doc, declares `mod scope;` and re-exports `scope_files`.
- Added the five comment-only fixture files under `crates/kernel/loop/tests/fixtures/repo/` and no other file under the fixture's `src/` or `crates/`.
- New `crates/kernel/loop/tests/scope_files.rs` asserts every row of the "Scope files of the fixture repository" table, reading the fixture from `CARGO_MANIFEST_DIR`.

## Deviated

The fixture cannot hold files outside itself, so the table's `../outside/*.ts` row alone cannot show that the search-root guard is obeyed. The test also builds a small repository under `CARGO_TARGET_TMPDIR` with an outside directory holding a match, an absolute pattern, and a root-level pattern; those assertions make the `..`/`/` guard and the empty search root observable to the mutation check. They are additional to the table, whose rows still each have one assertion.

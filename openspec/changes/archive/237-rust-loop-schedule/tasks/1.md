## Details

The fixture's `.rs` files are data, not code: give each a single `//`
comment line and nothing else.

cargo-mutants runs on every line this task adds. The pattern test, the
search root, the `..` and `/` guard, the fall-back to the entry itself,
the dedup and the byte sort must each change a value a table row checks.
Before exiting, run `cargo fmt --all`, then
`cargo mutants -p osq-kernel-loop -f <file> -o "$(mktemp -d)"` on each new
source file, then `sh scripts/verify-rust.sh` with `OSQ_CHANGE` set to
`openspec/changes/237-rust-loop-schedule`, so the link gate corpus test
sees this change's new requirements.

## Changed

- `src/core/migrate.ts` (new)
  - `migrateToOpenSpec({ cwd, config, sampleStub?, sampleSlug? })` migrates:
    - `features/<capability>.md` -> `openspec/specs/<capability>/spec.md`
    - `specs/<id>-<slug>/` -> `openspec/changes/<id>-<slug>/`
    - `specs/archive/<id>/` -> `openspec/changes/archive/<id>/`
  - Folder moves are single `rename`s, so each archived folder's whole `.run/`
    history (approved, done, results, events) moves with it.
  - `convertSpecToProposal(content)` rewrites legacy `spec.md` frontmatter to
    keep `title`, `depends_on`, and `features.reads` (dropping
    `features.writes`) and renames a prose `## Delta` heading to
    `## Delta (legacy)`, preserving the prose exactly.
  - `tickAllCheckboxes(content)` (exported, pure) rewrites every unchecked
    `[ ]` to `[x]` and is applied recursively to every archived `tasks.md`,
    including files nested inside an archive.
  - `createSampleStub` computes the next 3-digit id from the migrated changes
    root and creates `<next-id>-sample/` with `proposal.md`, `tasks.md`, and
    `tasks/1.md`. With max id 016 this is `openspec/changes/017-sample/`.
  - `MigrateResult` reports migrated features/changes/archives, converted
    proposals, ticked task files, the created stub, and skipped paths.
- `src/cli/migrate.ts` (new)
  - `migrateCommand(target, options)` accepts only `openspec`; anything else
    logs an error and signals a non-zero exit through an injectable sink.
    Passes `cwd`/`config` to the core migration and logs a summary.
- `src/cli/index.ts`
  - Registered `migrate <target>` (required argument) after `setup`.
- `tests/migrate.test.ts` (new, 11 tests)
  - One or more tests per acceptance line: feature/active moves, archive move
    preserving `.run/`, proposal conversion and `## Delta (legacy)` prose,
    archive ticking against seeded and real/fixture copies, fixture + real
    archive integration through both `openspec validate` commands, the
    `017-sample` stub, plus unit tests for the pure helpers and the CLI
    registration/dispatch.

## Deviations

- Feature docs are moved verbatim, not converted into OpenSpec
  `## Purpose`/`## Requirements` capability specs. Prose feature docs cannot be
  mechanically turned into requirement blocks without fabricating content, and
  the deterministic delta application path (`src/core/delta.ts` /
  `src/watcher/archiver.ts`) already owns living-spec structure. The task's
  only stated conversion requirement was the `spec.md` -> `proposal.md` rename
  with `## Delta (legacy)` preservation.
- `createSampleStub` runs by default and is idempotent: it skips when a
  `<id>-sample` folder already exists, otherwise creates `<next-id>-sample`
  computed from the migrated changes root (hence `017-sample` after 016).
- Implemented `tickAllCheckboxes` locally instead of importing
  `tickAllTaskCheckboxes` from `src/watcher/archiver.ts`, to avoid a
  core -> watcher dependency and because `archiver.ts` is outside this task's
  scope.
- `paths.openspecRoot` and `config.openspec` are still absent from
  `src/core/config.ts` (see Missing context). The OpenSpec root is resolved
  through the same defensive accessor used by tasks 3/4/6, defaulting to
  `openspec`.
- `migrateCommand` returns `null` and signals a non-zero exit (injectable
  sink) rather than throwing, so the CLI never crashes on an unsupported
  target and tests do not terminate the process.

## Changed

- `src/watcher/archiver.ts`
  - `archiveSpecFolder` now:
    1. applies the change's delta specifications via `applyDelta` while the
       folder is still in place (OpenSpec delta specs into
       `<openspecRoot>/specs/<capability>/spec.md`, then the legacy prose
       `## Delta` + `features.writes` fallback);
    2. moves the folder whole into `config.paths.archive` (legacy
       `specs/archive` or OpenSpec `openspec/changes/archive`);
    3. ensures every archived `tasks.md` is fully ticked.
    The whole `.run/` tree (approved, done, dead, running, results, events)
    moves with the folder because the move is a single `rename`.
  - Added exported `tickAllTaskCheckboxes(content)`: purely textual rewrite of
    every unchecked `[ ]` to `[x]`, preserving bullet style (`-`/`*`),
    numbering (`1.` / `1)`), and indentation. No `.run/` read or write.
  - Added `ensureArchivedTasksTicked(folderPath)`: walks the archived folder
    (skipping `.run`, `.git`, `.DS_Store`) and ticks every file named
    `tasks.md`.
  - `checkAndArchiveSpec` no longer calls `applyDelta` itself; the call now
    lives inside `archiveSpecFolder`, so deltas are applied exactly once.
- `tests/archiver.test.ts`
  - Kept all four legacy tests and added six:
    - `.run` history preservation (approved, done, results, events).
    - configured legacy `paths.archive` target.
    - OpenSpec config: delta merged into `openspec/specs/<capability>/spec.md`
      and folder moved to `openspec/changes/archive/<id>-<slug>`.
    - every archived `tasks.md` fully ticked (flat + nested + pre-ticked rows).
    - legacy path `tasks.md` ticking.
    - `checkAndArchiveSpec` applies ADDED exactly once and archives to
      `specs/archive` under the default config.
  - Added an `openSpecConfig()` helper that attaches `paths.openspecRoot` via a
    variable to stay strict-clean without editing `src/core/config.ts`.

## Deviations

- Moved `applyDelta` from `checkAndArchiveSpec` into `archiveSpecFolder`
  (acceptance line 3 says delta application happens "during
  archiveSpecFolder"), removing the old call to avoid applying ADDED twice and
  duplicating legacy feature prose.
- `archiveSpecFolder` applies the full `applyDelta` (OpenSpec + legacy prose)
  rather than only OpenSpec deltas. This preserves existing legacy behavior and
  still satisfies the OpenSpec requirement.
- Ticking runs on the archived copy after the rename, so "every archived
  `tasks.md`" is literally the moved file.
- `tickAllTaskCheckboxes` is exported for direct testing; only `tasks.md` files
  are touched (never task-unit `tasks/<n>.md` acceptance checklists).
- `paths.openspecRoot` is still not declared on `OsqPaths` in the working tree
  (see Missing context); the existing defensive accessor in
  `resolveOpenSpecRoot` is retained and `config.ts` was left untouched.

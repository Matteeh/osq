## Details

`crates/features/land/tests/support/mod.rs` does the same after its own
`git init`; take its shape. Use the same name and email `support::git`
already gives the test's git calls, `support::NAME` and
`support::EMAIL`, or literals when they are not public. Change no test
body and no file outside the scope. Read the local config in the new
test with `support::git`, as `crates/features/run/tests/run_worktree_tree.rs`
uses the support modules.

## Details

Reuse `goal_section`, `markdown_body` and `timestamp_ms` from
`src/read/text.rs`, the frontmatter parse `frontmatter_string` uses, and
`osq_kernel_specs::parse_task_list` for `tasks.md`. Parse event lines with
`serde_json::Value` one line at a time, never with core's typed `Event`,
since TypeScript passes over lines the typed parse refuses. Port the line
rules of `lastStartedTrailers` and `startedTrailers` in
`src/core/run/commit-message.ts`, `outcomeLine` and `readTrimmed` in
`src/core/run/squash-message.ts`, `readLandedAt` in
`src/core/web/web-data-lifecycle.ts`, `listDeltaCapabilities` in
`src/core/vcs/sync-specs.ts` and `parseStackedOn` in
`src/core/spec/stack-dependencies.ts`, as the requirement words them.

Copy the fixture with `cp -r`; never edit it and never regenerate it. Each
test row writes its folder under `env!("CARGO_TARGET_TMPDIR")`, named
after the test and row and removed first if it is left over, since tests
run in parallel.

cargo-mutants runs on every line this task adds, so each branch must
change a value a row checks: the goal fallback, each trimmed-or-absent
file, the task number fallback, the boolean-only `manual`, each condition
of a usable `started` line and the last-line choice, each condition of a
usable `archived` line, directories only under `specs/` and their order,
and the two-word rule of `.run/stacked-on`. Before exiting, run
`cargo fmt --all`, then
`cargo mutants -p osq-kernel-storage -f crates/kernel/storage/src/read/land.rs -o "$(mktemp -d)"`,
then `sh scripts/verify-rust.sh` with `OSQ_CHANGE` set to
`openspec/changes/256-rust-land-feature`, so the link gate corpus test
sees this change's requirements.

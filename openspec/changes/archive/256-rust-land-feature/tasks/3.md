The stacked refusal comes after the lookup failures. The branch and worktree refusals come before the landed report. The earlier-change refusal comes before the tip check.
- [ ] `Cargo.toml`, `Cargo.lock`, `src/lib.rs`, `src/feature.rs`, the other files under `src/land/`, `tests/support/mod.rs`, the fixtures and task 2's tests do not change, and task 2's tests keep passing.

## Details

Port `assertCheckoutBranch`, `assertWorktreeClean`, `stackedOn` and
`assertNoEarlierChange` in `src/core/vcs/land-checks.ts`, and the
`landed`/`archived` distinction of `readDependencyState` in
`src/core/spec/stack-dependencies.ts`. The other changes are the worktree
changes task 2's lookup lists that have an archived folder. A change has
landed when the default branch holds `openspec/changes/archive/<folder>`.
Its approval is on its branch when `show("osq/<folder>",
"openspec/changes/archive/<folder>/.run/approved")` gives text. Read each
change's facts with `osq_kernel_storage::read_land_facts` of its archived
folder in its worktree. Only the stacked refusal and the earlier-change
refusal skip a landed change.

In each row, commit the files the row gives an archived folder on that
change's branch, so its worktree stays clean, unless the row says the
worktree has an untracked file. An `archived` event is the line
`{"type":"archived","timestamp":"<time>","data":{}}` in
`.run/events/change.jsonl`, and `.run/approved` holds `sha256:` and 64
`0`. In the row where `main` holds `002-beta-orders`, merge `main` into
`osq/001-alpha-orders` in its worktree with the helper git runner before
`land` runs, so the base stays an ancestor of the tip.

cargo-mutants runs on every line this task adds, so each branch must
change a value a row checks. That means the stacked refusal and its
landed exception, the branch and detached texts, and the worktree status
check. It also means each condition of the earlier-change rule: this
change's own time and capabilities, the other's landed and approved
flags, the text comparison, the shared capabilities, and the direct and
indirect stacked exclusions.
Before exiting, run `cargo fmt --all`, then
`cargo mutants -p osq-feature-land -f <file> -o "$(mktemp -d)"` on
`src/land.rs` and `src/land/checks.rs`, then `sh scripts/verify-rust.sh`
with `OSQ_CHANGE` set to `openspec/changes/256-rust-land-feature`.

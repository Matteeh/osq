## Changed

- Added the land feature: `LandFeature` with the name `land`, one command `land <id>`, command and argument errors, and `run_land`.
- Added `src/land.rs` as the orchestrator over the settings, worktree lookup, landed report, message, commit and fast-forward, with the two task-3 refusal insertion points marked.
- Added `src/land/find.rs` for the worktree changes and pure folder matching, `src/land/message.rs` for the squash message and trailers, and `src/land/text.rs` for the failure and output texts.
- Added the config, storage and vcs kernel dependencies to the crate manifest and let cargo update `Cargo.lock`.
- Copied the archived fixture change and the golden message byte for byte into the crate's `tests/fixtures`.
- Added scratch-repository support for land repositories, worktree changes, fixture and arbitrary archived folders, commits, worktree removal and branch renames, snapshots, and feature invocations.
- Added `land_feature`, `land_settings`, `land_lookup`, `land_message` and `land_commit` tests covering every scenario this task names.

The task verify passes. `cargo fmt --all`, clippy with `-D warnings`, cargo-mutants on every new source file, and `OSQ_CHANGE=openspec/changes/256-rust-land-feature sh scripts/verify-rust.sh` all pass.

## Deviated

- Added `checkout_fallback_skips_unmatched_archives` to `land_lookup.rs`, beyond the named tests, so the checkout's archived fallback proves it filters by both location and query. Without it an `&&` mutant in that filter survived.

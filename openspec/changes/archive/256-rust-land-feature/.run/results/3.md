## Changed

- Added `crates/features/land/src/land/checks.rs` with the pure refusal texts for a stacked change, an off-branch or detached checkout, and an unclean worktree, plus the direct and indirect stacked-on closure and the first earlier unlanded approved change sharing a capability.
- Extended `run_land` with `check_refusals`, which runs the stacked, branch, worktree and earlier-change refusals in the requirement's order after lookup and before the landed report or any write. It reads each worktree change's archived `LandFacts`, landed flag and approved-on-branch flag through the vcs kernel.
- Added `crates/features/land/tests/refusals.rs`, proving every row of "Refusals before the land", "Refusals for a landed change" and "Earlier changes that do not refuse", checking after each refusal that `main` has not moved.

The task verify `cargo test -p osq-feature-land --test refusals` passes. `cargo fmt --all`, clippy with `-D warnings`, `cargo mutants` on `src/land.rs` (29 caught, 6 unviable), on `src/land/checks.rs` (23 caught) and on `tests/refusals.rs` (no mutants), and `OSQ_CHANGE=openspec/changes/256-rust-land-feature sh scripts/verify-rust.sh` all pass.

## Deviated

- Added two extra tests beyond the scenario rows: an other change archived at the same time as this one, and a change with no capabilities, so the text comparison and shared-capability filter cannot pass untested mutants.

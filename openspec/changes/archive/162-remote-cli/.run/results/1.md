## Changed
- Added `src/core/web/web-remote.ts`: the `ForwardedCommand`, `ForwardedOutput`, `ForwardedEnd` and `ForwardedCommandRunner` ports plus `createRemoteRoutes`, which reuses the write-action guards/token and streams `GET`/`POST api/commands` as NDJSON and routes `GET`/`PUT api/files/<id>` to `web-remote-files.ts`.
- Added `src/core/web/web-remote-files.ts`: `readChangeFiles` and `replaceChangeFiles`, resolving a change with `findChange` in the first tree from `changeTrees`, rejecting approved or foreign-tree changes, validating every uploaded path before touching a file, and replacing the folder's files while leaving `.run/` unchanged.
- Changed `src/core/web/web-server.ts`: `WebServerOptions.runCommand`, and dispatch of site-relative `/api/commands` and `/api/files/` requests to the remote routes before the actions and method rules. The file stays at 250 lines.
- Added `tests/web-remote-commands.test.ts` and `tests/web-remote-files.test.ts`, covering every scenario of both delta requirements, the rejection path, the 404/unsafe-selector/invalid-body cases, and every refusal row of the upload table (each with a byte-equal project snapshot).

## Details

Read every file through the default export of `node:fs/promises`, as
`readFile`. The test then counts reads by path with `mock.method(fs,
'readFile', ...)`, as `countArchivedEventReads` in
`tests/report-index.test.ts` does. Split `-z` output on `\0`. An `ls-files
-s` entry is `<mode> <blob> <stage>\t<path>`.

Build each test repository with `git init -b main`, the local config
`user.name`, `user.email` and `commit.gpgsign false`, and `git add -A` and
`git commit` through `execFileSync`. Write `logo.bin` from a `Buffer` and
make `link.txt` with `fs.symlink`.

`measures.ts` is near the 250-line budget, which is why the walk moves out
of it. Keep the `runTask` change to the one `createTaskMeasures` call.

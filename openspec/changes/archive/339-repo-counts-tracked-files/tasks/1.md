## Details

Create `blob_lines` with `CREATE TABLE IF NOT EXISTS` after the shared opener
returns. Do not change `SCHEMA_VERSION` or `initializeSchema`. Run `store`
inside `BEGIN` and `COMMIT`, and roll back on failure. The database keeps a
zero busy timeout, so a locked index stores nothing and the caller still
gets its counts.

- metrics-and-reporting: Stored blob line counts
- metrics-and-reporting: Blob lines beside the report's streams
- metrics-and-reporting: Blob line index that cannot open

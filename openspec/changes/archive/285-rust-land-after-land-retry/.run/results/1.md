## Changed

- `crates/features/land/src/land/after.rs`: added `retry`, which reads the failure
  record through `osq_kernel_storage::read_after_land_failure` with the checkout
  root and `HOME`, runs only when `vcs.afterLand` is set and the record names the
  change, and reuses `run` to clear or rewrite the record. On success it puts the
  passed line before the landed line; on failure it joins the failure lines and
  the landed line without its newline.
- `crates/features/land/src/land.rs`: `run_land` now sends a landed change
  through `landed_output`, which calls the retry after the refusals pass. Added
  the retry's `Implements` tags.
- `crates/features/land/tests/land_after_retry.rs`: new tests proving every row
  of "Retry on a landed change" and "Refused retry runs nothing", each with its
  own land repository and each removing its record before it ends.

Verified with `cargo test -p osq-feature-land --test land_after_retry`, the
feature's full test suite, and
`OSQ_CHANGE=openspec/changes/285-rust-land-after-land-retry sh scripts/verify-rust.sh`.
`cargo mutants` over both changed source files reports no missed mutants.

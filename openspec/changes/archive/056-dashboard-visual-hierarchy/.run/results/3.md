## Changed

- `packages/ui/src/graph/layout.ts`: `orderedArchived` now returns every
  archived change (undated included) sorted by numeric change number from
  `node.id` or the key's numeric prefix, tied by folder key. `graphLayout`
  places archived marks evenly by list index instead of landed time, so an
  undated change still gets a mark; active changes keep the right gutter and
  rejected changes stay behind their toggle. Added `laneLabelWidth(ids)`, which
  estimates the column from the longest capability-id character count and
  `GRAPH_GEOMETRY.laneLabelFontSize` (with a `0.62` average glyph factor plus
  padding) and floors it at `GRAPH_GEOMETRY.laneLabelWidth`. The computed width
  now drives the plot, the lane header text anchor, and the reads endpoints.
- `packages/ui/src/graph/relationships.ts`: `projectRelationships` takes the
  computed `laneLabelWidth` and ends each reads path at it instead of the old
  fixed constant.
- `packages/ui/src/graph/types.ts`: documented `laneLabelWidth` as a minimum,
  added `laneLabelFontSize: 16`, removed the now-unused `overlapOffset`.
- `packages/ui/src/graph/format.ts`: `markAriaLabel` renders
  `landed date <date>` when landed is set and `landed date not recorded`
  otherwise, so hover titles and keyboard focus labels never claim a date.
- `packages/ui/src/graph/GraphCanvas.tsx` and `GraphView.tsx`: the SVG
  description and doc comment now say archived marks increase left to right by
  change number.
- `tests/ui-graph.test.tsx`: the landed-time ordering test now asserts
  change-number order and that an undated (even malformed-date) archived change
  is kept and placed. Added a rendering fixture of two undated archived changes
  that depend on each other and read `metrics-and-reporting`; it asserts two
  marks in id order, one `graph-edge graph-edge-depends` path, one
  `graph-edge graph-edge-reads` path, the full `metrics-and-reporting` lane text
  in the SVG, and a label width above the minimum. Added a
  `landed date not recorded` assertion to the existing focus-label test.

## Deviated

- Acceptance says the label width is estimated from character count and the
  label font size. The SVG lane text sets no font size, so it inherits the SVG
  default of 16px; I encoded that as `GRAPH_GEOMETRY.laneLabelFontSize` with a
  `0.62em` average glyph factor in `layout.ts`. The estimate is deliberately
  generous (24px padding) so no name clips.
- The delta names only `layout.ts`/`GraphCanvas.tsx`/`relationships.ts`/
  `types.ts`; I also touched `format.ts` because the landed-date text lives
  there in `markAriaLabel`, and the SVG `desc`/doc comment text for accuracy.
  All are inside the task scope.

## Changed

- `packages/ui/src/report/cost.ts` (new): `CostChange` and `costChanges(graph)`.
  It projects every archived change, ascending by change number from `id` or the
  key's numeric prefix, including changes with no landed time. `CostChart`
  reverses it for display.
- `packages/ui/src/report/CostChart.tsx`: rewrote the chart as one horizontal
  row per change, newest first. Each row is a `<g class="report-cost-row">`
  whose `<title>` is the full folder key; the row label is the folder key
  shortened with an ellipsis past 28 characters; execution and planning are
  stacked left to right with the combined compact cost and coverage at the
  row's end. Height is `TOP + rows * ROW_HEIGHT + BOTTOM`. Planning rows below
  the first valid planning record are suppressed, and a labelled dashed rule
  marks that boundary. The summary table lists every archived change with its
  landed date or `landed date not recorded`.
- `packages/ui/src/report/scales.ts`: added `shortenLabel` and `labelStep`.
- `packages/ui/src/report/format.ts`: `compactCost` now accepts a nullable cost
  so an absent row cost still prints `not reported (n/m)`.
- `packages/ui/src/report/landed.ts`: `planningBoundaryIndex` accepts any
  structural `{ planningCost, planningCoverage }` array. The cost projection
  moved out to keep the file under 250 lines.
- `packages/ui/src/report/WritesChart.tsx`: x labels are change numbers only,
  thinned by `labelStep` so consecutive printed labels are at least 24px apart.
  Every band is a `<g class="report-writes-band">` with a `<title>` holding the
  full folder key.
- `packages/ui/src/report/ReportView.tsx` and `index.ts`: compute and pass the
  cost rows and boundary key; export the new projection.
- `packages/ui/src/report/TokenChart.tsx`, `PassChart.tsx`, `DurationChart.tsx`:
  colors now come from the task-1 palette (`--accent`, `--muted`, `--text`,
  `--border`, `--status-regressed`) through `style`, not presentation
  attributes.
- `tests/ui-report.test.tsx`: added a `many-change report layout` suite with a
  50-change fixture (37 undated). It asserts 50 cost rows newest first, a full
  folder-key title on every shortened row, 24px-spaced thinned writes labels
  (also on an all-landed 50-change graph so thinning actually fires), and a
  full folder-key title on every writes band.

## Deviated

- Acceptance line 4 says chart colors come from the palette. I applied that to
  the other three report charts too, not just the two named entry points, since
  their literals (`#2f5d8a`, `#3f7a5c`, `#8a8a86`, `#d7d7d2`, `#b9b9b4`)
  otherwise contradicted the requirement.
- The 250-line overflow was in `landed.ts`, not `CostChart.tsx`, so I split the
  new projection into `cost.ts` instead of splitting `CostChart.tsx`.
- The thinning test renders one all-landed 50-change graph in addition to the
  50/37 fixture, because with 37 undated changes the writes axis only has 13
  bands and the thinning step never exceeds 1.

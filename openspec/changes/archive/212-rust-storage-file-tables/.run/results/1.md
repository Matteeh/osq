## Changed

- Copied `fixture/files/` and `fixture-rows/` byte-for-byte to
  `crates/kernel/storage/tests/fixtures/files/` and `files-rows/`, `.run/`
  folders included; the copies diff clean against the sources.
- Added `src/read/sections.rs`: `ResultSections` and
  `parse_result_sections(text)`, mirroring TypeScript's `parseResultSections`
  (heading drift, unknown heading ends the section, repeated heading appends,
  inline `touched:`, and the `None`/list-marker absence rule) with no regex
  crate.
- Added `src/read/results.rs`: `TaskDisclosure` and the `.run/results/<n>.md`
  reader, filtering to digits-and-`.md`, sorting numeric, keeping only files
  with a real `deviated`/`missing_context`/`outside_scope`.
- Added `src/read/manual.rs`: `ManualEdit` and `read_manual_edits`, reading
  frontmatter with `yaml-rust2` and the body with `markdown_body`, ordered by
  `kept_at` then file name.
- Added `frontmatter_yaml` in `src/read/text.rs` and the `disclosures` field
  on `ChangeSnapshot`, filled by `read_change`.
- Re-exported the five public items from `read/mod.rs` and `lib.rs`.
- Added `tests/reading_files.rs` (the five scenarios), plus
  `tests/reading_files_sections.rs` and `tests/reading_files_records.rs` for
  the mutation-killing edges.

## Changed

- `src/model/mod.rs`: added `mod file_rows;` and `mod insert_files;`, added the
  two `CREATE TABLE` lines for `disclosures (change, task, section, text)` and
  `manual_edits (kept_at, record, comment, paths, capabilities)`, inserted a
  snapshot's `disclosures` rows inside `insert_snapshot`, and made
  `build_read_model` call `insert_manual_edits` with `read_manual_edits` after
  the labels are filled. Added the `rust-storage/file-table-columns` doc lines.
- `src/model/file_rows.rs` (new): pure row mapping. `disclosure_rows` walks a
  snapshot's disclosures in task order and, per disclosure, appends a row for
  `deviated`, then `missing_context`, then `outside_scope` when present.
  `manual_edit_rows` maps the records to `kept_at`, `record`, `comment`, and
  `paths`/`capabilities` joined with `, `.
- `src/model/insert_files.rs` (new): the SQLite side. `insert_disclosures`
  writes rows into the enclosing transaction; `insert_manual_edits` opens the
  database and writes the manual rows in their own committed transaction.
- `tests/read_model_files.rs` (new): `files_fixture_rows` builds the files
  fixture's read model and compares `disclosures` and `manual_edits`, read back
  with `rusqlite` in table order, against `tests/fixtures/files-rows/*.json`,
  naming the table, row index, column and both values on a mismatch.

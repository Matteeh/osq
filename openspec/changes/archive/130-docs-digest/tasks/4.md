## Details

Markdown layout, with each section separated by one blank line:

- First line: `# osq digest: <since> to <until>`. Without `--until`, it is
  `# osq digest: since <since>`, and for ids it is
  `# osq digest: <id>, <id>` in the order given.
- For a range: `## Period`, with bullets `Changes: <n>`,
  `Requirements: <a> added, <m> modified, <r> removed, <n> renamed`, and
  `Capabilities: <name> (<n>), ...` (or `none`). Then `ADRs dated in range:`
  followed by `ADR <number> <title> (<date>)` entries joined by `; ` (or
  `none`), and `Halts that needed a human: <n>`. Then
  `Elapsed: <duration> (<recorded> of <n> changes recorded)` and
  `Cost: <cost> (<recorded> of <n> changes reported)`. Leave Cost out with
  `--no-cost`.
- An empty range prints the heading and then
  `No changes archived from <since> to <until>.`, or
  `No changes archived since <since>.`, instead of the period and changes.
- Per change: `## <id> <title>`, then `Archived: <day>`, then `### Goal` with
  the Goal verbatim.
- Then `### Requirements`, with a `#### <capability>` per capability and
  bullets `Added: <name>`, `Modified: <name>`, `Removed: <name>`, and
  `Renamed: <from> → <to>`. Print `none` when there is no capability.
- Then `### Decisions`, with bullets `ADR <number>: <rule>`; print `none` for
  an empty list.
- Then `### Tasks`, with bullets `Tasks: <n>`, `Attempts: <n>`, and
  `Dead: task <n> (<reason>); ...` (or `none`), and
  `Halts that needed a human: <n>`.
- Then `### Run`, with bullets `Elapsed: <duration>`, `Cost: <cost>`, and
  `Models: <model>, ...; planner <planner>`. Leave Cost and Models out with
  `--no-cost`.

## Details

An archived change's events live in `.run/events/`: `change.jsonl` for the
change, and `<n>.jsonl` per task, where `<n>` is digits. Treat only those as
task streams. A `dead` event's task is `data.task` when it is a string, or else
the stream's number. `tokens` events carry `cost`, and `started` events carry
`model`.

`readManifestApprovedAt` trusts `approvedAt` only when `.run/approved` exists,
so the complete fixture writes both. The archive time is the timestamp of an
`{"type":"archived"}` line in `change.jsonl`.

Find ADR numbers with the pattern `ADR\s+(\d+)` over the `## Decisions`
section's text, then pad each to three digits. A proposal without that heading
gives null, and one whose section names none gives an empty list.
`extractSection` returns `''` both for a missing and an empty section, so test
for the heading itself with `/^##\s+Decisions\s*$/m` first.

## Changed

- `src/core/report/archive-record.ts` (new, 199 lines): exports the
  `ArchivedChangeRecord` interface and its supporting `ArchivedCapability`,
  `ArchivedRename`, and `ArchivedTasks` interfaces,
  `readArchivedChange(change)`, and `listArchivedChanges(projectRoot,
  config)`. Reads the proposal title/Goal/`## Decisions` ADR numbers, delta
  capabilities, task count, approval-to-archive elapsed milliseconds, and
  planner attribution. Reuses `resolveChangeDoc`, `parseFrontmatter`,
  `extractSection`, `parseDelta`, `countTasks`, `readLandedAt`,
  `readBriefMetadata`, `readManifestMetadata`, `readPlannerAttribution`,
  `readManifestApprovedAt`, and `listChanges`. Missing and malformed files
  read as null or empty and never throw.
- `src/core/report/archive-record-run.ts` (new, 132 lines): exports
  `readArchivedRunFields(change)` and `ArchivedDeadAttempt`, holding
  `attempts`, `dead`, `halts`, `cost`, and `executorModels`. Reuses
  `parseEventLines`, `asData`, `observeTaskStream`, and `observeRetries` over
  the numbered task streams plus `change.jsonl`.
- `tests/change-digest-archive.test.ts` (new, 242 lines): writes temporary
  archives under a temporary project root and asserts the "Complete archive",
  "Older archive", and "Renamed requirement" fields exactly, plus folder
  order, a malformed proposal, and that a record contains no absolute path.

Task verify `node --import tsx --test tests/change-digest-archive.test.ts`
passes 5/0. Proposal verify `pnpm verify` exits 0 (2926 TS tests, 94 TSX
tests, 0 failures; typechecks, build, and lint pass).

## Deviated

- `readCapabilities` reuses `listDeltaCapabilities` from
  `web-data-lifecycle.ts` instead of re-listing `specs/` itself. It is the same
  reader the web document uses for delta capability names, so this is reuse
  rather than a new implementation; it is just not one of the functions the
  task text enumerated.
- The internal ADR-number helper is named `readAdrNumbers`, not
  `readDecisions`, to keep it distinct from the foundation's ADR reader.

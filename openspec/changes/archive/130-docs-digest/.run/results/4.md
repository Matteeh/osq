## Changed

- `src/core/report/digest-markdown.ts` (new, 139 lines): exports
  `formatDigestMarkdown(digest: ChangeDigest)`. Renders the selection heading,
  the `## Period` totals for a range (capabilities most first, ADRs in range,
  halts, elapsed and cost with recorded counts), and one block per change
  (`## <id> <title>`, `Archived:`, verbatim `### Goal`, `### Requirements`
  per capability with the four bullet kinds, `### Decisions`, `### Tasks`,
  `### Run`). Null fields print `not recorded`; an empty capability list or
  decision list prints `none`; an empty range prints the heading and
  `No changes archived ...`. Reuses `formatDuration` and `formatCost` from
  `report.ts`, and skips the cost and models bullets when the cost keys are
  absent.
- `src/cli/digest.ts` (new, 81 lines): exports `digestCommand(options)` and
  `registerDigestCommand(program)`. Loads config when not given, builds the
  digest, maps a `DigestSelectionError` to a `CommandError` with the same
  message, prints `serializeSortedJson` with `--json` or Markdown otherwise,
  writes the text plus one newline to `--out` resolved against `cwd` and
  prints nothing, and registers `osq digest [ids...]` with `--since`,
  `--until`, `--json`, `--out`, and `--no-cost`.
- `src/cli/index.ts`: imports and calls `registerDigestCommand(program)` next
  to `registerDoctorCommand(program)`. Now 240 lines, at or under 250.
- `tests/change-digest-command.test.ts` (new, 408 lines): drives
  `digestCommand` against temporary archives and covers "Every field in
  Markdown" (exact document), "JSON document" (schemaVersion, null period,
  stable requirement and `ADR-<number>` ids, rename `from`), "No paths or run
  output", "Byte-identical runs", "Written to a file", the Markdown "Empty
  range" (both bounded and open), "Without cost" (Markdown and JSON), a
  `CommandError` refusal, and the five registered options. It also digests
  this repository's 129 archive and checks the title and Goal first line and
  that no absolute path or `/home/` appears.
- `README.md`: `osq digest` line in `## Commands` after `osq report`, plus the
  five flags and a paragraph in `### Metrics & Reporting` saying the digest
  reads only archives, runs no model, and prints the same bytes for the same
  archives.
- `CHANGELOG.md`: one `## [Unreleased]` bullet for `osq digest` ending `(130)`.

## Deviated

- The markdown renderer emits only the requirement kinds a capability
  actually wrote (so no empty `Added:` bullets) and prints `- none` for a
  capability with no requirements. It renders all four kinds when present,
  matching the recorded delta shape from task 3.
- `models` prints `none` when no `started` model was recorded, because
  `executorModels` is an array rather than a nullable field; `planner` alone
  prints `not recorded` when null.

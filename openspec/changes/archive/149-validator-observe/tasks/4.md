## Details

Split the patch on lines starting `diff --git a/`. A block's path is its
`b/` path, or its `a/` path when the `b/` side is `/dev/null`. Drop a block
when that path starts with `<paths.openspecRoot>/`, and keep the text of
every other block byte for byte. A file the patch deletes is not a test
path.

`formatScenariosFile` writes a `# Scenarios to judge` heading, then for each
requirement a `## <capability>: <requirement>` heading, and under it each
scenario's text.

Write the prompt for a model that has never seen osq. Name every path
project-relative, one per line, and keep the rule lines short and literal.
The JSON example shows one finding with every field and says to write
`{"findings": []}` when every scenario holds.

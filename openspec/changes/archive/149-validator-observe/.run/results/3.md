## Changed

- `src/core/vcs/vcs.ts`: the `Vcs` port's `patch` is now
  `patch(base?: string): Promise<string>`, with a doc comment naming HEAD as
  the default.
- `src/core/vcs/git-vcs.ts`: `GitVcs.patch(base?)` forwards the base to
  `writes.patch(this.context, base)`.
- `src/core/vcs/git-vcs-write.ts`: `patch(ctx, base?)` diffs the temporary
  index against `base ?? 'HEAD'` instead of a hard-coded `HEAD`. The temporary
  index is still a copy of the real one, so the real index is untouched. The
  file stays at 246 lines.
- `src/core/vcs/no-vcs.ts`: `NoVcs.patch(_base?)` takes the same optional
  parameter and still rejects, naming the reason git is off.
- Added `tests/vcs-patch-base.test.ts` with three cases: `patch(base)` holds
  the commit after the base plus the uncommitted and untracked work while
  `patch()` holds only the latter two and `indexDigest()` is unchanged across
  both; `patch(base)` applied to a clean checkout of the base reproduces
  `a.txt`, `b.txt`, and the untracked `c.txt`; `NoVcs.patch` rejects with and
  without a base.

Touched: src/core/vcs/vcs.ts, src/core/vcs/git-vcs.ts, src/core/vcs/git-vcs-write.ts, src/core/vcs/no-vcs.ts, tests/vcs-patch-base.test.ts

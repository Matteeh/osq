## Changed

Implemented the task's ports and wired them as the acceptance and "Details"
describe. The task verify and `pnpm verify` both pass.

- New `src/watcher/validator-findings.ts`: `parseValidatorFindings`, strict on
  JSON shape, `kind: 'scenario'`, non-empty trimmed string fields, and the
  three problems; returns `null` otherwise.
- New `src/watcher/validator-inputs.ts`: `judgedScenarios`,
  `formatScenariosFile`, and `readValidatorInputs`. Parses deltas with
  `parseDelta`, living specs with `parseCapabilitySpec`, matches requirement
  names with `normalizeRequirementName`, drops `<paths.openspecRoot>/` patch
  blocks, filters tests with `isTestPath` plus existence, and orders result
  files with `compareNumericPrefix`. Returns `{ notRun: 'no_base' }` when git
  is off or `.run/base` is missing or empty, and `{ notRun: 'no_scenarios' }`
  when nothing is judged.
- New `src/watcher/validator-prompt.ts`: `buildValidatorPrompt`, intro then
  paths (change folder, delta specs, scenarios file, patch, changed tests,
  findings file), the rules, the `Executor claims (check them; do not start
  from them):` section, the findings JSON example, and the `CRITICAL:` line.
- `src/harness/types.ts`: `validator_ran` on `HarnessEventType` and
  `OsqEventData`; `ValidatorProblem`, `ValidatorFinding`, `ValidatorOutcome`,
  `ValidatorNotRunReason`, `ValidatorRanEventData`; optional `prompt` on
  `SpawnTaskOptions`.
- `src/harness/prompt.ts`: `buildExecutorPrompt` returns `options.prompt`
  unchanged when set.
- `decisions/010-validator-role.md` and the README `### Validator` section:
  the outcome list now says `not_run` in place of `skipped`; nothing else in
  those files changed.
- New `tests/validator-inputs.test.ts` (245 lines): every scenario of
  "Validator inputs", "Validator prompt", and "Validator findings file", plus
  "Prompt override" through `buildClaudeArgs` and `buildPiArgs`. It exercises
  `readValidatorInputs` against a temporary `GitVcs` repository and `NoVcs`.

The word "skipped" (any case) appears nowhere in `src/`; the change uses the
`not_run` outcome and `ValidatorNotRunReason` the task and delta specs now
require.

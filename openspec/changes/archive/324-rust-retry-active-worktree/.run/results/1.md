## Changed

- Copied `fixture/active-project/` and `golden/` unchanged into
  `crates/features/retry/tests/fixtures/active-project/` and
  `crates/features/retry/tests/fixtures/active-golden/`.
- `retry/find.rs`: builds the tree listing once through the root's
  `worktree_list` and `change_trees`, and exposes the listed entries and trees.
  Active changes are found from `list_tree_changes` when git is on and from
  `list_changes` when git is off; archived lookup now reuses the same listing.
  Each match carries its `ChangeTree`.
- `retry/plan_edits.rs` (new): refuses a worktree change whose `status` has
  `path` or `from` inside the change folder other than `tasks.md` and `.run/`,
  naming the edits relative to the folder, sorted by bytes.
- `retry.rs`: finds an active change first, checks plan edits for a tree that
  names a folder, then finishes in that tree; archived handling is otherwise
  unchanged.
- `retry/recertify.rs`: loads config from the project root, but runs verify and
  hashes scope files in the change's tree root.
- `retry/text.rs`: adds the plan-edits refusal text.
- `retry/archive_commit.rs`: made its tree-relative path helper visible to the
  plan-edit check.
- `tests/retry_active.rs` (new): proves every row of "Active worktree retry
  equals TypeScript's" (output, worktree `.run/` tree, branch tip and status),
  the `git mv` plan-edit refusal, and, for mutation coverage, that a checkout
  change is never refused for plan edits and an archived match is not shadowed
  by another active change.

## Deviated

- Added two extra tests beyond the acceptance list: a checkout change with
  uncommitted plan edits must still retry, and an archived match must be found
  while an unrelated active change exists. Both cover new branches and kill
  cargo-mutants mutants in `find_active`.
- The root-tree test recomputes `.run/approved` with `change_folder_seal` after
  its plan edits, because the refusal being tested is plan edits, not a stale
  approval.

## Missing context

  `tasks/2.md` and a `.run/extra.txt`, while the `plan-edits-004` golden covers
  `notes.md` and `proposal.md`. Both are now tested.

## Changed

- Added `src/cli/help-groups.ts`: exports `COMMAND_GROUPS` (Everyday, Setup
  and running, Inspection, Plumbing in the delta's order and membership),
  `BARE_OSQ_LINE`, and `configureGroupedHelp(program)`. The latter installs a
  `formatHelp` that renders the root program with commander's own `Help`
  methods (usage, description, then `BARE_OSQ_LINE`, `Options:`, the four
  `<title> commands:` groups, and an `Other commands:` fallback for anything
  unnamed), and defers to `Help.prototype.formatHelp` for every other command.
- `src/cli/index.ts`: imported `configureGroupedHelp` and call it after the
  last command (`registerSyncCommand`) is registered, leaving all subcommand
  registrations untouched.
- Added `tests/help-groups.test.ts`: asserts the bare-`osq` line before
  `Options:`, the four headings in order, the Everyday rows in order, exactly
  one row per registered command, no `Commands:`/`Other commands:` heading,
  `COMMAND_GROUPS` matching both the required structure and the registered
  commands, and every subcommand's help starting with `Usage: osq <name>` with
  no group heading and no bare-`osq` line.

`node --import tsx --test tests/help-groups.test.ts` passes (8 tests), and the
proposal's `pnpm verify` passes (typechecks, build, full test suite, lint).

## Changed

- Added the archived-worktree fallback: `find.rs` loads config only after no active change matches, builds `change_trees` from `worktree_list` with no stacked folders, and returns the first matching archived entry in a tree that names a folder.
- Added the archived retry orchestration in `retry.rs`: numeric task targets are refused with TypeScript's text, and `change` runs the existing approval, running, marker and record steps on the archived folder.
- Added `record::commit` to commit the cleared marker, `.run/events/change.jsonl` and retained files in the worktree tree with config git timeouts, the `osq: <id> land retry` message and `vcs.author`; a failed commit restores each path from `HEAD`, removes paths `HEAD` lacks, restages them ignoring failure, and fails with `osq could not record the retry: <git error>`.
- Added the archived refusals and commit-failure text to `text.rs`, and added `osq-kernel-config` and `osq-kernel-vcs` to the retry crate; `Cargo.lock` follows.
- Copied the archived-project fixture and archived-golden files unchanged into the crate.
- Added `tests/retry_archived.rs` for every archived golden row, the failed-commit restoration, and a root-archive case that proves only worktree trees count as archived.

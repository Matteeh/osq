## Changed

- `cleanSection` in `src/core/report/result-sections.ts` now treats a section
  as absent when, after splitting on non-blank lines, exactly one line remains
  and that line reduces to the word `None` once a leading list marker (`-`,
  `*`, `+`, or `<number>.`) is dropped and every `*` and `_` is set aside,
  allowing `None` alone or followed straight away by `.`, `;`, `,`, or `:` and
  any text. Text of a present section is still returned trimmed and unchanged.
  `checkBlocked` and `readChangeDisclosures` pick this up through the shared
  parser, so no caller changed.
- Added `tests/result-none-sections.test.ts`, covering every "Result file
  sections" scenario (`parseResultSections` for headings, blocked, bullet/bold,
  explanations, and a sentence starting with `None`; `readChangeDisclosures`
  for the more-than-one-line case) and one `runWatcherOnce` cycle with a fake
  agent whose result file says `- None.` under `## Blocked`, which reaches
  verify, finishes done, and archives. Fixture helpers copied from
  `tests/blocked-exit.test.ts`.

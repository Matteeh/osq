- Added `NextStep::archived_not_landed` and the archived `archived (not landed) — osq land <id>` next step, gated on `vcs.enabled` and git on.
- Threaded the land facts to the model and the land section; the line builders stay pure.
- Made lookup search the run's listing, including worktree and stacked changes, and resolve a path's location from it.
- Added `osq-kernel-config` and `osq-kernel-vcs` dependencies.
- Copied the seven land goldens and `print-land-goldens.mjs.txt` unchanged into the crate's fixtures.
- Added `tests/show_land.rs`: every golden row on its own git repository, the bad-config refusal, stacked lookup, a root below the repository top, and sync-stop malformed/reordered events.

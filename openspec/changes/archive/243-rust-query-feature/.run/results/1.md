## Changed

- `crates/features/report/Cargo.toml`: added `osq-kernel-storage` and `rusqlite` with `hooks`, plus `serde_json` as a dev-dependency; `Cargo.lock` was rewritten by cargo for those dependencies only.
- `crates/features/report/src/lib.rs`: kept the crate doc, declares `mod feature; mod query;`, and re-exports only `ReportFeature`.
- `crates/features/report/src/feature.rs`: added the unit `ReportFeature`, its `Feature` implementation, the `query` command, the argument-count usage error and the unknown-command error.
- `crates/features/report/src/query.rs`: added `run_query`, the `.osq`/`.gitignore` cache preparation, the read-model build and the first-statement row formatting, with SQLite's own messages for prepare and step failures.
- `crates/features/report/src/query/text.rs`: added the sixteen tables in `HISTORY_TABLES` order, the table-list formatter and the cell-text function with root, home and newline rewriting.
- Added `tests/fixtures/history/`, `tests/fixtures/bad-labels/` and `tests/fixtures/queries.json` as byte-for-byte copies of the storage fixtures and the change's golden file.
- Added `tests/support/mod.rs`, `tests/report_feature.rs` and `tests/query_run.rs`; the query tests cover the golden run cases, the table list, path rewriting with HOME set and unset, cache files, every value kind and the step failure.
- Verified with `cargo test -p osq-feature-report --test report_feature --test query_run`, `cargo clippy -p osq-feature-report --all-targets -- -D warnings`, `cargo mutants` on all three new source files (21 caught, 6 unviable), and `OSQ_CHANGE=openspec/changes/243-rust-query-feature sh scripts/verify-rust.sh`.

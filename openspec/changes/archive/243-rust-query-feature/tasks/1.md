## Details

Port `formatTableList`, `rewritePaths`, `cellText` and `formatText` from
`src/core/report/query-run.ts`, and `prepareDirectory` from
`src/core/report/stream-index.ts`. Copy the fixtures and the golden file
with `cp -r` and `cp`; never edit them, and never regenerate the golden
file.

Prepare only the first statement with `rusqlite::Batch::new(&connection, select)`
and its `next`, through `rusqlite::fallible_iterator::FallibleIterator`;
`Connection::prepare` would prepare the rest of the argument too. `next`
giving `Ok(None)` is the no-statement message. A prepare error's SQLite
message is the `msg` of `rusqlite::Error::SqlInputError` or the text of
`rusqlite::Error::SqliteFailure`; use that text alone, never the error's
`Display`. Read values with `rusqlite::types::ValueRef`. Take the home text
from `std::env::var("HOME")` filtered to a non-empty value, and the root
text from `std::path::absolute` of the invocation's root.

New `tests/support/mod.rs` holds the helpers both `tests/query_run.rs` and
task 2's `tests/query_authorize.rs` use: a fresh scratch copy of a fixture
under `CARGO_TARGET_TMPDIR`, removing a leftover folder of the same name
first, with a name per test since tests run in parallel; the golden cases,
read from `tests/fixtures/queries.json` with `serde_json` into a struct of
`name`, `group`, `fixture`, `select`, `result` and `text`; and running
`query` through `ReportFeature` with an optional select. Cargo compiles it
into each test that declares `mod support;`, so `tests/query_run.rs` must use
every helper and every field, or clippy's `dead_code` warning fails the
verify. A golden case whose `result` is `failed` compares the message of
`FeatureError::Failed`; bind it with a wildcard arm, as
`crates/core/tests/feature.rs` does.

cargo-mutants runs on every line this task adds, so each branch must change
a value a case or row checks: the blank-argument test, the argument count,
the gitignore-exists test, the root and home replacements and their order,
the newline escape, and each value kind in the cell text. Before exiting,
run `cargo fmt --all`, then `cargo mutants -p osq-feature-report -f <file> -o "$(mktemp -d)"`
on each new source file, then `sh scripts/verify-rust.sh` with `OSQ_CHANGE`
set to `openspec/changes/243-rust-query-feature`, so the link gate corpus
test sees this change's new requirements.

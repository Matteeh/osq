## Details

1. In `src/watcher/outcome.ts`:
   - Update `writeDoneMarker`:
     ```typescript
     export interface DoneMarkerMetadata {
       scopeHash: string;
       buildStamp: string;
       exitCode: number;
     }

     export async function writeDoneMarker(
       runDir: string,
       taskNumber: string,
       metadata?: DoneMarkerMetadata,
     ): Promise<void>
     ```
   - When `metadata` is provided, format content with YAML frontmatter:
     ```markdown
     ---
     scope_hash: "<hash>"
     build_stamp: "<buildStamp>"
     exit_code: <exitCode>
     ---
     <ISO timestamp>
     ```
   - When `metadata` is omitted, retain backward-compatible timestamp-only content.
   - Keep `src/watcher/outcome.ts` strictly under 200 lines.

2. Create `src/watcher/regression.ts`:
   - Import `crypto`, `fs/promises`, `path`.
   - Import `parseFrontmatter`, `parseTaskMd` from `../core/parser.js`.
   - `computeTaskScopeHash(projectRoot: string, scope: string[]): Promise<{ hash: string; fileHashes: Record<string, string | null> }>`:
     - For each file in sorted `scope`, read UTF-8 content and calculate `sha256:<hex>` (or `null` if missing).
     - Combine sorted entries into a canonical string and compute `sha256:${combinedDigest}`.
   - `checkDoneTasksScopeHashes(projectRoot: string, specFolderPath: string, currentTaskNumber: string): Promise<ScopeRegressionResult | null>`:
     - Determine all earlier task numbers `1` through `Number(currentTaskNumber) - 1`.
     - For each earlier task where `.run/done/<task>` exists:
       - Read and parse frontmatter of `done/<task>`.
       - If `scope_hash` is present, read `tasks/<task>.md`, parse its `scope`.
       - Compute current scope hash via `computeTaskScopeHash`.
       - If current scope hash does not equal recorded `scope_hash`:
         - Find differing paths (`modified`, `deleted`, or `added`).
         - Return `{ regressed: true, taskNumber, differingPaths, recordedHash, currentHash }`.
     - Return `null` when all earlier done tasks match.
   - Keep `src/watcher/regression.ts` under 250 lines.

3. In `src/watcher/runner.ts`:
   - At task success, compute post-task scope hash and resolve build info, passing them to `writeDoneMarker(runDir, taskNumber, { scopeHash, buildStamp: buildInfo.commit, exitCode: 0 })`.
   - Before spawning agent (after acquiring lock and checking approved hash), call `checkDoneTasksScopeHashes(projectRoot, specFolderPath, taskNumber)`.
   - If mismatch is detected, return failure without spawning the agent.
   - Keep `src/watcher/runner.ts` strictly under 200 lines.

4. Create `tests/runner-scope-hashes.test.ts`:
   - Test `writeDoneMarker` writes correct frontmatter and timestamp.
   - Test `computeTaskScopeHash` is deterministic and sensitive to content changes.
   - Test pre-spawn comparison passes when tree is unchanged.
   - Test pre-spawn comparison detects when task 1 file is modified after task 1 is done, identifying differing paths and preventing task 2 from running.

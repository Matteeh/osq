## Deviated

- **`regressedMarkers` is optional on `ChangeFolderSnapshot`.** The detail line
  asked for a required field, but `tests/state.test.ts` builds a snapshot object
  literal outside this task's scope and would fail `tsc` if the property became
  required. `readChangeFolder` always populates it and derivation treats absence
  as empty. No behavioural difference.
- **One out-of-scope test line edited:** `tests/report-task-states.test.ts`'s
  expected tally literal gained `regressed: 0`. Extending `TaskStatus` with
  `'regressed'` makes its `expected[task.status]` index invalid because the
  literal lacked the key. This is a mechanical, needed consequence of an
  acceptance line; without it `pnpm tsc --noEmit` fails.
- **`src/watcher/regression.ts` left as-is** (not in scope). It still writes its
  own `.run/regressed/<n>.md` and casts the event because it predates the typed
  union. Now that `'regressed'` is in the union, a later task can drop the cast
  and delegate to `writeRegressedMarker`/`recordRegressedEvent`; noted below.

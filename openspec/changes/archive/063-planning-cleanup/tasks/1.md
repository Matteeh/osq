## Acceptance

- [ ] `ObservedPlanningSession` requires `turns` and no longer declares `usage`, `edits`, `startedAt`, or `endedAt`. `harness`, `nativeSessionId`, `sessionDir`, `model`, `harnessVersion`, and `sessionCost` stay as they are.
- [ ] `sessionTurns` is gone, and `sessionEdits` reads only turn edits at each turn's timestamp. `sliceChangeOwnership` no longer takes `sessionUsage`, and a slice's `usage` always comes from its owned turns. `findPlanningSessions` passes `candidate.sessionCost ?? null`.
- [ ] The Claude, Codex, and OpenCode readers stop setting `usage` and `edits` and drop the loops and helpers that rebuilt edits from turns, such as `editsFromTurns`. `parseClaudeSession` still returns null when no turn has an edit.
- [ ] New `tests/planning-reader-shape.test.ts` parses one session with `parseClaudeSession`, one with `parseCodexObservation`, and one through `readOpencodePlanningSessions` with the existing fake `opencode`. It asserts each result has a non-empty `turns` and none of `usage`, `edits`, `startedAt`, or `endedAt` as keys.
- [ ] In the other planning test files, changes are limited to building sample sessions from `turns` instead of `edits` and `usage`, and removing assertions about the four removed fields. Every other assertion keeps its expected values.
- [ ] Recorded `plan.jsonl` pairs for the same inputs are byte-identical to before. The existing approval and slicing tests pass with unchanged expected values.

## Details

This is a pure refactor, and the listed tests pass before you start. A
worktree measurement showed that the type change breaks
`tests/planning-observed-helpers.ts`, the match, approve, claude, codex, and
opencode observation tests, `tests/planning-claude-turns.test.ts`, and
`tests/planning-slice.test.ts`, all inside `tests/planning-*.ts`. The `candidate`
helper in `tests/planning-observed-helpers.ts` should build a session with one
turn per edit it used to list. `PlanningSessionEdit` stays, because matching
still uses it internally. Tests outside `tests/planning-*.ts` are frozen.

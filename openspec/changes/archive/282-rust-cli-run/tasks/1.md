## Details

`crates/apps/cli/Cargo.toml` already depends on `osq-feature-run`, so no
manifest or `Cargo.lock` change is needed. On an empty root, `RunFeature`
loads the default config, finds no change and fails with
`run failed: Spec "1" not found in <root>/openspec/changes`, where `<root>`
is the folder's path as the test passed it. Remove and recreate the folder
at the start of the test so reruns start empty, as `copy_fixture` in
`crates/apps/cli/tests/binary.rs` does.

Run the proposal's verify as the watcher does, with
`OSQ_CHANGE=openspec/changes/282-rust-cli-run`, so the link gates see this
change's new scenario.

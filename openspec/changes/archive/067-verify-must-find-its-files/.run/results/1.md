## Changed

- Added `src/core/spec/verify-paths.ts`: moved `tokenizeVerifyCommand` and the
  named-path operand rules out of `linter.ts`, and added `listNamedPaths` and
  `missingNamedPaths` (exact operands by filesystem existence, glob operands via
  `resolveScope`).
- Added `src/core/spec/verify-starts.ts`: `analyzeVerifyStarts` runs the change's
  tasks in numeric order and returns contradictions and uncreatable paths, with
  the glob-operand rule that only an identical scope entry covers a glob.
- Added `scopeCoversPath` to `src/core/run/scope.ts`, a pure predicate that
  matches an exact entry or a glob/trailing-directory entry through
  `globToRegExp`.
- Rewrote `linter.ts` to import the shared tokenizer and operand rules, collect
  every task's parse result and resolved scope, then run one ordered pass after
  the task loop: it suppresses the unresolved-target warning when every missing
  named path is covered by the task's own or an earlier task's scope, and emits
  one contradiction warning per `green`/`any` task that creates its own named
  test plus one uncreatable warning per path no scope up to that task covers.
  `linter.ts` is now 1,094 lines, shorter than its 1,108-line baseline.
- Added `tests/verify-paths.test.ts` and `tests/lint-verify-starts.test.ts`.

Touched: src/core/spec/verify-paths.ts, src/core/spec/verify-starts.ts, src/core/spec/linter.ts, src/core/run/scope.ts, tests/verify-paths.test.ts, tests/lint-verify-starts.test.ts

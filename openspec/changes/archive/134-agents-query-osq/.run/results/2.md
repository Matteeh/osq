## Changed

- `src/core/report/query-run.ts` (new): exports `QueryError`, `QueryOptions`,
  `formatTableList`, and `runQuery`. `runQuery` returns the table list for a
  missing statement; otherwise it validates the statement on a schema-only
  in-memory copy of the five tables, then builds the real tables with
  `buildHistoryTables`, runs the statement under `setAuthorizer`, and closes
  the database. The authorizer allows only `SQLITE_SELECT`, `SQLITE_READ` of a
  `HISTORY_TABLES` name, `SQLITE_FUNCTION`, and `SQLITE_RECURSIVE`. Text output
  is a tab-separated header plus one row per result, null as an empty field and
  a newline as `\n`; `--json` is a JSON array of objects. Every string value
  has the project root replaced by `.` and the home directory by `~`.
- `src/cli/query.ts` (new): exports `registerQueryCommand(program)` and
  `queryCommand`. The command is `query [select]` with `--json`; a
  `QueryError` becomes a `CommandError`.
- `src/cli/index.ts`: two lines, an import and `registerQueryCommand(program)`.
- `tests/query-command.test.ts` (new): drives the real CLI over a temporary
  project for a select, a join, `WITH`, `--json`, a null field, newline and
  path rewriting, and no statement, and checks all eight refusals exit
  non-zero with the table list while every file under the project stays
  byte-identical.

## Deviated

- `runQuery` checks the statement against a schema-only in-memory database
  before calling `buildHistoryTables`. `buildHistoryTables` opens the stream
  index, which creates `.osq/` and `.osq/index.sqlite`; validating first is
  what lets a refused statement satisfy "changes no file". A successful query
  still builds the tables and uses the index as the entry point intends.
- The second-statement comparison trims trailing whitespace from both the
  input and the prepared `sourceSQL` before stripping one `;`, so a trailing
  space after a semicolon is not mistaken for a second statement.

## Missing context

- The deltas fix the refusal cause and the table list but not their exact
  wording; I used `osq query refused: <cause>` followed by the table list.
- The deltas do not say whether `--json` is indented; I emit compact JSON to
  keep column-key order.

## Acceptance

- [ ] `src/core/report/query-tables.ts` exports the port below. `buildHistoryTables` opens the index with `openStreamIndex` for the change tree's archive folder, runs inside `withStreamReads` with it, closes it afterwards even on error, and returns an in-memory `DatabaseSync` holding the five tables the delta names, with exactly those columns in that order.
- [ ] `changes` and `requirements` come from `listArchivedChanges`. `kind` is `added`, `modified`, `removed` or `renamed`; a renamed row's `requirement` is the new name and `renamed_from` the old one, null otherwise. `elapsed_seconds` is the record's elapsed time rounded to seconds.
- [ ] `tasks` has one row per `tasks/<n>.md`: its frontmatter `title`, `attempts` from `observeTaskStream` over the task's stream read with `readEventStream` (0 without a stream), and `done` 1 when `.run/done/<n>` exists, else 0. `dead_attempts` comes from the record's dead attempts.
- [ ] `disclosures` comes from `readChangeDisclosures`, one row per non-null section, with `section` `deviated`, `missing_context` or `outside_scope`.
- [ ] `HISTORY_TABLES` lists each table name with its column names, in the delta's order.
- [ ] `readArchivedRunFields` in `archive-record-run.ts` reads each stream with `readEventStream` instead of `fs.readFile` and `parseEventLines`. Every existing digest test passes unchanged.
- [ ] `tests/query-tables.test.ts` builds the tables over a temporary project with two archived changes, and checks every table's rows, including a renamed requirement, a dead attempt, a task without a stream, and each disclosure section.

## Port

```ts
export interface HistoryTable {
  readonly name: string;
  readonly columns: readonly string[];
}

export const HISTORY_TABLES: readonly HistoryTable[];

export function buildHistoryTables(
  projectRoot: string,
  config: OsqConfig,
): Promise<DatabaseSync>;
```

## Details

Load `node:sqlite` the way `stream-index.ts` does. Columns hold SQLite text,
integer, real or null; booleans are 0 or 1. Rows insert in change order, then
task order. Keep every file under 250 lines.

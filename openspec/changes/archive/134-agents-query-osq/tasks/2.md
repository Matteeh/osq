## Acceptance

- [ ] `src/cli/query.ts` exports `registerQueryCommand(program)`, registered from `createProgram` in `src/cli/index.ts` with one line next to `registerDigestCommand`. The command is `query [select]` with `--json`, and failures throw `CommandError`.
- [ ] `src/core/report/query-run.ts` runs the statement on the database from `buildHistoryTables`, under `setAuthorizer` that allows only `SQLITE_SELECT`, `SQLITE_READ` of the tables in `HISTORY_TABLES`, `SQLITE_FUNCTION` and `SQLITE_RECURSIVE`, and denies everything else. It closes the database afterwards.
- [ ] A statement is refused before it runs when the input, after trimming trailing whitespace and one `;`, is longer than the prepared statement's `sourceSQL` without its trailing `;`. A refusal message names the cause and lists every table with its columns.
- [ ] Text output is a header row of column names and one row per result, tab-separated; a newline inside a value prints as `\n`, and null as an empty field. `--json` prints a JSON array of objects. Without a statement, osq prints each table as `name(column, column, ...)`, one per line, and exits zero.
- [ ] Every string value has the absolute project root replaced by `.` and then the home directory by `~`.
- [ ] `tests/query-command.test.ts` runs the command over a temporary project for a select, a join, `WITH`, `--json`, and no statement, and checks refusals for `INSERT`, `DELETE`, `UPDATE`, `PRAGMA`, `ATTACH`, `select * from sqlite_master`, and `select 1; delete from changes`, each exiting non-zero with the table list and leaving every file under the project unchanged.

## Details

Follow `src/cli/digest.ts` for registering a command from its own file, so
`src/cli/index.ts` grows by two lines at most. Every value in the output comes
from the tables, so no verify log or tool summary can appear.

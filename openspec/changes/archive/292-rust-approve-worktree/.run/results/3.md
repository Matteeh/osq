## Changed

- Parsed `--base-ok` and `--ignore-dirty` in `feature.rs`, counting only non-flag arguments as change ids, and updated the `approve` usage to `<id> [--base-ok] [--ignore-dirty]`.
- Passed the two flags to `run_approve` as `ApproveOptions`.
- Added `approve/refuse.rs` with the off-default HEAD, dirty task-scope and taken-branch refusals, plus the rejected-branch claim decision. The refusal texts and the next kept name live in `approve/refuse/text.rs` and `approve/refuse/kept.rs`.
- With git on, `approve.rs` now runs the refusals after validation and before the seal or any write, and `approve/worktree.rs` renames a claimed rejected branch first among its writes and prints `  Kept rejected branch: <kept>` right after the hash line.
- Extended `tests/approve_feature.rs` with the new usage and the flag argument rows, and added `tests/approve_worktree_refusals.rs` for every golden refusal row, every "More refusals with git on" row, and "Kept branch name skips a taken one".
- `cargo test` for the task's three binaries, `cargo fmt --all`, clippy with `-D warnings`, `sh scripts/verify-rust.sh`, and a manual `cargo mutants` run over every changed source file all pass (61 caught, 4 unviable, no misses or timeouts).

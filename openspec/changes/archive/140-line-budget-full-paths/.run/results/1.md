## Changed

- Added `tests/line-budget-check.ts`, exporting `checkLineBudget(sourceDir,
  allowList, maxLines)`. It walks the tree with the same `.ts`-only,
  non-`.d.ts` rule as before, counts lines as `source.split('\n').length`, and
  returns messages for: an unlisted file over the limit, a listed path whose
  file is within the budget, and a listed path with no matching file.
- Reworked `tests/line-budget.test.ts` so `ALLOW_LIST` holds the eleven exact
  paths under `src/` from the proposal's Background table, with a comment that
  the list only shrinks. The source-budget case now calls `checkLineBudget` on
  `src/`; the UI case is unchanged.
- Added `tests/line-budget-check.test.ts`, covering over temporary trees a
  same-named unlisted file over the limit, a listed over-limit file, a listed
  within-budget file, a missing listed path, a clean tree, and `.d.ts` files
  being ignored.

Message paths are relative to the parent of the source directory passed in,
which is the repository root when called on `src/`, so violations read
`src/core/foo/types.ts has N lines (max 250)`.

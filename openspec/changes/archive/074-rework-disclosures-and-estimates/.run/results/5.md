## Changed

- Added `src/core/report/planning-price-gaps.ts`: `findUnpricedPlanningModels(folders, prices)` returns the sorted distinct non-empty `plan_started` models of sessions whose exit recorded input/output tokens in its slice or usage and that have no key in `prices` (a missing map leaves every model unpriced); `formatPriceKey(model)` returns `planning.prices[<json-quoted model>]`.
- Added `src/core/foundation/doctor-prices.ts`: `checkPlanningPrices(projectRoot, config)` walks active `changes/` entries (via `isActiveChangeFolderName`) and every `changes/archive/` directory, and returns null when nothing is unpriced, otherwise `{ name: 'planning-prices', ok: true, warning: true }` whose message names every missing key and says planning cost stays unreported. `runDoctorChecks` appends it after the validator check only when non-null.
- `src/core/spec/approve.ts`: `ApproveResult` gains `missingPrices`; it is computed with `findUnpricedPlanningModels([folderPath], config.planning?.prices)` right after observed sessions are appended, so a session found at approval is named. Approval writes are unchanged.
- `src/cli/approve.ts`: after the planning notice, prints one `Planning cost for <model> stays unreported; add planning.prices["<model>"]` line per missing model.
- Added `tests/planning-price-gaps.test.ts`: the finder (slice tokens, usage tokens, priced, token-less, null model, missing price map), `formatPriceKey`, `runDoctorChecks` on temp projects (archived unpriced model warns; priced and token-less leave the list unchanged), and `approveSpec` plus `approveCommand` for `claude-opus-5-5` with no price and then with one.

## Deviated

- "usage tokens" in the finder is read as non-null `usage.inputTokens` or `usage.outputTokens`, matching the slice rule (`input`/`output`) and the pricing path, rather than any token kind such as cache reads. Cache-only sessions cannot be priced, so they are not reported as gaps.

## Changed

- `RESULT_HEADINGS` in `src/core/foundation/init-blocks.ts` now lists the five headings in order: `## Changed`, `## Deviated`, `## Missing context`, `## Outside scope`, `## Next`, with each disclosure purpose naming its reader (reviewer/planner/human). `EXECUTOR_EXIT_LINES` and `MANAGED_AGENTS_MD_BODY` are derived from it, so the managed block changed with it.
- Replaced the managed block between the osq markers in `AGENTS.md` and `.opencode/agent/osq-coder.md` with the new constant.
- Added `src/core/report/result-sections.ts` (imports only `node:fs/promises` and `node:path`). `parseResultSections(content)` returns `changed`, `deviated`, `missingContext`, `outsideScope`, `next`, `touched`, each null when absent. Headings match after dropping leading `#`s, surrounding spaces, and one trailing colon, case-insensitively and with inner spaces collapsed. Both a `## Touched:` heading (body) and a final inline `Touched:` line fill `touched`. Empty or `None`-only sections (any case, optional period) are null. `readChangeDisclosures(folderPath)` reads `.run/results/<n>.md` in numeric order, returning `{ task, deviated, missingContext, outsideScope }` for tasks with at least one real disclosure; `countChangeDisclosures(folderPath)` returns the per-section task counts. Both are async, matching the `node:fs/promises` convention of the surrounding report modules and `osq show`.
- Added `tests/result-sections.test.ts` covering `## deviated:` with text, `## Missing context` of `None`, a real `##  Outside Scope`, a `## Touched:` heading and an inline `Touched:` line, unknown headings as boundaries, empty content, and `readChangeDisclosures`/`countChangeDisclosures` on a temp folder.
- Updated only the expected heading list in `tests/managed-blocks.test.ts`.

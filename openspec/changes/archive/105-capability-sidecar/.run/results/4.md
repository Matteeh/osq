## Changed

- Added `src/core/spec/migrate-sidecars.ts`: `migrateSidecars({ cwd, openspecRoot })` lists living capabilities with `readLivingCapabilityNames`, skips those with an existing sidecar, and writes `formatSidecar({ group: UNGROUPED })` to `<openspecRoot>/specs/<capability>/osq.yml`. Returns the written names in name order.
- Updated `src/cli/migrate.ts`: `migrateCommand` now accepts the `sidecars` target, calls `migrateSidecars`, and prints `wrote <n> sidecar(s)` plus one `  <capability>` line per sidecar written. The `openspec` path is unchanged. Overloads keep the `openspec` return type as `MigrateResult | null` so `tests/migrate.test.ts` typechecks unchanged.
- Added `tests/migrate-sidecars.test.ts`: scaffolding and run-twice scenarios through `migrateCommand` with an injected logger on a temporary project.

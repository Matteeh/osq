## Changed

Implemented the fold layer of `osq-core`.

- `crates/core/Cargo.toml`: added `proptest = { workspace = true }` under
  `[dev-dependencies]`; `[dependencies]` stay `serde` and `serde_json`.
- `crates/core/src/lib.rs`: added `pub mod fold` and re-exported `Stream`,
  `TaskId`, `TaskStatus`, `TaskState`, `apply_task`, `ChangeRecord`,
  `ChangeState`, `apply_change`, `apply`, `ChangeStatus` and `change_status`.

  submodules.

  text (TypeScript `compareNumericPrefix`), and `Stream::from_file_name` for
  `<digits>.jsonl`, `change.jsonl` and `validator.jsonl`.

  reason, paused-until; new is `Pending`, attempt 0), and `apply_task` for the
  eight transition rows.

  `apply_change` and `apply` for the three stream kinds.

  first rule of the status table that holds.

  The large tables sit in documented `const`s so each test stays short.
- `crates/core/tests/fold_props.rs`: `any_event_sequence_folds_the_same_way`,
  a `proptest` drawing line and stream choices up to 50 long and a random
  split, checking fold-twice equality, split-join equality and no panic.

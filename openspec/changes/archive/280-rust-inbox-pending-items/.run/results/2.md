## Changed

- `read.rs` now reads each entry's `.run/paused.md` with storage's
  `read_usage_pause` next to its snapshot, keeping a pause list aligned with
  the change list; the project-root read does the same.
- `groups/running.rs` now builds running and paused items together, suppresses
  a paused item when a live running item names the same change and task, and
  sorts the group stably by change id then task id. It shares one head builder
  for both lines and prints the fixed-form pause time as `<day> <time> UTC`.
- Added `needs/pending.rs` with pure after-land-failed and autopilot-stopped
  item builders, including folder matching, queue-title fallback and the
  whitespace-normalized stop detail.
- `lib.rs` reads the after-land record with `HOME`, the stop record and the
  queue titles only through rust-storage, places archived, after-land,
  validator and autopilot items in TypeScript's order, and reads pauses through
  the new aligned change data.
- Added `tests/inbox_pending.rs` with the four pending scenarios plus an extra
  folder-match case for autopilot stops, each expected line taken from the
  delta tables (or the match rules).

## Deviated

- The delta writes `InboxFeature::at(1761134400000), the time
  2026-10-22T12:00:00.000Z`, but `1761134400000` is 2025-10-22. The expected
  lines use 2026-10-22, so the test uses `1792670400000` (2026-10-22T12:00Z)
  and the same instant as the live lock's `startedAt`. With the literal
  numeric value the "passed" row would still be in the future.
- Added one extra test for exact/padded autopilot folder matches so cargo-mutants
  cannot miss either `||` in `matches_folder`; the delta's autopilot table rows
  are still all checked in the scenario test.

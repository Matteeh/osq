## Changed

- Added `crates/kernel/storage/src/read/pending.rs` with `PauseRecord`,
  `AutopilotStop`, `AfterLandFailure`, `read_usage_pause`,
  `read_autopilot_stop`, `watch_state_dir` and `read_after_land_failure`.
  Frontmatter splits only through `parse_frontmatter`, timestamps go through
  `timestamp_ms`, `after-land.json` goes through `serde_json`, and
  `watch_state_dir` hashes the canonical or absolute project root with SHA-256.
- Added `crates/kernel/storage/src/read/queue.rs` with `QueueTitle` and
  `read_queue_titles`, porting TypeScript's `parseQueue` rules into the kernel.
- Exported the new readers and records from `read/mod.rs` and the crate root,
  and added `sha2.workspace = true` to the storage manifest. `Cargo.lock`
  needed no change because `sha2` was already locked for other crates.
- Added `tests/reading_pending_records.rs` with one test per pause, stop,
  watch-state and after-land scenario, and `tests/reading_queue_titles.rs`
  with one test per queue scenario, each checking the delta's table rows.
- Ran `cargo test -p osq-kernel-storage --test reading_pending_records --test reading_queue_titles`,
  then the proposal's `OSQ_CHANGE=openspec/changes/280-rust-inbox-pending-items sh scripts/verify-rust.sh`;
  both pass, including every existing storage test and the corpus link gates.
  Checked the new files by hand with `cargo mutants`: no missed mutants in
  either `pending.rs` or `queue.rs`.

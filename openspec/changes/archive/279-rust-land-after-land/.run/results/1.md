## Changed

- Added `crates/features/land/src/land/after.rs`: runs `vcs.afterLand` through `run_verify` in the checkout, keeps the last 20 non-blank output lines, writes or clears `$HOME/.osq/watch/<sha256(canonical checkout)>/after-land.json`, and returns the passing line or the failure lines.
- Added `crates/features/land/src/land/time.rs` with the run crate's epoch-millisecond clock and fixed UTC formatter, copied rather than depended on.
- Wired the after-land finish into `run_land`'s `Done` path and added `Implements: rust-land/land-after-land-command` to the touched docs.
- Added `osq-kernel-harnesses`, `serde_json` and `sha2` to the land crate and updated `Cargo.lock`.
- Added `crates/features/land/tests/land_after.rs` proving the after-land outcomes (unset, passing, failing, noisy tail, timeout) and that a passing command clears the record, with fixed UTC formatter rows and record-path coverage.

## Deviated

- Added one extra after-land case for a record path that cannot be removed. `cargo-mutants` missed the `NotFound` guard in `clear_record`; the new case makes the land fail instead of passing, so that branch is covered.
- The fixed UTC formatter rows are a non-test helper called from an existing scenario test, so every test that names `Covers` still owns a land repository and cleans up its record.

Touched: Cargo.lock, crates/features/land/Cargo.toml, crates/features/land/src/land.rs, crates/features/land/src/land/after.rs, crates/features/land/src/land/time.rs, crates/features/land/tests/land_after.rs

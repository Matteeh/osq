# Task 2 result

## Changed

- Added `src/core/spec/assumptions.ts`. It exports `readAssumptions(body)`,
  which finds `## Assumptions` the same way `readSurfaceSection` finds
  `## Surface` (heading alone on its line, to the next `## ` heading), strips
  HTML comments, trims lines, drops empty ones, strips a leading `- ` marker,
  returns `null` for an absent section, `[]` when the only line is `None`, and
  otherwise the assumption lines. It also exports
  `assumptionsSectionIsEmpty(body)` and the `PROPOSAL_ASSUMPTIONS_ERROR`
  message.
- `src/core/spec/linter.ts`: imported the new module and added one check in
  `lintChangeFolder` right after the Surface check, under the same
  `resolvedDoc.kind === 'proposal'` exemption, recording the error on the
  proposal file with `section: 'Assumptions'`. A missing section produces no
  finding, so every existing proposal stays silent.
- Added `tests/assumptions-lint.test.ts`: a table over `readAssumptions`
  (absent, `None`, bullet + plain line, comment + `None`) and
  `lintChangeFolder` cases over a temporary scaffolded project for the
  comment-only failure, the missing-section exemption, and the `None` and list
  acceptances, building the change the way `tests/proposal-surface-lint.test.ts`
  does.
- Task verify passed: `node --import tsx --import ./tests/git-test-env.ts
  --test tests/assumptions-lint.test.ts` (8 pass, 0 fail). Proposal verify
  `pnpm verify` passed: typechecks, build, all CLI and UI tests, and lint.

## Details

The section, as it appears in the proposal template:

```markdown
## Assumptions

<!-- One line per assumption the plan rests on that the human should check
before approving, such as "Every caller passes an absolute path." -->
None
```

In `FALLBACK_PROPOSAL_MD` the text sits inside a template literal; escape
backticks only if the text gains any.

The schema instruction bullet, indented like its neighbours:

```yaml
      - **Assumptions**: one line per assumption the plan rests on that the
        human should check before approving. Write `None` when there are none.
```

The planner bullet, wrapped like its neighbours:

```markdown
- `## Assumptions` follows `## Decisions`. Give one line per assumption the
  plan rests on that the human should check before approving, or write
  `None`. osq shows them as a notice on the approve view.
```

Golden events change because the golden run scaffolds a project from the
templates; measured on 2026-10-08, only `dead.jsonl` and `verified.jsonl`
change.

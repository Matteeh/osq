## Acceptance

- [ ] `src/tick.rs`'s `folder` ticks only `<folder>/tasks.md`, walks no subfolder, and returns `Ok(())` when that file does not exist; the checkbox reader accepts only a `-` bullet. The walk, `SKIPPED` and any item left unused go. `folder`'s doc still ends with `Implements: rust-archive/archive-task-checkboxes`, and `relocate.rs` does not change.
- [ ] The fixture's `notes/tasks.md` and `.run/approved` hold exactly the new bytes that Details gives for them.
- [ ] The golden tree's `notes/tasks.md` and `.run/approved` get the same bytes as the fixture's, and the golden root `tasks.md` changes only its star line, to the unticked star line in Details; no other fixture or golden file changes.
- [ ] In `tests/archive_move.rs`, `ticked_task_lines` checks the rows of rust-archive "Ticked task lines" as the delta now gives them, with the star row unticked and `notes/tasks.md` equal to its new bytes.
- [ ] `skipped_entries_are_not_ticked` keeps checking that each `.run`, `.git` and `.DS_Store` `tasks.md` keeps its unticked line, and no other test in `tests/archive_move.rs` changes.
- [ ] New `tests/archive_seal.rs` proves "Archived seal matches approval", comparing `change_folder_seal` of the archived folder and the archived `.run/approved` with the literal seal, and "Missing root tasks file".
- [ ] Each new test's one-line doc names `Covers: rust-archive/archived-seal-matches-approval` or `Covers: rust-archive/missing-root-tasks-file`.

## Details

The new bytes:

- fixture and golden `notes/tasks.md`: the line `- [ ] a nested tasks file keeps its bytes` followed by one LF;
- fixture and golden `.run/approved`: `sha256:9e4011d19d8c95e04f274c6f9cbdbbea2ae81869c997edd3b30687be72ce2a37` with no newline;
- the golden root `tasks.md` star line: `* [ ] a star item`.

TypeScript's archiver gets the same rule in task 1; the golden tree is what
it leaves for the fixture. Edit the five fixture and golden files with the
exact bytes above; the seal was computed with `hashChangeFolder` on the
fixture change with the new `notes/tasks.md`, and the archive's own approval
gate checks it.

cargo-mutants runs on every line this task touches. The missing-file branch,
the root-only read and the `-` bullet must each change a value a test
checks; add a row worked out from the delta's rules if a mutant survives.
Before exiting, run `cargo fmt --all`, then
`cargo mutants -p osq-feature-archive -f crates/features/archive/src/tick.rs -o "$(mktemp -d)"`,
then `sh scripts/verify-rust.sh` with `OSQ_CHANGE` set to
`openspec/changes/253-archive-keeps-seal`.

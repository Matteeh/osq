## Changed

- Added `tests/decisions-own.test.ts` with three tests:
  - "reads and validates the ADRs without error or warning": reads osq's
    `decisions/`, validates against its living specs with `validateDecisions`,
    asserts at least one ADR, no ignored file, no errors, no warnings, and
    `checkProjectRules(repoRoot, DEFAULT_CONFIG)` empty.
  - "documents the frontmatter format in decisions/README.md": asserts the
    README describes `status`, `applies_to`, and `rule`.
  - "passes the same checks with one more accepted ADR and a refreshed rules
    block": copies `decisions/`, `AGENTS.md`, and `openspec/specs` into a temp
    folder with `fs.cp`, writes an accepted `applies_to: all` ADR at the next
    free number, refreshes the copy with `writeRulesBlock`, then asserts the
    same checks stay clean.
- Removed the `describe("osq's own decision records")` block from
  `tests/decisions-read.test.ts`, along with the imports and constant it left
  unused (`fileURLToPath`, `readLivingCapabilityNames`, `repoRoot`).

## Deviated

- The task said the rest of `tests/decisions-read.test.ts` is unchanged "apart
  from imports the removal leaves unused." I also removed the `repoRoot`
  constant, because `fileURLToPath` was its only consumer. Keeping it would
  leave `repoRoot` unused and `tsconfig.json` sets `noUnusedLocals: true`, so
  `pnpm typecheck:cli` (part of the proposal verify) would fail.
- Added the README-format test. The delta requirement states
  `decisions/README.md` SHALL describe the frontmatter format; the new own-
  records test is the only place it belongs, so I covered it there.

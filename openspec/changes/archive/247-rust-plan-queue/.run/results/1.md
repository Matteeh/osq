## Changed

- `crates/features/plan/src/lib.rs` keeps the crate doc, declares `mod feature; mod queue;`, and re-exports only `PlanFeature`.
- `crates/features/plan/src/feature.rs` adds `PlanFeature`, its `plan` name, its one `queue` command, unknown-command and usage refusals, and the call to `queue::run_queue`.
- `crates/features/plan/src/queue.rs` adds `run_queue`: missing-file refusal, parse-detail prefixing, and the formatted text mapped to `FeatureError::failed("queue", …)`.
- `crates/features/plan/src/queue/parse.rs` adds the private item and the pure parser, including heading/dependency/fixes checks and JSON string quoting.
- `crates/features/plan/src/queue/text.rs` adds the private row and the pure `Queue:` formatter; task 1 rows are all `unplanned` with no change, 0 rejections, and every dependency then fix as unmet.
- `crates/features/plan/tests/plan_feature.rs`, `tests/queue_items.rs` and `tests/queue_corpus.rs` prove the task's six scenarios from repositories under `CARGO_TARGET_TMPDIR`; the corpus test is ignored and reads this repository's `openspec/queue.md`.

## Deviated

- Added refusal rows beyond the task table's required JSON-escape rows: empty title, whitespace title, leading/trailing/double hyphen, and a fix naming a later item. They kill `cargo-mutants` survivors in `parse_heading`, `parse_fixes` and `is_slug`.
- `QueueItem`, `QueueRow` and the parse/text helpers are `pub(super)`/`pub(crate)`, not module-private, so `queue.rs` and the sibling `text.rs` can use them without changing the crate's public surface.

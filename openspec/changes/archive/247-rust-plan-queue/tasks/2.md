## Details

Port `scanQueueAssociations`, `selectAssociation`, `mapActiveState` and
`readQueueState` from `src/core/status/queue-state.ts`, leaving out the vcs
check: an archived item is always `landed`. Storage's `ChangeEntry` gives
each folder's name, location and path; `ChangeSnapshot::status` is the
`ChangeStatus` the state maps from, and core's `ChangeStatus` lives in
`crates/core/src/fold/status.rs`. Read `brief.md` with
`std::fs::read_to_string`; a missing or unreadable file belongs to no item.
Keep the reading in `run_queue` and pass plain values to the pure functions
in `links.rs`, so each rule is a small named function.

Copy the fixture and the golden file with `cp -r` and `cp`; never edit them
and never regenerate the golden file. The golden fixture holds `.run/`
folders, so copy with `cp -r` of the folder, not a glob. Task 1's tests in
`tests/plan_feature.rs`, `tests/queue_items.rs` and `tests/queue_corpus.rs`
must keep passing unchanged: their repositories hold no change folder, so
every item stays `unplanned`.

The states test builds `.run/running/1.pid` and `.run/events/1.jsonl` in
its own folders, since `.run/running/` and `*.pid` are gitignored; an event
line reads like `{"type":"started","timestamp":"2026-10-04T10:00:00.000Z","data":{"attempt":1}}`,
and a change regression like `{"type":"regressed","timestamp":"2026-10-04T10:01:00.000Z","data":{"task":"change","reason":"worktree_dirty"}}`
in `.run/events/change.jsonl`.

cargo-mutants runs on every line this task adds, so each branch must change
a value a row checks: the trim of `queue_item`, each status mapping, the
archived-first ambiguity check, the last rejected folder, the leading-digit
id and its fallback, the proposal check, the landed filter of unmet slugs,
and the hash comparison. Before exiting, run `cargo fmt --all`, then
`cargo mutants -p osq-feature-plan -f <file> -o "$(mktemp -d)"` on each
source file this task changes, then `sh scripts/verify-rust.sh` with
`OSQ_CHANGE` set to `openspec/changes/247-rust-plan-queue`.

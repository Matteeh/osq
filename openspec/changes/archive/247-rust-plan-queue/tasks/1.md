## Details

Port `parseSection`, `parseFixesLine` and `parseQueue` from
`src/core/status/queue-parser.ts` without the hash, which task 2 adds, and
`formatQueue` from `src/core/status/queue-state.ts`. The crate has no regex
dependency, so match the heading, dependency and fixes lines by hand; keep
each check a small named function in the order `parseSection` runs them,
since the first refusal wins. Item boundaries are line starts whose text
begins `##`, then spaces or tabs, then `[`; slice the raw text at those
byte offsets.

`PlanFeature::run` matches the command first: any name but `queue` is
`FeatureError::unknown_command`, then a `queue` call with arguments is the
usage error, before any file is read. Build errors only through core's
constructors and match `FeatureError` with a wildcard arm, as
`crates/core/tests/feature.rs` does. The path in messages is
`invocation.root.join("openspec").join("queue.md")` shown with `display()`.

Each test writes its repository into its own folder under
`env!("CARGO_TARGET_TMPDIR")`, named after the test and removed first if it
is left over, since tests run in parallel. The corpus test's root is
`Path::new(env!("CARGO_MANIFEST_DIR")).join("../../..")`; it counts
the lines of `openspec/queue.md` that start with `## [` and checks the
output has that many lines after `Queue:`. Task 2 makes `queue` also read
this repository's change folders, so the corpus test must check only what
"This repository's queue" says, never states or change ids.

cargo-mutants runs on every line this task adds, so each branch must change
a value a row checks: each refusal, the `nothing` value, the fixes line's
presence, the `\r` and trailing-blank trims, the `###` line that is no item,
and each JSON escape. The table covers only `\t` and `\"`; add rows of your
own, in the same test, for slugs holding a backslash, a backspace, a form
feed and U+0001, whose details TypeScript writes as `\\`, `\b`, `\f` and
`\u0001`. A quoted text never holds `\n`, since the file is split into
lines first, so write no separate arm for it. Before exiting, run `cargo fmt --all`, then
`cargo mutants -p osq-feature-plan -f <file> -o "$(mktemp -d)"` on each new
source file, then `sh scripts/verify-rust.sh` with `OSQ_CHANGE` set to
`openspec/changes/247-rust-plan-queue`, so the link gate corpus test sees
this change's new requirements.

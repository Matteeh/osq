## Changed

- Added `src/core/vcs/land.ts` exporting `landChange(projectRoot, config, id)`,
  which returns `{ lines, code }` and follows the version-control delta's
  "Land" and "Land cleanup": it refuses unsafe state, syncs and verifies the
  worktree, squash-merges into the checkout, commits with the squash message,
  and removes the leftover draft and worktree. It reuses `buildSquashMessage`,
  `syncWithDefaultBranch`, `findLeftoverDrafts`, `readDependencyState`,
  `runVerificationCommand`, `worktreePath`, `worktreeBranch`, `listChanges`,
  `matchesFolder`, `findLandCandidates`, and `readLandedAt`.
- Added `src/core/vcs/land-checks.ts` holding the "Land refusals": vcs-off,
  checkout branch, checkout status, worktree status, and the earlier-unlanded
  shared-capability refusal, plus the proposal-verify stop helper.
- Added `src/cli/land.ts` with `landCommand` (injectable `cwd`, `config`,
  `stdout`, `stderr`, `exit`; `loadConfig` inside the error handling) and
  `registerLandCommand`.
- Added `registerDoctorCommand` to `src/cli/doctor.ts` and moved the inline
  `doctor` registration in `src/cli/index.ts` to it, in its original help
  position, then registered `land` next to `message`.
- Added `tests/vcs-land.test.ts` (Land, Land cleanup, Land command outputs and
  registration) and `tests/vcs-land-refusals.test.ts` (every refusal,
  checking the checkout HEAD/status and the worktree HEAD are unchanged),
  driven through `landCommand` on real temporary projects.

## Deviated

- `land-checks.ts` also holds the proposal-verify stop helper
  (`runLandVerify`) and `outputTail`. `land.ts` was 259 lines and the
  repo caps source files at 250, so the verify stop moved next to the other
  land stops. `land.ts` is now 229 lines.
- The earlier-unlanded-change refusal is skipped on the "already landed"
  cleanup path, since that path only cleans up and never writes the checkout.
- I ran a single read-only `git status --porcelain` from the shell to inspect
  the working tree before writing this result. No git write was performed.

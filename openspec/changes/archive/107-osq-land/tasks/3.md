## Details

Build projects the way `tests/squash-message.test.ts` does: a real temporary
repository, changes approved into worktrees with `approveSpec`, and
`runWatcherOnce` with an adapter that edits files in scope. For "Two changes
land in order", approve both changes before landing either, so both branches
are cut from the same default branch, and give each a delta that adds a
requirement to one capability. Proposals use a local `node verify.cjs`
verifier.

A `pre-commit` hook in the repository applies to every worktree. Install the
hook scenario's hook after the change has archived, and land with a default
branch that has not moved, so the land commit is the only commit it sees.

`Osq-Head` needs no code change: "Squash commit message" already reads the
worktree's HEAD, which is the sync commit after a sync.

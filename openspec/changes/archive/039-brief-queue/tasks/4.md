## Details

This is a behavior-preserving extraction from the oversized files produced by
tasks 1-3. Do not change task semantics to make the split easier. Keep
`src/core/queue.ts` as a small re-export facade so `src/cli/queue.ts`,
`src/cli/plan.ts`, `tests/queue.test.ts`, `tests/queue-plan.test.ts`, and
`tests/queue-budget.test.ts` retain their existing import paths and API names.

Move queue markdown hashing and parsing plus `getQueuePath` and `readQueue` to
`queue-parser.ts`. Move association scanning, state selection, projection, and
active-failure derivation to `queue-state.ts`. Move planning usage aggregation,
budget evaluation, next-item selection, and preparation to
`queue-planning.ts`. Export the minimum internal state projection needed by
planning, but keep report-only history and elapsed-time derivation for task 5.
Dependency direction is parser to state to planning; the facade re-exports and
no extracted module imports the facade.

Move `QueueConfig` and its finite non-negative atomic-block validation to
`config-queue.ts`. Re-export the type from `config.ts` so `src/index.ts` and
consumer imports remain unchanged. Keep default merging, environment handling,
planner validation, harness configuration, and error text byte-compatible.

Move only queue-specific command orchestration from `plan.ts` to
`plan-queue.ts`: option-mode validation, read-only queue preparation, landed
dependency context, and the incomplete-cost notice. Keep `readBriefInput`,
`formatBriefContent`, `buildOpeningPrompt`, and `planCommand` exported from
`plan.ts`, and preserve the same create/resume, print, adapter, manifest, and
planning-telemetry sequence. The extracted helper receives explicit inputs and
does not acquire a second configuration or filesystem-loading path.

Use the existing tests as frozen regression coverage; `tests.modify: false`
forbids changing them. Do not edit `tests/line-budget.test.ts`, add an allow-list
entry, compress code mechanically, or hide responsibilities in an unrelated
allow-listed module. Run the task verify and `pnpm verify` before exit.

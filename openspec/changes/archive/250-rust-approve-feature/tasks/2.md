## Details

The change folder passed to the specs kernel is the root joined with
`openspec/changes/<folder>`, so each finding's `file` is that path joined
with the file, shown with `display()`, as the rows' `<d>` says. The
`proposal.md` in each row's change folder holds `---\ntitle: A\n---\n`.
Copy the living spec from `tests/fixtures/approve-repo/openspec/specs/alpha/spec.md`,
which task 1 added.

cargo-mutants runs on every line this task adds, so each branch must
change a value a row checks: the finding lines, the merged validation
running only after a clean change validation, and the merge error line.
Before exiting, run `cargo fmt --all`, then
`cargo mutants -p osq-feature-approve -f <file> -o "$(mktemp -d)"` on each
source file this task changes, then `sh scripts/verify-rust.sh` with
`OSQ_CHANGE` set to `openspec/changes/250-rust-approve-feature`.

## Changed

- Added `osq-kernel-storage` and `osq-kernel-specs` to the approve crate, with the matching `Cargo.lock` entry.
- Added `ApproveFeature` with the `approve <id>` command and argument errors.
- Added `run_approve`, which finds the first matching active change, refuses an approved change with steering triggers, seals it, creates `.run/`, writes `.run/approved`, and prints the approval lines.
- Ported the lookup match, the steering triggers, the refusal texts and the output text as pure helpers.
- Added the approve feature, lookup, steering, marker, output and golden tests, with shared helpers under `tests/support/`.
- Copied the golden fixture to `tests/fixtures/approve-repo/` with both `tasks-md.txt` files renamed to `tasks.md`, and copied TypeScript's two approval markers to `tests/fixtures/approve-markers/`.
- Ran `cargo fmt --all`, clippy with `-D warnings`, cargo-mutants on every new source file with no misses, and `sh scripts/verify-rust.sh` with `OSQ_CHANGE` set.

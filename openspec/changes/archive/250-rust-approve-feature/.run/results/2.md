- `cargo test -p osq-feature-approve --test validation_refusals` passes, every other `osq-feature-approve` test still passes, `cargo fmt --all`, clippy with `-D warnings`, `cargo mutants` on `approve.rs` (6 caught, 1 unviable) and `lint.rs` (4 caught) with no misses, and `sh scripts/verify-rust.sh` with `OSQ_CHANGE=openspec/changes/250-rust-approve-feature` all pass.

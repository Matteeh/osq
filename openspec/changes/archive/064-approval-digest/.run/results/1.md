## Changed

- `src/core/spec/parser.ts`: exported the existing private `extractSection` so the digest can read `## Human steps`.
- `src/core/spec/digest-flags.ts` (new): the fixed flag rules. `shared_file` per task pair over all resolved scope paths (existing and declared-missing); `sensitive_path` per kind from the Details list, with env-template exclusion; `verify_without_test` for task and proposal verifies naming no test token/segment or runner; `removed_requirement` per capability; `unknown_capability` for a delta capability with no living spec. Flags are emitted in the fixed id order, then task-number or name order.
- `src/core/spec/digest.ts` (new): the `ApprovalDigest`/`ApprovalFlag`/`ApprovalFlagId` types, `buildApprovalDigest`, `collapseWhitespace`/`firstTwoSentences`, `formatApprovalDigest`, `formatApprovalFlags` (returns one `Flag: <label> — <excerpt>` line per flag), and `summarizeApprovalFlags`. Reuses `resolveScope`, `parseDelta`, `parseSpecMd`, `parseTaskMd`, `resolveChangeDoc`, and `extractSection`.
- `tests/approval-digest.test.ts` (new): temporary-project fixtures for a clean change, a `tests.modify` change, and one change per flag, asserting structure, labels, excerpts, env-template exclusion, runner/test detection, stable flag order, and the three formatters.

## Deviated

- `formatApprovalFlags` returns `string[]` (one entry per flag) rather than a joined string. The acceptance says "one `Flag: <label> — <excerpt>` line per flag", and task 2 prints "the `formatApprovalFlags` lines"; an array is the literal shape. Task 2 can join or iterate.
- `formatApprovalDigest` picks its own readable layout (Change/Goal/Tasks/Capabilities/Human steps); the acceptance only fixes that it omits flags.
- Sensitive-path matching uses the basename at any depth for package manifests, lockfiles, `osq.config.*`, and managed instruction names; the Details wording only states "at any depth" explicitly for package manifests and lockfiles. The Claude plan command path is taken from the exported `CLAUDE_PLAN_COMMAND_PATH` constant so it cannot drift.
- Kept both new modules at or under the 250-line source budget by trimming comments and using `split(' ')` set construction; no allow-list entry was added.

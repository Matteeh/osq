## Changed

- `src/core/report/approval-flags.ts` (new): `collectApprovalFlagOutcomes` reads
  `.run/manifest.json` from each active and archived change folder, accepts only
  a manifest whose `approvalFlags` carries a string-array `ids` and a
  `shown`/`confirmed` `mode`, and skips anything else without recomputing flags.
  Trouble is a task-stream `dead` event or a task- or change-stream `regressed`
  event. Exports `ApprovalFlagId`-typed key order (`shared_file`,
  `sensitive_path`, `verify_without_test`, `removed_requirement`,
  `unknown_capability`, then `none`) and `formatApprovalFlagOutcomes`.
- `src/core/report/report.ts`: `MetricsReport` gains `approvalFlags:
  ApprovalFlagOutcomes`; `getMetricsReport` fills it from `allSpecFolders` and
  `formatMetricsReport` prints `Approval flags:` between the planning and cycle
  sections via the helper, so neither grandfathered function grows logic.
- `src/cli/report.ts`: `toStableMetrics` emits `approvalFlags` with `changes`
  and a per-key `byFlag`, each `{ shown, confirmed }` of `{ fired, troubled }`.
- `tests/report-json.test.ts`: top-level key list, the two hand-built reports,
  and the shape/text assertions include `approvalFlags`.
- `fixture/report/expected.json`: regenerated through the real command; the only
  diff is the zeroed `approvalFlags` block.
- `tests/report-approval-flags.test.ts` (new): builds shown/confirmed flags with
  and without later task `dead` and task/change `regressed` events, a `none`
  change, a legacy manifest without the field, and invalid/malformed manifests,
  asserting `changes` and every per-key count, plus text and JSON output.

## Deviated

- Only flag ids among the five known ones are counted; an unrecognized id in a
  recorded manifest is ignored rather than mapped to `none`. The task text only
  fixes the six keys, and the manifest writer emits only known ids.

Touched: src/core/report/approval-flags.ts, src/core/report/report.ts, src/cli/report.ts, tests/report-approval-flags.test.ts, tests/report-json.test.ts, fixture/report/expected.json

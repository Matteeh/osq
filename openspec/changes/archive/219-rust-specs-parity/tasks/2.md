## Details

Run the CLI with `std::process::Command`: test targets are not runtime
code, so the no-runtime-Node gate does not scan them. Give each command
`OPENSPEC_TELEMETRY=0` and the project folder as its working directory,
and build each project under `env!("CARGO_TARGET_TMPDIR")`. Take the
landing order and the replay as `tests/replay_corpus.rs` does. Shared
helpers may sit in a module folder under
`tests/openspec_parity_support/`, which task 3 reuses through `mod`.
Name items in failure output by their path relative to the repository
or the crate.

A scratch run on 2026-10-18 found the five listed differences and no
other, over 13 living specs and 216 archived changes, in about a minute.
If an item differs that is not listed, first read OpenSpec's messages. If
the Rust validator breaks a rule as rust-specs states it, write the item
and both results under `## Blocked`. Never edit `src/`, a fixture, an
existing test or anything under `openspec/`.

Keep the test files under 250 lines and every function under 80. Workspace
lints include `clippy::pedantic` and `-D warnings`. Run `cargo fmt --all`
before exiting.

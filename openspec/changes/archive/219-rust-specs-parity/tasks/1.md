## Details

Visit call expressions with `syn::visit::Visit`, and take the line from
the path's span through `proc-macro2`'s `span-locations`. Read the
manifest's `members` array line by line, as `crates/core/tests/no_io.rs`
reads `[dependencies]`, and add no TOML crate. The fixture is the source
of truth. Copy it, and never edit it. Nothing builds the fixture
workspace, so leave it out of the root `members`. Tests find it from
`env!("CARGO_MANIFEST_DIR")`. Write the error cases under
`env!("CARGO_TARGET_TMPDIR")`. `Cargo.lock` gains no new package
version: `syn` 2.0.119 and `proc-macro2` 1.0.107 are already locked.

Split the code into `src/` modules as ADR 023 says: the pure source scan
and the workspace walk in separate files. Keep every `.rs` file under 250
lines and every function under 80. Workspace lints include
`clippy::pedantic` and `-D warnings`. Meet them rather than allowing them.
Keep tests in `tests/`. When the mutation step reports a missed mutant,
add a case for it. Run `cargo fmt --all` before exiting.

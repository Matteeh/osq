## Changed

- `.github/workflows/rust.yml`: added a `parity` job that checks out the repo,
  sets up pnpm, Node 24, the Rust toolchain and the Rust cache, installs with
  `pnpm install --frozen-lockfile`, runs clippy on `osq-kernel-specs` with the
  `parity` feature, runs the parity corpus tests against the pinned OpenSpec
  outside the schedule, and on the schedule installs
  `@fission-ai/openspec@latest` outside the lockfile and runs the same tests
  with `OSQ_OPENSPEC_BIN` and `OPENSPEC_TELEMETRY=0` supplied through the
  step's `env`. The `on` block and the `cargo` and `mutants` jobs are
  unchanged.

  tests', ...)` with one case per table row, using `stepsOf`, `stepRunning`,
  `stepUsing` and `scheduleStep`.

  `tests/rust-adrs.test.ts` and the five specs kernel corpus tests plus the

  "Rust ADRs are accepted" row.

  checks.

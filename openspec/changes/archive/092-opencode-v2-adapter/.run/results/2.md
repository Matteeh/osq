## Changed

- `src/harness/opencode/opencode.ts`: `buildOpencodeArgs` emits
  `run <prompt> --standalone --agent <agent> --auto --format json --model
  <model>` with no `--dir`, folding a configured `opencode.variant` into the
  model as `<model>#<variant>`. `spawn` tracks the streamed `sessionID` and
  run totals, then runs `opencode session export --standalone <sessionID>`
  bounded by `timeouts.harnessPreflightSeconds` (10 when unset) and appends a
  remainder `tokens` event. `spawnInteractive` runs
  `opencode mini --prompt <prompt>` plus `--model`/`--agent` and no variant.
  `preflightOpencode` assesses `--version` with `assessOpencodeVersion` and
  exits 1 below 2.0.0 with the "OpenCode diagnostics" message.
- Added `src/harness/opencode/opencode-session.ts` with the run tracker,
  session-export parser, `readOpencodeSessionUsage`, the field-wise clamped
  remainder, and the single `tokens` append when the remainder is non-zero.
- Added `tests/opencode-v2.test.ts` covering the four "OpenCode v2 task
  execution" scenarios, with the observed stream and export copied to
  `tests/fixtures/events/opencode-v2/`.
- `tests/opencode-spawn.test.ts` and `tests/harness-interactive.test.ts` now
  assert the v2 arguments.
- `tests/watcher-preflight.test.ts`: changed only the first case's fake
  opencode version and the log line it expects from `opencode 1.0.0` to
  `opencode 2.0.0`, the change that lets the new preflight refusal pass.
- `README.md`'s opencode section says the adapter needs opencode 2 and that
  `variant` is passed as `<model>#<variant>`.

`node --import tsx --test tests/opencode-v2.test.ts` and `pnpm verify` both
pass (exit 0).

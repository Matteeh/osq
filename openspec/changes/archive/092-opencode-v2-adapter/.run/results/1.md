## Changed

- Added `src/core/foundation/config-opencode.ts` exporting `OPENCODE_TESTED_RANGE`
  (`>=2.0.0 <3.0.0`), `assessOpencodeVersion`, and `diagnoseOpencode`. The
  assessment reads the first `major.minor.patch` in the `--version` output, so
  `opencode v2.0.18` reads as `2.0.18`. `ok` is false only below 2.0.0; 3.0.0+
  and unparseable output pass.
- Declared `diagnose: diagnoseOpencode` on the opencode entry in
  `harness-catalog.ts`, importing the module.
- Added `tests/opencode-doctor.test.ts`, which drives `runDoctorChecks` with a
  fake opencode binary via `opencode.bin` and covers version 2 (pass), version
  1 (fail, doctor exits 1), version 3 (warn), unparseable output (warn), plus
  the catalog hook identity.

Touched: src/core/foundation/config-opencode.ts, src/core/foundation/harness-catalog.ts, tests/opencode-doctor.test.ts

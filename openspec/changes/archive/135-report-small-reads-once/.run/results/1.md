## Changed

- `src/core/report/stream-reads.ts`: added a second `shared` parser cache to the
  `withStreamReads` scope and exported `readSharedFile`, `readTextFile`, and
  `freezeDeep`. `readSharedFile` shares one read per resolved path and parser
  like `readParsedFile`, but rejects with the file-system error and caches a
  failed read so it is not retried. `readTextFile` is `readSharedFile` with a
  module-level identity parser. `freezeDeep` freezes a value, every nested
  object and array, returns the same value, and leaves already-frozen values
  and primitives alone.
- `src/core/report/change-reads.ts` (new): exports `readBriefData` and
  `readManifestObject`. `readBriefData` runs a module-level `parseFrontmatter`
  parser through `readSharedFile` and deep-freezes the frontmatter data, or
  gives null when the brief is missing or unreadable. `readManifestObject`
  reads `.run/manifest.json` through `readSharedFile`, parses it as a plain
  JSON object, deep-freezes it, and gives null when the manifest is missing,
  unreadable, malformed, or not a plain object.
- `tests/report-shared-reads.test.ts` (new): covers read sharing inside a
  scope (including concurrent and nested calls), per-call disk reads outside a
  scope, isolation between scopes, `ENOENT`/`EISDIR` rejection in and out of a
  scope, no retry and no unhandled rejection for a cached failed read, parser
  throws, `readTextFile`, `freezeDeep`, and the once-per-scope brief and
  manifest reads, counting reads with `mock.method` on the default
  `node:fs/promises` export.

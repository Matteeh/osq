## Changed

- `tests/report-small-reads-once.test.ts` (new): builds three archived queue
  changes beside an empty home, runs `getMetricsReport`, and counts
  `fs.readFile` calls through `mock.method` on the default `node:fs/promises`
  export. Asserts every task file, `brief.md`, `.run/manifest.json` and
  `proposal.md` is read exactly once per run, names any repeated path, and
  asserts each is read twice across two runs. Seen red first: per run the old
  code read each proposal and task file twice and each brief and manifest four
  times.
- `src/core/spec/parser.ts`: `parseSpecMdFromFolder` now reads the resolved
  proposal or spec through `readSharedFile` with a module-level
  `parseFrozenSpecMd` that returns `freezeDeep(parseSpecMd(content))`. A read
  error still rejects with the file-system error (EISDIR preserved).
- `src/core/status/state.ts`: `readChangeFolder` reads each task file through
  `readTextFile`, so its task reads share with the report's; a read error still
  rejects.
- `src/core/status/queue-state.ts`: `scanQueueAssociations` reads the brief
  through `readBriefData`; a missing or unreadable brief still leaves the
  change out. Removed the now-unused `fs`, `path` and `parseFrontmatter`
  imports.
- `src/core/report/report.ts`: `readTaskMetadata` reads through `readTextFile`
  (missing files still yield empties) and `readPlannerModel` reads the brief
  through `readBriefData`.
- `src/core/report/approval-flags.ts`: `collectApprovalFlagOutcomes` reads the
  manifest through `readManifestObject`, and `parseRecordedFlags` now takes the
  parsed manifest object instead of text.
- `src/core/report/brief-to-approval.ts`: reads the manifest through
  `readManifestObject` instead of its own JSON parse.
- `src/core/run/manifest-approval.ts`: checks `.run/approved` first as before,
  then reads `.run/manifest.json` through `readManifestObject` and trusts a
  parseable `approvedAt`.

No reader mutates a proposal, brief data or manifest. `pnpm verify`
(typechecks, build, every test, lint) passes, including the
`fixture/report/expected.json` golden and the report text and JSON tests. The
task verify `node --import tsx --test tests/report-small-reads-once.test.ts`
passes.

Touched: src/core/report/report.ts, src/core/report/approval-flags.ts, src/core/report/brief-to-approval.ts, src/core/run/manifest-approval.ts, src/core/spec/parser.ts, src/core/status/state.ts, src/core/status/queue-state.ts, tests/report-small-reads-once.test.ts

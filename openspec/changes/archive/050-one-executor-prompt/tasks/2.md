### Layout

Lines join with `\n`. Optional parts are dropped whole when empty.

1. `You are a coding agent working autonomously on an osq task. Follow AGENTS.md strictly.`
2. `Task File: `, `Parent Spec: `, `Task Title: `, `Scope: ` (joined `, `), `Entry: ` (joined `, `), `Verify Command: `, `Result Destination: `, one per line, all paths relative to the project root.
3. `priorContextLines(...)`, exactly as the adapters call it today.
4. When there are delta specs: an empty line, `Delta Specs:`, then `- <path>` per delta.
5. When there are living specs: an empty line, `Living Capability Specs:`, then `- <path>` per spec.
6. An empty line, `Rules:`, then the `EXECUTOR_STEPS` lines.
7. `capabilityRuleLines(resolveCapabilityRules(options))`.
8. An empty line, `Exiting:`, then the `EXECUTOR_EXIT_LINES` lines.
9. An empty line, then `CRITICAL: Before exiting, you MUST write <result path> as the Exiting rules above describe. Change no file outside Scope except that result file.`

## Details

Reuse the catalog lookup, executor identity, and planner selection helpers from task 1 together with `runDoctorChecks`, `buildManifest`, `recordLifecycleEvent`, `startWatcher`, `planCommand`, and the existing `HarnessAdapter.preflight` and `spawnInteractive` ports. Do not add adapter methods or move adapter-specific argv, setup, stream parsing, or process behavior into generic modules.

In doctor, replace its private harness-name binary switch with catalog executable resolution while retaining the current probe seam, timeout behavior from configuration, no-binary success result, and CLI output contract. In watcher startup, call the supplied adapter's optional preflight directly before the first cycle; remove the OpenCode import and name gate rather than replacing them with new catalog booleans.

Use executor identity for approval manifest and started-event metadata. Preserve the manifest schema and planner.model-or-null semantics established by 032. Use planner selection at both planCommand decision points: formatting a newly created brief and launching the interactive adapter. Pass an absent native model override through as absent while recording `default` in brief metadata where required.

The architecture test reads registered names from the catalog and inspects only generic consumers: `src/core/config*.ts`, `src/core/doctor.ts`, `src/core/manifest.ts`, `src/cli/plan.ts`, `src/watcher/loop.ts`, and `src/watcher/spawn.ts`. Allow harness names inside the catalog, adapter modules, type names, user-facing fixture data, and tests that intentionally select a harness. Reject semantic comparisons and fallback selection logic in generic consumers; avoid a naive ban that rejects unrelated prose or typed configuration access required inside the catalog.

New workflow tests use disposable fixture copies and the deterministic fake executables delivered by 032. Existing tests named by verify are read-only regressions. Run the task verify and `pnpm verify` before exit, and do not weaken existing assertions to accommodate the refactor.

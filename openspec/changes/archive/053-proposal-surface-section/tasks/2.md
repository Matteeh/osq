## Acceptance

- [ ] Every `proposal.md` written inline by a file in this task's scope contains a `## Surface` section holding `None`. The section sits after `## Non-goals` when the proposal has one, and otherwise directly before the next `##` heading or at the end of the body.
- [ ] Nothing else in these files changes: no assertion, name, or other proposal text.
- [ ] The task's verify command passes.

## Details

This task's `scope` is authoritative over any injected code-ownership rules.

Task 3 adds a lint rule that rejects a proposal without `## Surface`. With that
rule, these files are the ones that write proposals inline and approve or lint
them. A trial run of the rule failed tests in each of these eight files and
nowhere else outside task 3's scope. The section is harmless before the rule
lands, so this task changes no behavior.

Add the section wherever a proposal string or proposal-building helper appears.
Where a helper builds every proposal in a file, change the helper once. A
proposal a test deliberately makes invalid for another reason still gets the
section, so that the test keeps failing only for its intended reason.

- [ ] core's `Node` gains a public field `function: bool`, placed after `public`, as rust-core "Link graph" says. Its doc comment says an item or test node sets it when the item is a function.
- [ ] `CodeItem` gains a public field `function: bool`, placed after `public`, and `code_tags` sets it as rust-linter "Code tags" says. Every function a macro's tokens give, such as one in `proptest!`, is a function.
- [ ] `build_link_graph` sets `function` on `Item` and `Test` nodes from `code_tags`, and to false on every other node, as rust-linter "Link graph build" says.
- [ ] `crates/kernel/linter/tests/code_tags.rs` checks the new Function column of "Items of the tags fixture" for every row, and `crates/kernel/linter/tests/link_graph.rs` checks the new Function column of "Nodes of the link graph fixture" for every row. Copy the values from the delta's tables. The two fixtures do not change.

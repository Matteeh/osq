## Details

osq sets `OSQ_CHANGE` to this change's folder for every verify, so the
corpus test sees `rust-linter/link-gates` and this change's new scenarios
as live. Run it by hand with
`OSQ_CHANGE=openspec/changes/232-rust-link-gates cargo test -p osq-kernel-linter --test link_gates_corpus -- --include-ignored`.
Without the variable it reports this change's own new tags, which is
expected until archive.

The corpus test does not fail on `owned-once` findings. The fourteen
placeholder crates are unowned until this change archives and
`rust-workspace` becomes living, and the follow-up queue item makes the
test fail on every finding. Do not add an exception list of files or
tags, and do not edit any living spec.

If the gates with `OSQ_CHANGE` set report anything other than the tags
above, a rule disagrees with the repository. Say which finding in
`## Blocked` rather than changing the rule or the code it names.

## Changed

- `src/relocate.rs`: ports `relocateArchivedSpec` without the record removal and the `archived` event. It removes `plan-prompt.md` when present, creates `openspec/changes/archive/`, picks the first free folder name, renames the change, ticks the archived folder, and returns the archived path relative to the root with `/` separators.
- `src/tick.rs`: ports `ensureArchivedTasksTicked` and `tickAllTaskCheckboxes`. It walks the archived folder, skips `.run`, `.git` and `.DS_Store`, ticks only `tasks.md`, applies JavaScript's multiline line starts (`\n`, `\r`, U+2028, U+2029), and leaves unchanged text unwritten. The line-start and checkbox rules are pure private helpers with no regex crate.
- `src/feature.rs`: calls `relocate::run` with the change folder `archive::run` returns and returns the archived relative path through `Output::text`.
- Added `tests/archive_move.rs`, `tests/archive_golden.rs`, and a byte-for-byte `tests/golden/project/` copy of the change's golden tree.

## Deviated

- Added a few named tests beyond the five scenario names: missing `plan-prompt.md`, skipped `.run`/`.git`/`.DS_Store` entries, runs of spaces and tabs, and an unchanged read-only `tasks.md`. They make the port's conditions observable to cargo-mutants.
- `free_target` reads the archive directory once and searches a finite suffix range instead of the TypeScript `stat` loop; it gives the same first-free name without a loop that a mutated increment can hang.

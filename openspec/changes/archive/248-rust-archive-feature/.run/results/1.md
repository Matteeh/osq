## Changed

- `crates/features/archive/Cargo.toml`: added `osq-kernel-specs`, `osq-kernel-storage`, `serde_json` and `yaml-rust2` as workspace dependencies; `Cargo.lock` gained only those four entries for `osq-feature-archive`.
- `src/lib.rs`: declared the private modules `apply`, `archive`, `feature`, `record`, `relocate` and `tick`, re-exporting only `ArchiveFeature`.
- `src/feature.rs`: implemented `ArchiveFeature`'s `Feature` name, one `archive <change>` command, argument errors, unknown-command refusal, and dispatch to the orchestrator with empty output text.
- `src/archive.rs`: change lookup by folder or leading digits, the approval/seal/done/marker gates, the `merge_change` merge before any write, and the write-failure message using the living path relative to the root.
- `src/apply.rs`: writes merged living specs, removes emptied capabilities (`spec.md`, `osq.yml`, then the folder), writes created sidecars from the proposal's `creates`, and copies replacement `osq.yml` sidecars, returning a typed path and `std::io::Error`.
- `src/record.rs`, `src/relocate.rs`, `src/tick.rs`: one-line module docs for tasks 3 and 2.
- `tests/fixtures/project/**`: byte-for-byte copy of the change's fixture project, `.run/` folders included.
- `tests/support/mod.rs`: fixture path, fresh scratch copy, archive run and full folder tree helpers.
- `tests/reseal/mod.rs`: rewrites a change folder's `.run/approved` from `change_folder_seal`.
- `tests/archive_feature.rs`: proves the feature's name and command, the argument-error table and change lookup by id or folder.
- `tests/archive_refusals.rs`: proves the not-done table (markers, events, approval, seal mismatch) and the non-applying delta refusal, each writing nothing else.
- `tests/living_spec_writes.rs`: proves the living specs after an archive, all eleven `creates` rows, and the living-file write failure; it also covers a missing emptied-capability sidecar and an unremovable one.

Verification: `cargo test -p osq-feature-archive --test archive_feature --test archive_refusals --test living_spec_writes` passes, `cargo fmt --all`, `cargo clippy -p osq-feature-archive --all-targets -- -D warnings` and `OSQ_CHANGE=openspec/changes/248-rust-archive-feature sh scripts/verify-rust.sh` pass. `cargo mutants` on `feature.rs`, `archive.rs` and `apply.rs` reports no missed mutants; `lib.rs`, `record.rs`, `relocate.rs` and `tick.rs` have no mutants.

## Deviated

- Added two tests beyond the listed scenarios in `living_spec_writes.rs`: an emptied capability with no sidecar, and one whose sidecar cannot be removed. They cover the two `remove_file` guard mutants that the beta row alone did not kill.

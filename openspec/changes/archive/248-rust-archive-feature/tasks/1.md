## Details

Port `applyOpenSpecDeltas` and `removeEmptiedCapability` from
`src/core/spec/apply-deltas.ts`, `applyArchiveSidecars` from
`src/watcher/archive-sidecars.ts`, and `readCreates` with
`readCreatesEntry` from `src/core/spec/capability-relations.ts`. Use
`osq_kernel_storage::list_changes` and `read_change` for the change and its
fold, `osq_core::Seal::parse` and `osq_kernel_storage::change_folder_seal`
for the seals, `osq_core::Change::draft`, `approve` and `archive` for the
gates, each `TaskFile`'s `done` for the markers,
`osq_kernel_specs::merge_change` for the merge, and
`osq_kernel_specs::parse_frontmatter` with `yaml_rust2::Yaml` for
`creates`; trim with `osq_kernel_specs::js_trim`. For a
`MergeChangeError::Merge` use the inner `MergeError`'s `Display`, not the
`MergeChangeError`'s, since that one adds the delta's path. Merge every
delta before the first write, so a refusal writes nothing. Do not move the
change folder, remove `plan-prompt.md`, tick checkboxes or write a record;
tasks 2 and 3 do that.

Copy the fixture with `cp -r` and never edit it. New `tests/support/mod.rs`
holds four helpers: the fixture's path; a fresh scratch copy of it under
`CARGO_TARGET_TMPDIR` that first removes a leftover folder of the same
name; a run of `archive` through `ArchiveFeature` with a list of arguments;
and a tree of a folder, every file by relative path with `/` separators and
its bytes and every folder by path with no bytes. Cargo compiles it into
each test that declares `mod support;`, so each test file must use all four
helpers, or clippy's `dead_code` warning fails the verify. New
`tests/reseal/mod.rs` holds one helper, which writes a change folder's
`change_folder_seal` text to its `.run/approved`; only test files that edit
a sealed file declare `mod reseal;`. Tasks 2 and 3 use both unchanged. Give
every test its own scratch name, since tests run in parallel, and keep each
test function under clippy's 80-line limit with named helpers. Match
`FeatureError` with a wildcard arm, as `crates/core/tests/feature.rs` does.
Compare a refused run's tree with the fixture's tree minus the paths the
row removed or replaced.

cargo-mutants runs on every line this task adds, so each condition must
change a value a row checks: the argument count, the folder and the id
match, each gate and the done markers, the emptied capability's three
removals, each `creates` entry shape and the malformed list, the
`spec.md`-is-a-file and `osq.yml`-exists tests, and the replacement copy.
Before exiting, run `cargo fmt --all`, then
`cargo mutants -p osq-feature-archive -f <file> -o "$(mktemp -d)"` on each
new source file, then `sh scripts/verify-rust.sh` with `OSQ_CHANGE` set to
`openspec/changes/248-rust-archive-feature`, so the link gate corpus test
sees this change's requirements.

## Details

Port `applyArchiveSpecs`, `restoreArchiveSpecs`, `archiveSpecsRecordPath`
and `removeEmptyDir` from `src/watcher/archive-specs.ts`, and the record
removal at the start of `relocateArchivedSpec` in `src/watcher/archiver.ts`.
`src/apply.rs` stays as task 1 left it: put the files back in
`src/archive.rs` when its call returns the error. Read each recorded file as
text; one that cannot be read, a folder or a missing file alike, records
`null`.

The test file declares `mod support;` and uses its four helpers unchanged,
all four of them; no row edits a sealed file, so it does not need
`mod reseal;`. Give every test its own scratch name, and keep each test
function under clippy's 80-line limit with named helpers.

cargo-mutants runs on every line this task adds, so each step must change a
value a row checks: the stopped-record test, every recorded path, the `null`
removals and the empty-folder removal (the `epsilon/osq.yml` row, where
`gamma/spec.md` was written before the failure), the record write's failure,
and the record removal after success, which `tests/archive_golden.rs`
checks. Before exiting, run `cargo fmt --all`, then
`cargo mutants -p osq-feature-archive -f <file> -o "$(mktemp -d)"` on each
new or changed source file, then `sh scripts/verify-rust.sh` with
`OSQ_CHANGE` set to `openspec/changes/248-rust-archive-feature`.

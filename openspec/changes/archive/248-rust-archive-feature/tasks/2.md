## Details

Port `relocateArchivedSpec`, `ensureArchivedTasksTicked` and
`tickAllTaskCheckboxes` from `src/watcher/archiver.ts`, leaving out the
record removal, which task 3 adds, and the `archived` event, which this
change does not write. Copy the golden tree with `cp -r` and never edit or
regenerate it.

Both test files declare `mod support;` and use its four helpers unchanged,
all four in each file; `tests/archive_move.rs` also declares `mod reseal;`
for the "Line starts" rows, which edit the sealed `tasks.md`. The golden
test compares the files of the scratch copy's tree, path and bytes, with
the files of `tests/golden/project`'s tree, and checks the two absent
folders by name. Give every test its own scratch
name, and keep each test function under clippy's 80-line limit with named
helpers.

cargo-mutants runs on every line this task adds, so each condition must
change a value a row checks: the name counter and its start at 1, the
`.run`, `.git` and `.DS_Store` skips, the `tasks.md` name test, the line
starts, the space-or-tab runs, the `-` or `*` test, the unchanged-text test,
and the path separators of the output text. Before exiting, run
`cargo fmt --all`, then `cargo mutants -p osq-feature-archive -f <file> -o "$(mktemp -d)"`
on each new or changed source file, then `sh scripts/verify-rust.sh` with
`OSQ_CHANGE` set to `openspec/changes/248-rust-archive-feature`.

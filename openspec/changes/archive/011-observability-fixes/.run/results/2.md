# Task 2 result: adapter `text` events drive runner result synthesis

## Changed

- `src/harness/types.ts`: added `'text'` to `HarnessEventType` and exported `TextEventData { readonly text: string }`.
- `src/harness/opencode.ts`: in `processOpencodeStdoutLine`, a completed `type === 'text'` event now extracts `part.text ?? eventObj.text` and, when non-empty, appends `{ type: 'text', timestamp: resolveEventTimestamp(eventObj), data: { text } }`. Whole text parts only; tool/step_finish branches untouched.
- `src/harness/agy.ts`: in `processAgyStdoutLine`, an `event === 'result'`/`result` payload now extracts `result.response` and, when non-empty, appends a `text` event via `resolveAgyTimestamp`. Partial `text_delta` fragments from `step_update` are still only used for tokens and are never persisted as text.
- `src/watcher/runner.ts`: `extractFinalTextFromStream` now reads exclusively `event.type === 'text'` and `event.data.text` (last non-empty wins). Deleted the private `extractTextFromStreamEvent` helper and its 10-shape candidate list, plus the now-unused local `asRecord` helper.
- `tests/runner-synthesized-result.test.ts`: removed the `NoResultStubAdapter` mock. Added real-`AgyAdapter`/real-`OpencodeAdapter` cases that spawn on-disk fake harness binaries (`fake-agy.mjs`, `fake-opencode.mjs`) and assert a single completed `text` event, that no `text_delta`/partial fragment becomes a text event, and that exit 0 with no result file synthesizes `results/1.md` with `synthesized: true` frontmatter, writes `result_written`, runs verify, and writes `done/1`. Added a real-adapter `no_result` case against a silent fake opencode binary, a type/import assertion for `HarnessEventType`/`TextEventData`, and a fallback-dropped test proving raw payload shapes are ignored.

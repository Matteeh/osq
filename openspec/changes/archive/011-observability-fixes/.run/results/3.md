# Task 3 result: already_running lock collision no longer records a dead event

## Changed

- `src/watcher/runner.ts`:
  - In `runTask`, the `!lockResult.acquired` branch no longer calls `recordDeadEvent(specFolderPath, taskNumber, 'already_running')`.

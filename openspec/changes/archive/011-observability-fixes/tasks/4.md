## Acceptance
- [ ] extractOpencodeTokens extracts reasoning tokens from tokens.reasoning or tokens.reasoningTokens
- [ ] extractAgyTokens extracts reasoning tokens from usage.thinking_tokens or usage.reasoning_tokens
- [ ] Both adapters include reasoningTokens on emitted tokens event data
- [ ] report.ts reads reasoningTokens from tokens events and aggregates into TokenMetrics reasoning
- [ ] report.ts prefers adapter reported cachedTokens over total - input - output - reasoning remainder
- [ ] report.ts uses remainder derivation strictly when no cache field exists on the event

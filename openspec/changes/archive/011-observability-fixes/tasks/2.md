## Acceptance
- [ ] HarnessEventType union in src/harness/types.ts includes text with data payload containing text: string
- [ ] OpencodeAdapter extracts completed assistant text from stdout and appends a text event to events.jsonl
- [ ] AgyAdapter extracts completed assistant response from result payload and appends a text event to events.jsonl
- [ ] Neither adapter emits partial text_delta stream fragments as text events
- [ ] Runner extractFinalTextFromStream reads exclusively from text events and drops the 10-shape fallback candidate list
- [ ] When an agent exits 0 with no result file, the runner synthesizes results from the last text event
- [ ] Test runs real adapters against fake harness binaries asserting text emission and synthesis without mock adapters

## Signatures

In `src/harness/types.ts`:

```ts
export type HarnessEventType =
  | 'started'
  | 'tokens'
  | 'tool'
  | 'text'
  | 'file_changed'
  | 'verify_ran'
  | 'result_written'
  | 'exited'
  | 'done'
  | 'dead';

export interface TextEventData {
  readonly text: string;
}
```

In `src/watcher/runner.ts`:

```ts
export async function extractFinalTextFromStream(
  specFolderPath: string,
  taskNumber: string,
): Promise<string | null>;
```

## Details

1. In `src/harness/types.ts`, add `'text'` to `HarnessEventType` and export `TextEventData`.
2. In `src/harness/opencode.ts`:
   - In `processOpencodeStdoutLine`, when `eventObj.type === 'text'`, extract `part.text ?? eventObj.text`.
   - If non-empty, append `{ type: 'text', timestamp: resolveEventTimestamp(eventObj), data: { text } }` to `events.jsonl`.
3. In `src/harness/agy.ts`:
   - In `processAgyStdoutLine`, when `eventObj.event === 'result'` or `eventObj.result`, extract `result.response`.
   - If non-empty, append `{ type: 'text', timestamp: resolveAgyTimestamp(eventObj), data: { text: response } }` to `events.jsonl`.
   - Partial `text_delta` fragments from `step_update` are not emitted as text events.
4. In `src/watcher/runner.ts`:
   - In `extractFinalTextFromStream`, iterate through lines in `.run/events/<n>.jsonl`. For each parsed event with `type === 'text'`, read `event.data?.text`.
   - Return the last non-empty string, or `null` if none found. Drop `extractTextFromStreamEvent`'s 10-shape fallback candidate list.
5. In `tests/runner-synthesized-result.test.ts`:
   - Add end-to-end tests running `OpencodeAdapter` and `AgyAdapter` against fake harness binaries that output JSON stdout lines including assistant text and result responses.
   - Assert that `text` events are appended to `events.jsonl` and that result files are synthesized with `synthesized: true` frontmatter when the result file is missing.
   - Invariant: A mock-only test is a verify failure.

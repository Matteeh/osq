## Decisions / deviations

- `firstAttemptPassRate` is a 0–1 fraction rounded to two decimals. The field is
  named a rate; the spec did not fix a percent form.
- A size observation of 0 maps into the `1-2` bucket (bucket function is
  `<=2 -> 1-2`). The spec lists only positive-labelled ordered buckets.
- `formatMetricsReport` gained an optional second `OsqConfig` parameter
  (defaults to `DEFAULT_CONFIG`) so existing callers keep working; the CLI passes
  the loaded config explicitly.
- `formatRepositoryRecordBody` deliberately does not print the measured task
  count, since the cli-foundation section is limited to pass rate, dead rows,
  largest pass, and median duration; the record object still carries
  `measuredTasks` for the too-small gate and task 2.

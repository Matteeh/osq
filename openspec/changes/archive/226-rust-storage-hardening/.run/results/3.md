## Changed

- `read/text.rs`: `frontmatter_string` and `markdown_body` now call `osq_kernel_specs::parse_frontmatter`. An `Err` reads as no frontmatter key and the whole text as the body; `markdown_body` still returns the borrowed suffix by subtracting the parsed body's length. Removed `frontmatter_yaml`, `valid_frontmatter`, `match_frontmatter`, `strip_newline` and the `YamlLoader` import; the `yaml_rust2::Yaml` import stays for the key lookup.
- `read/manual.rs`: `parse_record` reads `kept_at`, `paths` and `capabilities` from the `Frontmatter.data` mapping `parse_frontmatter` returns, and an `Err` yields no record.
- Added `tests/reading_frontmatter.rs` with one test per row of rust-storage "Frontmatter the specs kernel refuses" and one that walks every `.rs` under `src` and finds `YamlLoader` only in `read/snapshot/events.rs`.

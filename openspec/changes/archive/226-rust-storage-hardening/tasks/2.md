## Acceptance

- [ ] New `read/snapshot/manifest.rs` holds a crate-private `Manifest` struct that derives `serde::Deserialize`, with camelCase names and the fields and types of rust-storage "Manifest file". Every field is optional and defaults when missing, and unknown keys are ignored. `approvalFlags` and `notices` are their own small structs. The `items` entries and `opened` entries of `notices` stay `serde_json::Value`, so the tolerant filtering of "Manifest notices" still applies to them. `crates/kernel/storage/Cargo.toml` adds `serde.workspace = true`.
- [ ] `read_manifest` in `read/snapshot/folder.rs` returns `Result<Option<Manifest>, StorageError>`. A missing file is `Ok(None)`. Another read failure is `StorageError::Read` with the path. A text that does not deserialize is the new `StorageError::Manifest { path, source }`, where `source` is the `serde_json::Error`. Its `Display` writes `<path>: <source>`, and its `source()` returns the serde error.
- [ ] `approved_at`, `read_planner` and `manifest_notices` take `Option<&Manifest>` and give the same values as today for every manifest that reads. `read_change` propagates the manifest error with `?`, and its `# Errors` doc names `StorageError::Manifest`.
- [ ] New `tests/reading_manifest.rs` proves rust-storage "Manifest files read or refused", one assertion per table row. It writes each case's change folder, holding only `.run/manifest.json` or a directory at that path, under `env!("CARGO_TARGET_TMPDIR")`, and reads it with `read_change` as an active `ChangeEntry`. It also checks one `StorageError::Manifest` error's `source()` is some.
- [ ] Each test has a one-line doc naming `Covers: rust-storage/manifest-files-read-or-refused`, and has no `#[ignore]`.

## Details

The history fixture's `001-run` manifest holds notice items `{"id":7,...}`
and `"junk"` and an opened entry `3`. They stay valid JSON values inside the
typed `notices` and are dropped by the existing filters, so
`reading_history.rs` stays green unchanged. Keeping the TypeScript names
needs `#[serde(rename_all = "camelCase")]`. `planner` and `effort` are
`Option<String>`, so `null` and a missing key both read as none. The archive
corpus tests read every archived manifest, so `sh scripts/verify-rust.sh`
proves that each one reads. Adding `serde` to storage only changes storage's
dependency list in `Cargo.lock`.

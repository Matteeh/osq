## Deviated

The "one gate definition" source check matches the import specifier against the
three shapes named in the task (`../core/run/test-gate.js`,
`../run/test-gate.js`, `./test-gate.js`) rather than only a path ending in
`run/test-gate.js`. `task-commit.ts` lives in `run/`, so its literal specifier
is `./test-gate.js`, which the acceptance's regex wording would have rejected
while the task's own import guidance requires it.

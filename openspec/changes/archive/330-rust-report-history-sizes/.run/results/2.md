## Changed

Ported the rest of `report`'s History section into new report modules:

- `blocks.rs` gathers rework from `read_change_fixes`, disclosures from `read_result_disclosures` and dependencies from `read_dependencies_added`, over every non-rejected entry, and writes both the text blocks and their conditional JSON members.
- `sizes.rs` measures every non-rejected entry with `read_task_sizes`, buckets tasks by acceptance lines and by scope files for the legacy and resolver-2 series, selects `startsAtChange` and each largest first-attempt pass, and writes the `history.sizes` JSON member.
- `sizes_text.rs` writes the three size tables, the resolver-2 start line and the size hint from the config limits.
- `order.rs` holds the shared leading-number ordering the blocks and sizes use.
- `js_number` now also writes JavaScript number text for the tables and their JSON values.
- `mod.rs`, `output.rs` and `history_json.rs` build the new values and append or insert them.

Copied the new `sizes-project` fixture and TypeScript's new goldens, added the `sizes-project` row to `report_summary.rs`, and added `report_sizes.rs` with the four scenario tests plus a numeric-order case across digit lengths.

`cargo fmt --all`, the task verify and `OSQ_CHANGE=openspec/changes/330-rust-report-history-sizes sh scripts/verify-rust.sh` pass. Targeted cargo-mutants over `blocks.rs`, `sizes.rs`, `sizes_text.rs` and `order.rs` reports every mutant caught (135 caught, 8 unviable).

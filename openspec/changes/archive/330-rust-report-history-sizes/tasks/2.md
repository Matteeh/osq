## Details

Port the rework, disclosures, dependencies and sizes parts of
`buildMetricsReport` and `formatMetricsReport` in `src/core/report/report.ts`,
from `const rework = await collectRework` and from `formatRework`,
`formatDisclosures`, `formatDependencies` and the size lines after the
`    Requeued for agent:` line, through the `  Size hint:` line. The JSON
members follow `toStableMetrics` in `src/cli/report.ts`, which leaves
`rework`, `disclosures` and `dependencies` out when they are empty. Never
read anything under `src/` from Rust; it is in `entry` only so you can
port it.

The History text and JSON now grow by several blocks. Put the blocks and
the size tables in new modules, such as one for the three blocks and one
for the sizes, and keep `history_text.rs` and `history_json.rs` small.
Write every number with `js_number`, which writes numbers as JavaScript
does. `round2` must round a half up, as `Math.round` does; Rust's
`f64::round` rounds a half away from zero, which differs for negative
values only, and no value here is negative. The median text is
TypeScript's `formatDuration` of the rounded seconds times 1000.

The old `report_summary.rs` table gains one row, and its goldens now run
through the end of History. Keep the rest of the file as it is.
`report_history.rs` passes unchanged. "Size hints" writes an `osq.toml`
holding only a `[limits]` table into its copy.

When the mutation check reports a missed mutant, add a test case for that
line rather than keeping a branch no test reaches. Take its expected value
from the TypeScript source. Run the proposal's verify as the watcher does,
with `OSQ_CHANGE=openspec/changes/330-rust-report-history-sizes`, so the
link gates see this change's new requirements.

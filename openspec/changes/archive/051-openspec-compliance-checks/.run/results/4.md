## Changed

- Added `.github/workflows/openspec-latest.yml` named `OpenSpec latest`. It
  triggers on a weekly `schedule` cron (`0 6 * * 1`) and `workflow_dispatch`,
  with one `differential` job that repeats the `ci.yml` checkout, pnpm,
  setup-node (Node 24), and `pnpm install --frozen-lockfile` steps, then installs
  `@fission-ai/openspec@latest` under `$RUNNER_TEMP/openspec-latest` with
  `npm install --prefix` (lockfile untouched), prints its version via
  `"$RUNNER_TEMP/openspec-latest/node_modules/.bin/openspec" --version`, and runs
  `node --import tsx --test tests/openspec-differential.test.ts` as the last step
  with `OSQ_OPENSPEC_BIN` pointing at that binary and `OPENSPEC_TELEMETRY: '0'`.
- Added `tests/openspec-latest-workflow.test.ts`, which parses the workflow with
  the `yaml` package and asserts every acceptance line, including the single job,
  the repeated `ci.yml` steps, the ordering of install/print/test, that
  `OSQ_OPENSPEC_BIN` and `OPENSPEC_TELEMETRY` are set on the last step, and that
  no step runs `pnpm add`, `pnpm update`, a non-frozen `pnpm install`, or an
  `npm install` without `--prefix`.

- `tests/cut-over.test.ts`

    expects `specs:`/`archive:` keys in `config.ts`; it now asserts those keys are
    absent and that `openspecRoot: 'openspec'` is present (keeping the legacy

  - Imported `getArchiveDir`; the successful-execution archive assertion now

  - Imported `getArchiveDir`; both archive assertions in `runWatcherOnce` tests
    resolve through `getArchiveDir(DEFAULT_CONFIG.paths.openspecRoot, tmpDir)`.

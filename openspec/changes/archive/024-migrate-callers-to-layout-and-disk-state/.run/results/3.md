# Task 3 — archiving/diagnostics modules use canonical layout

## Changed

- `src/watcher/archiver.ts`
  - Imported `getArchiveDir` from `../core/layout.js`.
  - `archiveSpecFolder` now resolves its destination with
    `getArchiveDir(config.paths.openspecRoot, projectRoot)` instead of
    `path.join(projectRoot, config.paths.archive)`. Updated the doc comment to
    name the canonical `<openspecRoot>/changes/archive`.
  - `checkAndArchiveSpec` already called the overloaded
    `deriveSpecState(projectRoot, specFolderPath)` (the disk-backed overload
    delegating to `deriveSpecStateFromDisk`); left as-is and covered by tests.
- `src/core/doctor.ts`
  - Imported `getArchiveDir` and `getChangesDir` from `./layout.js`.
  - `validConfig` now validates `config.paths.openspecRoot` instead of the removed
    `paths.specs`/`paths.archive`.
  - `checkLocks` scans only `getChangesDir(config.paths.openspecRoot, projectRoot)`
    (dropped the legacy `specs/` root and the now-single-element `Set` dance).
  - `checkArchives` scans only `getArchiveDir(config.paths.openspecRoot, projectRoot)`
    (dropped the legacy `specs/archive` root).
- `src/core/migrate.ts`
  - Imported `getArchiveDir` and `getChangesDir` from `./layout.js`.
  - `resolvePaths` no longer reads `config.paths.specs`/`config.paths.archive`.
    Legacy sources are the fixed `specs/` and `specs/archive/` directories; targets
    are `path.join(projectRoot, config.paths.openspecRoot, 'specs')`,
    `getChangesDir(...)`, and `getArchiveDir(...)`.
  - Removed the now-unused `OPENSPEC_DEFAULT_ROOT` export and `resolveOpenSpecRoot`
    helper (only this module referenced either).
- `tests/archiver.test.ts`
  - Imported `getArchiveDir`; `openSpecConfig()` now returns `DEFAULT_CONFIG`
    (openspecRoot is part of `OsqPaths`).
  - All archive assertions resolve through
    `getArchiveDir(DEFAULT_CONFIG.paths.openspecRoot, tmpDir)`.
  - Replaced the removed-config "legacy archive path" test with one asserting a
    custom `openspecRoot` still derives via `getArchiveDir`; removed the duplicate
    legacy `checkAndArchiveSpec` test.
- `tests/doctor.test.ts`
  - Added a config test (`openspecRoot` not a string fails the config check).
  - Added a test proving corrupt contents under legacy `specs/archive` are ignored,
    so the archives check is anchored to `getArchiveDir`.

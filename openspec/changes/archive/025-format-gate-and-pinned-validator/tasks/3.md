## Details

1. In `templates/openspec/schemas/osq/schema.yaml`:
   - Under `artifacts:` -> `id: tasks`:
     Update `instruction:` to explicitly instruct:
     "Tasks are executed ONLY by osq watch after human approval. Archiving is owned exclusively by osq and NEVER openspec archive. Checkboxes in tasks.md are strictly written by the osq runner as a write-only projection of runtime verification. Agents MUST NOT execute tasks directly or edit checkboxes in tasks.md, preventing bypass of the approval hash."
   - Under `apply:`:
     Update `instruction:` to explicitly instruct:
     "Tasks in osq are executed strictly by running osq watch. Do not execute tasks directly, do not edit tasks.md checkboxes, and never run openspec archive or openspec apply. Task checkboxes are updated automatically by the runner upon passing independent verification."
2. In `templates/openspec/config.yaml`:
   - Update `context:` and `rules:` to state that task execution is performed exclusively by `osq watch`, archive is osq-owned, and checkboxes in `tasks.md` are write-only runner projections.
3. In `templates/openspec/schemas/osq/README.md`:
   - Add clear documentation on execution authority: agents with OpenSpec skills must delegate execution to `osq watch`.
4. Create `tests/schema-instructions.test.ts`:
   - Assert `schema.yaml` contains "executed only by osq watch" (or equivalent), "never openspec archive", and "written by the runner".

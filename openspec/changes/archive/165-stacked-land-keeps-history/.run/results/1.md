## Changed

- `src/core/vcs/vcs.ts`: added `mergeBase(a, b)`, `trailerValues(from, to, key)`, and the optional fifth `extraParents` argument on `commitTree` to the `Vcs` interface.
- `src/core/vcs/git-vcs-read.ts` (new): moved the bodies of `root`, `head`, `indexDigest`, `stashList`, `status`, `show`, and `pathExists` here, each taking a `GitWriteContext`; `GitVcs` keeps one-line delegations to them.
- `src/core/vcs/git-vcs.ts`: delegates those reads to `git-vcs-read.ts`, delegates `mergeBase`/`trailerValues` to `git-vcs-merge.ts`, and forwards `extraParents` to `commitTree`. 242 lines.
- `src/core/vcs/git-vcs-land.ts`: `commitTree` takes `extraParents` and passes `-p parent` then one `-p <commit>` per extra parent, in order; added `@scenario`/`@adr 003` tags.
- `src/core/vcs/git-vcs-merge.ts`: added `mergeBase` (one `git merge-base <a> <b>`, null on failure) and `trailerValues` (one `git log <from>..<to>` with a `%x1e`/`%x1f`-separated `%(trailers:key=...,valueonly,...)` format), bounded by `ctx.run`; added `@scenario`/`@adr 003` tags.
- `src/core/vcs/no-vcs.ts`: `mergeBase` returns null, `trailerValues` returns an empty list, and `commitTree` accepts the optional `extraParents` argument.
- `tests/vcs-write.test.ts`: `PORT_MEMBERS` gains `mergeBase` and `trailerValues`.
- `tests/vcs-history-ops.test.ts` (new): temporary-repository tests for "Vcs history reads" (merge base, trailer values, NoVcs) and "Commit with extra parents" through `GitVcs` and `NoVcs`, with expected values from the scenario THEN lines.

Touched: src/core/vcs/vcs.ts, src/core/vcs/git-vcs.ts, src/core/vcs/git-vcs-read.ts, src/core/vcs/git-vcs-land.ts, src/core/vcs/git-vcs-merge.ts, src/core/vcs/no-vcs.ts, tests/vcs-write.test.ts, tests/vcs-history-ops.test.ts

## Acceptance
- [ ] src/core/layout.ts exports resolvers for changes, tasks, .run, done, dead, and events
- [ ] All layout helpers derive paths starting from openspecRoot
- [ ] OsqPaths in src/core/config.ts removes specs and archive properties while keeping openspecRoot
- [ ] DEFAULT_CONFIG.paths defines openspecRoot defaulting to 'openspec'
- [ ] tests/layout.test.ts asserts deterministic path derivation from openspecRoot
- [ ] tests/config.test.ts passes with updated OsqPaths schema
- [ ] src/core/layout.ts stays under 200 lines

## Details

1. Create `src/core/layout.ts`:
   - Export path helper functions that accept `openspecRoot` (and optional `projectRoot`):
     - `getChangesDir(openspecRoot: string): string` -> `${openspecRoot}/changes`
     - `getArchiveDir(openspecRoot: string): string` -> `${openspecRoot}/changes/archive`
     - `getSpecsDir(openspecRoot: string): string` -> `${openspecRoot}/specs`
     - `getChangeRunDir(changeFolder: string): string` -> `${changeFolder}/.run`
     - `getChangeTasksDir(changeFolder: string): string` -> `${changeFolder}/tasks`
     - `getDoneMarkerPath(changeFolder: string, task: string): string` -> `${changeFolder}/.run/done/${task}`
     - `getDeadMarkerPath(changeFolder: string, task: string): string` -> `${changeFolder}/.run/dead/${task}.md`
     - `getEventsPath(changeFolder: string, task: string): string` -> `${changeFolder}/.run/events/${task}.jsonl`
   - Ensure the module is under 200 lines.
2. In `src/core/config.ts`:
   - Update `OsqPaths`: remove `specs` and `archive`. Keep `openspecRoot`, `features`, `decisions`, and `templates`.
   - Update `DEFAULT_CONFIG.paths` to reflect the removed properties and retain `openspecRoot: 'openspec'`.
3. In `src/core/init.ts`:
   - Replace any references to `config.paths.specs` or `config.paths.archive` with `src/core/layout.ts` resolvers.
4. Create `tests/layout.test.ts`:
   - Test every helper in `src/core/layout.ts` against relative and absolute root paths.
5. In `tests/config.test.ts`:
   - Update assertions to verify that `paths.openspecRoot` is present and default, and that `paths.specs` is no longer part of `OsqPaths`.
6. Verification:
   - Run `node --import tsx --test tests/layout.test.ts tests/config.test.ts`.

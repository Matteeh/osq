  `getChangesDir`, `getArchiveDir`, `getSpecsDir` (each `(openspecRoot, projectRoot = '')`),
  `getChangeRunDir`, `getChangeTasksDir`, `getDoneMarkerPath`, `getDeadMarkerPath`, and
  `getEventsPath`. All join through a single `openspecRoot`/`changeFolder` root via

  derivation, determinism, root tracking, and the module's <200-line budget.
- `tests/config.test.ts`: dropped `paths.specs`/`paths.archive` assertions; asserts
  `openspecRoot === 'openspec'` and that `specs`/`archive` are absent from `OsqPaths`
  instances.

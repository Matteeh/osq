# Tasks

## 1. Lookup, header and status

- [x] 1. When a human runs show with an id, the Rust show feature finds the change and prints TypeScript's header, goal, contract and task lines with the right status and next step

## 2. Section seams

- [x] 2. When show builds its text, every later section is a function of the change that today returns no lines, called where TypeScript prints it

## 3. Run history

- [x] 3. When a change has run, show prints each task's run lines and the event timeline as TypeScript does

## 4. Approval digest

- [x] 4. When a change is unapproved, show prints its planning sessions and TypeScript's approval digest without flags
- [x] 5. When an unapproved plan has risks, show's digest prints TypeScript's flag lines

## 5. Archived changes

- [x] 6. When a change is archived, show prints TypeScript's verification, validation, recertifications and land view, and every golden matches

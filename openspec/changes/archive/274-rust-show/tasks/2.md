died blocked: the run, digest
and archived sections were constants that no later task could make depend on
the change, and tasks 3, 4 and 6 may not edit `text.rs`, `tasks.rs` or
`header.rs`. The previous result file for task 2 belongs to that run-history
task, now task 3.

Write every stub body as exactly `vec![]`. cargo-mutants skips a
replacement equal to the body, and the existing outline and whole-text
tests catch the replacements that add a line. Do not compose stubs inside
another stub. A function whose result is only other empty stubs leaves a
missed mutant.

fills `archived/section.rs`, each with further modules under its
`section/` folder. Leave `events.rs` and `planning.rs` alone. They read
the change folder through `change.path` from task 3 and task 4 on.

Name each new item's doc after what it will print. Private items need
only one doc line. Run the proposal's verify with
`OSQ_CHANGE=openspec/changes/274-rust-show`.

## Details

Keep event `data` keys in file order with a small ordered `Deserialize`
in the crate that collects `(key, serde_json::Value)` pairs. Do not turn on
serde_json's `preserve_order` feature. JavaScript's `String()` prints an
object as `[object Object]`, joins an array's items with `,` with `null`
inside as empty, prints `null` as `null`, and prints numbers without a
trailing `.0`. Task 1 already prints the `Disclosures:` line.

Never name a file `section.rs` directly under `src/events/`: task 2's scope
claims every `src/*/section.rs`.

Write the test's fixture copy as `tests/show_outline.rs` does, including the
running marker. Never read anything under `src/` from Rust. If cargo-mutants
reports a missed mutant on a branch no golden reaches, add a test on a
scratch folder whose expected text you read from the TypeScript source. Run
the proposal's verify with `OSQ_CHANGE=openspec/changes/274-rust-show`.

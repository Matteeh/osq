## Details

With vcs off, the land view starts `Land: git is off`, then lists the gates at
archive, the spec changes and the disclosures. Durations round as TypeScript's
`formatDuration` does.

Write each test's fixture copy as `tests/show_runs.rs` does, including the
running marker. Never read anything under `src/` from Rust. If cargo-mutants
reports a missed mutant on a branch no golden reaches, add a test on a
scratch folder whose expected text you read from the TypeScript source. Run
the proposal's verify with `OSQ_CHANGE=openspec/changes/274-rust-show`.

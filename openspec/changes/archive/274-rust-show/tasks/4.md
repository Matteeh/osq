## Acceptance

- [ ] `src/planning.rs` and `src/planning/**` read `.run/plan.jsonl` and print the `Planning Sessions:` section as TypeScript does, durations included.
- [ ] `digest::lines` in `src/digest/section.rs`, with any modules under `src/digest/section/`, prints the approval digest of an unapproved change as `buildApprovalDigest` and its format do: the goal, the steps before approval, tasks with their scope file counts and `tests.modify` lines, capabilities, decisions and human steps. An approved change prints no digest.
- [ ] Flags come from `src/digest/section/flags.rs`, declared in `src/digest/section.rs`, which returns no flag lines here with the body `vec![]`; task 5 replaces it. The digest test compares every digest line but the `Flag:` lines, so a mutant that adds a line there fails it.
- [ ] Only these files change. `src/text.rs` already calls `planning::section` and, last, `digest::lines` (task 2); both read the change folder through `change.path`. The digest takes the project root as that path's third ancestor for an active change and its fourth for an archived or rejected one, from `change.location`.
- [ ] A new `tests/show_digest.rs` proves "Show approval digest" in one test whose doc names `Covers: rust-show/show-approval-digest`. Every public item ends its doc with `Implements: rust-show/<requirement>`.
- [ ] `cargo fmt --all` then the proposal's verify pass.

## Details

Count scope files with the loop kernel's `scope_files`. It keeps an exact
entry, and a pattern that matches nothing, as itself, so keep only paths
that exist, as TypeScript counts. Read decisions with the specs kernel's
`read_decisions` and deltas with `parse_delta`.

Never name a file `section.rs` directly under `src/planning/`: task 2's
scope claims every `src/*/section.rs`.

Write the test's fixture copy as `tests/show_outline.rs` does. Never read
anything under `src/` from Rust. If cargo-mutants reports a missed mutant on
a branch no golden reaches, add a test on a scratch folder whose expected
text you read from the TypeScript source. Run the proposal's verify with
`OSQ_CHANGE=openspec/changes/274-rust-show`.

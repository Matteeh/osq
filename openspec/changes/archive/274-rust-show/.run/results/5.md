## Changed

- `crates/features/show/src/digest/section/flags.rs` now builds TypeScript's `Flag:` lines in its fixed order and formats each as `Flag: <label> — <excerpt>`.
- `flags/tasks.rs` reads each task's verify, `verify_starts`, scope, resolved paths and `tests.modify`, with TypeScript's task-number ordering.
- `flags/sensitive.rs` emits shared-file flags and the sensitive-kind flags for manifests, lockfiles, CI workflows, osq and OpenSpec config, managed instructions and env files.
- `flags/verify.rs` emits verify-without-a-test flags using TypeScript's test-file, test-folder and runner rules, and verify-starts conflicts for the paths a verify names.
- `flags/paths.rs` tokenizes verify commands, resolves scope paths as TypeScript does, recognizes named path operands, and decides missing paths and named-path coverage.
- `flags/capabilities.rs` emits removed-requirement and unknown-capability flags, reusing the digest's capability rows and resemblance rule.
- `flags/decisions.rs` emits ADR departure flags in section order followed by check-modification flags for accepted ADRs.
- `crates/features/show/tests/show_flags.rs` proves the whole `1` and `007` outputs, then covers every sensitive kind, operand and verify-start rule, verify-without-a-test rule and task-number ordering on scratch projects.

## Deviated

- Added scratch-project tests beyond the one golden test, as the task allows, so cargo-mutants on every changed flags line reports no missed mutant.
- `flags.rs` does not call `model::placeholder::is_placeholder`: TypeScript's `buildApprovalFlags` never consults the planning sentinel, and the `007` golden expects its sentinel verify to be flagged. Calling it here would diverge from TypeScript.

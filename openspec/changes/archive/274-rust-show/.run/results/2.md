## Changed

- `src/model.rs`: `Change` gained `path`, the change folder's path from `Found`, and `placeholder` is now declared `pub(crate) mod placeholder;` so task 5 can call `is_placeholder`.
- `src/runs.rs`, `src/digest.rs`, `src/archived.rs`: each now holds only `mod section;` and a `pub(crate) use` of its section functions. The `LINES`, `VERIFICATION`, `VALIDATION`, `RECERTIFICATIONS` and `LAND` constants are gone.
- Added `src/runs/section.rs` (`task_lines(change, task)`), `src/digest/section.rs` (`lines(change)`) and `src/archived/section.rs` (`verification`, `validation`, `recertifications`, `land`, each taking `&Change`), every body exactly `vec![]`.
- `src/tasks.rs`: `task_lines(change, task)` now calls `runs::task_lines(change, task)` between the `Verify:` line and the `Disclosures:` line.
- `src/header.rs`: the header calls `archived::verification(change)` between `Next:` and `After landing:`.
- `src/text.rs`: builds the text in TypeScript's `formatShowText` order: header, goal, contract, tasks, `archived::validation`, `planning::section`, `archived::recertifications`, `events::section`, `archived::land`, then `digest::lines`.

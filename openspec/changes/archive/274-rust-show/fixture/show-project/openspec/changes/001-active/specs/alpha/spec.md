## ADDED Requirements

### Requirement: Alpha counts
Alpha SHALL count its calls.

#### Scenario: Alpha counts
- **WHEN** alpha is called twice
- **THEN** its count is two

## MODIFIED Requirements

### Requirement: Alpha starts
Alpha SHALL start at zero and count from there.

#### Scenario: Alpha starts
- **WHEN** alpha starts
- **THEN** its count is zero

## REMOVED Requirements

### Requirement: Alpha sleeps
**Reason**: alpha no longer sleeps.

## Changed

- Added `crates/features/run/src/feature/pause.rs` with a pure pause-file
  content function and a write that creates `.run/` when missing.
- Added the named `USAGE_LIMIT_WAIT` constant (1800 seconds) to the run's
  runner settings, and made the `RunOutcome::Paused` arm of `start::run` write
  `.run/paused.md` before failing with the existing usage-limit text.
- Added the executable fake pi at
  `crates/features/run/tests/fixtures/limit-pi/run.sh`.
- Added `crates/features/run/tests/run_usage_pause.rs`, proving the "Paused on a
  usage limit" scenario over two runs: events, attempt 1 both times, pause file
  bytes, rust-storage read back, no exited/retry/recertification event, and no
  dead, done or running marker. It also covers the default body and creating a
  missing `.run/`.
- `cargo test -p osq-feature-run --test run_usage_pause --test run_outcomes
  --test run_attempts` passes. The proposal's
  `OSQ_CHANGE=openspec/changes/293-rust-run-usage-pause sh scripts/verify-rust.sh`
  passes. A manual `cargo mutants` run over the two changed source files caught
  every viable mutant.

Touched: crates/features/run/src/feature/pause.rs, crates/features/run/src/feature.rs, crates/features/run/src/feature/start.rs, crates/features/run/tests/run_usage_pause.rs, crates/features/run/tests/fixtures/limit-pi/run.sh

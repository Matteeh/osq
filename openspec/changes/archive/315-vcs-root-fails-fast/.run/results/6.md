## Changed

- `crates/features/show/src/facts.rs`: `read` now decides git through a
  `git_root` helper that calls rust-vcs `project_git_root`; a `NestedRoot`
  maps to `show failed: <display>`, and the old local root comparison and
  `real` helper are gone. Show still reads git with `vcs.enabled` off, as its
  land lines did before, by asking `project_git_root` with an enabled copy of
  the config and treating a nested answer as git off.
- `crates/features/report/src/report/mod.rs`: `run` calls `project_git_root`
  right after `load_config` and maps a `NestedRoot` to `report failed:
  <display>`, passing the folder on to the entries reader.
- `crates/features/report/src/report/entries.rs`: `entries` takes that folder
  instead of running its own git root check; the local comparison and `real`
  helper are gone.
- `crates/features/inbox/src/read.rs`: `changes` calls `project_git_root` right
  after `load_config` and maps a `NestedRoot` to `inbox failed: <display>`;
  `stacked_folders` now takes the kernel's folder instead of asking git for the
  root itself.
- Added `crates/features/show/tests/show_nested_root.rs`,
  `crates/features/report/tests/report_nested_root.rs` and
  `crates/features/inbox/tests/inbox_nested_root.rs`. Each builds its own
  `<outer>` repository under `CARGO_TARGET_TMPDIR`, runs its crate's row
  through `Feature::run` on `<outer>/sub`, checks the full refusal message,
  and checks that `<outer>`'s status, branches, worktrees and files outside
  `.git` are unchanged.
- Changed `show_git_on_requires_the_repository_root` in
  `crates/features/show/tests/show_land.rs` and
  `report_git_off_below_the_repository_top` in
  `crates/features/report/tests/report_trees.rs` to expect the nested-root
  refusal instead of the old git-off behaviour.
- Ran `cargo fmt --all`, the task verify, every `osq-feature-show`,
  `osq-feature-report` and `osq-feature-inbox` test, and the proposal verify
  with `OSQ_CHANGE=openspec/changes/315-vcs-root-fails-fast`; all pass. A
  cargo-mutants run over the changed source lines found 11 mutants: 7 caught,
  4 unviable, none missed.

## Deviated

- Show keeps its living "Show git state" behaviour with `vcs.enabled` off:
  it reads git when the root is a repository's top level, because its land
  goldens depend on that, while the normal `project_git_root` call returns
  `Ok(None)` in that case. The helper therefore calls `project_git_root` with
  an enabled config copy and maps a nested answer to git off, which keeps the
  old quiet fallback and still runs no git when `vcs.enabled` is off and the
  root is outside a repository.
- No `OSQ_DIFF` was available outside the watcher, so I reconstructed the
  pre-change source of the four changed source files, wrote a unified diff of
  only this task's changed lines, and ran `scripts/mutants-rust.sh` on it.

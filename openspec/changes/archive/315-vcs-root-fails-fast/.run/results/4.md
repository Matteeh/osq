## Changed

- `crates/features/archive/src/archive.rs`: after `load_config`, `archive` calls
  rust-vcs `project_git_root` and maps a `NestedRoot` to `archive failed:
  <display>`; the result decides whether the lookup reads worktrees.
- `crates/features/archive/src/lookup.rs`: `find` takes the kernel's git answer
  instead of reading `config.vcs.enabled`, so a root the kernel gives no folder
  for lists only the checkout's changes.
- `crates/features/retry/src/retry.rs`: `retry` now loads `osq.toml` and calls
  `project_git_root` before it lists changes, mapping a `NestedRoot` to `retry
  failed: <display>`, and passes the kernel's result on.
- `crates/features/retry/src/retry/find.rs`: `find_archived` no longer loads the
  config or runs its own `GitVcs::root` check; it takes the config and the
  kernel's git folder, so a nested root never reaches worktree listing.
- `crates/features/run/src/feature/worktree.rs`: `git_on` is now
  `project_git_root(root, config).is_some()`; its own git-root comparison is
  gone.
- `crates/features/run/src/feature/refusals.rs`: `check` asks `git_on` once and
  passes the answer to `find_change`; the old canonical root comparison is
  replaced by `has_repository`, which asks `project_git_root` for the tree root
  with `vcs.enabled` forced on so run's "needs a git repository" refusal still
  holds when git is configured off.
- Added `crates/features/archive/tests/archive_nested_root.rs`,
  `crates/features/retry/tests/retry_nested_root.rs` and
  `crates/features/run/tests/run_nested_root.rs`. Each builds its own `<outer>`
  repository under `CARGO_TARGET_TMPDIR`, runs the crate's row through
  `Feature::run` on `<outer>/sub`, checks the `NestedRoot` display, and checks
  that `<outer>`'s status, branches, worktrees and files outside `.git` are
  unchanged.
- Ran `cargo fmt --all`, the task verify, the three crates' full test suites,
  `cargo clippy` with `-D warnings`, and the proposal verify with
  `OSQ_CHANGE=openspec/changes/315-vcs-root-fails-fast`; all pass. A
  cargo-mutants run over the changed source lines found 15 mutants: 11 caught,
  4 unviable.

## Deviated

- Run keeps its "Rust run needs a git repository at `<root>`" refusal when
  `vcs.enabled` is off by asking `project_git_root` with a copy of the config
  whose `vcs.enabled` is true. The living run refusal applies with git off too
  and `run_refusals`'s "outside git" row must pass unchanged; the real call
  would answer `Ok(None)` without running git in that case.
- No `OSQ_DIFF` was available outside the watcher, so I reconstructed the
  pre-change source of the six changed source files, wrote a unified diff of
  only this task's changed lines, and ran `scripts/mutants-rust.sh` on it.

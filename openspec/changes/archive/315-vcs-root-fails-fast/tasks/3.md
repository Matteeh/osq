## Details

Map the `NestedRoot` to `FeatureError::failed` with the command's own
name, `approve` or `reject`, and its display. Run the commands through
`ApproveFeature`'s `Feature::run` with an `Invocation` on `<outer>/sub`,
as the crate's other feature tests do. Snapshot `<outer>`'s git state
with the git CLI in the test, with `GIT_CONFIG_GLOBAL=/dev/null` and
`GIT_CONFIG_NOSYSTEM=1`.

Run the proposal's verify with
`OSQ_CHANGE=openspec/changes/315-vcs-root-fails-fast`, so the link gates
see this change's requirements.

- rust-vcs: Every git command refuses a nested root

## Acceptance

- [ ] `selectVcs` throws a new exported `NestedRootError`, with the message version-control "Vcs selection" gives, when `config.vcs?.enabled` is true and the real project root differs from git's real top level; with `vcs.enabled` off it still returns `NoVcs` with reason `not the repository root`.
- [ ] `runCli` reports a `NestedRootError` as it reports a `ConfigLoadError`: `Error: <message>` on stderr, exit code 1, no stack trace.
- [ ] New `tests/vcs-root-refusal.test.ts` proves "Folder below the root with git on" through `selectVcs`.
- [ ] It proves every row of "Commands below the root with git on" with `each`, running each command through `runCli` with the cwd set to `<outer>/sub` and stdout and stderr captured, and comparing `<outer>`'s git state and file list before and after.
- [ ] It proves cli-foundation "Doctor below the repository root with git on".
- [ ] `selectVcs` and `runCli` carry an `@scenario` line for each scenario they serve; `tests/vcs.test.ts` and every other test pass unchanged, and `pnpm typecheck:cli` passes.

## Details

`<outer>` comes from `fs.mkdtemp` under `os.tmpdir()`, made real with
`fs.realpath` before it is used in the expected message, and is made a
repository with `git init -q -b main`, `-c user.name=osq -c
user.email=osq@example.invalid` on the commit, as `tests/vcs.test.ts`
does with its `git` helper and a cleaned git environment. Remove it after
each test.

Run each command the way `tests/cli-capture.ts` runs `runCli`: change
into the folder, capture the stream writes and the exit code, and restore
them afterwards. The scenario helper's `covers` is the function the test
calls through `run`: `selectVcs` for "Folder below the root with git on",
`runCli` for the two command scenarios.

Every listed command already reaches `selectVcs` before it writes; a
rough version of this change, measured on 2026-10-23, showed each row
refusing with the repository untouched. `doctor`, `lint` and `inbox` let
the error escape `runCli` today, which is why `runCli` must handle it.

## Scenarios

- version-control: Folder below the root with git on
- version-control: Commands below the root with git on
- cli-foundation: Doctor below the repository root with git on

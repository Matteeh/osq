## Details

Map the `NestedRoot` to `FeatureError::failed` with the command's own
name, `plan`, `lint` or `doctor`, and its display. `plan --next` must
refuse before it reads the queue or writes a change folder. Run each
command through its crate's `Feature::run` with an `Invocation` on
`<outer>/sub`. Snapshot `<outer>`'s git state with the git CLI in the
test, with `GIT_CONFIG_GLOBAL=/dev/null` and `GIT_CONFIG_NOSYSTEM=1`. A
rough version of this change, measured on 2026-10-23, broke only the one
named test in these crates.

Run the proposal's verify with
`OSQ_CHANGE=openspec/changes/315-vcs-root-fails-fast`, so the link gates
see this change's requirements.

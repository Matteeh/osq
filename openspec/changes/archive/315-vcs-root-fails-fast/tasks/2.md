## Details

Use `GitVcs::new(root).with_timeouts(&config.timeouts)` and the `Vcs`
trait's `root()`, which already gives the top level made canonical.
`config` is `osq_kernel_config::Config`; the crate already depends on
`osq-kernel-config`. Build the test repositories with the `Scratch`
helper in `tests/support/mod.rs`, as `tests/setup_reads.rs` does, and
`<plain>` under `std::env::temp_dir()`, since every folder under
`CARGO_TARGET_TMPDIR` sits inside this repository.

Run the proposal's verify with
`OSQ_CHANGE=openspec/changes/315-vcs-root-fails-fast`, so the link gates
see this change's requirements.

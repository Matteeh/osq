## Details

The default `spawn` is `node:child_process`'s `spawn` with `stdio: 'ignore'`
and `detached: true`, then `unref()`. Give `InboxSoundDeps.spawn` that same
call shape, returning something with `on('error', ...)` and `unref()`, so a
test fake can emit an error. The default `bell` writes `\u0007` to
`process.stdout`, the default `warn` writes a line to `process.stderr`, and
the default `exists` checks the file synchronously.
Build a local `Date` for each quiet-hours case with `new Date(2026, 0, 1, h, m)`.

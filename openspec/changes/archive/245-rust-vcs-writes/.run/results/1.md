## Changed

- `crates/kernel/vcs/src/error.rs`: added `VcsError::Failed { command, output }` with the `<command> failed: <output>` display and `None` from `source()`, leaving `Spawn` unchanged.
- `crates/kernel/vcs/src/git.rs`: added the private `run` runner every read and write goes through, with extra environment variables after the `with_env` pairs, optional standard input, and lossy UTF-8 decoding of both streams. `read` now uses it, and a private `write` helper turns a failed exit into `VcsError::Failed` with the joined command and stdout followed by stderr. The `Vcs` implementation now calls the new writes.
- `crates/kernel/vcs/src/git/write.rs`: new module holding each branch, worktree, index and commit write's git arguments, the pure `parse_author` split, and the `commit.gpgSign` read that adds `-S`.
- `crates/kernel/vcs/src/port.rs`: the trait is now osq's version-control port, with `create_branch`, `rename_branch`, `worktree_add`, `worktree_remove`, `worktree_prune`, `stage`, `commit` and `commit_tree`, each documented with its `Implements:` tag.
- `crates/kernel/vcs/tests/git_command.rs`, `crates/kernel/vcs/tests/history_reads.rs`: only `assert_spawn`'s destructuring changed to a `let ... else` now that `VcsError` has a second variant.
- `crates/kernel/vcs/tests/branch_and_commit_writes.rs`: new scenario tests for all six acceptance scenarios, using `tests/support/mod.rs` unchanged and the committer and date environment variables.

## Deviated

- `parse_author` uses `strip_suffix('>')` with `split_once('<')` instead of an index and `index + 1`. Both split at the first `<`, and this avoids an unkillable mutant: git strips a leading `<` from `GIT_AUTHOR_EMAIL`, so an index-based off-by-one produces the same commit author and no black-box test can see it.

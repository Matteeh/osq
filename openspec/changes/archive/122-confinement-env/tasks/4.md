## Details

For the spawn tests, write a small fake binary into a temporary folder: a
Node script with a `#!/usr/bin/env node` line and mode 0o755. It prints a
version and exits 0 for `--version`. Otherwise it writes
`JSON.stringify(process.env)` to the path in `OSQ_FAKE_ENV_RECORD` and exits
0. That variable reaches it because every `OSQ_` variable passes. Point
each adapter at it the way `tests/claude/exec-support.ts`,
`tests/codex/support.ts`, and `tests/pi/support.ts` point at their fakes, and
copy what you need rather than importing another test's helpers if that
drags in unrelated setup. Set `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`,
`AGENT_PROBE`, and `SECRET_PROBE` on `process.env` only inside each test, and
restore them afterwards.

`src/harness/agy/agy.ts` and `src/harness/opencode/opencode.ts` are on the
line budget's allow list, so they may grow. Import `buildRoleEnv` from
`../../core/run/role-env.js`.

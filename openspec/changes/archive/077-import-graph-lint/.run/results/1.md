## Changed

- New `src/core/spec/import-graph.ts` (188 lines) exporting `IGNORED_DIRS`,
  `ImportGraph`, `ReachingFile`, `BuildImportGraphOptions`, `buildImportGraph`,
  `reachImports`, and `reachImporters`. It walks every JavaScript and TypeScript
  file outside ignored folders and `options.skip`, finds specifiers with one
  regex over file text (`from`, side-effect `import`, dynamic `import()`,
  `require()`), and resolves only relative specifiers through the exact path,
  the `.js`/`.jsx`/`.mjs`/`.cjs` to `.ts`/`.tsx`/`.mts`/`.cts` rewrite, each
  script extension, and each `index` script extension. `.d.ts` files are neither
  nodes nor resolution targets.
- `src/watcher/measures.ts` (222 lines): `countImportFanIn` keeps its signature
  and now counts non-scoped `src/**/*.ts` files whose graph imports include a
  scoped `src/` file. `listTsFiles`, `importSpecifier`, `SCRIPT_EXTENSION_REGEX`,
  and the local ignored-dir set are gone; `gatherRepoCounts` imports
  `IGNORED_DIRS` from the graph module.
- New `tests/import-graph-build.test.ts` (17 tests) covering the "Import graph",
  "Import specifier resolution", and "Import fan-in from the shared graph"
  scenarios plus `export ... from`, `import type`, dynamic `import()`,
  `require()`, `.d.ts` exclusion, `options.skip`, bare/aliased specifiers,
  depth limits in `reachImporters`, and the osq repository comparison.

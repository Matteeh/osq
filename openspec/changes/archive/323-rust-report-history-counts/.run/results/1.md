## Changed

Added `read_task_history` with `TaskHistory`, `PreSpawnHistory`, `StartCount`,
`RetryGroup` and `ScopeHistory` under `src/read/task_history/`. The reader
parses each event line as plain JSON, skips blank and non-object lines, and
folds the stream in file order into attempts, unexplained re-runs, dead
reasons, verify codes, pre-spawn runs and declared starts, costs, retry
groups, stuck events and scope counts, matching TypeScript's report
observers.

Added `read_rejection_planner` under `src/read/rejection.rs`. It shares the
same loose line parser, returns `None` without a `rejected` change event, and
otherwise reads the brief's trimmed `planner` through `frontmatter_string`.

Exported every public item from `read` and the crate root, with each public
item's doc ending in its `Implements: rust-storage/...` line.

Added `tests/reading_task_history.rs`, covering every "Task histories" table
row plus a fast test for the unequal detection exit-code split, and
`tests/reading_rejection_planner.rs`, covering every "Rejection planners"
row. A full `cargo mutants --workspace --jobs 4` run over the changed source
caught all viable mutants with no timeouts.

## Changed

Ported the `History:` section and the nine `history` JSON members through
`Scope regressions:`. The report now reads each counted task with storage's
`read_task_history` and each rejected change with `read_rejection_planner`,
in the same entry and task order the status counts walk.

- Added `history.rs` to aggregate attempts, unexplained re-runs, dead reasons,
  verify runs, pre-spawn runs, costs, retries, rejections and scope regressions.
- Added `history_text.rs` and `history_json.rs` for the new text lines and the
  sorted JSON member, keeping `output.rs` small.
- Added `js_number.rs` for `not reported` and JavaScript's `toFixed` cost text,
  rounding a tie away from zero and treating the sign apart.
- Reused the query JSON real/string writers by exposing them inside the crate.
- Moved `serde_json` to the crate's normal dependencies.
- Copied the new `history-project` fixture and every updated golden into the
  report crate.
- Added the `history-project` row to `report_summary.rs`.
- Added `report_history.rs` proving the history project and every reported
  cost-text row. Every scratch root is fresh under `CARGO_TARGET_TMPDIR`.

The task verify and `OSQ_CHANGE=openspec/changes/323-rust-report-history-counts
sh scripts/verify-rust.sh` both pass. Hand-run cargo-mutants over the new
report modules reports no remaining missed mutant.

## Deviated

`report_history.rs` has two cost rows beyond the scenario table: a total of
`0.01`, to cover the two-decimal boundary, and `100`, to cover a whole total
with more integer digits than decimals. Both expected texts and per-spec costs
come from rust-report "Report cost text". They also kill mutation-check misses
in the shared cost formatter.

## Changed

- `src/watcher/worktree-run.ts`: added exported `approvalCommitted(change, config)`, which returns true without git and otherwise asks git whether `<change folder>/.run/approved` exists at `HEAD` via `pathExists`, using `relativeChange` for the folder.
- `src/watcher/loop.ts`: in `runWatcherCycle`'s per-change loop, a worktree change with an uncommitted approval is skipped before the stale-lock reaper and every later step, writing no marker or event. Non-worktree changes are not checked.
- `tests/watcher-approval-pending.test.ts`: new scenario tests through `runWatcherCycle` with a counting adapter: "Seal before commit" (reset the approval commit, cycle spawns nothing and writes no `regressed/change.md` or change event) and "Commit lands" (recommit the change folder, next cycle spawns task 1).

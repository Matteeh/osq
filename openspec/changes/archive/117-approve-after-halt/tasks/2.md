## Acceptance

- [ ] New `src/core/spec/approve-branch.ts` exports `claimBranch(vcs, projectRoot, folderPath, folderName)`, returning the kept branch name or null, as the spec-lint-and-approve delta's "Rejected branch kept at approval" says. The rejection record's path is `<dirname of folderPath>/rejected/<folderName>/.run/rejected.md`, relative to `projectRoot` in POSIX form. The branch counts as checked out when `vcs.worktreeList()` lists it. Any other existing branch throws `branch osq/<folder> already exists`.
- [ ] `approveIntoWorktree` calls `claimBranch` where it called `refuseExistingBranch`, which is removed, and sets `keptBranch` on the result of both the stacked and the new-worktree approval when a branch was renamed. `ApproveResult` in `src/core/spec/approve.ts` gains an optional `keptBranch` with a doc comment.
- [ ] `osq approve` prints `  Kept rejected branch: <branch>` after the `Hash:` line when `keptBranch` is set, and nothing new otherwise.
- [ ] New `tests/approve-rejected-branch.test.ts` covers the delta's "Rejected branch renamed", "Rejected branch checked out", and "Next free name" scenarios through `approveSpec`. It commits the rejection record on the branch with `git` itself; it does not run `osq reject`.
- [ ] `tests/approve-worktree.test.ts` passes unchanged, its "refuses an existing branch" case included.

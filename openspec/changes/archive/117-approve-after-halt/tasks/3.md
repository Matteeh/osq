## Details

Build the project and approve it the way `tests/worktree-run.test.ts` does.
To get a sealed but uncommitted approval, run `git reset --soft HEAD~1` and
then `git reset` in the worktree after `approveSpec`. That undoes the approval
commit and leaves its files on disk, untracked. The "Commit lands" case then
commits the change folder with `git add` and `git commit` in the worktree and
runs one more cycle. Let `biome check --write` sort the imports.

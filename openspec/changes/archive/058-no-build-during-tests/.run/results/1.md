## Changed

- `tests/package-install-smoke.test.ts`: removed the `npm run build` call before
  `npm pack`. Before packing it now asserts `dist/cli/bin.js` and
  `ui/dist/index.html` exist, failing with
  `<path> is missing; run pnpm build before verifying`.
- `tests/bin-execution.test.ts`: removed the `npm run build` call from the
  `before` hook. The hook now asserts `dist/cli/bin.js` exists with the same
  message pattern. All other assertions are unchanged.
- `tests/package-hygiene.test.ts`: added a `never runs a build command from any
  test under tests/` test beside the existing pnpm scan, backed by a
  `collectSpawnOffenders` helper and three build-command patterns (spawn/exec
  `run`+`build`, `vite`+`build`, and `stage-ui.mjs`). The patterns are assembled
  from fragments (`STAGE_UI_SCRIPT`, `['"]`-wrapped quotes, `[^);]*` windows) so
  the scanner's own source contains none of the command shapes it matches. Also
  widened the shared `collectTestSources` glob from `ts|js` to `ts|tsx|js` so
  every test source under `tests/` is scanned.

naming only `tests/bin-execution.test.ts:36` and
`tests/package-install-smoke.test.ts:126`; it did not flag `linter.test.ts`
(`pnpm build` fixture data) or itself.

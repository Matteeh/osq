## Acceptance

- [ ] In `newCommand`, `doneCommand`, `rejectCommand`, `retryCommand`, `queueCommand`, and `inboxCommand`, each `console.error(<text>); process.exit(1);` pair becomes `throw new CommandError(<text>)`, using `CommandError` from `src/cli/command-error.ts`, as the cli-foundation delta's added "Command errors" says. `<text>` stays byte for byte the same, and nothing else in those files changes.
- [ ] New `tests/command-error-changes.test.ts` uses `runCliCaptured` from `tests/cli-capture.ts` on a project made with `scaffoldProject`, and checks that each of these has exactly one stderr line with that text, no stdout line, and exit code 1: `osq new ///` gives `Error: Spec name cannot be empty`, and `osq done 999 1 --manual ' '` gives `Error: --manual <reason> is required to mark a task done`.
- [ ] The same file checks the same shape, with the stderr line starting with the given text, for: `osq done 999 1 --manual x` (`Error marking task done:\n  Spec "999" not found`), `osq reject 999 --reason x` (`Error rejecting 999:\n  Spec "999" not found`), `osq retry 999 1` (`Error retrying 999 1:\n  Spec "999" not found`), and `osq queue` without a queue file (`Queue error: Queue file not found`).
- [ ] The same file awaits `inboxCommand({ cwd, config: DEFAULT_CONFIG, home, stdout })`, with `home` the path of a regular file in the test's temporary folder, and checks that it rejects with a `CommandError` whose message starts with `Inbox error: ENOTDIR` and whose `exitCode` is 1.
- [ ] Every function stays within 80 lines and every file within its line budget. `tests/command-error.test.ts`, `tests/done-manual.test.ts`, `tests/new.test.ts`, `tests/reject.test.ts`, `tests/retry.test.ts`, `tests/queue.test.ts`, `tests/inbox.test.ts`, and every other test pass unchanged.

## Details

The inbox is tested by calling `inboxCommand` directly because through
`runCli` it would write its last-look cursor under the real home directory.
With `home` a regular file, creating the cursor's folder fails with `ENOTDIR`
and nothing is written outside the temporary folder.

## Changed

- New `src/core/status/show-land-types.ts` holds the Ports types
  (`LandGateKind`, `LandGate`, `LandDisclosure`, `LandHalt`, `LandView`).
- New `src/core/status/show-land-gates.ts` exports `buildLandGates(timeline,
  proposalVerify, checkCommand)`, the archive-gate projection: it cuts at the
  last `archived` event, takes each numbered task stream's last non-`phase`
  `verify_ran`, then the `change` stream `verify_ran` whose command is the
  proposal's verify, then the declared `check`, then `validator_ran`. It is a
  separate module from `show-land-model.ts` only to stay inside the file and
  function budgets.
- New `src/core/status/show-land-model.ts` exports `readLandView`, returning
  null unless `details.location` is `archived` and otherwise a `LandView`:
  gates from `details.timeline`, `capabilities` from `readArchivedChange` for
  the `listChanges(projectRoot, config, ['archived'])` entry whose path
  resolves to `details.folderPath`, disclosures from `readChangeDisclosures`
  (deviated and outside scope only), halt from `.run/regressed/change.md`
  through `parseFrontmatter`, `lastSync`/`lastSyncStop` from `readLastSync`,
  and the git fields from `selectVcs` with `defaultBranch`,
  `readDependencyState`, `listBranches`, `countCommits` and `diffStat` for
  `worktreeBranch(folderName)`. With git off (`vcs.kind !== 'git'`) the four
  git fields are null. It writes nothing.
- New `src/core/status/show-land-lines.ts` exports `landLines(details)`: the
  blank line, headline, `Gates at archive:`, `Diff:`, `Spec changes:`,
  `Disclosures:`, `Halted:` and `Sync stopped:` lines. It imports only
  `./show-types.js` and reads no files, so `tests/show-text.test.ts`'s
  renderer-import rule stays green.
- `src/core/status/show-types.ts`: `SpecDetails` gains `land?: LandView`.
- `src/core/status/show-model.ts`: `withNextStep` sets `land` from
  `readLandView` for an archived folder, so `formatShowJson` carries it before
  `digest`.
- `src/core/status/show-output.ts`: `formatShowText` appends the land lines
  after `formatSpecDetails` and before the digest lines.
- `src/core/web/web-data-types.ts`: `WebChange` gains
  `readonly land?: LandView | null`.
- `src/core/web/web-data-change.ts`: `getWebChange` always sets `land` from
  `readLandView` with the details it already builds.
- `src/core/web/web-data.ts`: re-exports `LandDisclosure`, `LandGate`,
  `LandGateKind` and `LandView` as types.
- New `tests/land-view.test.ts` (13 tests) covering every "Land view model"
  scenario (2 commits behind, landed, gates at archive with a post-archive
  sync run excluded, capabilities/disclosures/diff against `diffStat`, halt and
  sync stop, active/rejected null, git off) and "Land in show" (the worktree
  summary text, `land` before `digest` in JSON, git-off headline, singular
  `commit`/not-moved/missing-branch headlines, active unchanged), plus both
  "Land view document" scenarios through `getWebChange`. The git cases build a
  temporary repository, add an `osq/042-pricing` worktree holding the archived
  change and a code commit, then move `main` two commits past it; the landed
  case commits the archive folder on `main`.

## Deviated

- Added `show-land-gates.ts` beyond the two modules acceptance bullet 1 names,
  so no file exceeds 250 lines and no function exceeds 80. It is inside the
  task's `show-land-*.ts` scope glob.
- The validator gate line appends `, <n> findings` at the end of the line
  (after the command) and adds ` exit <code>` only when the outcome is exactly
  `failed`. The spec's ordering of the failed-exit and finding-count fragments
  was ambiguous; `validated` runs no longer read `exit 0`.
- The renderer derives the `LandView`/`LandGate` shapes from
  `SpecDetails['land']` rather than importing `show-land-types.ts`, because
  `tests/show-text.test.ts` allows a `show-*-lines.ts` module to import only
  `./show-types.js` and other renderer modules.

## Missing context

- The task did not say whether `readLandView` should treat `vcs.enabled:
  false` in a real git repository as "git off", or only an unselected `NoVcs`.
  I followed the delta spec literally: git is off when `selectVcs` returns
  `NoVcs` (`vcs.kind !== 'git'`).

## Changed

- `src/core/vcs/vcs.ts`: added the exported `VcsDiffStat` interface and the
  `diffStat(from, to, exclude)` member on `Vcs`, carrying the rule in its doc
  comment.
- `src/core/vcs/git-vcs-diff.ts` (new): `diffStat` runs
  `git diff --numstat --no-renames <from>...<to> -- . :(exclude)<path>…`
  through the same `GitWriteContext.run` read runner `countCommits` uses,
  sums each output line as one file with `-` counted as 0 lines, and returns
  null on a non-zero exit.
- `src/core/vcs/git-vcs.ts`: `GitVcs.diffStat` delegates to the new module.
- `src/core/vcs/no-vcs.ts`: `NoVcs.diffStat` returns null.
- `tests/vcs-write.test.ts`: added `diffStat` to `PORT_MEMBERS` and nothing
  else.
- `tests/vcs-diff-stat.test.ts` (new): covers the three "Vcs diff count"
  scenarios on a temporary repository (merge-base count, folder exclusion plus
  a binary file, unknown ref) and `NoVcs` from `selectVcs` on a folder with no
  git.

## Changed

- `packages/ui/src/contracts.ts`: re-exports `LandView`, `LandGate` and
  `LandDisclosure` from `src/core/web/web-data.ts` as types only.
- `packages/ui/src/change/LandPanel.tsx` (new): renders a `LandView` as the
  `Land` `h3`, the headline, and `h4` sections `Gates at archive`, `Diff`,
  `Spec changes`, `Executor disclosures`, plus `Halted` and `Sync stopped`
  when set. Gates show name (`Task <n>`/`Verify`/`Check`/`Validator`),
  outcome, duration rounded to whole seconds, a failed gate's exit code, the
  validator's finding count, and the command as `<code>`. Diff reads
  `<files> files changed, +<added> -<removed>` or `Unavailable`; spec changes
  list each capability's added/modified/removed names and renames as
  `<from> → <to>`; disclosures render each task's deviated and outside-scope
  text in `<pre className="review-text">`. The missing states read
  `None recorded` (gates) and `None` (spec changes, disclosures).
- `packages/ui/src/change/land.css` (new): tokens `--bg`, `--border`,
  `--muted`, `--text` from `review.css`, with `overflow-wrap: anywhere` on
  `.land-command`, `.land-text` and `.land-disclosure .review-text`.
- `packages/ui/src/change/ChangeView.tsx`: computes `land = change.land ?? null`
  and renders `LandPanel` after `BriefPanel` and before the actions panel and
  `TaskTable` in both the review-less and review branches; a null/missing
  `land` renders as before.
- `packages/ui/src/change/index.ts`: exports `LandPanel`.
- `packages/ui/src/main.tsx`: imports `./change/land.css` after `review.css`.
- `tests/ui-land.test.tsx` (new, 16 tests): every headline (3 commits, 1
  commit, not moved, landed, git off, missing branch), a failed gate's exit
  code and the validator's finding count, the diff/None states, a rename as
  `<from> → <to>`, disclosure and halt/sync-stop rendering, heading order
  before the task table, markup equality of a missing `land` and `land: null`,
  and `ChangeView` over the real archived `buildWebFixture` document from
  `getWebChange`.

  rather than new files; the file is well under the 250-line budget.

## Details

The UI imports from `src/` only as types; `tests/import-graph.test.ts`
fails a runtime import. The test file itself may import `getWebChange` and
the fixture builder at runtime, as `tests/ui-review.test.tsx` does.

`tests/ui-change.test.tsx` reads every entry of `packages/ui/src/change/` as a
file and fails if any contains `EventSource`, `addEventListener`,
`setInterval`, `setTimeout`, `fetch(`, `dangerouslySetInnerHTML` or the
lower-case word `markdown`, including in comments and CSS. Put every new
file directly in that folder, with no subfolder, and avoid those words.
Render all text as escaped React text.

## Details

TypeScript's provider outage rule is `findOpenProviderRetry` in
`src/watcher/provider-outage.ts`, and its pause is
`pauseTaskOnUsageLimit` and `recordUsagePause` in
`src/watcher/usage-pause.ts`. Read them only to check a rule; the delta
is the contract. Rust code never imports or calls anything under `src/`.

The fake harness takes a script of starts, each a `StartError` or a list
of events and a `HarnessExit`, records every `StartRequest` it receives
and its start count, and returns its `agent_env` names. Share its record
with the test through `Rc<RefCell<..>>`, since `harnesses` owns the boxed
fake. The fake clock returns a fixed `now_ms` and records each wait
without sleeping. In the tables, "open retry `503`" is a `HarnessRetry`
the fake gives with phase `start`, `attempt` 7, no `max_attempts` and
error `503`; "ended with success" adds one with phase `end`, `attempt` 7
and `success` `Some(true)`. A runner event is a `HarnessRetry` whose
`max_attempts` is set, which separates it from the fake's. "Exit 1" is
`exit_code` 1 and `timed_out` false; "timed out with exit 124" is 124 and
true.

Give each event to `on_event` as soon as the harness gives it, and keep
a copy of the start's events only to judge that start.

cargo-mutants runs on every line this task adds. The exit-code and
timed-out checks, the open-retry rule, the retry count bound and each
event field must change a value a row checks; add a row-style test with
values worked out from the delta's rules if a mutant survives. Before
exiting, run `cargo fmt --all`, then
`cargo mutants -p osq-kernel-runners -f <file> -o "$(mktemp -d)"` on each
new source file, then `sh scripts/verify-rust.sh` with `OSQ_CHANGE` set
to `openspec/changes/246-rust-runners-roles`.

## Details

TypeScript's rules are `buildRoleEnv` in `src/core/run/role-env.ts` and
`findUsageLimit` and `pauseUntil` in `src/core/run/usage-pause.ts`. Read
them only to check a rule; the delta is the contract. Rust code never
imports or calls anything under `src/`. The Windows case rules of
`buildRoleEnv` are not ported.

`now_ms` and the parsed reset time are epoch milliseconds as `i64`; add
`wait` in whole milliseconds. The day-count conversion to and from a
civil date must agree with the leap-year rows of "Pause times", so
include both directions in the same file and test them only through
`pause_until`.

cargo-mutants runs on every line this task adds. Each range bound of the
parser, the strictly-later reset rule and the date conversion must
change a value a table row checks; add a row to the test, with values
worked out from the delta's rules, if a mutant survives. Before exiting,
run `cargo fmt --all`, then
`cargo mutants -p osq-kernel-runners -f <file> -o "$(mktemp -d)"` on each
new source file, then `sh scripts/verify-rust.sh` with `OSQ_CHANGE` set
to `openspec/changes/246-rust-runners-roles`, so the link gate corpus
test sees this change's new requirements.

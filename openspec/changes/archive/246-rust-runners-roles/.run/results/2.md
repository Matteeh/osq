## Changed

Added the typed runner settings (`Role`, `RoleSettings`, `RunnerSettings`), the
`Clock`/`SystemClock` port, and `run_task` with its `Harness`, `StartRequest`,
`TaskRequest`, `HarnessExit`, `StartError`, `RunOutcome` and `RunError` types.
The runner picks the role's harness and model, forwards harness events as they
arrive, builds the agent environment with `role_env`, retries failed starts with
`HarnessRetry` start/end events, and pauses on a usage limit with `Paused`.
Added fake-harness and fake-clock support and tests for every scenario, including
extra open-retry rows that kill surviving mutation-test mutants.

## Deviated

Added a few edge-row tests beyond the acceptance tables (a zero exit with an open
retry, a timed-out zero exit, and failed retry-end rows) so cargo-mutants on the
failed-start rule and the runner have no survivors.

## Acceptance

- [ ] For a task whose `events` hold `retry` events, `formatSpecDetails` prints `      Retries: <n> (<a> automatic)` after the task's `Verify:` and `Pre-spawn verify:` lines. `<a>` counts events with `data.automatic === true`.
- [ ] For a task whose latest `stuck` event comes after its latest `retry` event, it also prints `      Stuck: same failure twice (<fingerprint>)`.
- [ ] Tasks with neither event print neither line, so every existing show output is unchanged.
- [ ] New `tests/show-retries.test.ts` drives `osq show` on a change with a manual retry, an automatic retry, and a `stuck` event on one task, and none on another, and asserts the lines.

## Details

Build both lines from `TaskDetail.events` in small helpers outside
`formatSpecDetails`, the way the pre-spawn line is built. `SpecDetails` gains
no field, because the web dashboard reads it. Every existing test is frozen.

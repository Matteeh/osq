## Changed

- `src/core/status/show.ts`: added two small helpers built from `TaskDetail.events`, mirroring `formatPreSpawnVerify`. `formatRetries` counts `retry` events and how many carry `data.automatic === true`, rendering `      Retries: <n> (<a> automatic)`. `formatStuck` finds the latest `stuck` event and the latest `retry` event, rendering `      Stuck: same failure twice (<fingerprint>)` only while no later `retry` clears it. Both lines are pushed in `formatSpecDetails` immediately after the `Verify:` and `Pre-spawn verify:` lines. No `SpecDetails` field was added.
- `tests/show-retries.test.ts`: new test driving the real `showCommand` on a change whose first task has a statement pre-spawn run, a manual retry, an automatic retry, and a `stuck` event, and whose second task has none. It asserts both lines, their ordering after the verify lines, that a later retry suppresses the stuck line, and that the plain task prints neither line.

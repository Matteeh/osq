## Details

Define `OPENCODE_PLANNER_AGENT_TEMPLATE` in `src/harness/opencode.ts`.
The template declares YAML frontmatter with `description: Interactive planning agent for osq`, `mode: all`, and `permission:` configuring `read: allow`, `write: allow`, `edit: allow`, `glob: allow`, `grep: allow`, `bash: deny`, `git: deny`, `webfetch: deny`, and `websearch: deny`.
The body includes a direct pointer to `PLANNER.md`: `Follow PLANNER.md strictly for change planning rules and procedure.` and `Writes are expected only under openspec/changes/<id>/`.
In `OpencodeAdapter.setup`, resolve the planner agent filename (`config.planner?.agent || 'osq-planner'`). If the agent file does not exist, write `OPENCODE_PLANNER_AGENT_TEMPLATE`. If it exists, ensure it is written idempotently without modifying user customizations outside managed blocks, or if unmanaged, retain content so repeated runs are byte-identical.
In `src/cli/setup.ts`, ensure `setupCommand` continues to invoke `adapter.setup`.
Create `tests/opencode-planner-setup.test.ts` verifying that `osq setup` writes `.opencode/agent/osq-planner.md` with required tool permissions, that `bash` and `git` are denied, that the body points to `PLANNER.md`, and that executing setup twice yields byte-identical output.

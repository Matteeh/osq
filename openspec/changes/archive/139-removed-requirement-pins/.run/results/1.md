## Changed

- Added `tests/living-specs-pins.test.ts`. It holds `PRESERVED_REQUIREMENTS` and
  the pin check, which now takes a changes directory and a living specs
  directory. It collects, per capability, the names counted deltas removed or
  renamed away using `parseDelta`'s `removed` and `renamed` (`from`) lists,
  reading every folder under `<changesDir>/archive/` and every active folder
  holding the record at `archiveSpecsRecordPath`. A pinned name in that set is
  skipped; every other missing name fails with
  `<capability> is missing preserved requirement "<name>"`. Cases run the check
  against this repository's `openspec/changes` and `openspec/specs`, and against
  temporary folders for: an archived delta that removed the pin, an active
  change with the archive record that renamed it, a same-named removal in a
  different capability (still fails), a pin lost with no delta, and an active
  change without the record (ignored).
- `tests/living-specs-delta-equivalence.test.ts`: removed `PRESERVED_REQUIREMENTS`,
  the `it('preserves requirements introduced by 017 and 020 through 027', ...)`,
  and the now-unused `requirementNames` helper. The replay test and every other
  `it` are unchanged.

## Deviated

- The acceptance line says "Nothing else in the old file changes", but
  `requirementNames` was used only by the moved `it`. Leaving it behind would be
  an unused local and fail `noUnusedLocals` during `pnpm verify`, so I moved it
  to the new file rather than leave it dead. The pin names and the failure
  message are byte-for-byte unchanged.

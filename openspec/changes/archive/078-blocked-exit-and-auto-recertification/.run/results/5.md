## Changed

- New `src/core/report/report-scope.ts`: `observeScopeRegression(events)` counts
  scope-regression detections and their finite detection exit codes, and splits
  passed `recertification` events by origin. A passed event with
  `automatic: true` counts as automatic, any other passed event counts as human,
  `outcome: requeued` counts for agent, and malformed outcomes are not guessed.
- `src/core/report/report-events.ts`: `observeTaskStream` no longer counts scope
  events inline; it calls `observeScopeRegression` and exposes the six counters,
  including the new `scopeRecertifiedAutomatically`. The file is 238 lines and
  `observeTaskStream` is well under its 80-line limit.
- `src/core/report/report.ts`: `ScopeRegressionHistory` gained
  `recertifiedAutomatically`, `getMetricsReport` aggregates it, and
  `formatMetricsReport` prints `    Recertified automatically: <n>` right after
  `    Recertified by human: <n>`.
- `fixture/report/expected.json`: added `"recertifiedAutomatically": 0` in
  alphabetical key order (after `detected`).
- `tests/report-json.test.ts` and `tests/report-scope-regressions.test.ts`: their
  expected scope-regression objects, and the JSON key list, gained
  `recertifiedAutomatically`; nothing else changed.
- New `tests/report-auto-recertification.test.ts`: covers the "Automatic and
  human recertifications", "No scope regression history", and "Blocked deaths"
  scenarios through `getMetricsReport`, `formatMetricsReport`, and
  `osq report --json` on a temp project.

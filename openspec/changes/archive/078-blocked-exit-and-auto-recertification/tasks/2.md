what `checkMissingVerifyPaths` takes plus the change folder and task number,
runs the blocked check from `blocked.ts`, then `checkMissingVerifyPaths`.

the existing `task-verify.js` import line, so the line count doesn't grow. Keep
`checkMissingVerifyPaths` exported; other tests import it.

run cycles with a `MockAdapter` and a capturing logger.

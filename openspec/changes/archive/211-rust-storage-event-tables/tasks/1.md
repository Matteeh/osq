## Details

Types, all public with `Clone`, `Debug` and `PartialEq`:

- `TableEvent { stream: Stream, timestamp: String, event: Event }`, using rust-core's `Stream` and `Event`.
- `Notice { id: String, severity: String }`.
- `LinkEntry { severity: String, file: String, message: String }`.
- `PlanRecord { notices: Vec<Notice>, traceability: Option<Vec<LinkEntry>> }`.
- `ManifestNotices { items: Vec<Notice>, opened: Option<Vec<String>> }`.

Keep the events in the fold pass that already exists in
`src/read/snapshot/events.rs`. `Facts::observe` already sees each envelope
with its stream. Move the selection into a new file under
`src/read/snapshot/`, because `events.rs` is close to the 250-line cap. A
`validator_ran` event in a task stream is not kept, and a `paused` event in
`change.jsonl` is not either.

Read `plan.jsonl` and the manifest's `notices` with `serde_json` values in
pure functions, one per rule of "Plan records" and "Manifest notices", in a
new file under `src/read/snapshot/`. `read_manifest` in
`src/read/snapshot/folder.rs` already reads the manifest; reuse its value
instead of reading the file twice. An unreadable or malformed `plan.jsonl`
line is never an error.

`read_history` lists with `list_changes` and reads with `read_change`, as
`read_archive` does. Leave `read_archive` as it is.

The fixtures are the source of the expected values. Copy them; never edit
them. TypeScript's `osq query --json` printed the files under `history-rows/`
for the `history/` project. Task 2 reads them. Tests find the fixtures from
`env!("CARGO_MANIFEST_DIR")`.

Keep every `.rs` file under 250 lines and every function under 80. Workspace
lints include `clippy::pedantic` and `-D warnings`; meet them rather than
allowing them. Keep tests in `tests/`, never in a `#[cfg(test)]` module.
When the mutation step reports a missed mutant, add a test case for it in
`tests/reading_history.rs`. Run `cargo fmt --all` before exiting.

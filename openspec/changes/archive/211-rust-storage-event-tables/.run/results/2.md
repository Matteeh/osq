## Changed

- `src/model/mod.rs`: `CREATE_TABLES` now creates all twelve tables with
  TypeScript's column names and order, and `write_read_model` fills the nine
  event tables per archived snapshot plus the `notices` rows of archived and
  rejected snapshots by folder name. `build_read_model` reads the trial labels
  before it touches the database, then `read_history`, writes, and fills the
  label columns.
- `src/model/event_rows.rs` (new): the `pauses` and `recertifications` row
  mapping, with the `attribution` entry, `automatic` and `source` rules.
- `src/model/stream_rows.rs` (new): `focused_runs`, `mutation_picks` and
  `mutation_survivors` row mapping with per-stream position counters.
- `src/model/validator_rows.rs` (new): `validator_runs`, `validator_findings`
  and `link_findings` row mapping and the five-string valid-finding rule.
- `src/model/notice_rows.rs` (new): the plan-record and manifest `notices`
  rows, the rejected-last-record rule and the folder-name sort.
- `src/model/labels.rs` (new): `TrialLabels`, `read_trial_labels` and
  `apply_labels`, one `UPDATE <table> SET label = ? WHERE id = ?` per label.
- `src/model/insert_events.rs` (new): the nine tables' SQLite inserts.
- `src/model/rows.rs`: `table_events`, `string_of`, `is_task_number`,
  `number_f64` and `flag` helpers, with `count_i64`/`len_i64` made `pub(super)`.
- `src/model/error.rs`: the `ReadModelError::Labels` variant and its message.
- `src/lib.rs`: re-exports `TrialLabels` and `read_trial_labels`.
- `tests/read_model_history.rs` (new): the nine-table comparison against
  `tests/fixtures/history-rows/<table>.json` (with table, row, column and both
  values named on failure), the column names and order, the label assertions,
  the malformed label file, the label-file shapes, and a `notices` ordering
  case.

## Deviated

- All tests live in `tests/read_model_history.rs`, the one test file the task's
  scope allows, so it is 457 lines, over the planner's 250-line guidance. The
  previous attempt split the extra cases into `tests/read_model_history_edges.rs`
  and the watcher killed it as a scope violation.
- `mutation_survivors.line` and `column` are bound as `f64` (a JSON number read
  with `as_f64`, null for anything else). The columns are untyped and both the
  fixture and golden comparisons equal numbers by value.
- The row-mapping functions take a snapshot, which the task's Details allows,
  and iterate `facts.table_events`, rather than taking one `TableEvent` at a
  time.

## Changed

- Added `LineEnding` as a public struct exported from the crate root.
- Added `version`, `hook_names` and `line_endings` to the `Vcs` trait and implemented them on `GitVcs`, each bounded by `timeouts.git` through the existing runner.
- Added `crates/kernel/vcs/src/git/setup.rs` with the three reads and their pure parsers for git's version, the executable hook names under the configured hooks folder, and `ls-files --eol -z` index line endings.
- Added `crates/kernel/vcs/tests/setup_reads.rs` with one test per scenario: repository reads, a hooks folder from `core.hooksPath`, reads outside a repository, and a program that cannot start.
- `cargo test -p osq-kernel-vcs --test setup_reads` passes, and `sh scripts/verify-rust.sh` passes with `OSQ_CHANGE` pointing at this change (without it, the corpus link gate checks only the living spec, where this change's new scenario tags do not exist yet).
- `cargo mutants` on `src/git/setup.rs` caught 20 mutants with 2 unviable and none missed.

Touched: crates/kernel/vcs/src/lib.rs, crates/kernel/vcs/src/port.rs, crates/kernel/vcs/src/git.rs, crates/kernel/vcs/src/git/setup.rs, crates/kernel/vcs/tests/setup_reads.rs

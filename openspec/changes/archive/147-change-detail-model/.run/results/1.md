## Changed

Split the reader out of `src/core/status/show.ts` into renderer modules that read no files, leaving `show.ts` a facade over the model plus re-exports. `osq show` output is byte-identical.

- `src/core/status/show-types.ts` (new): every interface `show.ts` exported (`TimelineEvent` through `SpecDetails`) unchanged, plus `stringList`.
- `src/core/status/show-text.ts` (new): `formatSpecDetails` and its alias `formatShowOutput`, with `formatEventData` and `formatVerificationHistory`. `formatSpecDetails` is now an assembler over section functions `headerLines`, `proseLines`, `taskSectionLines`, `taskHeaderLines`, `taskFooterLines`, `planningSessionLines`, `recertificationLines` and `timelineLines`, each at most 80 lines.
- `src/core/status/show-task-lines.ts` (new): `formatPreSpawnVerify`, `validMissingPaths`, `retryCounts`, `formatRetries`, `formatStuck`, `formatInstructionsChanged`, `formatDependenciesAdded`, `formatTaskScenarios`, `formatDisclosures`.
- `src/core/status/show-run-lines.ts` (new): `FOCUSED_FAILED_NOTE` (still assembled from fragments, comment kept), `formatFocusedRuns`, `numberOrZero`, `mutationSurvivorLines`, `formatMutationRuns`.
- `src/core/status/show.ts`: keeps `buildSpecDetails` (still grandfathered), `isTestPath` import, and the rest of the model; imports types and `stringList` from `show-types.js`; re-exports every type and `formatSpecDetails`/`formatShowOutput`. Every `show*.ts` file is at most 250 lines.
- `tests/function-budget.test.ts`: removed the `core/status/show.ts#formatSpecDetails` grandfather entry.
- `tests/show-text.test.ts` (new): discovers the renderer modules, asserts they import neither `node:fs` nor (for `./show*` specifiers) anything but `show-types.js` and each other, asserts `show.js` re-exports the same function objects as `show-text.js`, and renders a hand-built empty `SpecDetails` asserting `(no tasks)`, `(no planning sessions)`, `(no events recorded)`.

Task verify: `osq show output identical in 324 renderings`.
Proposal verify: `pnpm verify` passes (CLI and UI typechecks, build, full test suite, lint).

## Acceptance
- [ ] Test packs a local tarball and installs it into an isolated temporary directory
- [ ] npx osq init scaffolds configuration, template directories, and AGENTS.md in the consumer project
- [ ] npx osq new smoke creates a valid change specification in the consumer project
- [ ] Test is bypassed when OSQ_SKIP_PACK_TEST is set for fast local test runs
- [ ] Smoke test runs entirely offline against the local packed tarball without registry access

## Details

1. In `tests/package-install-smoke.test.ts`:
   - Check if `process.env.OSQ_SKIP_PACK_TEST` is truthy (`'1'` or `'true'`). If so, mark the test skipped or return early so local test cycles remain fast.
   - Run `pnpm build` and `npm pack` in the project root to generate a fresh `.tgz` tarball in `os.tmpdir()`.
   - Create a clean temporary directory in `os.tmpdir()`.
   - Initialize a minimal `package.json` with `npm init -y` inside the temporary directory.
   - Install the local tarball using `npm install <path-to-tarball>` (running offline).
   - Execute `npx osq init` inside the consumer directory. Assert that `osq.config.ts`, `.env.example`, `AGENTS.md`, and `specs/_template/` are created.
   - Execute `npx osq new smoke` inside the consumer directory. Assert that `specs/001-smoke/spec.md`, `tasks.md`, and `tasks/1.md` are scaffolded properly.
   - Clean up the temporary project and tarball in an `after` block.
2. In `.github/workflows/ci.yml`:
   - Ensure `OSQ_SKIP_PACK_TEST` is unset in CI so this integration test runs automatically on every pull request and push to main.

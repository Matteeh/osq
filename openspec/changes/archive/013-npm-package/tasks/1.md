## Acceptance
- [ ] package.json defines keywords, packageManager, and sideEffects: false
- [ ] prepublishOnly script uses npm run build rather than depending on pnpm on PATH
- [ ] npm pack --dry-run produces a tarball containing dist/, templates/, README.md, LICENSE, and package.json
- [ ] Tarball excludes root source files, tests, configs, .github, and specs
- [ ] Automated test executes npm pack --dry-run --json and asserts the exact package file list

## Signatures

In `package.json`:

```json
{
  "name": "osq",
  "version": "0.1.0",
  "sideEffects": false,
  "keywords": [
    "spec-driven-development",
    "coding-agents",
    "agentic-engineering",
    "watcher",
    "cli"
  ],
  "packageManager": "pnpm@9.15.4",
  "scripts": {
    "prepublishOnly": "npm run build"
  },
  "files": [
    "dist",
    "templates"
  ]
}
```

## Details

1. In `package.json`:
   - Add `"sideEffects": false`.
   - Add `"keywords": [...]` with relevant metadata terms.
   - Add `"packageManager": "pnpm@9.x"` (or current version from `.github/workflows/ci.yml`).
   - Change `"prepublishOnly"` from `"pnpm build"` to `"npm run build"`, ensuring standard npm publish environments execute the build without requiring `pnpm` binary on `PATH`.
   - Ensure `"files"` field includes `"dist"` and `"templates"`. Note that `README.md`, `LICENSE`, and `package.json` are included in npm tarballs by default.
2. In `tests/package-hygiene.test.ts`:
   - Run `npm pack --dry-run --json` via `child_process.execFile`.
   - Parse JSON output and assert that every tarball file path belongs to `dist/`, `templates/`, or matches `README.md`, `LICENSE`, or `package.json`.
   - Assert that no `.ts` source files from `src/` (outside declarations), test files, `.github` files, or change spec files are bundled.
   - Assert `sideEffects: false`, `keywords`, and `packageManager` exist in parsed `package.json`.

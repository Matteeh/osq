## Details

For the revised-plan row, build the approved, blocked change and its
current record the way `tests/auto-steer-inbox.test.ts` does (copy its
setup; don't import from it), then call `getWebChange` with that test's
config. For the archived and rejected rows, `buildWebFixture` from
`tests/fixtures/web/build.ts` gives `002-archived-change` and
`002-rejected-change`; select them by folder key, since id 002 is
ambiguous there. Use `DEFAULT_CONFIG` there, which has no version control,
so an archived change's next step is `landed`.

The browser package may import only types from `src/`, so the paste block
text has to be in the document. Static export already replaces the project
root in every string, so the absolute path in `text` is scrubbed there.

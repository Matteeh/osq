- `src/core/web/web-data.ts`: re-exports `WebPlanHandoff` and `WebAutoSteer`.
- Added `tests/web-change-next.test.ts` with one `node:test` block per row of "Change documents carry the next step": unplanned without/with `plan-prompt.md`, the approved blocked change with a current `ready` record, an archived change, and a rejected change.

## Changed

- `src/core/vcs/vcs.ts`: added the exported `VcsPushResult` interface and the
  `fetchBranch`/`pushBranch` members on `Vcs`.
- `src/core/vcs/git-vcs-remote.ts` (new): `fetchBranch` runs
  `git fetch --no-tags <remote> refs/heads/<branch>` and reads the commit
  `FETCH_HEAD` names; `pushBranch` runs `git push --porcelain <remote>
  <commit>:refs/heads/<branch>`, returns `done` on exit 0, `rejected` on a
  porcelain `!` line holding `[rejected]`, throws git's combined output
  otherwise, and carries that output on every result. Both tag the
  "Vcs remote operations" scenarios and ADR 003/014.
- `src/core/vcs/git-vcs.ts`: `runRemote` bounds the remote calls at
  `timeouts.gitRemoteSeconds` with `GIT_TERMINAL_PROMPT=0`; `GitVcs`
  delegates both port methods to `git-vcs-remote.ts`.
- `src/core/vcs/no-vcs.ts`: both new methods reject naming the reason git is
  off, as the other writes do.
- `src/core/foundation/config.ts`: `OsqTimeouts` gained optional
  `gitRemoteSeconds`.
- `src/core/foundation/config-vcs.ts`: added
  `DEFAULT_GIT_REMOTE_SECONDS = 120`. `DEFAULT_CONFIG` is unchanged.
- `tests/vcs-write.test.ts`: `PORT_MEMBERS` gained both members,
  `FORBIDDEN_ARGUMENTS` dropped `push` and gained `--force-with-lease`,
  `--mirror` and `--delete`, and a new case fails naming any file other than
  `git-vcs-remote.ts` whose argument list holds `push`.
- `tests/vcs-remote.test.ts` (new): bare `origin` plus two clones cover fetch
  without moving the local branch/status/index, fetch with no remote, a
  fast-forward push, a rejected push after the remote moved, the
  `gitRemoteSeconds` bound, and `NoVcs` rejecting both.

## Deviated

- `git-vcs-remote.ts` takes a `GitRemoteRun` callback rather than a context
  object like `git-vcs-land.ts`. `GitVcs` already sits at 249 lines after the
  additions; an object-typed context plus a constructor assignment pushed it
  over the 250-line budget, so the run function is passed inline.

## Outside scope

- `src/core/vcs/git-vcs.ts` is at 249/250 lines. The next member added to
  `GitVcs` needs a split first.

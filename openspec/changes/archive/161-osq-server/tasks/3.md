## Acceptance

- [ ] `landChange` in `land.ts` takes an optional fifth parameter, `LandOptions` (ports below), and calls `beforeMove` with the land commit after `commitTree` and before `fastForward`, as version-control "Land publishes to origin" says; a throw stops the land with that error and the default branch unmoved. Without it the land behaves exactly as today. `landChange` stays at or under 80 lines; move a block such as the sync-stop recording into a helper in `land.ts` if it would not.
- [ ] New `src/core/vcs/land-publish.ts` exports `landAndPublish` (ports below), implementing steps 1 to 4 of the requirement with the remote `origin`, the branch from `vcs.defaultBranch()`, `fetchBranch`, `isAncestor`, `fastForward` and `pushBranch`. Each line it adds goes into the returned `lines` in order: `Updated ...` before the land's lines, `Pushed ...` before `Landed ...`. Each stop is an `Error` with the exact message of the requirement, where `<id>` is the change's number as `landChange` words its own messages.
- [ ] `LandCommandOptions` in `src/cli/land.ts` gains `publish?: boolean`; with it `landCommand` calls `landAndPublish` instead of `landChange`, with the same stale-build refusal, output, rebuild line and `CommandError` handling. `registerLandCommand` adds no flag.
- [ ] New `tests/vcs-land-publish.test.ts` covers every scenario of "Land publishes to origin". It builds an archived change in a temporary git project as `tests/vcs-land.test.ts` does, adds a bare repository in the same temporary folder as `origin` and pushes `main` to it, and moves `origin` from a second clone with its own `git` calls; "Origin moved while landing" pushes from that clone inside `hooks.afterFetch`. It also runs one land through `landCommand` with `publish: true` and checks that `origin`'s `main` holds the land commit, and that `landCommand` without `publish` leaves `origin` untouched.
- [ ] Every touched source file stays at or under 250 lines and no file in `src/` holds the word "skipped". Every existing test, each `tests/vcs-land*.test.ts` included, passes unchanged.

export interface LandOptions {
  /** Runs with the land commit after it is built and before the default branch moves; a throw stops the land. */
  readonly beforeMove?: (commit: string) => Promise<void>;
}
export async function landChange(
  projectRoot: string,
  config: OsqConfig,
  idOrPrefix: string,
  progress?: (line: string) => void,
  options?: LandOptions,
): Promise<LandResult>;

export interface LandPublishHooks {

export async function landAndPublish(
  projectRoot: string,
  config: OsqConfig,
  idOrPrefix: string,
  progress?: (line: string) => void,

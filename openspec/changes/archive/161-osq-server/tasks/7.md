## Acceptance

- [ ] New `packages/ui/src/server/` holds `resolveApiBase(pathname)`, which returns `/p/<project>` for a path starting `/p/<project>/` with a project of letters, digits, `.`, `_` or `-` starting with a letter or digit, and `''` for any other path; a server status client that requests `<base>/api/server` with the injected fetch and returns the `WebServerStatus` or null on any failure; and the header label and Service panel components with their CSS. `contracts.ts` re-exports `WebServerStatus` with `export type`.
- [ ] `createDashboardData` takes an optional `base`, default `''`, and prefixes every document path and the event source path with it; `createActionClient` takes an optional second parameter `base`, default `''`, and prefixes its actions URL. With the default every requested path is exactly today's.
- [ ] `main.tsx` resolves the base from `window.location.pathname`, passes it to the data module and the actions client, and only when it is not `''` loads the status once at start and again after every refresh and every applied snapshot, keeping the last status when a request fails. `App` takes an optional `server?: WebServerStatus | null`; with one it renders `<project> on <name>` in the header and the Service panel first on the home route, before `HomeView`; without one it renders exactly as today.
- [ ] The Service panel implements web-inspection "Server header and service panel" with the exact line texts, `Waiting: <reason>` styled as a warning with the existing status palette, and a layout that wraps at 360 pixels with no fixed width wider than that.
- [ ] New `tests/ui-server.test.tsx` covers every scenario of "Server header and service panel", rendering `App` as `tests/ui-home.test.tsx` does, every row of "Service panel states" included; checks `resolveApiBase` for `/`, `/index.html`, `/p/osq/`, `/p/osq/index.html` and `/p/../`; and checks with recording fetch and event source stand-ins that a base of `/p/osq` puts the documents, the event source and the actions URL under `/p/osq/api/` while the default base requests `/api/` paths and never `api/server`.
- [ ] Every touched UI source file stays at or under 250 lines, imports from `src/` stay `import type`, and `pnpm typecheck:ui` passes. Every existing test, each `tests/ui*.test.tsx`, `tests/serve*.test.ts` and `tests/web-export.test.ts` included, passes unchanged.

- [ ] The `Vcs` interface gains `fetchBranch` and `pushBranch` and `vcs.ts` exports `VcsPushResult` (ports below). `GitVcs` implements both by delegating to new `src/core/vcs/git-vcs-remote.ts`, as it delegates land operations to `git-vcs-land.ts`; `NoVcs` fails both naming the reason git is off, as its other writes do.
- [ ] `git-vcs-remote.ts` implements version-control "Vcs remote operations": the exact fetch and push argument lists, `FETCH_HEAD` read back after the fetch, the porcelain `!` line with `[rejected]` as the only `rejected` case, git's combined output on every result, and every other failure thrown with git's output.
- [ ] Both operations run through `runGit` with the same redirecting-variable cleanup as every other call, `GIT_TERMINAL_PROMPT=0` in their extra environment, and a bound of `timeouts.gitRemoteSeconds`. `OsqTimeouts` in `config.ts` gains an optional `gitRemoteSeconds` next to `gitCommitSeconds`, and `config-vcs.ts` exports `DEFAULT_GIT_REMOTE_SECONDS = 120` next to `DEFAULT_GIT_COMMIT_SECONDS`; `DEFAULT_CONFIG` does not change.
- [ ] `tests/vcs-write.test.ts` implements "Operations osq never runs" as modified: `PORT_MEMBERS` gains `fetchBranch` and `pushBranch`; `FORBIDDEN_ARGUMENTS` drops `push` and gains `--force-with-lease`, `--mirror` and `--delete`; and a new case fails naming the file when an argument list containing `push` sits in any `src/core/vcs/` file other than `git-vcs-remote.ts`, using the same argument-list scan as the forbidden-argument case. Its other cases stay as they are.
- [ ] New `tests/vcs-remote.test.ts` covers every scenario of "Vcs remote operations" with a bare repository in a temporary folder as `origin` and two clones of it, built with the test's own `git` calls as `tests/vcs-write.test.ts` builds repositories; no network is used. It also checks that `NoVcs` rejects both operations.
- [ ] Every touched source file stays at or under 250 lines and no file in `src/` holds the word "skipped". Every other existing test passes unchanged.

## Ports

```ts
// src/core/vcs/vcs.ts
/** A push's outcome: taken, or refused because the remote has commits the pushed one lacks. */
export interface VcsPushResult {
  readonly status: 'done' | 'rejected';
  /** Git's combined output, stdout first. */
  readonly output: string;
}

// added to interface Vcs
/** The commit `<remote>`'s `branch` names after fetching it; fails with git's output. */
fetchBranch(remote: string, branch: string): Promise<string>;
/** Push `commit` to `<remote>`'s `branch` as a fast-forward only, never forcing. */
pushBranch(remote: string, commit: string, branch: string): Promise<VcsPushResult>;
```

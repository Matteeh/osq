## Changed

- `src/cli/help-groups.ts`: added `commandGroups(slices)`, which returns a new array of groups — `COMMAND_GROUPS` copied into fresh arrays, a command it already names kept in place when the slice declares that group (else throws `slice <slice>: command <name> is listed under <title>, not <group>`), and any other command appended to its declared group in registry order. `configureGroupedHelp(program, groups)` now formats the root help from the passed `groups` instead of reading `COMMAND_GROUPS`. Added `registerSliceCommands(program, slices)`, which calls each slice command's `register(program)` in registry order with both checks: a name already on the program throws `slice <slice>: command <name> is already registered` before the register runs, and a register that then adds no command of that name throws `slice <slice>: register did not add command <name>`. All three exported functions carry `@scenario cli-foundation: ...` and `@adr 016` tags.
- `src/cli/index.ts`: `createProgram(version?, slices = SLICES)` now registers every slice command through `registerSliceCommands(program, slices)` after its own commands and installs the root help with `configureGroupedHelp(program, commandGroups(slices))`. The file is exactly at the 250-line budget and `createProgram` stays well over 80 lines, so its `tests/function-budget.test.ts` grandfather entry still holds; a doc comment above `createProgram` carries the two scenario tags and `@adr 016`.

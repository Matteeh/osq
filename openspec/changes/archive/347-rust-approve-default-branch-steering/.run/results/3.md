## Changed

- Copied the four goldens and their print script into `crates/features/approve/tests/fixtures/default-branch-golden/` unchanged.
- Added `approve/default_branch.rs`: commits uncommitted plan edits as `osq: <id> replanned`, moves archived changes active, rewrites living specs from the default branch, writes `.run/requirements-base`, `.run/approved` and the `approved` event, commits `osq: <id> approved`, runs `sync_change` with records and verify off, records sync commits, records an approval stop for every sync stop (including `sync_conflict` through the task 4 seam), and recertifies differing done markers. The output adds `  Merged <default> into osq/<folder>`.
- Widened `lookup.rs` to worktrees whose active or archived change folder holds `.run/approved`, and made `approve` fall back to the first matching archived worktree change that has steering triggers. Archived changes without a default-branch trigger now get the new archived-steering refusal.
- Sent a worktree change with a default-branch trigger to the new default-branch approval, while git-off and other steered changes keep the steered path. Removed the old default-branch refusal.
- Updated `approve_steering.rs` rows for default-branch triggers to expect steered approvals, and removed the obsolete `sync_conflict` row from `approve_steered.rs`.
- Added `approve_default_branch.rs` and `approve_archived_lookup.rs`, covering every scenario row plus extra cases for outside-folder edits, spec removal, spec-removal errors and non-numeric done markers so every changed source line has a mutation-killing test.

## Deviated

- The new tests carry their own copy of the golden case builder instead of extending `worktree_support/mod.rs`, which is outside this task's scope and is left byte-identical.
- `stop_error` carries `#[cfg_attr(docsrs, mutants::skip)]`: until task 4 lands "Conflict reopen", its conflict and non-conflict arms record the same way, so cargo-mutants sees equivalent mutants. Task 4 removes the marker with the conflict path.

## Acceptance

- [ ] New `src/core/lifecycle/retry-archived.ts` holds the lookup and the commit of cli-foundation "Explicit retry command" for an archived change. The lookup gives `findChange`'s match when an active change matches. Otherwise it gives the first archived change in an osq worktree that matches, refusing a numeric target on it with the requirement's message, and with no match it throws `findChange`'s own error. The commit commits the retained marker, the removed `change.md` and `change.jsonl` on the worktree's branch, and puts the files back on failure.
- [ ] `retrySpec` in `src/core/lifecycle/retry.ts` calls the new lookup in place of `findChange` and changes nothing else. `retryCommand` in `src/cli/retry.ts` runs the commit after `retrySpec` returns for an archived change in a worktree, before it prints. `src/core/lifecycle/retry.ts` stays within the 250 lines `tests/line-budget.test.ts` allows.
- [ ] New `tests/retry-archived.test.ts` proves "Retrying a land stop on an archived change" and "Retrying a task of an archived change" with `createRecoveryProject`, `commitMain` and the project's `retry` and `land` from `tests/recovery-support.ts`, as `tests/recovery-land-red-verify.test.ts` builds its stopped land. Each `describe` is named after its scenario.
- [ ] Every other test does not change and keeps passing.
- [ ] Each exported function this task adds or changes carries `@scenario cli-foundation: <scenario name>` lines for the scenarios it serves and `@adr 003`.

## Details

Port the commit and put-back of `recordLandStop` in
`src/core/vcs/land-stop.ts`: the worktree's `selectVcs`, `vcs.commit` with
the repository-relative paths, `vcs.discard` and a restore of each file's
earlier bytes on failure. The paths are the retained `change.<n>.md` that
`retainFailureMarkers` reports, the removed `change.md`, and
`.run/events/change.jsonl`. The author is `config.vcs.author`, and the
message is `osq: <id> land retry`. Find archived worktree changes with
`listChanges(projectRoot, config, ['archived'])` and `matchesFolder` from
`src/core/status/change-locations.ts`, keeping only those whose
`tree.worktreeFolder` is set. Never run git from the test except through
`tests/recovery-support.ts`'s `git` helper.

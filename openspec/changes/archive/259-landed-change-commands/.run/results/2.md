## Changed

Added `src/cli/plan-finished.ts` with `refuseFinishedChange`, which looks up the first archived change in any tree with `listChanges(projectRoot, config, ['archived'])` and `matchesFolder`, reads its `landed` or `archived` state with `readDependencyState`, and throws the requirement's message naming the queue path relative to the project root. It returns without writing for an empty name or no archived match.

`src/cli/plan.ts` calls it in the branch that is about to create a new change for a name that matched no active change, immediately before `createChange`. `--next`, steering, a resumed change and `--run` are untouched. Two blank lines were removed inside `planCommand` so the file stays within the 250-line source budget.

Added `tests/plan-finished.test.ts`, which proves both "Plan a finished change" rows: a landed one-task change from `createRecoveryProject` after a successful `land`, and an archived change written into a scaffolded project with `vcs.enabled` off. Each row asserts the exact refusal message and that the changes directory lists the same folders after the failed plan.

Touched: src/cli/plan.ts, src/cli/plan-finished.ts, tests/plan-finished.test.ts

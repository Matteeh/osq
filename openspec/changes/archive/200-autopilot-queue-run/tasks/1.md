## Details

`config.ts` is at its budget. Measured on 2026-10-16: it fits when `defineConfig` first takes the block out with `const { autopilot, ...user } = config;` and destructures the rest from `user` (a longer name makes Biome wrap that line), the four `validatedPlanner` lines become one conditional `const`, and the blank line after the `validateWatchConfig` call goes. Destructuring `autopilot` out matters: left in the rest spread, its `Partial` type breaks the `OsqConfig` return type.

Tag the exported resolver with `@scenario cli-foundation: Autopilot values` and `@adr 021`.

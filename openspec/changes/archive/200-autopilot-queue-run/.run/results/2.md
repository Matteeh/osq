## Changed

- New `src/core/status/queue-approval.ts`: the `QueueApproval` and `QueueApprovalEntry` types, `hashText`, and the exports `queueApprovalPath`, `writeQueueApproval`, `readQueueApproval` and `itemApproval`. `writeQueueApproval` writes `<openspecRoot>/.run/queue-approval.md` with `approved_at`, `approver` and the slug→hash `items` mapping in queue order, then reads the file back and hashes its exact text as `sha256:` for the returned record. `readQueueApproval` parses it with `parseFrontmatter` and returns null for a missing or unparsable file. `itemApproval` answers `approved`, `changed`, or `unapproved`.
- New `src/core/status/autopilot-stop.ts`: the `AutopilotStopReason` union with all nine reasons, the `AutopilotStop` type, and the exports `autopilotStopPath`, `writeAutopilotStop`, `readAutopilotStop` and `clearAutopilotStop`. The record is `<openspecRoot>/.run/autopilot-stop.md`; `change` and `detail` are left out when absent, a missing or unparsable file reads as null, and clearing a missing file succeeds.
- `src/cli/queue.ts`: `queueCommand` reads the queue and any approval record and, with one, inserts the `Approved by <approver> at <approved_at> (<hash>)` line after `Queue:` and appends ` approved` / ` changed since approval` / ` not approved` to each item line, leaving `formatQueue` untouched. New `approveQueue` reads the queue, records every item's hash, clears the autopilot stop, prints `Approved <n> queue items (<hash>)`, then prints the autopilot-off line unless `autopilot.enabled`. `readApprover` uses `selectVcs` with `configValue('user.name')`/`configValue('user.email')` and returns empty without git. New `registerQueueCommand` registers `osq queue` (same description) and its `approve` subcommand.
- `src/cli/index.ts`: the inline `queue` block is replaced by `registerQueueCommand(program)`.
- `src/cli/remote-client.ts`: `apply` still forwards plain `queue` but overrides the `queue approve` subcommand's action with `refused('queue approve')`, so it refuses with the local-only line.
- New `tests/queue-approval.test.ts`: 11 tests proving the eight scenarios, run through `queueCommand`'s module, `runCliCaptured`, and `createProgram`/`forwardProgram` against temporary projects.
- `pnpm verify` passes (EXIT=0) and the task verify passes 11/11.

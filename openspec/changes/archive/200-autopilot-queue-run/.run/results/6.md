## Changed

- New `packages/ui/src/home/needs-you-model.ts` with two pure functions:
  `needsYouRoute(item)`, the change route, or null for an `autopilot-stopped`
  item whose `autopilotStopped.change` is null, and `needsYouReason(item)`,
  ` — <reason>` for an autopilot stop and null for any other kind. Each is
  tagged `@scenario web-inspection: Stop rows on the home view`, `@adr 020`
  and `@adr 021`.
- `packages/ui/src/home/NeedsYouGroup.tsx` now takes its route and reason from
  that model: it renders the title as an `<a>` only when the model returns a
  route, as a `<span class="home-change">` otherwise, and appends
  `<span class="home-reason">` when the model returns a reason. Every other
  kind is unchanged (route non-null, reason null, so the markup is byte for
  byte what it was). Tagged with the same scenario and ADRs.
- New `tests/ui-autopilot-stop.test.tsx`: proves "Autopilot stopped label" via
  `needsYouKindLabel`, "Stop rows on the home view" by rendering
  `NeedsYouGroup` with `renderToStaticMarkup` for each table row (linked change
  vs. plain-text queue item), and the model's route/reason by a table of cases.

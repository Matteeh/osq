## Details

Put the folder fsync behind `#[cfg(unix)]`. On other systems the rename
and the file's `sync_all` are the limit std offers. A test cannot observe
an fsync, so the rows check the visible results: the new bytes, no
leftover temporary file, and the errors.

Run the proposal's verify as the watcher does, with
`OSQ_CHANGE=openspec/changes/326-rust-feature-events-adr`, so the link
gates see this change's new requirements.

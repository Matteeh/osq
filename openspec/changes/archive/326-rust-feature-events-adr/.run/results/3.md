## Changed

- Raised the workspace `rust-version` to 1.89 and added `osq-kernel-config`, `osq-kernel-vcs` and `serde_json` to the loop kernel's dependencies.
- Applied clippy's own `collapsible_if` and `manual_is_multiple_of` rewrites across the scoped files, then `cargo fmt --all`; no allow or lint change was added.
- Added `src/delivery.rs` and `src/delivery/` with `run_command`, `CommandRun` and `ReactionFailure`, exported from the loop crate root.
- Delivery lists active changes from `list_changes`, or from `list_tree_changes` over the git worktrees when `vcs.enabled` names a repository root; a worktree-listing failure gives the `delivery`/* failure.
- Delivery takes each change's `.run/delivery.lock` with `File::try_lock`, skips a held lock quietly, and reports a lock that cannot be taken.
- Each reacting feature reads `.run/delivered/<feature>` through a compact, sorted, durable cursor; missing cursors start empty, invalid cursors fail, and offsets advance only over complete lines through the last newline.
- Event lines are delivered to listed kinds in file-name byte order; refused lines become warnings, unlisted kinds are passed over, and a failed reaction stops that feature for that change while leaving its cursor before the failed line.
- Added `tests/command_entry.rs`, `tests/delivery.rs` and `tests/delivery_support/mod.rs`, proving every named scenario and the additional git-worktree and unreadable-cursor branches needed by mutation coverage.
- Ran `cargo fmt --all`, the task verify, `sh scripts/verify-rust.sh` with `OSQ_CHANGE` set, and mutation over the full change diff. The diff had 219 mutants: 155 caught, 64 unviable, none missed.

## Deviated

- Added two extra tests beyond the scenario table: a git-worktree change is delivered when `vcs.enabled`, and is ignored when it is off. The mutation check showed these branches needed explicit coverage.
- Added an unreadable-cursor case (the cursor path is a folder) beside the `[1]` invalid-cursor row, to distinguish a missing cursor from one that cannot be read.

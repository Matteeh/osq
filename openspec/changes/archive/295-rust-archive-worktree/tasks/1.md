## Details

Build the trees as the plan feature's `trees.rs` does, `GitVcs::new`,
`with_timeouts`, `worktree_list` turned into `TreeCandidate`s and
`change_trees`, with no stacked folders, and find the change's tree as
`found_in` in its `steer/lookup.rs` does. A feature never calls another, so
write that code in this crate. Keep the vcs-off path on `list_changes`, so
the 248 tests, which have no `osq.toml`, never run git.

Pass the tree's root wherever `archive.rs` and `relocate.rs` take the root
today. Commit after `relocate::run`, port the path choice from
`commitArchive` in `src/core/run/task-commit.ts` and the message from
`formatCommitMessage`, and keep both pure.

In the test, build each repository with `git` through
`std::process::Command`, as `retry_archived.rs` does, exactly as the golden
script's header says, under a new folder of `CARGO_TARGET_TMPDIR` named
after its row. The script's TypeScript calls stand in for the Rust
`archive` run; leave them out. Write the hook with mode `0o755` through
`std::os::unix::fs::PermissionsExt`. Read the tip with
`git log -1 --format=%B <branch>`, the commit with
`git show --no-renames --name-status --format= <branch>` and the status
with `git status --porcelain --untracked-files=all` in the tree, and build
the text the golden holds before comparing. A test cannot set environment
variables.

When the mutation check reports a missed mutant, add a test case for that
line rather than keeping a branch no test reaches. Take its expected value
from the TypeScript source or a golden. Run the proposal's verify as the
watcher does, with `OSQ_CHANGE=openspec/changes/295-rust-archive-worktree`,
so the link gates see this change's requirements.

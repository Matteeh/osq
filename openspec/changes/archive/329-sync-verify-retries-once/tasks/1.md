## Details

Reuse how `tests/vcs-sync.test.ts` builds a scratch repository with an
archived change in its worktree and moves the default branch. Copy what the
new file needs, since that file must not change.

The verify is a small `node -e` or shell command that reads and writes a
marker file in the test's scratch folder, outside the worktree, so the
merged tree stays clean. Count the runs in the "Verify red on both runs"
case with the same marker, as one line per run.

`src/core/vcs/sync-verify.ts` must stay within the 250-line source budget.

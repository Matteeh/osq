## Details

Build the rows as `tests/land_sync_verify.rs` builds "Sync verify outcomes",
with the support module's public helpers, copying what the new file needs.
The marker path is absolute, under the row's scratch folder and outside the
worktree.

`append_event` writes `exit_code: Some(0)` today; it takes the run's exit
code instead.

Run the verify as the watcher does, with
`OSQ_CHANGE=openspec/changes/329-sync-verify-retries-once`, so the link
gates see this change's new scenario.

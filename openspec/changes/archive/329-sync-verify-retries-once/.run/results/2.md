## Changed

- `crates/features/land/src/land/sync/verify.rs`: `one` runs a command that exits non-zero once more in the same worktree. If the second run exits 0, both runs are recorded with their own logs and `verify_ran` events, the failed one keeping its non-zero exit code; if it also fails, the sync stops with `sync_verify_red` and the second run's output tail. Added a `record` helper and made `append_event` take the run's exit code instead of always writing 0.
- `crates/features/land/tests/land_sync_verify_twice.rs`: new test file proving "Sync verify runs twice", one test per row, each with its marker file in that row's own scratch folder outside the worktree.

## Changed

- `crates/kernel/storage/src/read/snapshot/markers.rs`: `HaltMarker` gains
  `fingerprint: Option<String>`, read with the existing `string_field` helper
  as the frontmatter's `fingerprint` when it is a string, else `None`. Every
  other field reads exactly as before.
- `crates/kernel/storage/tests/reading_markers.rs`: its six `HaltMarker`
  literals gain the fingerprint their marker file holds (`sha256:2` for task
  2; `None` for the others). Both scenarios are otherwise unchanged.
- `crates/kernel/storage/tests/marker_fingerprint.rs`: new test proving
  "Marker fingerprint" for the `052-stuck` change folder under
  `CARGO_TARGET_TMPDIR`: a string fingerprint reads, a numeric one gives
  `None`, and a regressed marker without one gives `None`.

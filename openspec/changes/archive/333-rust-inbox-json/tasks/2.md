## Details

Port `readLastLook` and `resolveLastLookPath` in
`src/core/status/inbox-cursor.ts` and `writeLastLook` in `src/cli/inbox.ts`.
Take the hash from rust-storage `watch_state_dir`, the last part of the path
it gives; add no dependency and change no crate but this one. Write the run's
time as `toISOString()` does with a small pure function, since no crate the
inbox depends on formats one. `collectLandedItems` in
`src/core/status/inbox.ts` shows the cursor filter: strictly later than the
cursor, and no limit of ten while a cursor exists.

Never read anything under `src/` of the repository from Rust; the TypeScript
files are in `entry` only so you can port them.

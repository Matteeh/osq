## Details

TypeScript reads the fingerprint in `src/core/status/state.ts`, where a dead
marker with `stuck: true` and a string `fingerprint` gives the task its
`stuck` value; the inbox needs it for its JSON. Read it with the
`string_field` helper `markers.rs` already uses for `reason`.

Never read anything under `src/` of the repository from Rust; the TypeScript
file is in `entry` only so you can see the rule.

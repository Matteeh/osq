## Changed

- `src/core/run/manifest.ts`: made `ManifestData.approvedAt` optional and added
  optional `createdAtSource: 'created'`. Replaced the old mtime-based
  `resolveCreatedAt`/`resolveChangeDoc` import with `resolveCreation`, which
  keeps a valid existing manifest `createdAt` (with its `created` marker when
  present, never adding one to an unmarked value), else uses the change folder's
  valid non-epoch birth time marked `created`, else the current time marked
  `created` only when no approval flags were passed. `approvedAt` is now written
  only on the approval path.
- `tests/manifest-creation.test.ts`: new test file covering the plan-time
  manifest, approval/reapproval keeping the creation time, an existing unmarked
  `createdAt`, and the no-manifest birth-time fallback.

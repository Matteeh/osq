## Changed

- Added `src/core/run/manifest-approval.ts` exporting
  `readManifestApprovedAt(changeFolder)`; it returns the manifest `approvedAt`
  only when `.run/approved` exists and the value parses as a date.
- `src/watcher/auto-retry.ts`: dropped the local `readApprovedAt` in favor of
  `readManifestApprovedAt(folderPath)` for the automatic-retry cutoff.
- `src/core/web/web-data-lifecycle.ts`: `readManifestMetadata` fills `approvedAt`
  through `readManifestApprovedAt`.
- `src/core/report/planning-slice-lookup.ts`: `manifestApproval` now delegates to
  `readManifestApprovedAt`.
- Added `tests/manifest-approval-gate.test.ts` covering the reader with and
  without the marker, a missing/malformed/invalid manifest, the web graph
  `approved` field before and after the marker, and `resolveChangeApprovalTime`
  for an unmarked manifest, a marked manifest, and a rejected change with no
  recorded slice.
- `tests/planning-slice.test.ts` and `tests/planning-slice-archive.test.ts` now
  write `.run/approved` wherever they write a manifest `approvedAt`.

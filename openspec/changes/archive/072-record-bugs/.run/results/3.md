## Changed

- Added `src/core/report/brief-to-approval.ts` exporting
  `readBriefToApprovalSeconds(folderPath)`: reads the manifest, requires
  `createdAtSource: "created"` and a valid `createdAt`, then measures to
  `readManifestApprovedAt(folderPath)`, returning rounded non-negative seconds or
  null.
- Added `src/core/report/scope-size.ts` exporting `taskScopeSize(events,
  startScopeFiles)`: the key count of `scopeHashes` on the last `measures` end
  event that carries one, else the start value.
- `src/core/report/report.ts`: `deriveMeasuredTask` now feeds `scopeFiles` from
  `taskScopeSize`; `readApprovedAtMs` reads `readManifestApprovedAt`; the unused
  `parseBriefDateMs`/`readBriefDateMs` are gone; the cycle row's brief-to-approval
  calls `readBriefToApprovalSeconds`; `RepositoryRecord` carries
  `firstAttemptPasses` and the body prints
  `First-attempt passes: <passed>/<measured>`; a cycle phase with zero coverage
  prints `not reported (0 of <m> archived changes)`.
- `fixture/report/`: the two archived manifests keep their `approvedAt`
  and gain `.run/approved`, so brief to approval reads as null for those
  pre-marker records while approval-based phases stay trusted.
- Regenerated `fixture/report/expected.json` from `reportCommand` with
  `json: true`; the diff touches only cycle values (the two brief-to-approval
  rows and the brief-to-approval/total phase aggregates). Scope sizes are
  unchanged because the fixture has no `measures` events.
- Added `tests/report-record-accuracy.test.ts` covering, through
  `getMetricsReport`/`getRepositoryRecord` and `formatMetricsReport` on temp
  projects: marked creation to trusted approval, the absent marker, the untrusted
  approval, the uncovered-phase text, created files sized 5 in buckets/largest
  pass/record, the start-only fallback, and `First-attempt passes: 8/8`.
- Updated `tests/report-cycle.test.ts` (manifest setup writes the marked
  `createdAt` plus `.run/approved`; fixture brief-to-approval rows and aggregates
  now null/zero and the uncovered-phase text is asserted),
  `tests/report-sizes.test.ts` (counts replace the rate), and `tests/plan.test.ts`
  (the count line).

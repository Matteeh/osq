## Changed

- Added `crates/features/run/src/feature/output.rs` with `tail_verify_output` and `excerpt_verify_output`, ported from TypeScript and sized entirely by the two config limits. It drops trailing whitespace, keeps the last failing-tests line onward, cuts long lines by Unicode character, and appends `Full output: <log>`.
- Added `crates/features/run/src/feature/log.rs`, which writes each verify's whole output to the next free `.run/logs/<target>-<n>.log`, creates the logs folder, and writes `.gitignore` holding `*` and a newline when missing.
- Updated the verdict and events so every verify writes its log and `verify_ran` event with `log` and the config-sized `output` tail, and so dead markers use the config-sized excerpt. Empty task output becomes `Process exited with code <code>`; a timed-out task verify keeps the excerpt of its output under `Watcher independent verify timed out:`.
- Removed `OUTPUT_TAIL_BYTES` and the byte `tail` from the run crate.
- Added `crates/features/run/tests/run_verify_output.rs`, proving every row of "Verify output from the config" plus empty change output, log-name counting, and excerpt/tail edge cases. Updated `verify_timeout_keeps_the_output_tail` to expect 40 `é` lines and the full-output line.
- Ran `cargo fmt --all`, `cargo clippy -p osq-feature-run --all-targets -- -D warnings`, the task verify, all `osq-feature-run` tests, and `OSQ_CHANGE=openspec/changes/309-rust-run-verify-tail sh scripts/verify-rust.sh`; all pass.
- Ran `cargo mutants` over the changed source files `output.rs`, `log.rs`, `verdict.rs` and `events.rs`: 50 tested, 45 caught, 5 unviable, none missed.

## Changed

- `crates/kernel/runners/src/run.rs`: added `HarnessExit::error` and the required
  `Harness::harness_version()` port method; `run_task` already returns the exit
  unchanged, so no judgement code changed.
- `crates/kernel/runners/tests/support/mod.rs`: `FakeHarness` now carries a
  version, returns `None` by default, and has `with_version` for tests; `exit`
  builds an exit with no error.
- `crates/kernel/runners/tests/run_task.rs`: added
  `exit_error_and_harness_version`, one assertion per named row.
- `crates/kernel/harnesses/src/pi/harness.rs`: removed `last_error()` and its
  field, added the stored preflight version with public `with_preflight` and
  `harness_version()`, and made `failure` fill the exit's `error`. Blank
  preflight versions read as `None`.
- `crates/kernel/harnesses/tests/pi_harness_run.rs`: rows and assertions now
  read the exit's `error`; `settled_start_hides_stderr` checks the exit's
  `error`, and the row values are unchanged.
- `crates/kernel/harnesses/tests/pi_harness_version.rs`: new table test for the
  five "Pi harness version" rows, without starting a program.

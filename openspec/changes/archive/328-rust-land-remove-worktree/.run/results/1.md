- Wired the cleanup into `run_land` after a land commit and for an already landed change.

- Replaced the landed-change placeholder line with `<folder> has already landed\n<cleanup line>\n`, or `<folder> has already landed; nothing to clean up\n`.
- Removed `text::landed_worktree` and its placeholder text.
- Added `tests/land_cleanup.rs` proving every row of "Cleanup outcomes" and "Cleanup of a landed change".
- Updated `tests/land_lookup.rs` for the modified "Already landed" rows, and the landed text in `tests/refusals.rs` and `tests/land_after_retry.rs`.

## Deviated

- The log tests write a nested `.run/logs/.gitignore` containing `*`, as osq's own log folder does, so the probe log is ignored by git as the scenario says.

## Changed

- Added `planning_token_models` in `crates/kernel/storage/src/read/planning_models.rs`. It reads `.run/plan.jsonl`, parses `plan_started` and `plan_exited` records the way TypeScript does, correlates first start and first exit by `sessionId`, keeps sessions whose start names a model and whose exit recorded a usage or slice token count, and returns the distinct models sorted by bytes.
- Exported the reader from `read` and the crate root and added the requirement's `Implements` tags.
- Added `tests/reading_planning_token_models.rs`, proving every row of "Planning token models of a folder" in its own scratch folder, plus slice cost-source edges and an unreadable log.
- Task verify and the proposal verify both pass. `cargo mutants -p osq-kernel-storage -f crates/kernel/storage/src/read/planning_models.rs` tested 38 mutants: 37 caught, 1 unviable, 0 missed.

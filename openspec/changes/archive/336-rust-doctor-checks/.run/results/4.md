## Changed

- `run_doctor` now appends the `languages`, `planning-prices` and validator lines after the git lines, before deciding whether any line fails.
- Added `src/doctor/languages.rs`, holding TypeScript's language presets and gate/extra coverage as data and building the `languages` line from the git check's tracked paths plus the root manifests.
- Added `src/doctor/prices.rs`, reading active and archived change folders through rust-storage's `planning_token_models` and warning about unpriced models with JSON-quoted `planning.prices[...]` keys.
- Added `src/doctor/validator.rs`, building `validator-runs` from archived snapshots and `validator_failing`, `validator-harness*` from the harness module with renamed lines, and `validator-model`.
- Refactored `src/doctor/git.rs` to return its lines together with the tracked paths from `line_endings()` in the usable git case, and `src/doctor/changes.rs` to share its real-root and folder listing with the new checks.
- Added `tests/doctor_languages.rs`, `tests/doctor_prices.rs` and `tests/doctor_validator.rs`, proving every row of "Doctor languages lines", "Doctor planning prices lines" and "Doctor validator lines".

## Details

Build the fake git as `tests/vcs.test.ts` does in "Vcs git read timeout":
a shell script that answers `--version` and `rev-parse --show-toplevel`,
sleeps 5 seconds on `worktree prune`, and otherwise runs the real `git`.
Select it with `selectVcs(dir, config, { gitBinary })` on a `git init`
repository, with `timeouts.gitSeconds: 0.1`. `worktreePrune` goes through
`ok` in `src/core/vcs/git-vcs-write.ts`, which throws git's combined output,
so the new text reaches the error message with no change there.

The scenario helper's `covers` is the `GitVcs` method `worktreePrune`; call it
through `run`.

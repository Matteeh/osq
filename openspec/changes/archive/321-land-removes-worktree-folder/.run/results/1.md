- `tests/vcs-git-timeout-message.test.ts`: new scenario test for "Prune past its time limit", using a fake git that answers `--version` and `rev-parse --show-toplevel`, sleeps on `worktree prune`, and otherwise delegates to the real git, with `timeouts.gitSeconds` set to `0.1`.

- The fake git uses `exec sleep 5` on `worktree prune` rather than `sleep 5; exit 0`, so the timed-out child does not leave a sleeping grandchild holding the pipes open.

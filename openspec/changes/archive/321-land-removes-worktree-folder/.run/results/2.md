## Changed

- Moved the worktree cleanup out of `src/core/vcs/land.ts` into the new `src/core/vcs/land-cleanup.ts`, which now copies the worktree's archived `.run/logs` into the checkout, deletes the whole worktree folder with ignored files, and then runs `worktreePrune`.
- A failed cleanup now prints `Could not remove worktree <path>: <cause>` and makes both the fresh-land and already-landed paths exit 1, while keeping the land commit and the `Landed`/`Kept branch` lines.
- Cleanup now also handles a folder left at the worktree path after git has stopped listing the worktree, so the next `osq land <id>` removes it.
- Added `tests/vcs-land-cleanup.test.ts` covering all four delta scenarios: ignored build output, logs kept in the checkout, removal failure after the land commit, and leftover folder removal on the next land.

## Changed

- Added `crates/kernel/storage/src/read/now.rs` with `read_now_facts`, `NowFacts` and `NowTask`, reading a change folder's proposal presence, task entries and done/manual/dead/regressed/running markers without failing. Task files are listed in byte order; marker existence uses `symlink_metadata`, and the manual flag is read only through rust-specs `parse_frontmatter`.
- Exported the reader and both types from `crates/kernel/storage/src/read/mod.rs` and the crate root in `crates/kernel/storage/src/lib.rs`.
- Added `crates/kernel/storage/tests/reading_now_facts.rs`, with one test for "Now facts of a change folder" and one for every row of "Now facts edges", each using a fresh folder under `CARGO_TARGET_TMPDIR`.

## Deviated

- `NowTask` needs the five boolean fields rust-storage "Now facts" names. Clippy's pedantic `struct_excessive_bools` rejects a struct with more than three, so the struct carries `#[expect(clippy::struct_excessive_bools, reason = "rust-storage/now-facts names five independent boolean facts")]`. The reason is recorded on the attribute, per ADR 023's lint-gate rule, instead of changing the required public fields.

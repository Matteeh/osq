## Changed

- Restored and completed the task's report implementation in `src/report/`: `arguments` parses only `--json`; `entries` loads the config, applies show's root check, and lists the root, worktrees and stacked folders when git is on; `counts` reads each non-rejected change through storage's `read_now_facts` and applies the status order; `output` writes TypeScript's header, `Specs Summary:`, `Now:` text and the sorted `completionRate`/`now`/`specs` JSON with no trailing newline.
- `ReportFeature` lists `report` then `query`; `report` accepts repeated `--json` in any position and refuses every other argument before reading a file. `query` is unchanged.
- Added `osq-kernel-config` and `osq-kernel-vcs` to the crate's dependencies.
- Copied the change's fixture projects and goldens into `tests/fixtures/summary/`, hidden `.run/` markers included.
- Updated `tests/report_feature.rs` for both commands and the `summary` unknown-command row; added `tests/report_summary.rs` for the five goldens, repeated `--json`, status order, argument errors, a refused config and the shortest-decimal rate; added `tests/report_trees.rs` for the worktree scenario, stacked approvals, a root below the repository top and an unset `HOME`.
- Corrected the copied JSON goldens, which the prior attempt's patch had stored with a trailing newline. They now match the change's goldens byte for byte, as the scenario requires.
- `cargo test -p osq-feature-report --test report_feature --test report_summary --test report_trees` passes, `cargo fmt --all` passes, and `OSQ_CHANGE=openspec/changes/305-rust-report-summary sh scripts/verify-rust.sh` passes.

## Deviated

- The worktree scenario's `osq.toml` also holds `vcs.author`, because the config kernel refuses `vcs.enabled = true` without an author; the scenario names only `enabled = true`.
- The completion rate is stored as integer hundredths, `(done * 20000 + total) / (total * 2)`, which is JavaScript's `Math.round(done / total * 10000)`, and `rate` trims the decimal to JavaScript's shortest form.
- `tests/report_trees.rs` also counts a change under the isolated home's stacked approvals root, proves a root below the repository top makes git off, and proves an unset `HOME` adds no stacked change; `tests/report_summary.rs` adds a `12.5` rate case. These extra assertions kill mutants the scenario rows alone leave alive.
- Restored `Cargo.lock` after cargo added the two new crate dependencies to its `osq-feature-report` entry, so no file outside the task's scope remains changed.

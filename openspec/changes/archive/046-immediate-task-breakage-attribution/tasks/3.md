## Details

This task closes the planning-scope omission recorded in both completed task
results and the active change regression. Modify tests only; do not change
`runTask`, `checkAndArchiveSpec`, configuration defaults, or capability deltas.
Reuse `DEFAULT_CONFIG` and construct a local configuration override with
`gates: { changeVerifyAfterTask: false }` for scenarios whose subject is
strictly archive-time failure, scope-audit ordering, or prompt retention.

In the clean archive case, retain `DEFAULT_CONFIG` so the test covers the new
default behavior. The two successful task runs each append a change-target
`verify_ran`, and `checkAndArchiveSpec` appends the established archive-time
third event; assert their commands and successful exit codes without weakening
the existing task-stream and archive assertions.

Use the opt-out consistently for every `runTask` call in an isolated scenario,
while leaving `checkAndArchiveSpec` on the same local config. This ensures a
deliberately failing proposal verifier is first encountered by the archive
gate and ensures a failed scope audit records no ordinary change verification.
In `plan-prompt-lifecycle.test.ts`, allow the task helper to accept the local
config or make the failing-archive case execute the task with that config.

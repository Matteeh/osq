## Details

The README and the repository's `.env.example` are ungoverned: `ungoverned`
in `osq.config.ts` defaults to `README*` and `.env*`. `templates/.env.example`
is a template that `osq init` copies, owned by cli-foundation, so tests keep
comparing the scaffolded file with it. Do not edit `README.md`,
`.env.example` or `templates/.env.example`.

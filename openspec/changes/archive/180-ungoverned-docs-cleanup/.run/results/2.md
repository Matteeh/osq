## Changed

Removed every README and repository `.env.example` assertion from the eight
harness, scaffold and package tests, keeping all scaffold/template and
CHANGELOG checks:

- `tests/harness-defaults-docs.test.ts`: dropped the `safer harness defaults:
  README` describe block, dropped `readmePath` and `repoEnvExamplePath`, and
  renamed the mirror test to `mirrors the scaffolded .env.example in templates
  byte for byte`, comparing the scaffolded file with `templates/.env.example`
  only. The CHANGELOG describe block stays, so the `section` helper and
  `changelogPath` stay.
- `tests/pi-default-scaffold.test.ts`: dropped `repoEnvExamplePath` and made
  the same mirror change, comparing only with `templates/.env.example`.
- `tests/codex-guidance.test.ts`: dropped the `codex consumer guidance: README`
  describe block and the `mirrors the repository .env.example exactly` test,
  dropped `repoRoot`, `repoEnvExamplePath`, `readmePath` and the
  `fileURLToPath` import, and rewrote the file comment to describe scaffold
  coverage only.
- `tests/pi-default-docs.test.ts`: dropped the `pi default harness: README
  Upgrading` and `pi default harness: README Pi section` describe blocks and
  `readmePath`. The CHANGELOG describe block, `section` and `lines` stay.
- `tests/opencode-config.test.ts`: dropped `README documents opencode in
  harness list with sample configuration block`.
- `tests/opencode-setup.test.ts`: dropped `README notes --auto flag approves
  any action the agent file does not deny`.
- `tests/init-planning-guidance.test.ts`: dropped the two README tests,
  `repoRoot`, `readmePath` and the `fileURLToPath` import; kept `generates a
  config with no required planner model`.
- `tests/package-hygiene.test.ts`: renamed the Node baseline test to `aligns
  package metadata, CI, and workspace manifests on Node 24 LTS` and dropped

  packed files stays, since it checks the npm package's contents.

repository's `.env.example`.

## Changed

- Copied `fixture/pi-run.jsonl`, `fixture/pi-edges.jsonl`,
  `golden/pi-run-events.json` and `golden/pi-edges-events.json` byte for byte
  into the harness crate with `cp`.
- Added `serde_json.workspace = true` to the crate and let cargo add
  `serde_json` to the crate's `Cargo.lock` dependency list.
- Added `src/pi.rs` with `PiSettings`, `PiStreamState` and `settled`, plus
  `pi_args` and `pi_line_events`. `src/lib.rs` now declares `mod pi` and
  re-exports those four items.
- Added pure helpers under `src/pi/`: `args.rs` builds pi's argv, `summary.rs`
  builds and root-strips tool summaries, `path.rs` gives Node-style relative
  paths, and `stream.rs` translates pi's lines into core `Event`s.
- Added `tests/pi_args.rs` with every table row, `tests/pi_stream.rs` for both
  goldens and the non-whole-count scenario, and `tests/pi_stream_edges.rs` for
  extra root, path, empty-field and whole-float cases.
- `cargo mutants` on each new source file caught every viable mutant: `pi.rs`
  6 caught / 1 unviable, `args.rs` 4 caught, `summary.rs` 20 caught,
  `path.rs` 9 caught, `stream.rs` 33 caught / 7 unviable.
- `OSQ_CHANGE=openspec/changes/242-rust-harness-process sh scripts/verify-rust.sh`
  passes (format, clippy with `-D warnings`, every Rust test).

## Deviated

- Count fields also accept JSON floats whose value is whole, such as `3.0`
  and `1e2`, because the delta says a count counts when it is a whole number.
  The delta's non-whole examples (`1.5`, `-2`) still give absent counts.
- The verify script printed `mutation check not run: OSQ_DIFF is not set`, so
  its workspace mutation step was skipped; the per-source-file `cargo mutants`
  runs above stand in for it.

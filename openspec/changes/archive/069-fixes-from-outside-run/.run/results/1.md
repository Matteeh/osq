## Changed

- `src/watcher/build-project.ts` (new): exports `resolveProjectCommit(projectRoot)` plus the shared `readGitCommit`/`readGitTopLevel` git helpers. Returns the project root's short HEAD or null outside git.
- `src/watcher/build.ts`: `resolveBuildInfo(packageRoot?)` now defaults to `PACKAGE_ROOT` and reads only that root's `package.json`. The commit is the short HEAD only when `git rev-parse --show-toplevel` resolves to the same real path as the root, otherwise the root's `dist/` hash, otherwise `unknown`. Removed the project-first version fallback and the local git helper; per-root cache retained.
- `src/harness/types.ts`: `StartedEventData` gains `projectCommit?: string | null`.
- `src/watcher/spawn.ts`: resolves `resolveBuildInfo()` (osq identity) and `resolveProjectCommit(projectRoot)` together and records `projectCommit` on the `started` event.
- `src/watcher/loop.ts`: resolves `resolveBuildInfo()` for the idle status line, so it names osq's version and commit.
- `src/watcher/regression.ts`: `buildDoneMetadata` resolves `resolveBuildInfo()` for `build_stamp` and `resolveProjectCommit(projectRoot)` for the new `project_commit`.
- `src/watcher/outcome.ts`: `DoneMarkerMetadata` gains `projectCommit?`; `writeDoneMarker` emits `project_commit: "<sha>"` or `project_commit: null` after `build_stamp`.
- `tests/fixtures/events/verified.jsonl`, `tests/fixtures/events/dead.jsonl`: the `started` event gains `"projectCommit":null`; nothing else changed.
- `tests/watcher-build-identity-project.test.ts` (new): covers the package-root semantics, installed-below-top dist fallback, checkout HEAD, run identity records with and without project git, and the idle status prefix.

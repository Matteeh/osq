## Acceptance

- [ ] `normalizeFailureBody` replaces a number that follows a duration key with `<duration>`, keeping the key and separator, so `duration_ms: 3.803686` becomes `duration_ms: <duration>` and `# duration_ms 92.962079` becomes `# duration_ms <duration>`.
- [ ] After the project root replacement, it replaces every path under the temp directory, both as `os.tmpdir()` returns it and as its real path, with `<tmp>` followed by whatever follows the first segment below the temp directory. `/tmp/paas-Hfp38F/state.db` becomes `<tmp>/state.db`, `/tmp/paas-Hfp38F` becomes `<tmp>`, and `file:///tmp/paas-Hfp38F/a.mjs` becomes `file://<tmp>/a.mjs`. The segment ends at a slash, whitespace, or a quote character.
- [ ] New `tests/dead-fingerprint-node-test.test.ts` writes a failing `node:test` file into a temp directory. That file creates a `mkdtemp` directory, prints its path, and fails an assertion whose message includes the path. The test runs the file twice with `node --test`, writes each combined output as a `verify_red` dead marker through `writeDeadMarker`, and asserts the two fingerprints are equal. A second file identical except for its assertion message gives a different fingerprint.
- [ ] `tests/dead-fingerprint.test.ts` changes only its assertion that `/tmp/proj/src/a.ts` survives normalization without a project root, which now expects the temp directory replacement, and may add cases for the new rules.

## Details

Build the temp path patterns from `os.tmpdir()` and its `fs.realpathSync`
result, escaping them for use in a regular expression. Add no configuration.
Every existing rule and the fingerprint format stay as they are.

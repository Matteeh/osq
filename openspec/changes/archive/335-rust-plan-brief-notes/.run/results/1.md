## Changed

Reworked `arguments::parse` to read the full `plan` grammar: `--next`,
`--replan`, `--print`/`-p`, `--brief <value>` and `--notes <value>`, with one
name and TypeScript's five semantic refusals in order. The parsed value carries
the mode, trimmed name, brief value and print flag. Updated `PlanFeature`'s
`plan` usage text.

Added `--print` to `run_next` and `run_steer`: the prompt is returned with one
trailing newline and `plan-prompt.md` is not written, while every other file is
still written.

Updated `tests/plan_feature.rs` for the new usage and `tests/plan_next.rs` for
the new "Plan argument errors" rows. Added `tests/plan_arguments.rs` for every
"TypeScript argument refusals" row and `tests/plan_print.rs` for both "Printed
next prompt" rows and "Printed steering prompt".

## Deviated

None.

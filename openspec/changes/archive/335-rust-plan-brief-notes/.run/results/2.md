## Changed

Added `run_new`, which plans a new change from a brief file or standard input:
it steers an active matching change, refuses archived and numeric names with
TypeScript's messages, reads the brief, makes TypeScript's slug, chooses the
next number, writes `proposal.md`, `tasks.md`, `tasks/1.md`, `brief.md` and,
unless `--print`, `plan-prompt.md`, then returns the `unplanned` handoff.
`brief.md` follows TypeScript's frontmatter ordering and scalar formatting.
`PlanFeature::run` dispatches a name with `--brief` to `run_new`.

Added the `yaml-rust2` dependency, widened the internal plan helpers to
`pub(crate)`, and added `tests/plan_brief.rs`, `tests/plan_brief_stdin.rs` and
`tests/plan_brief_texts.rs`. Copied the golden brief fixture into
`tests/fixtures/brief-created/`, with `tasks-md.txt` renamed to `tasks.md`.

Verify: the task's three test binaries pass, `cargo test -p osq-feature-plan`
passes, `cargo fmt --all --check` and workspace clippy pass, and
`sh scripts/verify-rust.sh` passes with `OSQ_CHANGE` set for this change.
`cargo mutants` on `src/new.rs` caught 38 and found 3 unviable; on
`src/feature.rs` it caught 12 and found 2 unviable.

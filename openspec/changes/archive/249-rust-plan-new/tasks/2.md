## Details

Port `buildBaseOpeningPrompt` from `src/cli/plan-queue.ts` and
`formatCapabilitySpecsSection` and `formatArchitectureDecisionsSection` from
`src/cli/plan-sections.ts`, under `DEFAULT_CONFIG`: no `After land:` line,
the decisions folder `decisions` and the openspec folder `openspec`. The
`Landed dependencies:` lines name the archived folders of the item's
dependencies only, never its fixes. Read `PLANNER.md` with
`std::fs::read_to_string`. `read_decisions`'s `Adr::applies_to` keeps
`group:<name>` names as written, which the prompt shows; `Adr::governs`
is not used.

Copy the fixture and the golden files with `cp -r` and `cp`, renaming only
`tasks-md.txt`; never edit them and never regenerate them. The golden test
runs `PlanFeature::at(1792584000000)`, whose UTC date, 2026-10-21, is the
date in the golden `brief.md`, and replaces each `<root>` in
`tests/fixtures/plan-created/handoff.txt` with the scratch copy's path shown with
`display()` before comparing.

Task 1's tests must keep passing unchanged. cargo-mutants runs on every
line this task adds, so each branch must change a value a row checks: the
`PLANNER.md` fallback, each section's trim, the directory filter and sort
of capability folders, the accepted filter, the empty ADR section, each
scope form, and the dependency lines. Before exiting, run `cargo fmt --all`,
then `cargo mutants -p osq-feature-plan -f <file> -o "$(mktemp -d)"` on each
source file this task changes, then `sh scripts/verify-rust.sh` with
`OSQ_CHANGE` set to `openspec/changes/249-rust-plan-new`.

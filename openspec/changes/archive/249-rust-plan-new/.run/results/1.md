## Changed

- Turned `PlanFeature` into a clocked struct with `new()`, `at(now_ms)`, the `queue` and `plan` commands, and pre-file `--next [--replan]` argument checking.
- Added `next.rs` and its pure `select`, `number`, `files`, `date` and `handoff` submodules: active-failure refusal and ordering, queue item choice and rejection refusal, change numbering, proposal/tasks/brief texts, UTC date conversion, and the handoff.

- Added `tests/plan_next.rs` and `tests/plan_folder.rs` for all task scenarios plus failure precedence and ordering rows; moved the existing tests to `PlanFeature::new()` and updated the plan command and unknown-command rows.

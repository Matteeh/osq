## Changed

- Added `crates/apps/cli/src/lib.rs` with `CliResult`, `features()` in the required registry order, and `run_cli`, which builds top-level and per-command help from each `Command`'s data and dispatches to the first feature that lists the command. A successful output prints its text with code 0, a `FeatureError` prints its display with code 1, and an unknown command prints `unknown command: <name>` with code 1 without calling any feature.
- Rewrote `crates/apps/cli/src/main.rs` to read the process arguments after the program name, use the current directory as root, call `run_cli`, write both streams, and exit with its code. Non-UTF-8 arguments and an unreadable current directory print one stderr line and exit 1.
- Added `tests/dispatch.rs`, proving the registry order, every help row, help for every registered command, unknown-command refusal, first-feature-wins, and CLI crate ownership. The dispatch scenarios use small test features defined in the test.
- Added `tests/binary.rs`, proving `inbox`, `queue` and `query` through the built `osq-rs` against each feature's own `run` in a second fresh fixture copy, the feature error through the binary, the unknown-command exit code, and both entry-point error paths.
- Added `tests/fixtures/project` with `openspec/queue.md` and change `001-alpha` (proposal and brief), and `tests/fixtures/ownership` with the rust-cli ownership spec over `crates/apps/cli/**` and the files it maps.

`cargo test -p osq-cli` passes: 11 tests. `cargo fmt --all --check`, `cargo clippy -p osq-cli --all-targets -- -D warnings` and `cargo mutants -p osq-cli` (24 caught, 7 unviable, 0 missed) pass. The proposal verify, `OSQ_CHANGE=openspec/changes/263-rust-cli-dispatch sh scripts/verify-rust.sh`, exits 0.

## Changed

- New `src/core/report/query-pauses.ts`. Exports `PAUSE_TABLES`, holding
  `pauses(change, task, paused_at, until, source)`, and `insertPauses(db,
  subjects)`. It lists each archived subject's digit-named `.jsonl` task
  streams in numeric order, reads each with `readEventStream` through the
  shared scope/index, and inserts one row per `paused` event: `change` the
  folder name, `task`/`until`/`source` from the event's object `data`, and
  `paused_at` the event's `timestamp`. An event without object `data` adds no
  row, and a field of the wrong type reads as null. The insert carries the
  three pause `@scenario` lines and `@adr 008`. `listTaskStreams` is a local
  copy of the helper in `query-task-streams.ts`, which is outside this task's
  `scope`.
- `src/core/report/query-tables.ts`: imports `PAUSE_TABLES`/`insertPauses`,
  lists `...PAUSE_TABLES` in `HISTORY_TABLES` after `...TASK_OUTCOME_TABLES`,
  and calls `insertPauses(db, subjects)` in `build` after `insertLinkFindings`.
- `tests/query-command.test.ts`, `tests/query-trial-tables.test.ts`,
  `tests/query-tables.test.ts`: only their pinned table lists gained the
  `pauses(change, task, paused_at, until, source)` line / table entry after
  `task_outcomes`; no other assertion changed.
- `tests/query-task-outcomes.test.ts`: the `task outcomes listed` case now
  asserts the delta's wording, `task_outcomes(...)` directly after the
  `link_findings` line rather than last; no other case changed.
- New `tests/query-pauses.test.ts` proves "Pauses of one archived change",

  the real `osq query` command over a hand-written archive.

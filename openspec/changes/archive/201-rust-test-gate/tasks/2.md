## Details

Git calls in tests strip `GIT_DIR`, `GIT_INDEX_FILE` and `GIT_WORK_TREE`, like `cleanGitEnv` in `tests/languages-map.test.ts`; `tests/worktree-guard.test.ts` shows a committed project going through `approveSpec` and `runTask` with vcs off. Compare test-module lines exactly, after turning `\r\n` into `\n`. The before lines must stay a subsequence of the after lines, so lines may be added inside a module but none removed or changed. In `tests/test-gate.test.ts`, change only `GATE_SOURCES` and `GATE_IMPORT`, following "One gate definition": `src/core/run/test-snapshot.ts` replaces `src/watcher/verify.ts`, and the import may name `gatedTestPathFilter`, because task 3's `src/core/spec/linter.ts` will import only that. It is the one preexisting test this task changes; the other two test files are new.

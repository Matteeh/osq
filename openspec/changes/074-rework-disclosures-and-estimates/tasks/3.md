## Acceptance

- [ ] `LandedItem` gains optional `disclosures?: { deviated: number; missingContext: number; outsideScope: number }`. `collectLandedItems` sets it from `countChangeDisclosures` only when one count is above zero; other landed items stay exactly as before.
- [ ] `landedLine` in `src/core/status/inbox-text.ts` appends ` — disclosed: ` and the non-zero counts in the order deviated, missing context, outside scope, such as `— disclosed: deviated 1, outside scope 2`, only for items that carry `disclosures`.
- [ ] `osq show <id>` prints `      Disclosures: <names>` after the task's pre-spawn, retry, and stuck lines for each task whose result file has a real disclosure, naming `deviated`, `missing context`, and `outside scope` in that order from `parseResultSections`. A task without one prints no such line.
- [ ] New `tests/disclosures-inbox-show.test.ts` archives a change on a temp project whose task 1 result has a real `## Outside scope` and a `## Missing context` of `None`, and asserts the inbox JSON item, its text line, the `osq show` line, and that a landed change without disclosures has no `disclosures` key.

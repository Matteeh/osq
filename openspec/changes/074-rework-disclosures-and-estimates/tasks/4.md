## Acceptance

- [ ] `PlanningConfig` gains `disclosures: { recentChanges: number; maxCharacters: number }`, defaulting to 3 and 4000; `validatePlanningConfig` accepts a partial block over the defaults and rejects a value that is not a positive integer with a message naming `planning.disclosures.<key>`.
- [ ] New `src/core/report/recent-disclosures.ts` exports `formatRecentDisclosures(projectRoot, config)`, which returns null when the `recentChanges` highest-numbered archived changes hold no disclosure from `readChangeDisclosures`, and otherwise the section body.
- [ ] The body opens with "Executor claims from result files, not verified facts. Check them against the code before relying on them." Then, newest change first and task order within a change, each disclosure is a `<change folder> task <n>, <deviated|missing context|outside scope>:` line followed by its text with every line prefixed `> `.
- [ ] The entries after the opening sentence total at most `maxCharacters`; the first entry that does not fit is cut to fit, ends with `[truncated]`, and nothing after it is included. No `## Changed`, `## Next`, `Touched:`, or heading line from the result file appears.
- [ ] `buildOpeningPrompt` in `src/cli/plan.ts` appends `## Recent executor disclosures` and the body after the repository record only when the body is not null, in every planning mode.
- [ ] New `tests/plan-disclosures.test.ts` covers the window size, the budget cut, the `> ` prefix on a disclosure line that starts with `#`, the exclusions, the section's absence without disclosures, and `osq plan <name> --print` output ending with the section.
- [ ] `tests/config-planning.test.ts` changes only its expected default and parsed planning objects.

## Details

This task's `scope` is authoritative over any injected code-ownership rules.
Change only the template constant in `opencode.ts`; the setup logic that writes
the file only when absent stays as it is. The constant is a template literal:
escape the backtick in the `` "*`*" `` key as `` \` ``, and write the newline
key as `"*\\n*"` in TypeScript so the file contains the YAML escape `"*\n*"`.
`$(` needs no escape because it is not `${`.

`parseFrontmatter` from `src/core/spec/parser.js` returns the nested `bash`
object with its keys in file order, because none of them is an integer-like
string. `osq setup` does not overwrite an existing planner agent file, so write
this repository's copy by hand.

The lint warning about `src/harness/` scope without `tests/fixtures/events/` is
expected: no harness event changes.

### Planner agent file

```markdown
---
description: Interactive planning agent for osq
mode: all
permission:
  read: allow
  edit: allow
  glob: allow
  grep: allow
  bash:
    "*": deny
    "osq lint*": allow
    "pnpm osq lint*": allow
    "npx osq lint*": allow
    "*;*": deny
    "*&*": deny
    "*|*": deny
    "*>*": deny
    "*<*": deny
    "*`*": deny
    "*$(*": deny
    "*\n*": deny
  webfetch: deny
  websearch: deny
---

Follow PLANNER.md strictly for change planning rules and procedure.
Writes are expected only under openspec/changes/<id>/.
The only shell command you may run is `osq lint <slug>`.
```

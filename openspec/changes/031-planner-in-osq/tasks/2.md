## Acceptance
- [ ] HarnessAdapter interface declares spawnInteractive accepting prompt, cwd, model, and agent
- [ ] OpencodeAdapter spawns opencode binary with inherited stdio and resolves with process exit code without capturing stdout
- [ ] AgyAdapter spawns agy binary with inherited stdio, -i flag, and resolves with process exit code without capturing stdout
- [ ] MockAdapter implements spawnInteractive, records invocation arguments, and returns configured exit code
- [ ] tests/harness-interactive.test.ts verifies argv formatting and uncaptured stdout for both adapters using fake binaries

## Details

Add `InteractiveSessionOptions` interface to `src/harness/types.ts` containing `prompt: string`, `cwd: string`, `model?: string`, and `agent?: string`.
Update `HarnessAdapter` to declare `spawnInteractive(options: InteractiveSessionOptions): Promise<number>`.
In `src/harness/opencode.ts`, implement `spawnInteractive` on `OpencodeAdapter`. Resolve binary via `resolveOpencodeBinary`. Construct argv passing `prompt`, `--dir` with `cwd`, `--model` if provided, and `--agent` if provided. Spawn child process with `stdio: 'inherit'` so terminal I/O is direct and uncaptured. Resolve with child process exit code (defaulting to 1 if closed without code). Keep existing executor `spawn` untouched.
In `src/harness/agy.ts`, implement `spawnInteractive` on `AgyAdapter`. Resolve binary via `resolveAgyBinary`. Construct argv passing `-i` with `prompt`, `--model` if provided, `--agent` if provided, and `--dangerously-skip-permissions` if configured. Spawn child process with `stdio: 'inherit'`. Resolve with exit code.
In `src/harness/mock.ts`, implement `spawnInteractive` on `MockAdapter` storing recorded interactive calls in an array and returning configured exit code.
Create `tests/harness-interactive.test.ts` with fake validating binaries asserting exact argv construction and that stdout is not redirected to pipes.

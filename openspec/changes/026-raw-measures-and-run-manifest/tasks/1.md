## Acceptance
- [ ] src/core/manifest.ts exports ManifestData interface with hashes record, osqVersion, harness, model, effort, createdAt, approvedAt
- [ ] src/core/manifest.ts exports buildManifest that hashes AGENTS.md, PLANNER.md, the first matching config file, and each capability spec from features.reads and features.writes
- [ ] Each hash is sha256:<hex> computed from UTF-8 file content, or null when the file does not exist
- [ ] src/core/manifest.ts exports writeManifest that writes .run/manifest.json as indented JSON
- [ ] src/core/approve.ts calls buildManifest and writeManifest after writing the approved marker
- [ ] tests/manifest.test.ts verifies manifest.json is written with correct hashes and metadata
- [ ] src/core/manifest.ts is under 250 lines

## Details

1. Create `src/core/manifest.ts`:
   - Import `crypto`, `fs/promises`, `path`.
   - Import `resolveBuildInfo` from `../watcher/build.js`.
   - Import `parseSpecMdFromFolder` from `./parser.js`.
   - Import `getSpecsDir` from `./layout.js`.
   - Define `ManifestData` interface:
     ```
     hashes: Record<string, string | null>  // key → "sha256:<hex>" or null
     osqVersion: string
     harness: string
     model: string
     effort: string | null
     createdAt: string         // ISO 8601
     approvedAt: string        // ISO 8601
     ```
   - `hashFileContent(filePath: string): Promise<string | null>` — read file as UTF-8, compute `sha256:${hex}`, return `null` on ENOENT.
   - `resolveConfigPath(projectRoot: string): Promise<string | null>` — check `osq.config.ts`, `osq.config.js`, `osq.config.mjs` in order, return the first that exists or `null`.
   - `buildManifest(projectRoot: string, specFolderPath: string, config: OsqConfig): Promise<ManifestData>`:
     - Parse the proposal from `specFolderPath` using `parseSpecMdFromFolder`.
     - Hash `AGENTS.md`, `PLANNER.md`, resolved config file.
     - For each name in `features.reads` and `features.writes` (deduplicated), hash `<specsDir>/<name>/spec.md`.
     - Get osq version from `resolveBuildInfo(projectRoot)`.
     - Read harness from `config.harness`, model from the active harness config (agy or opencode).
     - Set `effort` to `null`.
     - Set `createdAt` to mtime of `proposal.md` (or `spec.md`) as ISO string.
     - Set `approvedAt` to `new Date().toISOString()`.
   - `writeManifest(runDir: string, manifest: ManifestData): Promise<void>` — write `manifest.json` with `JSON.stringify(manifest, null, 2)`.

2. Modify `src/core/approve.ts`:
   - Import `buildManifest`, `writeManifest` from `./manifest.js`.
   - After `await fs.writeFile(approvedPath, ...)`, add:
     ```typescript
     const manifest = await buildManifest(projectRoot, folderPath, config);
     await writeManifest(path.join(runDir), manifest);
     ```

3. Create `tests/manifest.test.ts`:
   - Scaffold a temp project with `scaffoldProject`, `createNewSpec`.
   - Write a proposal with known features reads/writes.
   - Write known content to `AGENTS.md`, `PLANNER.md`, `osq.config.ts`.
   - Create a capability spec file under `openspec/specs/<name>/spec.md`.
   - Call `approveSpec`.
   - Read `.run/manifest.json`, parse it, assert:
     - `hashes['AGENTS.md']` matches expected SHA-256 of the known content.
     - `hashes['PLANNER.md']` matches expected SHA-256.
     - `hashes['config']` matches expected SHA-256 of the config file.
     - `hashes['<specName>']` matches expected SHA-256 of the spec content.
     - `osqVersion` is a non-empty string.
     - `harness` equals `config.harness`.
     - `effort` is `null`.
     - `approvedAt` is a valid ISO 8601 string.
   - Test case: missing file produces `null` hash.

4. Run verification:
   `node --import tsx --test tests/manifest.test.ts`

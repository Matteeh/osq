## Details

1. Modify `src/harness/types.ts`:
   - Add `'measures'` to `HarnessEventType` union.
   - Add `MeasuresEventData` interface:
     ```
     phase: 'start' | 'end'
     scopeFiles: number
     scopeLines: number
     repoFiles: number
     repoLines: number
     importFanIn: number
     proposalWords: number
     taskWords: number
     deltaRequirements: number
     deltaScenarios: number
     changedFiles?: number
     changedLines?: number
     scopeHashes?: Record<string, { before: string | null; after: string | null }>
     ```
   - Add `measures: MeasuresEventData` to `OsqEventData`.

2. Create `src/watcher/measures.ts`:
   - Import `fs/promises`, `path`, `crypto`.
   - Import `appendHarnessEvent` from `../harness/types.js`.
   - Import `resolveChangeDoc` from `../core/parser.js`.

   - `gatherScopeCounts(projectRoot: string, scope: string[]): Promise<{ files: number; lines: number }>`:
     - For each file in scope, resolve against projectRoot, count lines (split '\n').
     - Files that don't exist contribute 0 lines and 0 files.

   - `gatherRepoCounts(projectRoot: string): Promise<{ files: number; lines: number }>`:
     - Walk the project root recursively.
     - Skip `node_modules`, `dist`, `.git`, `.run`, `coverage`, `.nyc_output`, `.vscode`, `.idea`.
     - Count all text files and their line counts.

   - `countImportFanIn(projectRoot: string, scope: string[]): Promise<number>`:
     - Walk `src/` directory for `.ts` files.
     - For each file not in scope, read content and count how many scoped files it imports (string match on relative import paths).
     - Return total count of importing files.

   - `countWords(text: string): number`:
     - Split on whitespace, filter empty, return length.

   - `countDeltaRequirementsAndScenarios(specFolderPath: string): Promise<{ requirements: number; scenarios: number }>`:
     - Read delta spec files under `specFolderPath/specs/*/spec.md`.
     - Count lines matching `### Requirement:` and `#### Scenario:`.

   - `hashFileForMeasures(filePath: string): Promise<string | null>`:
     - Read file, return `sha256:<hex>`, or `null` on ENOENT.

   - `snapshotScopeHashes(projectRoot: string, scope: string[]): Promise<Record<string, string | null>>`:
     - Hash each scoped file, return map of relative path to hash.

   - `emitMeasures(specFolderPath: string, taskNumber: string, phase: 'start' | 'end', data: MeasuresEventData): Promise<void>`:
     - Call `appendHarnessEvent` with `type: 'measures'`, timestamp, and data.
     - This is the single code path.

3. Modify `src/watcher/runner.ts`:
   - Import `emitMeasures`, `gatherScopeCounts`, `gatherRepoCounts`, `countImportFanIn`, `countWords`, `countDeltaRequirementsAndScenarios`, `snapshotScopeHashes` from `./measures.js`.
   - After `const taskData = parseTaskMd(taskContent);` and before `const lockResult = ...`:
     - Read proposal content: `const proposalDoc = await resolveChangeDoc(specFolderPath);`
     - `const proposalContent = proposalDoc ? await fs.readFile(proposalDoc.path, 'utf8') : '';`
   - After the `started` event is guaranteed recorded (inside the try block, after `spawnTaskAgent` is called but we need measures before spawn), move measures emission to just before `spawnTaskAgent`:
     - Gather all start-phase counts.
     - Emit measures start event.
     - Take scope hash snapshot for later use at end.
   - This means between lock acquisition and `spawnTaskAgent`, add the measures gathering and start emission.

4. Create `tests/measures.test.ts`:
   - Test `countWords`: empty string returns 0, single word returns 1, multiline returns correct count.
   - Test `gatherScopeCounts`: create temp files, count lines.
   - Test `gatherRepoCounts`: create temp project, verify node_modules excluded.
   - Test `countImportFanIn`: create src/ files with imports, verify fan-in count.
   - Test `countDeltaRequirementsAndScenarios`: create delta spec files, verify counts.
   - Test `snapshotScopeHashes`: hash known content, verify sha256 prefix.

5. Run verification:
   `node --import tsx --test tests/measures.test.ts`

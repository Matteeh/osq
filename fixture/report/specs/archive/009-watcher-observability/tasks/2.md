- [ ] createLogger writes exclusively to process.stderr with optional bracketed prefix
- [ ] Quiet level suppresses info and verbose messages

## Details

1. createLogger writes exclusively to process.stderr.write(...). Never use process.stdout or console.log.
2. Prefix format: if prefix is supplied (e.g. 'osq'), each line is prefixed as [] \n.
3. Level filtering:
   - 'quiet': ignores info and erbose; writes warn and error.
   - 'normal': writes info, warn, and error; ignores erbose.
   - 'verbose': writes all message levels.
4. No external color libraries. Use inline ANSI escape codes or none.
5. src/cli/index.ts adds --verbose and -q, --quiet options to the watch command.
6. 	ests/logger.test.ts intercepts process.stderr.write to verify message filtering and formatting for each level.

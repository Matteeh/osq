## Details

1. spawnWithTimeout tracks startTime = Date.now() and records pid: child.pid and elapsedMs: Date.now() - startTime.
2. When a task starts, log via logger.info:
   	ask  started (pid: 61604, timeout: s)
   and append started event with { pid, timeoutSeconds, ... } to .run/events/.jsonl.
3. When the agent process exits, log via logger.info:
   	ask  exited (code: , elapsed: s)
   and append exited event with { exitCode, signal, timedOut, elapsedSeconds } to .run/events/.jsonl.
4. Invariant: The log line and the events.jsonl record are generated together at the point of event emission.
5. 	ests/runner-lifecycle-logging.test.ts tests mock/spawn runs capturing stderr to assert started and exited logs contain pid, timeout, exit code, and elapsed time.

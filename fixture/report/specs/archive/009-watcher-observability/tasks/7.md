## Details

1. Stream text capture:
   - When adapters process text chunks or events (such as text event in OpenCode or agent_response in agy), store or parse the last emitted text.
   - extractFinalTextFromStream retrieves the last emitted text string for the task number.
2. When spawnResult.exitCode is 0 and .run/results/N.md does not exist:
   - Check extractFinalTextFromStream with specFolderPath and taskNumber.
   - If non-empty text exists:
     - synthesizeResultFile writes .run/results/N.md with frontmatter synthesized: true and an attribution header comment.
     - Append result_written event with { synthesized: true } to .run/events/N.jsonl.
     - Log summary: task N result synthesized from agent message.
     - Continue to the independent verify step as normal.
   - If no text was produced (null or empty string):
     - Record dead marker .run/dead/N.md with reason: no_result.
3. In README.md:
   - Update the dead reasons explanation to clarify that agent exit without writing a result file or producing final text is dead with reason: no_result (if final text was produced, the runner synthesizes a result file with synthesized: true).
4. tests/runner-synthesized-result.test.ts tests exit 0 with missing result:
   - Case A: final text exists -> result file is synthesized and verify succeeds.
   - Case B: no text exists -> marked dead with reason no_result.

2. Standard event shape for tool events:
   { type: 'tool', timestamp: string, data: { tool: string, summary: string } }
3. Summary extraction logic in extractToolEventSummary:
   - For file tools (ead, edit, write, glob): return the target path or pattern string (checked from input.path, input.file, input.filepath, or input.pattern).
   - For ash: return the first 60 characters of the command (input.command or input.cmd).
   - For any other tool: return the first 60 characters of JSON stringified input or parameters.

## Details

1. uildAgyArgs adds --output-format and stream-json to the returned CLI argument array.
2. In AgyAdapter.spawn:
   - Stream parser streamParser = new AgyEventStreamParser(specFolderPath, taskNumber, logger) receives stdout chunks via onStdout.
   - streamParser.flush() is awaited after process exit.
3. Event parsing matching ixture/agy-events.jsonl:
   - When step_update.usage is present:
     - promptTokens: usage.input_tokens || 0
     - candidateTokens: usage.output_tokens || 0
     - cachedTokens: usage.cache_read_tokens || 0
     - 	otalTokens: usage.total_tokens || (promptTokens + candidateTokens)
     - Append { type: 'tokens', timestamp, data: { promptTokens, candidateTokens, totalTokens, cachedTokens, cost: 0 } } to .run/events/.jsonl.
   - When step_update.step_type === 'tool':
     - Tool name: step_update.tool_name || step_update.tool_info?.name
     - Summary: parameters.CommandLine (first 60 chars) for bash/run_command, or path parameters for file tools.
     - Append { type: 'tool', timestamp, data: { tool, summary } } to .run/events/.jsonl and call logger?.verbose([tool] : ).
4. Graceful fallback: If stdout emits non-JSON text (plain text output when flag is omitted or unsupported), lines that fail JSON.parse are discarded silently without throwing or killing the process.
5. 	ests/agy-stream-events.test.ts executes parser against ixture/agy-events.jsonl verifying tokens events and plain text fallback.

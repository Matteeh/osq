## Details

1. Create `src/harness/stream.ts` and implement shared utilities:
   - `asRecord`
   - `firstNonEmptyString`
   - `resolveEventTimestamp`
   - `EventStreamParser` parameterized by a line handler `(line: string) => Promise<void>`.
2. Refactor `src/harness/agy.ts` and `src/harness/opencode.ts` to import these utilities, replacing `AgyEventStreamParser` and `OpencodeEventStreamParser` with the shared parser.
3. In `src/watcher/runner.ts`, import `asRecord` from `src/harness/stream.js` and remove local copy.
4. In `src/core/report.ts`:
   - Remove legacy aliases from `TokenMetrics` (`promptTokens`, `candidateTokens`, `totalTokens`, `prompt`, `candidate`).
   - Remove `totalEvents` from `FileChangeMetrics`.
   - Remove legacy aliases from `MetricsReport` (`totalSpecs`, `activeSpecs`, `archivedSpecs`, `totalTasks`, `doneTasks`, `deadTasks`, `runningTasks`, `pendingTasks`, `completionPercentage`, `completionRatio`, `deadBreakdown`).
5. Update tests that access removed aliases to use the canonical fields (`report.specs.total`, `report.tasks.done`, `report.tokens.input`, `report.failureBreakdown`, etc.).
6. In `tests/harness-shared.test.ts`, write unit tests covering `EventStreamParser` with split chunks, empty lines, and error resilience, along with `asRecord`, `firstNonEmptyString`, and timestamp parsing.

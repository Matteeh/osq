## Acceptance
- [ ] CostMetrics interface defines total, perSpec record, and formattedTotal
- [ ] getMetricsReport sums cost reported in event data per spec and in total
- [ ] formatMetricsReport prints "Reported cost: $X.XX" when total cost is greater than zero
- [ ] formatMetricsReport omits the reported cost line entirely when no event carries cost
- [ ] README.md notes reported cost reflects harness price table rather than invoice billing
- [ ] tests/report-cost.test.ts verifies cost calculation on fixture/report/ and omission when zero

## Signatures

In `src/core/report.ts`:

```ts
export interface CostMetrics {
  readonly total: number;
  readonly perSpec: Record<string, number>;
  readonly formattedTotal: string;
}

export interface MetricsReport {
  // ...
  readonly cost?: CostMetrics;
}
```

## Details

1. In `src/core/report.ts`, aggregate `cost` fields from event streams:
   - Sum `cost` reported directly by harness events (`event.data.cost`). Do not compute prices from an internal pricing table.
   - Track both cumulative project cost (`total`) and per-spec cost breakdown (`perSpec: Record<string, number>`).
   - Format `formattedTotal` as a standard currency string (e.g. `$0.15` using `toFixed(2)`, or `$0.0012` using `toFixed(4)` if below one cent).
   - If no events carry cost (or accumulated cost is 0), omit the `cost` property from `MetricsReport`.
2. In `formatMetricsReport(report)`:
   - If `report.cost && report.cost.total > 0`, include the line `  Reported cost: ${report.cost.formattedTotal}` in the report output (under a Cost section or following Token Usage).
   - When no event carries cost, omit the line and section completely.
3. In `README.md`:
   - Under the `osq report` command documentation, note: "Reported cost reflects the harness's internal price table rather than the invoice."
4. In `tests/report-cost.test.ts`:
   - Test `getMetricsReport` against `fixture/report/` and assert `report.cost.total` sums to `0.1533` (±0.0001) from 009 events, and formatted text includes `Reported cost: $0.15`.
   - Test against an empty or cost-free fixture and assert `report.cost` is undefined and formatted output contains no "Reported cost" string.

## Details

1. In `src/core/report.ts`, replace the Gemini-specific `promptTokens`/`candidateTokens` schema with harness-neutral categories:
   - `input`: un-cached input tokens.
   - `cached_input`: cached input tokens (cache reads).
   - `output`: generated completion tokens.
   - `reasoning`: internal chain-of-thought tokens.
   - `total`: total tokens consumed.
   - `cacheSharePercent`: percentage of input derived from cache: `(cached_input / (input + cached_input)) * 100` rounded to 1 decimal place, or 0 if `input + cached_input === 0`.
2. Map event fields from both OpenCode and Antigravity:
   - `input`: `Number(data.input ?? data.input_tokens ?? data.promptTokens ?? data.prompt ?? 0) || 0`
   - `cached_input`: `Number(data.cached_input ?? data.cachedTokens ?? data.cache_read_tokens ?? data.cache?.read ?? 0) || 0`. If Antigravity stream-json has no cache field, `cached_input` defaults to 0.
   - `output`: `Number(data.output ?? data.output_tokens ?? data.candidateTokens ?? data.candidate ?? data.completionTokens ?? 0) || 0`
   - `reasoning`: `Number(data.reasoning ?? data.thinking_tokens ?? data.reasoningTokens ?? 0) || 0`
   - `total`: `Number(data.total ?? data.totalTokens ?? (input + cached_input + output + reasoning)) || 0`
3. Update `formatMetricsReport(report)` to print:
   ```
   Token Usage:
     Input: <input>
     Cached input: <cached_input> (<cacheSharePercent>% cache share)
     Output: <output>
     Reasoning: <reasoning>
     Total tokens: <total>
   ```
4. In `tests/report-tokens.test.ts`:
   - Run `getMetricsReport` on `fixture/report/`.
   - Assert exact counts: `input: 290061`, `cached_input: 9036195`, `output: 60368`, `reasoning: 0`, `total: 9386624`, `cacheSharePercent: 96.9`.
   - Assert `formatMetricsReport` output matches expected neutral labels and percentage display.

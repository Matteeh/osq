## Deviated

- Details step 1 said "Install the local tarball using `npm install <path-to-tarball>` (running
  offline)". `npm install` of the tarball cannot resolve the package's runtime deps
  (`commander`, `chokidar`, `jiti`, `yaml`) without registry metadata/cache, which contradicts the
  hard acceptance line "runs entirely offline ... without registry access". Used
  `pnpm add <tgz> --offline` instead: it installs the same packed tarball into the consumer project
  from the local pnpm store, then `npx osq` resolves the local `.bin/osq`. `npm pack` and `npx osq`
  are kept exactly as specified.
- Details step 2 (`.github/workflows/ci.yml` should leave `OSQ_SKIP_PACK_TEST` unset) was not
  applied because the task `scope` is only `tests/package-install-smoke.test.ts`. No workflow sets
  the variable, so CI already runs the test.

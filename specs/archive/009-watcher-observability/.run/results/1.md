# Task 1 result — opencode config schema support

## Changed

- `src/core/config.ts`
  - Added `LogConfig` (`heartbeatSeconds?`).
  - Added optional `log?: LogConfig` to `OsqConfig`.
  - Added exported `OsqUserConfig` type: `Partial<Omit<...>>` plus `Partial<>` for `limits`, `paths`, `timeouts`, `agy`, `opencode`, `log`.
  - Added `log: { heartbeatSeconds: 60 }` to `DEFAULT_CONFIG`.
  - `defineConfig` now accepts `OsqUserConfig` and merges `log` over defaults (in addition to existing `agy`/`opencode`/`limits`/`paths`/`timeouts` merges).
  - `loadConfig` internal typing switched from `Partial<OsqConfig>` to `OsqUserConfig`.
- `src/index.ts`: exported `LogConfig`, `OpencodeConfig`, and `OsqUserConfig` types.
- `osq.config.ts`: configures `opencode: { bin, model, agent, variant: 'thinking' }` as the schema check required by the task.
- `tests/opencode-config.test.ts`: added two tests covering `OsqUserConfig` partial opencode merge and `log.heartbeatSeconds` default (60) plus override (5).

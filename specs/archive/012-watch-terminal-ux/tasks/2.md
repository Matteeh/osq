## Acceptance
- [ ] Loop logs a permanent info line when an approved spec is detected and picked up
- [ ] Loop logs a permanent info line when a completed spec is archived
- [ ] Loop logs a permanent info line when a spec is halted because a task died
- [ ] Loop logs watcher errors at error level on permanent lines
- [ ] Info lines use prefix symbols (▶, ✓, ✗, ■) when enabled and plain words in non-TTY, CI, or NO_COLOR
- [ ] Idle status displays spinner, watching path, approved waiting count, and last archived spec summary
- [ ] On SIGINT, status row is cleared, cursor restored, waiting line logged, and second SIGINT terminates

## Details

1. In `src/watcher/loop.ts`:
   - Pass `logger` from `startWatcher` into `runWatcherCycle`, and from `runWatcherCycle` into `runTask(..., logger)`.
   - When scanning specs in `runWatcherCycle`:
     - If an approved spec with a pending task is picked up, log a single permanent info line: `▶ spec <id> picked up (<folder>)` (or `[spec] <id> picked up` without symbols).
     - When `checkAndArchiveSpec` succeeds, log a single permanent info line: `✓ spec <id> archived (<folder>)`.
     - When `runTask` returns failure (`success: false`), log a single permanent info line: `■ spec <id> halted (task <n> dead)`.
     - Log unexpected errors caught during cycles at error level: `✗ watcher error: <msg>`.
   - Symbol formatting: helper `resolveSymbol(sym, word)` outputs unicode symbols (`▶`, `✓`, `✗`, `■`) when interactive symbols are enabled (`isTTY` true, not CI, no `NO_COLOR`), else output words (`[spec]`, `[archived]`, `[halted]`, `[error]`).
   - Idle status: when no tasks are running, set `logger.status('watching <specsDir> · <count> approved waiting · last: <id> archived <ago>')`.
   - SIGINT handling: register a process `SIGINT` listener (with clean removal on exit). On first SIGINT: clear status row, restore cursor (`\x1b[?25h`), log `waiting for running task to exit (press Ctrl+C again to kill)`, and wait for active task. On second SIGINT: kill process immediately.
2. In `tests/watcher-loop-logging.test.ts`:
   - Create end-to-end tests with `runWatcherCycle` and `startWatcher` using `MockAdapter` and test logger.
   - Assert exact log lines emitted on spec pick-up, spec archival, dead task halting, and idle status updates.
